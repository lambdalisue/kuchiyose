# 中俣 尚己 文法形式に基づいた日本語文体の多次元的抽出

日本語文法学会. 大阪大学.
<https://www.nihongo-bunpo.org/images/1C-1_P81-88.pdf>

<strong>全文を読んだ。日本語で、解釈できる文体軸を客観的に導いた研究である。</strong>

## 既存の「語の文体」への批判

まず [馬場 (2022)](baba-2022.md) の 5 軸への批判が明快である。

- 元になった評価値は、[柏野 (2015)](https://doi.org/10.15084/00003109) が BCCWJ の
  サンプルに <strong>作業者の主観で</strong> 付けたものである
- <strong>専門度・客観度・硬度・くだけ度は中程度から強い相関があり、結局のところ一次元的</strong>
- 井上 (2009) の「白書で使われるか」、佐野 (2016) の語彙密度も同じく一次元的

> このような一次元的な尺度は、ある語を論説文で使ってよいか、というような実用的な課題を
> 解決するのには向く。しかしながら、多様な書き言葉・話し言葉の全容を記述するには足りない

この批判は正しいが、範囲に注意が要る。実データで確かめたところ、4 指標は確かに 1 軸
だが語りかけ性度は独立していた（[馬場](baba-2022.md#何次元あるか実測した)）。<strong>1 次元では
なく 2 次元である。</strong>

## Biber の多次元的文体分析

英語では Biber (1988) が標準になっている。手順はこうである。

1. 多様なジャンルのテキストを集める
2. <strong>客観情報のみ</strong>（語の頻度、各種指標）を抽出する
3. <strong>因子分析</strong>で次元を取り出す
4. 因子負荷量で「どの形式がその軸を作るか」、因子得点で「どのジャンルがその軸で特徴
   づくか」を見る

主観に頼らず、因子間の相関も抑えられる。英語では 6 次元（Involved vs Information
Production、Narrative vs Non-narrative ほか）。

<strong>これを日本語の書き言葉・話し言葉に対して行った研究は見当たらなかった</strong>——というのが
この研究の出発点である。

## 日本語で抽出された 4 因子

880 サンプル × 89 の文法形式。最尤法、プロマックス回転、4 因子モデル。

<strong>分析にジャンルのラベルを使っていない。</strong> 頻度データだけから軸を決め、そのあとで軸と
ジャンルの関係を見る。

| | 軸 | 説明力 | 対応する Biber の次元 |
| --- | --- | --- | --- |
| D1 | <strong>共感的対話 対 客観的伝達</strong> | 0.556 | D1: involvement vs information processing |
| D2 | <strong>語り 対 非語り</strong> | 0.184 | D2: Narrative vs Non-Narrative |
| D3 | <strong>新情報の解説</strong> | 0.161 | — |
| D4 | <strong>聞き手への配慮</strong> | 0.099 | — |

プロマックス回転の結果、<strong>因子間の相関はほとんど見られない</strong>。D1 と D2 に弱い負の相関が
ある程度。

> 特に D1「共感的対話 VS 客観的伝達」と D2「語り VS 非語り」は他の研究とも通底する
> <strong>頑健な評価軸</strong>として抽出可能

## この軸の性質

| | |
| --- | --- |
| 解釈できる | ○ 4 つとも日本語で名前が付いている |
| 客観的に導かれた | ○ 主観の評価値に依存しない |
| 多次元 | ○ 因子間の相関が抑えられている |
| 日本語 | ○ |
| 決定的に計算できる | ○ 文法形式の頻度と因子負荷量から出る |
| 題材に依らない | <strong>△ 文法形式なので有利だが、未確認</strong> |

[Stamatatos](stamatatos-2009.md) が「無い」と言った <strong>高い水準での言い表し</strong> に、日本語で
最も近いのがこれだと思われる。しかも英語の Biber と 2 軸が一致しており、言語をまたいだ
頑健性がある。

<strong>言葉で言い表せる。</strong>「共感的対話の側に寄っている」「聞き手への配慮が少ない」は、
そのまま人に伝わる。

## 各因子を作る文法形式

<strong>本文に載っていた。そのまま実装できる。</strong>

### D1: 共感的対話 対 客観的伝達

| | 形式 | ジャンル |
| --- | --- | --- |
| + | 終助詞、だ、から（接続）、んだ、<strong>縮約形</strong>、指示代名詞、推量性判断、疑問詞、たら、ない、ちょっと、もう、みたい、ばいい、まだ、し、あの N、N って、これ、だな、そう（様態） | 雑談 1.47、用談 1.39、会議 0.96 |
| − | <strong>格助詞</strong>、N の N、<strong>受身</strong>、ている、て、について、という、よう（様態） | 白書 -1.22、新聞 -0.78、科学 -0.78、学会 -0.73 |

終助詞や縮約形で相手の共感を呼び起こす文体と、格助詞で論理関係を明確にし受身で主観を
廃する文体の対立。<strong>単純な話し言葉 対 書き言葉ではない</strong>——学会発表が客観的伝達の側に
来ることから分かる。

### D2: 語り 対 非語り

| | 形式 | ジャンル |
| --- | --- | --- |
| + | N は、<strong>た</strong>、のだ、V ない、ている、構造格、て、N も、<strong>しかし</strong>、ば、使役、てしまう、ほど、ながら、だろう | 文学 1.59、雑誌 0.56、自然 0.41 |
| − | です、N って、んです、ね、っていう N | 会議 -0.77、用談 -0.68、雑談 -0.68、白書 -0.67 |

提題助詞と「た」、出来事の連鎖の「て」、同時の「ながら」、捉え方の「のだ」、転換の
「しかし」、評価を含む「てしまう」「ほど」。

### D3: 新情報の解説

| | 形式 | ジャンル |
| --- | --- | --- |
| + | んです、可能、けれど、っていう N、その N、N って、と思う、て、てしまう | 模擬講演 1.88、学会 0.41 |

<strong>上位 70 サンプルは全て模擬講演である。</strong> これはジャンルに固有の文体であって、個人差
を表す軸ではない。

### D4: 聞き手への配慮

| | 形式 | ジャンル |
| --- | --- | --- |
| + | <strong>ます、ません</strong>、という N、です、ていただく、この、のです、よう（様態）、これ | 学会 1.45、模擬講演 0.43、会議 0.39 |

## 注意

<strong>話し言葉が含まれている。</strong> 対象は BCCWJ に加えて CSJ（模擬講演）と CEJC（雑談）で
ある。<strong>書き言葉だけを対象にすると、D1 の + 側や D3 はそのまま移らない。</strong>

<strong>因子負荷量の数値は載っていない。</strong> どの形式がどちら側かは分かるが、重みは分からない。
自分のコーパスで因子分析をやり直すか、形式の有無で近似することになる。
