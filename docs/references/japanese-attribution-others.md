# 日本語の著者識別——系譜と、読み残し

日本語側の <strong>系譜</strong>と、まだ原典に当たれていないものを置く場所。読了したものは見出しに
<strong>読了</strong>と書く。それ以外は <strong>検索結果と他論文の引用から拾ったもの</strong>で、採用前に当たること。

主要な論文は独立したファイルにしてある。[README](README.md) から辿ること。

## 品詞 n-gram の話題頑健性

<strong>品詞 n-gram を用いた著者推定手法 — 話題に対する頑健性の評価</strong>
<https://jglobal.jst.go.jp/detail?JGLOBAL_ID=201302291822438406>

関連: 話題に依存しない頑健性の評価
<https://jglobal.jst.go.jp/detail?JGLOBAL_ID=201202292975845425>

要旨によれば、<strong>話題の違う文章を用いても高い精度で著者を識別でき、既存手法より頑健</strong>
と報告している。

<strong>題材に対する頑健性を正面から扱った、数少ない日本語の研究である。</strong> J-GLOBAL には
要旨しかなく、本文は入手できていない。

なお [金 2013](jin-2013.md) が引く 金 2004 も「形態素タグの n-gram は trigram に書き手の
特徴が最も顕著に現れる」としており、同じ系統である。

## 花畑・青野 (2019) 語彙と文脈に着目した文学作品の著者推定

言語処理学会 第 25 回年次大会. 豊橋技術科学大学.
<https://www.anlp.jp/proceedings/annual_meeting/2019/pdf_dir/P7-27.pdf>

<strong>冒頭とデータ設計を確認した。</strong>

青空文庫の 10 人（芥川龍之介 163、太宰治 203、江戸川乱歩 79、泉鏡花 106、宮沢賢治 85、
夏目漱石 83、坂口安吾 301、与謝野晶子 84、森鴎外 69、夢野久作 153）。

<strong>論文は計 1,315 作品と書いているが、表 1 の内訳を足すと 1,326 になる。</strong> どちらが誤植かは
原文から決められない。<strong>この数を根拠に何かを言わない。</strong>

注目すべきは <strong>データの単位</strong> である。作品ではなく <strong>段落</strong> を 1 件として扱い、
<strong>277,479 件</strong>を得ている。

<strong>文書を単位にすると標本は数十本にしかならないが、段落を単位にすれば数千件になる。</strong>
ただし段落は短いので、段落 10 個以上を要求するような指標は測れなくなる。

> しかし, 日本の文学作品を対象とした著者推定に関する研究は, 我々が調査した範囲では
> 多くは行われていない.

<strong>「我々が調査した範囲では」が付いている</strong>（2019 年時点）。

## 井上 雅翔・山名 早人 (2012) 品詞 n-gram を用いた著者推定手法——話題に対する頑健性の評価

日本データベース学会論文誌 10(3), 7-12. ISSN 1883-1060. 早稲田大学 / 国立情報学研究所.
<https://dbsj.org/wp-content/uploads/journal/vol10/no3/dbsj-journal-10-03-007.pdf>

<strong>全文を読んだ。</strong> 発行元が無料で公開している。

抄録は、自ら提案した品詞 n-gram の手法について、<strong>異なる話題の文章群を用いた場合でも高い
精度で著者を推定できる</strong>ことを実験で確認し、既存手法より頑健であると報告している。

<strong>「高い精度」は候補者数に強く依存する。</strong> 異フォーラム（話題が違う）条件の図 4 では、
提案手法の精度は<strong>候補者 10 人で概ね 0.85〜0.9、1,000 人では 0.3〜0.4 まで落ちる。</strong>

<strong>頑健性と精度は別である。</strong> 5.3 節は、比較対象の松浦手法は 3-gram・4-gram で頑健性は
高いが精度は劣ると述べている。<strong>頑健とは「話題を変えても落ち方が小さい」であって
「精度が高い」ではない。</strong>

<strong>「題材で動かない」に真正面から答えている 1 本である。</strong> 入手できるなら読むこと。

## 読点の打ち方——定義が確定した

金 明哲・樺島 忠夫・村上 征勝 (1993)「読点と書き手の個性」計量国語学 18(8), 382-391.
金 明哲 (1994)「読点の打ち方と文章の分類」.

文学作品と科学技術論文を対象に、<strong>読点とその直前の一文字を抽出して、その文字の差異から
分析</strong>している。有効とされたのは 3 つ。

- <strong>読点の前の文字</strong>
- <strong>読点の前の文字の品詞</strong>
- <strong>読点を打つ間隔</strong>

作家ごとに特徴が見られると報告されている。

[金 2014](jin-2014.md) はこれを「文字・記号の bigram の一部分」と位置づけている。低次元
なので解釈と可視化に向く。[柳・金 2022](yanagi-jin-2022.md) では <strong>ジャンルに引きずられ
にくい</strong>特徴の 1 つとされた。

## 岩崎 拓也 (2018) 読点が接続詞の直後に打たれる要因

計量国語学 31(6), 426-442. 一橋大学. Elastic Net によるモデル構築。
<https://www.jstage.jst.go.jp/article/mathling/31/6/31_426/_pdf>

<strong>読了。読点の「どこまでが規範で、どこからが個人か」を切り分ける材料になる。</strong>

### 読点は 3 層に分かれる

石黒 (2011) の整理を引いている。<strong>これが効く。</strong>

| 層 | 何が決めるか |
| --- | --- |
| <strong>誰もが打つ</strong> | <strong>意味・長さ・構造</strong> |
| <strong>人により異なる</strong> | <strong>表記・音調・リズム</strong> |
| <strong>一部の人が打つ</strong> | <strong>強調</strong> |

<strong>読点という 1 つの現象の中に、規範と個人差が同居している。</strong> 下 2 層が個人差の層で
ある。

### 場面だけで 26 ポイント動く

BCCWJ のコアデータで、接続詞の直後に読点が打たれる割合。

| レジスター | 打つ割合 |
| --- | --- |
| <strong>新聞（PN）</strong> | <strong>65.6%</strong> |
| 雑誌（PM） | 53.8% |
| 白書（OW） | 46.0% |
| 書籍（PB） | 45.0% |
| Yahoo! 知恵袋（OC） | 43.2% |
| <strong>Yahoo! ブログ（OY）</strong> | <strong>39.5%</strong> |

<strong>個人を見る前に、場面だけで 39.5% から 65.6% まで動く。</strong>
[水上ほか](mizukami-2014.md) の「場面の寄与は人の寄与と同じ大きさ」が、
1 つの具体的な指標の上で数字になっている。

### モデル

BCCWJ コアデータ、説明変数 8 種、Elastic Net による正則化付き一般化線形モデル。

<strong>再現率 78.99% は学習内の値である。</strong> 論文は「この適合させたモデルを用いて、<strong>同じ分析
データに対して再分類</strong>を行った」と書いており、要旨も「元データの再分類を行った結果」と
限定している。

<strong>10 分割交差検証は λ と α を選ぶために使われただけ</strong>（`cv.glmnet` の中）で、78.99% は
交差検証の成績でもホールドアウトの成績でもない。<strong>汎化性能として引いてはいけない。</strong>

読点が打たれやすい上位の指標。

| | |
| --- | --- |
| 1 | 語彙素「で」 |
| 2 | <strong>接続詞が文頭にあるとき</strong> |
| 3 | 語彙素「が」 |
| 4 | <strong>レジスター「白書」</strong> |
| 5 | 語彙素「然しながら」 |
| 6 | 文字種「ひらがな → 改行」 |
| 7-10 | 「又」「ですから」「猶」「だが」 |

<strong>接続詞の語彙素ごとに、打たれやすさが違う。</strong> 論文はこれを<strong>連接類型とレジスターで</strong>
説明している——「然しながら」「又」「猶」は白書に集中し、「が」「だが」「で」は話し言葉的で
白書に出ない。<strong>個人の癖には一切言及していない。</strong>

なお「然しながら」は 24 例すべてが読点あり。<strong>論文の 3.3 節には「出現頻度が 1 例しかなく」
という表 3 と食い違う記述もある。</strong>

### 読み取れること（ここから下はこのノートの読みである）

<strong>1. 「読点の密度」では 3 層が混ざる。</strong> 接続詞の語彙素ごと、位置ごとに分けて初めて、
規範と個人差が分かれる。

<strong>2. 規範の層は個人差が小さいと見込める。</strong> 「文頭の接続詞の後に読点」は公用文の手引きに
書かれている常識である。<strong>論文はこれを測っていない</strong>——個人ごとの値を出していないので、
「誰を測っても同じ」かどうかは、この論文からは言えない。

<strong>3. レジスターの差が 26 ポイントある。</strong> 個人差より大きい可能性がある。
<strong>比べた相手は同じ論文の中に無い</strong>——[水上ほか](mizukami-2014.md)を経由した見込みである。

<strong>4. 「しかしながらの後には打つが別の接続詞では打たない」が個人の癖になるかは、未確認。</strong>
論文の説明はレジスターであって個人ではない。<strong>個人差として使うなら、自分で確かめる。</strong>

[馬場](baba-2022.md) が「接続詞は他の品詞と特異」としていたことと合わせると、
<strong>接続詞まわりは、書き手の癖が最も出やすく、同時に規範が最も強い場所である。</strong>

## 施 佳坤 (2023) 著者識別に基づく文体スタイル変換への取り組み

お茶の水女子大学 修士論文<strong>概要</strong>（2 ページ）.
<http://is.ocha.ac.jp/~gradthesis/pdf/master/2023/2023master2240679.pdf>

<strong>概要を読んだ。修士論文の本体ではない。</strong> 日本語での文体転換の試み。

手口が面白い。<strong>ChatGPT に著者の文を「標準的な日本語」に変換させて対訳データを作り</strong>、
T5 をファインチューニングして逆方向（標準 → 著者の文体）を学習する。評価は BERT の
文体判別器（3 値分類 94.1%）で、T5 は最良 78.18%。Zero-Shot と One-Shot を比べている。

<strong>差は計算していない。</strong> 対データによる教師あり変換を学習しているだけである。
「文体を抜いた版を作り、元の文との差を文体とみなす」<strong>という読みはこのノートの解釈</strong>で
あって、論文の主張ではない。確立された手法でもない。
