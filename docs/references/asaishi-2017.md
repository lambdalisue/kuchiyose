# 浅石 卓真 (2017) テキストの特徴を計量する指標の概観

日本図書館情報学会誌 63(3), 159-.
<https://www.jstage.jst.go.jp/article/jslis/63/3/63_159/_pdf>

<strong>全文を読んだ。</strong> 日本語テキストの計量指標を、言語単位ごとに棚卸ししたもの。
<strong>指標の候補一覧としてそのまま使える。</strong>

## 言語単位別の指標

| 単位 | 観点 | 指標 |
| --- | --- | --- |
| 文字 | 文字種 | 文字種別の比率 |
| | n-gram | 各記号列の出現頻度、頻度分布 |
| | <strong>位置</strong> | <strong>文頭・文末・読点の前後に来る文字の比率</strong> |
| 語 | 品詞 | 品詞別の比率、MVR |
| | 語種 | 和語・漢語・外来語・混種語の比率、GKR |
| | 種類 | 指示語、色彩語、人格語、比喩の頻度 |
| | 長さ | 単語長 |
| | 位置 | 品詞同士の接続率 |
| | 頻度 | 内容語の頻度、頻度分布の要約統計量 |
| 文節 | 係り受け | 係り受けの距離、木の高さ、葉の数 |
| 文 | 種類 | 平叙/疑問/命令/感嘆、単文/重文/複文、現在止/過去止/不定止、会話文、引用文 |
| | 長さ | 文長、文長の分布 |
| 段落 | 長さ | 段落長 |
| | 結束性 | 段落間の共起語率 |

## 著者推定に効くとされているもの

<strong>読点の直前にある文字の頻度分布。</strong> 著者の特徴が強く現れるという指摘がある。単に
読点の数を数えるのではなく <strong>どこで打つか</strong> を見る。

<strong>助詞・助動詞の頻度と頻度分布。</strong> 著者推定にも執筆時期推定にも手掛かりになる。
ランダムフォレストで特徴的な助詞・助動詞を抽出し、話者の政治的スタイルと結びつけた
研究もある。

<strong>単語長の分布。</strong> 著者推定・真贋判定で最も初期から使われてきた。日本語では
<strong>動詞の単語長</strong>の分布に著者の特徴が明確に現れるという報告がある。

<strong>文長。</strong> 同じく最初期から。Yule は文長の平均・中央値・四分位数で『キリストに
ならいて』の著者を推定した。

<strong>品詞比率と MVR</strong>（相の類 ÷ 用の類）。著者の文体的特徴を示す指標として使われる。

<strong>品詞同士の接続率。</strong>「普通名詞→接尾語」「形容動詞→副詞」など。

## 効かないと報告されているもの

<strong>係り受けの距離の分布。</strong>「著者推定においては係り受けの距離の分布には著者の特徴が
現れない」と報告されている。

日本語の係り受け距離の分布は Zipf 則に従うことが知られており、書き手によらず同じ形に
なるということだと思われる。<strong>試す前に落とせる指標の例である。</strong>

<strong>語彙の豊富さ（TTR）。</strong> テキストが長いほど小さくなるため、長さの著しく異なる
テキスト同士の比較には適当でない。

## この概観が押さえている論点

- <strong>読点は「どこで打つか」で見られている。</strong> 数を数えるのではなく、前後の文字を見る
- <strong>文末表現には種類の区分がある。</strong> 現在止 / 過去止 / 不定止
- <strong>係り受け距離は効かないと報告されている</strong>
- <strong>語彙の豊富さ（TTR）は長さと連動する。</strong> 長さの違うテキスト同士では比較できない
- ジャンル差についての知見も多い。個人差とは別の層である
