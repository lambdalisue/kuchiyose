# 財津 亘・金 明哲 (2018) テキストマイニングによる筆者識別の正確性ならびに判定手続きの標準化

行動計量学 45(1), 39-47. 富山県警察本部科学捜査研究所 / 同志社大学.
<https://www.jstage.jst.go.jp/article/jbhmk/45/1/45_39/_pdf>

<strong>全文を読んだ。[Sawant](authorship-gap-2026.md) が 2026 年に英語で提案した
「天井と床で目盛りを作る」を、日本語で、2018 年に、法廷で使える形でやっている。</strong>

## 何が識別を成り立たせているか

論文が土台に置いている前提が明示されている。

> 各個人によって表出される文体的特徴に <strong>「個人差」</strong> と <strong>「個人内恒常性」</strong> が存在する
> ことから筆者の識別が可能となる

<strong>この 2 つが揃わなければ識別は成立しない。</strong> 人によって違い、かつ同じ人の中では
安定している、ということである。

## 問いの立て方

3 種類の文章を用意する。

| 呼び名 | 中身 |
| --- | --- |
| <strong>疑問テキスト</strong> | 誰が書いたか分からない文章 |
| <strong>対照テキスト</strong> | 本人が書いたと分かっている文章 |
| <strong>無関係テキスト</strong> | 別人が書いた文章（複数） |

<strong>「この文章は本人が書いたか」を、他人との比較の中で判定する。</strong> 候補者リストの中から
当てる問題（closed set）ではない。

## 素材

<strong>「にほんブログ村」の 100 人。</strong> 20 代から 60 代の男女各 50 名。1 人あたり約 4,000 字。
分析には <strong>約 1,000 字</strong> の単位を使う。

<strong>長さは技術記事に近い（素材はブログである）である。</strong>

## 特徴 4 種 × 解析 4 種 = 16 分析

| 特徴 |
| --- |
| <strong>非自立語の使用率</strong> |
| <strong>品詞の bigram</strong> |
| <strong>助詞の bigram</strong> |
| <strong>読点の打ち方</strong> |

| 解析 |
| --- |
| 主成分分析（PCA） |
| 対応分析（CA） |
| 多次元尺度法（MDS） |
| 階層的クラスター分析（HCA） |

<strong>分類器（Random Forest、SVM）を使っていないのが特徴である。</strong> 理由が書かれている。

> 法廷では分析結果に関する説明責任がともなうことから、テキスト間の類似度を基に、
> 次元上にテキストを布置するまたはクラスターとしてテキストをまとめるといった
> <strong>視覚的に理解しやすい解析手法を採用する方が望ましい</strong>

<strong>説明できることを、精度より優先している。</strong>

## <strong>標準化——得点を足す</strong>

16 個の分析結果それぞれに、決まったルールで得点を付ける。

<strong>2 次元の布置なら:</strong> 疑問テキストが対照テキストの近くに来れば加点、無関係テキストの
側に寄れば減点。<strong>デンドログラムなら:</strong> 対照テキストと同じクラスターに入れば 2 点、
最も近ければ 1 点、それ以外は −1 点。

<strong>16 個の得点を合算する。</strong>

> 分析者が異なっても、<strong>同一手順を踏むことで同一の判定結果が得られる</strong>

これは米国のドーバート基準——手法が法廷で証拠能力を持つための要件——のうち
<strong>「判定手続きの標準化」</strong> に当たる。

## 結果——分離する。そして「判定不能」を置く

| 条件 | 平均得点 | SD |
| --- | --- | --- |
| <strong>同一人</strong> | <strong>+9.49</strong> | 0.96 |
| <strong>別人</strong> | <strong>−7.44</strong> | — |

<strong>閾値は絶対値 4。</strong> 得点が −4 から +4 の範囲にあるものは <strong>判定不能</strong> とする。

| | 判定不能率 |
| --- | --- |
| 同一人の組 | 14% |
| 別人の組 | 19% |

<strong>判定不能を除いた精度。</strong>

| | 値 |
| --- | --- |
| <strong>感度</strong>（同一人を同一人と判定） | <strong>100%</strong>（86/86） |
| <strong>特異度</strong>（別人を別人と判定） | <strong>95.1%</strong>（77/81） |

<strong>年齢と性別による差は無かった。</strong>

## 読み取れること

### 1. 「判定不能」が精度を支えている

100% と 95.1% は、<strong>2 割弱を「分からない」に逃がした上での数字</strong>である。無理に判定
すれば、どちらの数字も落ちる。

<strong>判定できない、と言えることが、100% を可能にしている。</strong>

### 2. 特徴の顔ぶれが、また一致した

| | 非自立語 | 品詞 bigram | 助詞 bigram | 読点 | 文字 bigram | 文字種 |
| --- | --- | --- | --- | --- | --- | --- |
| 財津・金 2018 | ✓ | ✓ | ✓ | <strong>✓</strong> | | |
| [金 2014](jin-2014.md) | ✓ | ✓ | | （bigram の一部） | ✓ | |
| [尤度比 2026](fusing-lr-2026.md) | ✓ | ✓ | | <strong>✓</strong> | ✓ | ✓ |
| [柳・金 2022](yanagi-jin-2022.md) | ✓ | ✓ | | <strong>✓</strong> | ✓ | |

<strong>読点の打ち方を独立した特徴として立てているのは 4 本中 3 本である。</strong>
[金 2014](jin-2014.md) だけは立てていないが、落としたのではなく <strong>文字・記号 bigram に
包含されている</strong>と位置づけている（低次元なので教師なし解析には向く、とも書いている）。

<strong>この特徴を否定している研究は見当たらない。</strong>

### 3. 説明できる手法を選ぶ理由が、外にもあった

<strong>法廷は説明責任を要求する。</strong> だから分類器ではなく、布置とクラスターを使う。

解釈できる数値には、指示に使える以外の価値もある。<strong>「なぜそう判定したか」を言える。</strong>
この研究が返すのも、点数ではなく、どの分析でどう位置づいたかである。

### 4. 1,000 字あれば足りる

<strong>1 人 4,000 字、判定単位 1,000 字で、感度 100%。</strong>

[尤度比 2026](fusing-lr-2026.md) も 1,000 字。[金 2013](jin-2013.md) も 1,100 字。
<strong>日本語で書き手を判定するには、1,000 字が目安である。</strong>

そして年齢・性別の影響が無いことも確認されている。<strong>書き手の属性で較正を変える必要は
無い。</strong>
