# 有馬 直也ほか (2018) 文末表現辞書を用いた文体分類とその応用

DEIM Forum 2018 C1-2. 兵庫県立大学.
<https://db-event.jpn.org/deim2018/data/papers/105.pdf>

<strong>手法の節を読んだ。</strong> 日本語の文末表現を、そのまま実装できる形で扱っている。

## 4 つの文体クラス

丁寧さの観点で 4 つに分ける。

| クラス | 定義 |
| --- | --- |
| 敬体 | 「です、ます」調 |
| 常体 | 「だ、である」調 |
| 会話体 | 「だよね、ですね」のように敬体・常体より柔らかい |
| ネット文体 | 会話体よりさらに砕けた表現 |

## 文末表現の抽出方法

<strong>ここが実装に直接使える。</strong>

1. 形態素解析する（JUMAN を使用）
2. <strong>末尾の形態素からさかのぼり、動詞・形容詞・名詞のいずれかに当たるまで</strong>を文末表現
   とする
3. 動詞・形容詞なら活用形も考慮する

例。

| 文 | 文末表現 |
| --- | --- |
| これはいい記事だ | `(名詞) + だ` |
| これはおいしいですね | `(形容詞の基本形) + ですね` |

<strong>文末が `」` で終わる文は対象外。</strong> 引用は数えない。

辞書はニュースサイト、新聞記事、Yahoo!知恵袋から構築し、末尾からの部分一致のために
トライ木を使う。どの文からも文末表現が抽出できなければネット文体とする。

## kakiburi にとって

<strong>「文をどう終えるか」を、具体的な手続きに落とせる。</strong>

kakiburi の指標は「文末表現」を漠然と扱っていたが、この抽出規則があれば決定的に計算
できる。しかも <strong>型として</strong> 取れる——`(名詞) + だ` のように、内容を消して形だけ残る。
[金 2013 の文節パターン](jin-2013.md)と同じ発想である。

4 クラスへの分類も、日本語に固有の丁寧さの軸として使える。[Stamatatos](stamatatos-2009.md)
が言語固有の特徴として挙げたギリシャ語の二言語併用に当たるものである。

<strong>引用を落とす規則</strong>がここにもある。[金 2013](jin-2013.md)、[柳・金 2023](yanagi-jin-2023.md)
と合わせて 3 件目で、日本語の文体研究では標準的な前処理と見てよい。

## 注意

- 目的が違う。この論文は「有益な投稿かどうか」を選別するために文体を分類しており、
  個人の識別ではない
- 4 クラスは <strong>集団の文体</strong> であって個人の文体ではない。個人差はこの下の層にある
- 辞書がニュース・新聞・知恵袋から作られているので、技術記事の文末表現をどこまで
  覆うかは不明
