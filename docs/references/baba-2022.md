# 馬場 俊臣 (2022)「語の文体」と「文章の文体」——『語の文体値データ』を利用した「文章の文体」の推定

計量国語学 33(7), 435-450. 特集・招待論文. 北海道教育大学.
<https://www.jstage.jst.go.jp/article/mathling/33/7/33_435/_pdf/-char/ja>

<strong>要旨と算出方法を読んだ。日本語で、いますぐ使える解釈可能な資源がある。</strong>

## 『語の文体値データ』

馬場 (2022) が <strong>2022 年 2 月に第 1 版を公開</strong>した資源。BCCWJ（現代日本語書き言葉均衡
コーパス）の図書館サブコーパスに付いている『文体情報』——人手で各サンプルに与えられた
文体の評価値——を元にしている。

<strong>語彙素ごとに 5 つの値を持つ。</strong>

| 語文体値 | 何を表すか |
| --- | --- |
| 専門度 | 専門的か |
| 客観度 | 客観的か |
| 硬度 | 硬いか |
| くだけ度 | くだけているか |
| 語りかけ性度 | 語りかけているか |

短単位と長単位の両方の語彙素について用意されている。

### 算出方法

ある語彙素が使われているサンプルを特定し、それらのサンプルに付いた評価値の <strong>算術平均</strong>
を取る。同じサンプル内の複数回の使用は 1 回として数える。

```
語 W の専門度平均値 = (W が使われている各サンプルの専門度評価値の合計) ÷ (W が使われているサンプル数)
```

## 文章文体値

文章の側の値は、<strong>その文章に使われている語彙素の語文体値を平均するだけ</strong>で出る。

```
文章 S の文章文体値(専門度) = (S に使われている対象語彙素の専門度平均値の合計) ÷ (対象語彙素数)
```

品詞で対象を絞り、語文体値の元になったサンプル数に下限を設ける。同じ語彙素の重複は
1 回として数える。

<strong>検証。</strong> BCCWJ コアデータの各サンプルで算出したところ、<strong>先行研究が指摘している各
レジスターの文体的特徴を再現できた</strong>。

## kakiburi にとって

<strong>これは効く。</strong> 理由が 4 つある。

<strong>1. 解釈できる。</strong> 専門度、客観度、硬度、くだけ度、語りかけ性度。どれも人に説明できる
言葉であり、指示にもできる。「あなたの記事はくだけ度が高い。この下書きは硬すぎる」と
言える。

[Stamatatos](stamatatos-2009.md) が「無い」と言った <strong>高い水準での言い表し</strong> が、日本語
には資源として存在していたことになる。

<strong>2. 計算が軽い。</strong> 形態素解析して表を引いて平均するだけ。学習も要らず、決定的である。

<strong>3. 単位が揃っている。</strong> 5 つとも同じ尺度の平均値なので、比較も合成もしやすい。

<strong>4. 人手の評価に紐づいている。</strong> 元は人がサンプルを読んで付けた評価値である。機械が
勝手に作った次元ではない。

## 注意

- <strong>元が図書館サブコーパス（書籍）である。</strong> 技術記事や Web の語彙、コードに現れる語の
  被覆は期待できない。データに無い語彙素は除外することになる
- <strong>専門度は題材に強く連動するはずである。</strong> 専門的な話題を書けば専門度が上がる。
  [題材で動かない](../spec/000-axis.md)という条件に照らすと、専門度は書きぶりではなく
  題材を測る側に寄る可能性が高い。硬度・くだけ度・語りかけ性度の方が書きぶり寄り
- <strong>語の平均なので、構成や文の組み立ては見ていない</strong>

## 確認が要ること

- 短単位・長単位のどちらを使うか、品詞の絞り方、サンプル数の下限をいくつにするか

## 重大な批判がある

[中俣](nakamata-multidimensional.md) が、この 5 軸の妥当性に疑問を呈している。

<strong>1. 元の評価値は主観である。</strong> [柏野 (2015)](https://doi.org/10.15084/00003109) が
BCCWJ のサンプルに <strong>作業者の主観で</strong> 付けた評価に依拠している。5 軸が文体の違いを
捉えるのに適切かという妥当性の問題がある。

<strong>2. 実質的に一次元である。</strong>

> 馬場(2022b)によれば、「専門度」「客観度」「硬度」「くだけ度」はそれぞれ中程度から
> 強い相関があることがわかっており、<strong>結局のところ一次元的な尺度となっている</strong>

<strong>「5 つの解釈できる軸」ではない。</strong> 硬さ・くだけの 1 軸がほぼ全部である。多様な文体の
全容を記述するには足りない、と批判されている。

したがって kakiburi でこれを使うなら、<strong>1 つの軸として</strong>扱うのが正直である。5 つ並べて
5 次元あるかのように見せてはいけない。

より客観的で多次元の候補は[中俣の 4 因子](nakamata-multidimensional.md)である。
