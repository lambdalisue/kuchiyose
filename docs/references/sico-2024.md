# Lu et al. (2024) SICO——LLM に「人が書いたように」書かせる

Large Language Models can be Guided to Evade AI-Generated Text Detection.
TMLR 05/2024. arXiv:2305.10847.
<https://arxiv.org/pdf/2305.10847>

<strong>全文を読んだ。目的は検出器を欺くことだが、手順は「差を取る → 渡す → 検める → 直す」
のループになっている。</strong>

> [!NOTE]
> この論文が最適化しているのは <strong>AI 検出器のスコア</strong> である。検出器を持たない場面へ
> 移せるかは、この論文では示されていない。

## 手順

### 1. 差から特徴を <strong>言葉で</strong> 取り出す

<strong>K 組の（AI が書いたもの、人が書いたもの）を LLM に見せ、人の文章の特徴を記述させる。</strong>

出てくるのは自然言語の記述である。論文の例:

> Human writings exhibit a high level of clarity and conciseness ...

<strong>基準との差から特徴を拾う手順である。</strong>[林・相澤](japanese-llm-style.md) が n-gram の
頻度比でやったことを、自然言語の記述でやっている。

### 2. その記述を使って、手本を作り直す

特徴の記述 + 言い換え指示 + AI の出力 → <strong>人の文章に寄せた手本</strong>。

### 3. 手本を、語と文の置換で最適化する

語レベル（WordNet）と文レベルの置換候補を作り、<strong>検出器のスコアが下がる方を採る</strong>。
これを N 回繰り返す。

<strong>最終的に得られるのは、特徴の記述 + 課題の指示 + 最適化された手本、という 1 つの
プロンプトである。</strong>

## 結果

<strong>必要な素材は、人が書いたもの 40 本だけ。</strong>

> SICO only requires <strong>40 human-generated examples</strong> and a limited number of LLM inferences

<strong>6 つの検出器の AUC を平均 0.5 下げた。</strong> しかも一度作ったプロンプトは、
<strong>他の検出器にもそのまま効く。</strong>

そして人手評価で <strong>読みやすさと課題の達成率が人間並み</strong>。DIPPER（言い換え専用モデル）を
両方で上回った。<strong>崩して逃げているのではない。</strong>

## 読み取れること

### 1. ループが実際に回っている

| 段 | SICO が使うもの |
| --- | --- |
| 差を取る | AI と人の対から特徴を記述 |
| 渡す | 記述 + 手本をプロンプトに |
| <strong>検める</strong> | <strong>検出器のスコア</strong> |
| 直す | 置換して再評価 |

<strong>検める段が不透明な関数である。</strong> 検出器はスコアを返すが、なぜそうなったかは返さない。
したがってこのループは「何が効いたか」を説明できない。

### 2. 特徴を「言葉で」渡すのは、悪い手ではない

[Bhandarkar](bhandarkar-2024.md) は <strong>固定の特徴一覧</strong>を指示すると悪化すると示した。
SICO は <strong>その場で差から作った記述</strong>を渡して成功している。

<strong>両立する。</strong> 悪いのは「特徴を渡すこと」ではなく、<strong>固定の一覧を、選ばずに、全部
渡すこと</strong> である。[StyleRemix](styleremix-2024.md) の「上位 k 本を選ぶ」と同じ結論に、
別の側から着いている。

そして <strong>散文の記述で渡している</strong>。[SPTG の評価](sptg-evaluation-2025.md)の
「構造化出力は 24% 悪化する」と整合する。

### 3. 素材は 40 本

<strong>また同じ桁である。</strong>

| | 必要量 |
| --- | --- |
| SICO | <strong>40 本</strong> |
| [AuthorMix](authormix-2026.md) | 16 文 |
| [Masks and Mimicry](masks-mimicry-2025.md) | <strong>3 本</strong>が最良 |
| [Przystalski](przystalski-2025.md) | 10 文 |

### 4. 「人らしく」と「その人らしく」は別の課題である

<strong>SICO が解いたのは前者だけである。</strong> 特定の誰かに寄せてはいない。

[軸](../spec/000-axis.md)の目標「本人が書いたものとして通る」には両方が要る。
<strong>SICO は片方が解けることを示した。もう片方は
[まだ誰も解いていない](authorship-gap-2026.md)。</strong>

## 付記——LoRA で 1 人に合わせる試み

<strong>Small Is Enough / InMyStyle</strong>（arXiv:2607.29238）が、1 人のユーザーの文体に
LoRA で寄せている。<strong>ただし証拠としては弱い。</strong>

- 対象は <strong>1 人だけ</strong>。論文自身が「generalization across users, languages or amounts of
  available writing」を確立できないと認めている
- <strong>プロンプト方式との比較実験が無い</strong>
- 訓練の入力は合成データ
- 著者性のスコアは <strong>0.51〜0.53</strong> で頭打ち

<strong>ただし 1 つ効く知見がある。</strong> Qwen2.5 の 0.5B から 7B まで試して、総合スコアは
<strong>どのモデルサイズでも 0.69 で頭打ち</strong>だった。

<strong>モデルを大きくしても解けない。</strong> [AuthorMix](authormix-2026.md) の
「GPT-5.1 few-shot が Toward 0.08」と同じ方向を指している。
