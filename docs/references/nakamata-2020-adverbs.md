# 中俣 尚己 (2020) 主成分分析を用いた副詞の文体分析

計量国語学 32(7), 419-435. 京都教育大学.
<https://www.jstage.jst.go.jp/article/mathling/32/7/32_419/_pdf/-char/ja>

<strong>本文を読んだ。「選択肢があるところに文体がある」を日本語で実証している。</strong>

## 何をしたか

日本語教育で基本とされる副詞と、その類義語を合わせた <strong>164 語</strong>。BCCWJ の
<strong>14 レジスター</strong>での調整頻度を求め、<strong>主成分分析</strong>にかけた。

## 抽出された 2 軸

| | 軸 |
| --- | --- |
| PC1 | <strong>双方向的 対 一方向的</strong> |
| PC2 | <strong>自己表現的 対 公共的</strong> |

英語の文体研究と合致する、としている。

PC1 では Yahoo!知恵袋・Yahoo!ブログが一方の端、出版・図書館の書籍がもう一方の端に来る。
<strong>やりとりを意識しているかどうか</strong>の違いである。文学がやや双方向側に寄るのは、作中人物
のやりとりが話し言葉的だから。

## 副詞の 4 分類

2 軸で 3 種 4 類に分ける。

| | |
| --- | --- |
| A | 自分について表現する副詞 |
| B | 客観的に表現する副詞 |
| C1 | より洗練されたやりとりで使う副詞 |
| C2 | 日常的なやりとりで使う基本の副詞 |

## 最重要の発見——類義語はほぼ必ず別の文体になる

> 全部で 30 の組があり、<strong>うち 29 の組で、含まれる副詞は異なる文体グループに分類されて
> いる</strong>

例。

| 語 | 分類 |
| --- | --- |
| あまり | C2 日常的なやりとり |
| そんなに | C1 より洗練されたやりとり |
| それほど | A 自己表現 |

意味はほぼ同じなのに、文体が違う。<strong>意味が同じで文体が違う組が、日本語の副詞には
たくさんある。</strong>

### なぜこれが効くのか

[Stamatatos](stamatatos-2009.md#不安定性という基準) が紹介する Koppel et al. (2006) の
<strong>不安定性</strong>の基準——「その特徴に言い換えが存在するか」——を、日本語で実証したものに
なっている。

- 言い換えが無い語（`and`、`the`）は文体の選択ではない
- <strong>言い換えがある語は、選んだこと自体が文体である</strong>

英語では機械翻訳の往復で言い換えを作っていたが、日本語の副詞では <strong>類義語の組がそのまま
使える</strong>。しかも 30 組中 29 組で実際に文体が分かれている。

<strong>「同じ機会にどちらを選ぶか」を見る考え方は、3 方向から支えられている。</strong> Koppel の
理論、この論文の日本語での実証、そして [馬場のデータ](baba-2022.md)が示す語ごとの文体値。

## 機能文法の枠組み

ハリデー＆ハッサンの機能文法を援用している。談話の状況を 3 つの変項で見る。

| 変項 | 内容 |
| --- | --- |
| フィールド | 言語活動領域。何が行われているか |
| テナー | 役割関係。誰から誰に |
| モード | 伝達様式。書き言葉か話し言葉か、テクストの地位、修辞様式 |

> この中で最も「文体」と関係するのはモードであろうが、テナーも考察に含める。
> <strong>内容に関するフィールドは今回は考察しない</strong>

<strong>文体研究は、内容（フィールド）を切り離したうえで、残りを扱ってきた。</strong> この論文も
フィールドを考察から外している。

## 得られるもの

- <strong>164 副詞の 2 軸分類が公開されている</strong>（別表に全語の分類がある）
- <strong>類義語の組があれば、選択率を測れる。</strong>「あまり／そんなに／それほど」のうちどれを
  選ぶか。内容が決めるのは「どれかを使う機会」であって、どれを選ぶかではない
- <strong>PC1「双方向的 対 一方向的」が最も重要</strong>と結論されている。
  [4 因子の研究](nakamata-multidimensional.md)の D1 とも通じる
- 機能文法の 3 変項が、内容と状況を分ける枠組みになる

## 注意

- 対象が副詞 164 語に限られる
- BCCWJ のレジスター頻度から出しているので、個人差ではなくレジスター差の軸である。
  <strong>個人の書きぶりは、この軸の上のどこに位置するかとして表れる</strong>と考えることになる
