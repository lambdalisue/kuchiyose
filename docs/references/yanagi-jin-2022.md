# 柳 佳・金 明哲 (2022) 異ジャンル文章が混在した場合における著者識別分析

データ分析の理論と応用 11(1), 1-14. 同志社大学.
<https://www.jstage.jst.go.jp/article/bdajcs/11/1/11_1/_pdf>

<strong>全文を読んだ。kakiburi の「場面ごとに閉じる」という方針に、正面から関わる。</strong>

## 何をしたか

<strong>5 人の現役日本人作家の 2 ジャンル（小説・随筆）計 200 篇。</strong> 著者識別に有効と報告されて
いる <strong>14 種類の特徴量</strong>と <strong>7 種類の分類器</strong>で、ジャンルが混ざったときの精度を比べた。

日本語では、異ジャンルが混在する場合の著者識別の基礎研究がまだ無い、というのが出発点。

## 14 種類の特徴量

文字・記号の unigram / bigram / trigram、文節パターン、形態素タグ（品詞）の unigram /
bigram / trigram、形態素の unigram / bigram / trigram、タグ付き形態素の unigram /
bigram / trigram、<strong>読点の打ち方</strong>。

次元数は品詞 unigram が 32〜34、読点の打ち方が 31〜51 と小さく、文字 bigram は 826〜2,489
と大きい。

## 結果 1——著者はジャンルで書き分けている

主成分分析の散布図で、<strong>5 人中 4 人の小説と随筆が別のかたまりになった</strong>（湊かなえだけ
分かれない）。ジャンル推定の実験でも高精度で当たる。

<strong>kakiburi の「書きぶりは場面ごとにある」は支持される。</strong>

## 結果 2——ジャンルに引きずられない特徴量がある

| ジャンルの影響 | 特徴量 |
| --- | --- |
| <strong>受けにくい</strong> | 形態素タグ（品詞）の unigram、<strong>読点の打ち方</strong> |
| 大きく変わる | 文字・記号の unigram、文節パターン |

## 結果 3——混ざっていても著者は当てられる

候補 5 人、ジャンル混在での著者識別（LOOCV の平均正解率）。

| 特徴量 | 平均 | 最高 |
| --- | --- | --- |
| タグ付き形態素 unigram | <strong>0.9614</strong> | <strong>1.0000</strong>（RF） |
| 形態素 unigram | 0.9571 | 0.9950 |
| 品詞 bigram | 0.9443 | 0.9900 |
| 文節パターン | 0.9364 | 0.9800 |
| 文字 unigram | 0.9357 | 0.9850 |
| <strong>品詞 unigram</strong> | 0.8779 | 0.9250 |
| <strong>読点の打ち方</strong> | 0.8236 | 0.8750 |

<strong>分類器は Random Forest が一貫して最良</strong>（平均 0.9729）。

98 通りの組み合わせのうち、候補 5 人でも 68% が 90% 以上の正解率を出す。

<strong>ジャンルが混ざっても、適切な特徴量と分類器を選べば著者は当てられる。</strong>

## ここが重要——引きずられにくさと、強さは、両立しない

<strong>ジャンルに強い特徴量（品詞 unigram、読点）は、著者識別の精度では下位である。</strong>
逆に精度の高い文字 n-gram は、ジャンルによって大きく変わる。

論文はこれを比喩で説明している。

> <strong>流体が容器に注入されてからはじめて形を持つように、個人文体もまたなんらかのジャンル
> に落とし込まれないと実体化できない。</strong>

> チューニングしやすい部分ほどジャンルに引き摺られやすく、<strong>個人文体も現れやすい</strong>。その
> 最たるものは文字・記号の n-gram である

<strong>ジャンルは器であり、個人文体は流体である。</strong> 器の形に影響される部分ほど、本人の手が
入る部分でもある。

そして、ジャンルの制約が強く出る場面では、文節パターンのような引きずられにくい部分が
<strong>逆に個人文体を忠実にとどめる</strong>としている。

## kakiburi の方針への影響

論文の結論はこうである。

> <strong>特定のジャンルにとらわれず、複数のジャンルに注目した方が書き手の文体をより正確に
> 把握できる可能性がある</strong>

<strong>これは kakiburi の[「場面ごとに閉じる」](../spec/010-strategy.md)と食い違うように見える。</strong>

だが両立すると思われる。段によって要るものが違う。

| 段 | 場面の扱い | 理由 |
| --- | --- | --- |
| <strong>取り出す</strong> | <strong>またいで見る</strong> | 何が場面のせいで何が本人のせいかを切り分けられる |
| <strong>貸す・検める</strong> | <strong>閉じる</strong> | 書かせる場面の値でなければ指示にならない |

場面をまたいだデータは、<strong>場面に依らない部分を特定するのに使える</strong>。特定したうえで、
貸すときは場面ごとの値を使う。

<strong>そして「場面のコーパスが足りないとき」に借りられる特徴量が分かった。</strong> 品詞 unigram と
読点の打ち方は場面をまたいでも一貫するので、少ない場面の値を推し量る手掛かりになる。

## 今後の課題として挙げられていること

対象は小説と随筆に限られている。論文自身がこう書いている。

> 今後、SNS 上の投稿やメッセージ、電子メールといった<strong>比較的短いジャンルを含む横断的
> 著者識別</strong>の可能性についても検証したい

<strong>kakiburi が扱おうとしている場面そのものである。</strong> ここは未検証のまま残っている。
