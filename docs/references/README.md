# 先行研究

kakiburi にあるのは、最初は <strong>やりたいこと</strong> だけである。

> LLM に代筆させたときに、自分が書いたものとして通るようにしたい。書くものの種類は
> 限らない。

これを満たすために何が要るかは、思いつきで決めるものではない。「文章から書き手を
定量的に識別する」は <strong>計量文体論 / 著者識別（stylometry, authorship attribution）</strong>
として 60 年以上の蓄積がある。まず何が分かっているかを調べ、そこから
[軸](../spec/000-axis.md) を決め、[戦略](../spec/010-strategy.md)、戦術と落とす。

<strong>独自性は要らない。</strong> 結果が出ているものはそのまま採る。

## ここまでで分かったこと

<strong>1. やりたいことの半分は、既に解けている。</strong>

「この文章はその人らしいか」を測るのは著者識別そのもので、手法も特徴量も確立している。
日本語でも、1,100 字の作文 11 人で 99%、500 字の日記 6 人で 92% という実証がある
（[金 2013](jin-2013.md)）。短い場面でも届く見込みがある。

<strong>2. もう半分は、この分野でも未解決である。</strong>

[Stamatatos](stamatatos-2009.md) が名指ししている。

> it is not yet possible to explain the differences between the authors' style ...
> what we need is a higher level abstract description of the authorial style

判別はできるが <strong>説明はできない</strong>。そして代筆させるには説明が要る。指示できない特徴で
は書かせられない。

<strong>3. したがって kakiburi の仕事は「説明できる形で書きぶりを表すこと」に絞られる。</strong>

判別のための特徴量を自前で工夫しても、文字 n-gram を超えることはまず無い。そこは
借りる。労力は説明の層に割く。そして <strong>借りた判別器が、説明の層がどこまで届いているか
の物差しになる</strong>。

<strong>4. 使うべき特徴量は、もう挙がっている。</strong>

機能語（助詞・助動詞）の頻度、品詞 n-gram、文字 n-gram、文節パターン、読点の打ち方、
単語長・文長の分布。思いつく必要はない（[浅石](asaishi-2017.md)、[金 2013](jin-2013.md)）。

効かないと報告されているものもある。係り受け距離の分布、語彙の豊富さ（TTR）。試す前に
落とせる。

## 落とし穴として記録しておくこと

<strong>題材から完全には逃げられない。</strong> 機能語も文字 n-gram も、題材情報を拾ってしまうことが
分かっている（[Stamatatos](stamatatos-2009.md) §5）。「文体情報と題材情報の組み合わせ
だからこそ強いのではないか」とまで書かれている。題材の影響を消す設計は要るが、消し
きれる前提では立てない。

<strong>次元を増やすと題材が混ざる。</strong> 最頻出の数十語は機能語だが、数百語を超えると内容語が
多数派になる。

<strong>評価コーパスは題材とジャンルを揃えるのが作法。</strong> 理想は全員が同じ題材で書いたもの。
時期も揃える（文体は時とともに変わる）。

<strong>先行研究の対象は小説・作文・日記に偏っている。</strong> コードブロックや見出しを含む記事、
断片的なチャットなど、我々が扱う場面で同じことが成り立つかは確かめられていない。
ここは我々が確かめるしかない。
