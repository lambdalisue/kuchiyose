## 問題——著者を当てられることは、文体を表していることの証明にならない

> a good performance on the AV task does not ensure good "general-purpose" style
> representations. For example, as the same author might typically write about certain
> topics, representations trained on AV might also encode <strong>content information instead of
> style alone</strong>

同じ人はたいてい同じような話題を書く。だから著者識別は <strong>題材を手掛かりに当てることが
できてしまう</strong>。精度が高くても、文体を測れているとは限らない。

そして機能語や文字 n-gram に絞れば安全、という逃げ道も塞がれている。

> even these features have been shown to <strong>not necessarily be content-independent</strong>
> (Litvinova, 2020)

## 何をしたか——題材を揃えて訓練する

著者検証（AV）を訓練課題にして文体表現を学ぶとき、<strong>「違う著者」の例をどこから取るか</strong>で
題材の統制の強さが変わる。Reddit の 100 サブレディットで 3 段階を比べた。

| 統制 | 「違う著者」の発話をどこから取るか |
| --- | --- |
| <strong>会話</strong> | <strong>同じ会話スレッドの中から</strong> |
| ドメイン | 同じサブレディットから |
| 無し | 無作為に |

加えて、2 つの比較（AV）ではなく <strong>3 つ組</strong>（アンカー + 同一著者 + 別著者）にする CAV 設定
を導入している。

## 結果 1——統制が無いと、題材で当てているのが露呈する

各モデルを 3 種類のテストセットで測ると、こうなる（AUC）。

| 訓練時の統制 | 会話テスト | ドメインテスト | 無しテスト |
| --- | --- | --- | --- |
| 会話 | .69 | .70 | .71 |
| ドメイン | .68 | .71 | .73 |
| <strong>無し</strong> | <strong>.58</strong> | .63 | <strong>.79</strong> |

<strong>統制無しで訓練したモデルは、自分と同じ条件では .79 出るのに、題材を揃えられると .58 に
落ちる。</strong> 素の RoBERTa が .53 なので、ほぼ何も残らない。

<strong>その .79 は文体の精度ではなく、題材の精度だった。</strong>

会話統制のモデルは 3 条件すべてで .69〜.71 とほぼ変わらない。<strong>ばらつきが最小である。</strong>

## 結果 2——それでも題材から逃げきれていない

STEL-Or-Content という課題を作っている。<strong>同じ内容だが違う文体の文</strong>と、<strong>違う内容だが同じ
文体の文</strong>を並べ、どちらを選ぶかを見る。文体を優先すれば正解、題材を優先すれば不正解。

| モデル | 正解率 |
| --- | --- |
| 素の RoBERTa | 0.05 |
| 統制無しで訓練 | 0.22〜0.24 |
| ドメイン統制 | 0.28〜0.32 |
| <strong>会話統制 + CAV（最良）</strong> | <strong>0.42</strong> |

<strong>最良でも 0.42 で、無作為の 0.50 を下回る。</strong> 訓練で 0.05 から 0.42 まで上がったが、
<strong>どの文体表現も、まだ文体より題材を優先している。</strong>

論文自身も、会話を揃えても内容の手掛かりは残ると認めている。

> even when using the conversation CC, content information might still be useful for AV:
> If one person writes "my husband" and another writes "my wife" within the same
> conversation, it is highly unlikely that those utterances have been generated by the
> same person

## 結果 3——何を学んだかは見える

最良のモデルの埋め込みを凝集型クラスタリングにかけると、クラスタの中身に一貫性がある。

| クラスタ | 一貫している点 |
| --- | --- |
| 3 | <strong>末尾に句読点を打たない</strong>（97% 対 他クラスタ平均 37%） |
| 4 | <strong>大文字小文字と短縮形の綴り</strong>（`i` を使う発話の 67%、`didnt` を使う 27 件中 22 件） |
| 5 | <strong>アポストロフィの字種</strong>（`'` 対 `'`。90% 対 他クラスタ平均 0%） |
| 7 | <strong>発話中の改行</strong>（72% 対 平均 22%） |

<strong>文字レベルの表記の癖が、文体表現の主成分になっている。</strong>

## 読み取れること

### 1. 著者識別の精度は、そのままでは文体の精度ではない

[金 2013](jin-2013.md) の 99% も [柳・金 2022](yanagi-jin-2022.md) の 0.96 も、
<strong>題材で当てている分がどれだけ混ざっているかは測られていない。</strong>

### 2. 統制の粒度は「場面」では粗い

<strong>ドメイン統制はほとんど効いていない。</strong>（.28〜.32 対 会話 .35〜.42）サブレディット単位
——「技術記事」「チャット」のような括り——では、題材は揃わない。

<strong>揃えるなら会話の単位、つまり「同じ話題について書かれた別々の文章」まで降りる。</strong>

### 3. [Stamatatos](stamatatos-2009.md) の警告と一致する

「機能語も文字 n-gram も題材情報を拾う」に、<strong>数値が付いた。</strong> 最良の文体表現でも 0.42
である。<strong>題材の混入は減らせても、消せない。</strong>

### 4. 表記の癖は測る価値がある

アポストロフィの字種、末尾の句読点、改行。<strong>意味を持たない表記の選択が、文体表現の
上位クラスタを作っている。</strong>

日本語で対応するものは挙げられる。読点の打ち方、三点リーダの字数、感嘆符の全角半角、
括弧の種類、和欧間スペース、改行の入れ方。<strong>これらは題材と相関しにくい。</strong>
