# 較正を入れる。相手集合を回す

[前の実験](100-ceiling-floor.md)は等重みの平均で、尤度比に変えていなかった。
<strong>仕様が「混ぜると効く」と言っているのは尤度比に変えたあとの合算</strong>なので、そこを入れた。
あわせて<strong>相手集合を回して</strong>、分離が 5 本の選び方に依らないかを見た。

道具は [tools/spike-calibrate.pl](../../tools/spike-calibrate.pl) と
[tools/spike-rotate.pl](../../tools/spike-rotate.pl)。

## 経路

仕様どおりに通した。<strong>照合値は大きいほど同じ人らしいので、天井が上、床が下になる。</strong>

| | すること |
| --- | --- |
| 1 | 系統ごとに Cosine Delta で距離を出す |
| 2 | 系統ごとに、[同じ人の対と違う人の対](../spec/200-extract.md#較正と天井床)の距離に照らして<strong>尤度比に変える</strong> |
| 3 | 尤度比を<strong>合算</strong>して 1 つの照合値にする |
| 4 | 1 本 × 相手集合 の中央値を、その 1 本の点にする |

2 と 3 はどちらも[ロジスティック回帰](../spec/200-extract.md#尤度比はロジスティック回帰で当てはめる)、
[正則化つき](../spec/200-extract.md#尤度比はロジスティック回帰で当てはめる)（L2、λ = 0.1）。

較正は<strong>相手集合の中の対 10 本</strong>（同じ人）と<strong>基準の較正分 × 相手集合 15 本</strong>（違う人）。
基準が 6 本しかないので較正 3 / 床の点 3 に割った。<strong>仕様の 5 / 5 に届いていない。</strong>

## 答え——10 / 10 で分離した

| | 分離 | 隙間 最小 | 中央 | 最大 |
| --- | --- | --- | --- | --- |
| 全系統 | <strong>10 / 10</strong> | 0.108 | 0.203 | 0.563 |
| 文字種を抜く | <strong>10 / 10</strong> | 0.082 | 0.185 | 0.346 |

<strong>相手集合をどう選んでも分離する。</strong>[前の実験](100-ceiling-floor.md)は 1 通りだけだった
ので、そこが確かめられた。

## 文字種について、結論が変わった

> [!WARNING]
> <strong>この節の数字は使えない。</strong> 基準の場面が本人と違い、さらに文字種の分類に
> [2 つの欠陥](300-baseline-scene.md#途中でスパイクの欠陥が-6-つ出た)があった。
> 両方を直すと重みは 1.0 〜 1.5 に収まり、300 倍の振れは消える。
> <strong>結論は[次の実験](300-baseline-scene.md)に移った。</strong>

<strong>較正を入れると、文字種の重みがいちばん大きく出る。</strong> 回転 0 では +1.270 で、
文字 bigram の +0.626 の 2 倍である。<strong>3 本の反証と逆を向いている。</strong>

<strong>だが回すと分かる。</strong>

| 系統 | 重みの範囲（10 通り） | 振れ幅 |
| --- | --- | --- |
| 文字 bigram | 0.274 〜 0.626 | <strong>2.3 倍</strong> |
| 読点前 | 0.020 〜 0.524 | 26 倍 |
| 読点後 | 0.074 〜 0.619 | 8 倍 |
| <strong>文字種</strong> | <strong>0.005 〜 1.481</strong> | <strong>296 倍</strong> |

<strong>文字種の重みは決まっていない。</strong> 5 本の選び方で 300 倍動く。回転 6 では 0.005——
<strong>実質的に外されている。</strong>

<strong>これは「重みが大きいから効いている」の否定である。</strong> 較正が使えるのは同じ人の対 10 本
だけで、<strong>そこに合う値を何でも取ってしまう。</strong> 大きく出た回でも、その値に根拠は無い。

<strong>安定しているのは文字 bigram だけである。</strong> 10 通りとも 0.27〜0.63 の間にあり、
どの回でもいちばんか 2 番目に大きい。

## 隙間は狭くなった

| | 隙間 中央 |
| --- | --- |
| [等重みの平均](100-ceiling-floor.md) | 0.0598（距離の単位） |
| 較正あり | 0.203（対数尤度比の単位） |

<strong>単位が違うので直接は比べられない。</strong> だが同じ系統の組で比べると、
<strong>文字種を抜いたほうが隙間が狭くなった</strong>（0.203 → 0.185）——等重みのときは<strong>逆</strong>
（0.0598 → 0.0877）だった。

<strong>較正が文字種の分を吸っている。</strong> 等重みだと文字種の大きな距離が全体を薄めるが、
較正はそれを重みで調整できる。<strong>「混ぜると効く」は、較正があって初めて成り立つ。</strong>
仕様の書き方は正しかった。

## 何が言えるか

| | |
| --- | --- |
| <strong>骨格が端まで通った</strong> | 正規化 → 系統 → 距離 → 尤度比 → 合算 → 中央値 → 帯 |
| <strong>分離は頑健である</strong> | 相手集合 10 通りすべて |
| <strong>混ぜるには較正が要る</strong> | 等重みだと文字種が害になり、較正すると害にならない |
| <strong>文字種の重みは決まらない</strong> | 300 倍振れる。素材が足りない |

## 何が言えないか

<strong>文字種を落とすべきかは、まだ決まらない。</strong> 較正すれば害は消えるが、<strong>重みが決まらない
ことは残る</strong>。[較正が 10 対しかない](#経路)のが原因なので、<strong>先に要るのは素材である。</strong>

そして[前の実験と同じ限界](100-ceiling-floor.md#分かっていないこと)が残っている——
<strong>分離したのは「本人 対 LLM」であって「本人 対 他人」ではない。</strong> 床が 3 本しかなく、
題材も揃えていない。

<strong>題材と場面を揃えたのが[次の実験](300-baseline-scene.md)である。</strong> そこで分離の出どころが
割れる。
