# 指標の実験記録

候補ごとに 1 ファイル。採ったものも落としたものも置く。決まりは
[100-metrics.md](../spec/100-metrics.md#結果を記録する) にある。

ここは仕様ではない。観測の記録である。

## 素材

| 区分 | 件数 |
| --- | --- |
| 人が書いた記事 | 50 |
| AI が生成した記事 | 3 |
| AI の下書きを人が手直しした記事 | 1 |

断りのない測定は、人側 50 本のうち 7 本と、生成 3 本による。

読むときに知っておくべき偏りが 3 つある。

<strong>1 人の書き手のものしかない。</strong> 「人によって差が出る」という検査は、本当は
複数の書き手で見るべきだが、できていない。いま見ているのは「この書き手と機械が
違う」であって、「書き手どうしが違う」ではない。

<strong>人側は十数年にわたる。</strong> 同じ書き手でも書きぶりは年月で動く。分離しなかった
指標の一部は、時代の違いが幅を広げたせいかもしれない。

<strong>標本が小さい。</strong> ほとんどの判断が 10 本で下されている。示せるのは、その標本で
反例が出なかったことだけである。

## 値の出どころ

いま記録されている値は、すべて <strong>前身の実装</strong> で測ったものである。この実装で
測り直すまでは参考として扱う。

## まだ個別に検証していないもの

記号と構造の指標は、前身から一括で引き継いだままで、1 つずつ分離と安定を確かめて
いない。ファイルが無いのは試して落ちたからではなく、まだ試していないからである。

全角括弧、半角括弧、鉤括弧、感嘆符、疑問符、三点リーダ、絵文字、笑い、読点、
番号リスト、表、見出し、深い見出し、補足、警告、折りたたみ、コードブロック、
和欧間スペース欠落。

## 全体で分かったこと

生成した記事を <strong>語の置換だけ</strong> で書き直したところ、38 点が 94 点になった。段落の
作りも節の構成も変わっていない。

局所的な指標だけを揃えれば通せてしまうという実例である。大きい単位を覆う指標が
要る根拠がここにある。
