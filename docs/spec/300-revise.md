# 検めて、直す

[戦略](010-strategy.md#言うために何が要るか)が挙げた 4 つ目——<strong>直す側が受け取れる形</strong>
——を作る。<strong>ここで初めて[軸](000-axis.md)が満たされる。</strong>

返すものは 2 つある。

| | 何を言うか |
| --- | --- |
| <strong>判定</strong> | 通ったか。通らないか。判定できないか |
| <strong>指摘</strong> | どこが、こちらへ、これだけ違うか |

<strong>文章がどこから来たかを問わない。</strong> LLM に書かせたものも、自分で書いたものも、同じ
ようにここへ来る（[書かせることはしない](010-strategy.md#書かせることはしない)）。

## 同じ測り方で測る

対象の文章を、[評価](200-extract.md)と <strong>同じ指標、同じ単位、同じ定型の落とし方</strong>で測る。
[正規化](030-normalize.md)も同じ手順を通す。どれかが違えば、比べたものに意味が無い。

### 場面を指定させる

どの場面の幅と目盛りに照らすのかは、文章からは決まらない
（[評価](200-extract.md#場面ごとに分ける)）。

### 草稿の作られ方を疑う

<strong>本文が依頼文に漏れた草稿は、測定が膨らむ。</strong> 本文の書き出しをそのまま依頼文に使うと、
基準値が <strong>28 ポイント</strong>膨らんだ例がある（[Sawant](../references/authorship-gap-2026.md)）。

<strong>手本を見せること自体は、そこまで効かない。</strong> 手本を見せた場合の一致は 0.508 で、
[他人どうしの床 0.626](010-strategy.md#書かせることはしない)を下回っている。<strong>それでも
訊くのは、漏れたかどうかを我々が知りようがないからである。</strong>

kakiburi は書かせる側を持たないので、これを防げない。<strong>だから訊く。</strong> 本人の文章を参考
として渡したかどうかを申告させ、渡していれば判定に添える。

## 何を見るか

<strong>書きぶりだけを見てはいけない。</strong> 文体・内容・自然さの間には trade-off があり、文体に
強く寄せるほど内容が壊れ、日本語として不自然になる
（[文体転換の評価](../references/tst-evaluation.md)）。

| 次元 | 何を見るか | 何で測るか |
| --- | --- | --- |
| 書きぶり | 本人として通るか | <strong>系統</strong>を[照合値](200-extract.md#何を目盛りに載せるのか)にして目盛りへ |
| 書きぶり | どこが外れているか | <strong>指示できる指標</strong>が本人の幅に入っているか |
| <strong>人らしさ</strong> | <strong>機械が書いたと分かる文になっていないか</strong> | 繰り返し、エントロピー、圧縮率、語彙の豊富さ |
| 題材 | 書くべきことが保たれているか | 元の草稿との対照 |
| 日本語 | 読める文になっているか | — |

<strong>書きぶりが 2 行あるのは、機構が違うからである</strong>（[指標](100-metrics.md#指標には-3-種類ある)）。
系統は距離で全体の判定を作り、指示できる指標は幅で外れを出す。<strong>どちらも判定に使う。</strong>

<strong>人らしさを落とさない。</strong>[通る条件は 2 つ](010-strategy.md#通るには-2-つ要る)であり、
書きぶりが幅に入っても、機械が書いたと分かる文章は通らない。

<strong>題材が保たれていることは前提である</strong>（[性質 3](010-strategy.md#書きぶりとは何か)）。
見ていなければ、前提が成り立っているか分からない。

> [!WARNING]
> <strong>題材と日本語の測り方は、まだ決まっていない。</strong> 素直に作れば LLM に読ませることに
> なるが、それは[数える側に LLM を置かない](010-strategy.md#数える側に-llm-を置かない)に
> 反する。<strong>決まるまで、この 2 つは判定に混ぜない。</strong> 混ぜたことにして先へ進むと、
> 壊れた目盛りの上に全部が建つ。

## 全体の判定は 3 値で返す

### 目盛りに載せる

<strong>点数だけでは読めない。</strong> 0.5 が近いのか遠いのかは、比べる先が無ければ決まらない
（[Sawant](../references/authorship-gap-2026.md)）。[天井と床](200-extract.md#目盛りを作る)
に載せて読む。

<strong>読み方は[帯の規則](200-extract.md#帯は2-つの分布の重なりである)が決める。</strong> 両端を見る
ので、分布が分離していても重なっていても同じ規則で 3 値が出る。ここで場合分けし直さない。

<strong>無理に判定しない</strong>（[決定](010-strategy.md#届かないときは判定できないと言う)）。帯を
狭めれば判定不能は減るが、間違った判定が増える。

### 3 種類を合わせて「通る」を出す

<strong>照合値だけでは足りない。</strong>[通るには 2 つ要る](010-strategy.md#通るには-2-つ要る)以上、
人らしさが落ちていれば通らない。指示できる指標も判定に使う
（[指標](100-metrics.md#指標には-3-種類ある)）。

<strong>順に当てる。返す値が決まったら、そこで終わる。</strong>

| | 見るもの | 出る値 | 返す |
| --- | --- | --- | --- |
| 1 | <strong>人らしさ値</strong> | 機械 | <strong>通らない</strong> |
| | | 判定できない | <strong>判定できない</strong> |
| | | 人 | 次へ |
| 2 | <strong>照合値</strong> | 床側 | <strong>通らない</strong> |
| | | 帯の中 | <strong>判定できない</strong> |
| | | 天井側 | 次へ |
| 3 | <strong>指示できる指標</strong> | 幅の外にあるものがある | <strong>判定できない</strong> |
| | | 全部が幅の中 | <strong>通る</strong> |

<strong>1 を先に当てるのは、条件が独立だからである</strong>（[通るには 2 つ要る](010-strategy.md#通るには-2-つ要る)）。
文体がどれだけ寄っても、機械が書いたと分かる文章は別の条件で落ちる。照合値が天井側に
あることは、そこを何も保証しない。

<strong>3 が「通らない」ではなく「判定できない」を返すのはなぜか。</strong> 照合値は既に天井側にある
——<strong>系統で見るかぎり本人の範囲に入っている。</strong> それを覆して「通らない」と言えるだけの
根拠は、細く切った 1 つの指標には無い。<strong>だが黙って通すこともしない。</strong> 言えるものがある
以上、言って次の周へ回す。

<strong>3 に入れるのは、指摘に出せる指標だけである。</strong> それを <strong>前に出す指標</strong> と呼び、1 度だけ
定める。

> [効くと判定された指標](200-extract.md#どの指標が効くかを決める)から、
> [層 3](100-metrics.md#層-3系統に遡れないもの)と、指示して動かないと分かっているものを
> 除いたもの。

<strong>判定も指摘も、この同じ集合から取る</strong>（[指摘の選び方](#指摘は-3-本か-4-本に絞る)）。
別々に定めれば、止めた理由が指摘に出てこないという食い違いが起きる。

<strong>言えないもので止めない</strong>——止めておいて理由を言えなければ、受け取った側は何もできない。

<strong>段そのものが測れなければ、判定できないを返す。</strong>

| 測れていないもの | 返す |
| --- | --- |
| 人らしさ値 | <strong>判定できない</strong>。通過の必要条件を確かめずに先へ進めない |
| 照合値 | <strong>判定できない</strong>（[系統が欠けたとき](200-extract.md#系統が-1-つでも欠けたら照合値を出さない)） |

<strong>飛ばすのは 3 段目の中の、個々の指標だけである。</strong>[除外](100-metrics.md#除外の既定)に掛かった
指標を幅の中とも外とも扱わない、という意味であって、<strong>段を飛ばすことではない。</strong>

<strong>止めた理由を返す。</strong> どの段で止まったかを言わなければ、受け取った側は照合値を上げよう
として人らしさを下げる、という逆向きの直しをする。

### 組み合わせで決める

<strong>1 つの指標で判定しない。</strong> 単一の点数は騙せることが報告されている
（Krishna et al. 2020、[SPTG の評価](../references/sptg-evaluation-2025.md)経由）。

<strong>違う原理のものを混ぜたときにいちばん当たる</strong>（[決定](010-strategy.md#種類の違うものを混ぜるただし-5-系統前後まで)）。
正解率が同じでも判断が 35% 食い違う組み合わせがあり、<strong>そこにこそ足す価値がある</strong>
（[SPTG の評価](../references/sptg-evaluation-2025.md)）。

<strong>逆に、同じ現象を 3 通りに測ったものは 1 つに数える。</strong> どれを何本入れるかは
[評価](200-extract.md#判定に使う系統を選ぶ)が決める。

<strong>LLM の判定は混ぜない。</strong> SPTG の最良の組み合わせには LLM の判定が入っているが、
kakiburi は使わない（[決定](010-strategy.md#数える側に-llm-を置かない)）。

### 埋め込みを使うなら、較正で確かめる

<strong>埋め込みは、同じ依頼から作った 2 つを比べる場面で崩れる。</strong> 内容が同じなので区別できず、
性能が <strong>38.3%</strong> 落ちる（[SPTG の評価](../references/sptg-evaluation-2025.md)）。

kakiburi の床は「同じ依頼で LLM に素で書かせたもの」である
（[評価](200-extract.md#目盛りを作る)）。<strong>まさにその場面にいる。</strong>

<strong>だから重みを手で小さく置く、ではない。</strong> 重みは較正が決める
（[評価](200-extract.md#何を目盛りに載せるのか)）。ここで言えるのは <strong>予測</strong>である——
<strong>較正すれば小さく出るはずである。大きく出たら、較正か基準の作り方を疑う。</strong>

（[埋め込みは当面使わない](100-metrics.md#埋め込みは保留する)ので、これは使うと決めたとき
の話である。）

### 当てにならないときは言う

集めた文章が少なければ、幅も目盛りも当てにならない。

<strong>場面の文章が集まっていないときは、断る。</strong> 判定できないを返し、その場面の素材が足りない
と伝える。

<strong>近い場面から取る道は、いまは通れない。</strong> 場面をまたいでも一貫すると確かめられているのは
<strong>品詞 unigram と読点の打ち方</strong>だけで、文字・記号の unigram と文節パターンは大きく動く
（[柳・金 2022](../references/yanagi-jin-2022.md)）。<strong>そして品詞 unigram は集合に無い</strong>
——[品詞 bigram](metrics/品詞bigram.md) は別物である。

<strong>残る 1 つでは[照合値が作れない](200-extract.md#判定に使う系統を選ぶ)。</strong> 分類をまたいで
取ることも、較正することもできない。

> [!NOTE]
> <strong>通したいなら、品詞 unigram を集合に足すところから始まる。</strong>
>
> <strong>「弱い 2 つ」とは言えない。</strong> 同じ論文の実験 II では品詞 unigram 0.8779・読点の打ち方
> 0.8236 で下位に来るが、<strong>実験 III では読点の打ち方が単独最良（0.8160）</strong>である。
> <strong>順位は実験で入れ替わる。</strong> 意味があるかは、測ってから決める。

## 指摘を作る

### 外れを出す

指標ごとに、値が幅の外にあるかを見る。<strong>上に外れることと、下に外れることの両方を見る。</strong>
どちらを見るかは指標の定義に書いてある（[指標](100-metrics.md#定義に落とす)）ので、ここ
で指標ごとに場合分けしない。

<strong>上だけを見ると、指摘を消そうとする側は削るほうへ向かう。</strong> 書きぶりは幅であって上限で
はない。

判定も指標の定義を回す。測った値と幅は名前で突き合わせるので、
[名前が 1 か所にしか無いこと](100-metrics.md#名前は-1-度しか書かない)がここで効く。

### 指摘は 3 本か 4 本に絞る

<strong>外れた指標を全部並べてはいけない</strong>（[決定](010-strategy.md#一度に渡すのは-3-本か-4-本)）。

[前に出す指標](#3-種類を合わせて通るを出す)のうち、<strong>外れの大きい順</strong>に上位を取る。

<strong>同じ大きさなら、切り口そのものを調べた研究があるものを先に言う</strong>
（[指標](100-metrics.md#指示できる指標は系統の細い切り口である)）。裏付けの濃いほうから
出す。
外れ具合はその人の幅を単位にして測る。下端が[出現割合](200-extract.md#下限は使った割合で見る)
で見る指標なら、その割合を
[幅の単位に直したもの](200-extract.md#出てこないことの大きさを幅と同じ単位にする)を大きさ
とする。<strong>割合をそのまま並べない</strong>——上限が 1.0 なので、出てこないことが永久に上位に来ない。

この選び方は隠す側で検証されている。著者ベクトルと平均の差の絶対値で上位 k 軸を選ぶと、
<strong>同じ本数を無作為に選ぶより 6% 良い</strong>（[StyleRemix](../references/styleremix-2024.md)）。

<strong>kakiburi はそれより多くを知っている。</strong> その書き手が普段どこにいるかだけでなく、この
文章がどこにいるかも測れている。だから選ぶ基準は「その人で際立つ軸」ではなく
<strong>「この文章で外れている軸」</strong>になる。

<strong>指示して動かないと分かっている指標は、枠から外す</strong>
（[条件 3](200-extract.md#どの指標が効くかを決める)）。動かないものに枠を使えば、動くもの
が押し出される。<strong>[層 3](100-metrics.md#層-3系統に遡れないもの)も同じ理由で枠に入れない。</strong>

<strong>人らしさはこの枠に数えない</strong>（[指標](100-metrics.md#指標には-3-種類ある)）。3〜4 本と
いう上限は書きぶりの側の話であり、人らしさの指摘は
[別に立てる](#人らしさの直し方は書き直しに戻ることがある)。<strong>枠を奪い合わせると、機械
臭さを消す指示と、その人へ寄せる指示が、席を取り合う。</strong>

### 直せる形にする

外れた指標の名前と数値だけでは直せない。<strong>3 つ揃って初めて直せる。</strong>

| | 軸のどこに対応するか |
| --- | --- |
| <strong>観測</strong>。この文章ではどうだったか | ここが |
| <strong>直し方</strong>。どちらへ、どうすればよいか | こちらへ |
| <strong>普段</strong>。その人はどこからどこまでで書いてきたか | これだけ |

<strong>直し方は指標の定義から取る</strong>（[指標](100-metrics.md#定義に落とす)）。指摘を出す側で
書くと、指標を足したときに直し方の無い指摘が出る。

### 散文で渡す

<strong>表にしない。</strong> 構造化した形を求めると成績が落ちるという報告がある
（[SPTG の評価](../references/sptg-evaluation-2025.md)）。<strong>ただし証拠は弱い</strong>——モデル 1 つ、
64 件、しかも両条件とも偶然を下回る比較である。<strong>散文にする理由は、次の段落のほうが強い。</strong>

成功している例も散文である。人の文章と機械の文章の差を LLM に <strong>記述させ</strong>、その記述を
そのままプロンプトに置く手順で、読みやすさも課題達成率も人間並みになっている
（[SICO](../references/sico-2024.md)）。

<strong>ただし数値は落とさない。</strong> 次の周でも同じ値で照らすので、丸めたり言い換えたりして情報
を落とせば、指示と判定がずれる。散文にするのは <strong>言い方</strong>であって、根拠の値ではない。

### 人らしさの直し方は、書き直しに戻ることがある

寄せる向きは分かっている。人の文章は <strong>繰り返しでできており</strong>、機械の文章は語彙が散り
すぎて繰り返せない（[Zeng & Nini](../references/zeng-nini-2026.md)）。

<strong>そして推論設定で動く。</strong> 上の実験は温度も頻度ペナルティも既定値のままだったと論文自身
が認めている。<strong>頻度ペナルティを下げれば繰り返しは増える。</strong>

kakiburi は書かせる側を持たないので、これは <strong>直し方として伝える</strong>——「この設定で書き直
させる」と。文面を直す指摘とは別に立てる。

## 回す

### 直したら測り直す

直した文章をもう一度測る。同じ値と同じ目盛りを使っているので、指示どおりに直せば数値は
寄るはずである。

<strong>寄ったかを見るのは、指摘が名指しした指標である。</strong> 照合値ではない。

| 何が動いたか | 何が分かるか |
| --- | --- |
| 名指しした指標が動いた | 指摘は通じた |
| <strong>名指しした指標が動かない</strong> | [条件 3](200-extract.md#どの指標が効くかを決める)に返す |
| 指標は動いたが<strong>照合値が動かない</strong> | <strong>条件 3 に返さない。</strong> 下を見る |

<strong>2 つを混ぜてはいけない。</strong> 混ぜれば、正しく通じた指摘を「動かない」として落とす。

<strong>照合値は、1 つの系統の中の 1 つの切り口には鈍い。</strong> 実測では、読点を 40 個から 29 個へ
減らし直前の最頻文字を 22% から 0% にしても、[読点の打ち方](metrics/読点の打ち方.md)の距離は
1.7% 動くだけで、<strong>照合値は床から天井までの 0.9% しか動かなかった</strong>
（[実験](../spike/400-revise-loop.md)）。系統が 50 次元あり、読点が 40 個しか無ければ、
ほとんどの次元は 0 のまま——<strong>動いた分が薄まる。</strong>

<strong>だから照合値が動かないことは、指摘の失敗ではない。</strong> 3〜4 本の指摘を 1 周入れて照合値が
帯を越えることを期待しない（[ループ](010-strategy.md#使うときはループになる)）。

<strong>1 回で通ることは期待しない</strong>（[ループ](010-strategy.md#使うときはループになる)）。

### 直すと差が均されるのを見張る

人が直した文章は、自由に書いた文章より <strong>互いに似通う</strong>（効果量 1.42、
[Post-Editing](../references/post-editing-2026.md)）。<strong>直す経路は、書き手どうしの差を潰す
方向に働く。</strong>

kakiburi は差を出すための道具なので、これは逆向きの力である。

<strong>だが書き手どうしの均しは、1 人しか持たないこの道具からは見えない。</strong> 見えるものに
置き換える。

<strong>同じ文書の周回どうしを比べてはいけない。</strong> 2 周目は 1 周目を書き直したものなので、題材
も構成も語の大半も共有している。散らばりが小さいのは当たり前で、
[天井](200-extract.md#目盛りに載るのは1-本-対-その人である)——別々の文書どうしの散らばり——と比べ
れば <strong>健全なループでも必ず「狭い」と出る。</strong> 尺度が違う。

<strong>見るのは、別々の文書を同じ周回数だけ回したものどうしの散らばりである。</strong>

| いつ | 何を比べるか |
| --- | --- |
| 回す前 | 文書 A・B・C の草稿どうし |
| n 周後 | n 周した A・B・C どうし |

| 散らばりの変化 | 意味 |
| --- | --- |
| 変わらない | <strong>正常</strong> |
| <strong>周回とともに縮む</strong> | <strong>平板になっている。</strong> その人らしくなったのではない |

<strong>これは Post-Editing が測った量そのものではない。</strong> あちらは書き手どうしが似通う話で、

### 自分を検査する

<strong>本人の実際の文章を、ここに通す。</strong> 生成文より低く出る指標や組み合わせがあれば、それは
指示に従えたかを測っている（[Sawant](../references/authorship-gap-2026.md)）。数え方が
「指示しやすさ」に寄っているので、[数え方](100-metrics.md#数え方は-kakiburi-が決める)に
戻して直す。

<strong>本人がいちばん高く出ることが、目盛りが壊れていないことの最低条件である。</strong> 定期的に
回す。

### 本人が違うと感じたら

数値が通ると言い、本人が違うと言うなら、<strong>足りないのは指標である</strong>。指示でも目盛りでも
ない。[指標](100-metrics.md#集合が変わるとき)に戻る。

<strong>逆は信号にならない。</strong> 本人が受け入れたことは、通ったことの証拠にならない
（[決定](010-strategy.md#本人の読みは判定ではなく候補として使う)）。<strong>数値が通らないと言い、
本人が気付かないのは、正常な状態である。</strong>
