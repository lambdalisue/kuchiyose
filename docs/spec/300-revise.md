# 検めて、直す

この文書は、渡された草稿を検めて、直す側が受け取れる形で結果を返す手順を決める。
[戦略](010-strategy.md#言うために何が要るか)が挙げた要素のうち、最後の「直す側が受け取れる形」
を作る段である。[軸](000-axis.md)の「どこがその人と違うかを言う」は、この段で初めて
満たされる。言葉の意味は[用語集](../glossary.md)にある。

返すものは 2 つある。

| | 何を言うか |
| --- | --- |
| [判定](../glossary.md#判定) | 通ったか。通らないか。判定できないか |
| [指摘](../glossary.md#指摘) | どこが、どちらへ、どれだけ違うか |

文章がどこから来たかは問わない。LLM に書かせたものも、自分で書いたものも、同じように
ここで検める（[書かせることはしない](010-strategy.md#書かせることはしない)）。

## 同じ測り方で測る

対象の文章は、[評価](200-extract.md)で目盛りを作ったときと同じ指標、同じ単位、同じ定型の
落とし方で測る。[正規化](030-normalize.md)も同じ手順を通す。どれか 1 つでも違えば、
目盛りと比べた結果に意味が無くなる。

### 場面を指定させる

どの[場面](../glossary.md#場面)の幅と目盛りに照らすのかは、使う側に指定させる。文章の中身
からは決まらないからである（[評価](200-extract.md#場面ごとに分ける)）。

指定は、[カセット](../glossary.md#カセット)（目盛りを入れたファイル）を選ぶことで行う。
1 つの目盛りには 1 つの場面しか入らないので（[場面ごとに閉じる](010-strategy.md#場面ごとに閉じる)）、
カセットを選んだ時点で場面が決まる。

結果には、どの場面として検めたのかを必ず出す。カセットの名前は人が付けるもので、中身と
合っている保証が無いため、選び間違いは起こりうる。場面を出さずに別の目盛りで通して
しまうと、その間違いが結果から見えなくなる。

### 草稿の作られ方を疑う

本人の文章を参考として LLM に渡したかどうかを、使う側に申告させる。渡していれば、判定に
但し書きを添える。

理由は、本文が依頼文に漏れた草稿では測定が膨らむからである。本文の書き出しをそのまま
依頼文に使うと、基準値が 28 ポイント膨らんだ例がある（[Sawant](../references/authorship-gap-2026.md)）。
kakiburi は書かせる側を持たないので、漏れたかどうかを知る方法も、漏れを防ぐ方法も無い。
だから訊く。

> 手本を見せること自体の効き目は、そこまで大きくない。手本を見せた場合の一致は 0.508 で、
> [他人どうしの床 0.626](010-strategy.md#書かせることはしない)を下回っている。それでも
> 訊くのは、漏れたかどうかをこちらが知りようがないからである。

申告は 3 値で受け取る。「見せた / 見せていない」の 2 値にはしない。

| | 何を意味するか | 判定への効き方 |
| --- | --- | --- |
| 渡していない | 依頼文に本人の文章を含めていない | そのまま判定する |
| 渡した | 手本・書き出し・過去記事などを含めた | 値は出し、判定に但し書きを添える |
| 分からない（既定） | 草稿の作られ方を知らない | 同上 |

既定は「分からない」である。申告が無いことを「渡していない」と読んではいけない。そう
読むと、いちばん膨らみやすい草稿が、いちばん問題の無い草稿と同じ扱いで通ってしまう。

「渡した」「分からない」でも「判定できない」にはしない。渡したかどうかは値をどう読むか
の問題であって、値が出せない理由ではないからである。これを「判定できない」に落とすと、
[判定できないと言えること](010-strategy.md#届かないときは判定できないと言う)の意味が
薄まり、本当に判定できないときの重みが下がる。

「渡した」と「分からない」のときは、3 値のどれを返す場合も但し書きを添える。「通る」の
ときだけに添えるのではない。「通らない」も「判定できない」も、膨らんだかもしれない値の
上に出ているからである。

> 但し書きの中身は次のとおりである。「本人の文章を見せて書かせた草稿では測定が膨らむ。
> この値が膨らんでいないことは確かめられていない」。但し書きを省いて返すことはしない。

但し書きは、人向けの出力では stderr に「但し書き: 」を頭に付けて出す。道具向けの出力
（JSON）では、申告を `own_writing` に、添えた但し書きを `own_writing_caveat` に入れる。
「渡していない」のときは `own_writing_caveat` を null にする。stderr にだけ出すと、JSON
だけを読む道具に但し書きが届かず、省いて返したのと同じになる。

申告の受け取り方は[コマンド](../design/200-command.md#草稿の作られ方を訊く)が決める。
真偽の 2 値で受け取ってはいけない。2 値にすると「渡していない」と「分からない」が同じ形
になり、既定を「分からない」に置いた意味が消える。

## 何を見るか

書きぶりだけを見るのではなく、次の次元を見る。文体・内容・自然さの間には trade-off が
あり、文体に強く寄せるほど内容が壊れ、日本語として不自然になるからである
（[文体転換の評価](../references/tst-evaluation.md)）。

| 次元 | 何を見るか | 何で測るか |
| --- | --- | --- |
| 書きぶり | その人の書きぶりが出ているか | [系統](../glossary.md#系統)を[照合値](200-extract.md#何を目盛りに載せるのか)にして目盛りへ載せる |
| 書きぶり | どこが外れているか | [指示できる指標](../glossary.md#指示できる指標)が本人の[幅](../glossary.md#幅)に入っているか |
| 人らしさ | 機械の書きぶりが残っていないか | [人らしさの指標](200-extract.md#人らしさの境目は同じ材料から出る)（圧縮率・短い繰り返し・長い繰り返し・語彙の豊富さ・エントロピー・句読点の密度） |
| 題材 | 書くべきことが保たれているか | 元の草稿との対照 |
| 日本語 | 読める文になっているか | — |

書きぶりが 2 行あるのは、働き方が違うからである（[指標](100-metrics.md#指標の種類)）。
系統（多数の次元をまとめて見る指標）は距離で全体の判定を作り、指示できる指標（1 つの数で
表せて直し方を言える指標）は幅で外れを出す。どちらも判定に使う。

人らしさも判定に使う。[味が出るには 2 つの条件が要る](010-strategy.md#味が出るには-2-つ要る)
ので、書きぶりが幅に入っていても、機械が書いたと分かる文章は通さない。

題材が保たれていることは、書きぶりを比べるための前提である
（[書きぶりの性質](010-strategy.md#書きぶりとは何か)）。見ていなければ、前提が成り立って
いるかどうかも分からない。

> [!WARNING]
> 題材と日本語の測り方は、まだ決まっていない。素直に作れば LLM に読ませることになるが、
> それは[数える側に LLM を置かない](010-strategy.md#数える側に-llm-を置かない)に反する。
> <strong>決まるまで、この 2 つは判定に混ぜない。</strong> 混ぜたことにして先へ進むと、壊れた
> 目盛りの上に全部が建つことになる。

## 全体の判定は 3 値で返す

### 目盛りに載せる

照合値は[天井と床](200-extract.md#目盛りを作る)に載せて読む。天井は本人の文章どうしの
照合値が取る範囲、床は素の機械の文章（[基準](../glossary.md#基準)）の照合値が取る範囲で
ある。点数だけでは、0.5 が近いのか遠いのかが決まらない。比べる先が要る
（[Sawant](../references/authorship-gap-2026.md)）。

読み方は[帯の規則](200-extract.md#帯は2-つの分布の重なりである)が決める。
[帯](../glossary.md#帯)は天井と床のあいだの、どちらとも言えない区間である。規則は両端を
見るので、2 つの分布が分離していても重なっていても、同じ規則で 3 値が出る。ここで改めて
場合分けはしない。

無理に判定はしない（[決定](010-strategy.md#届かないときは判定できないと言う)）。帯を狭め
れば「判定できない」は減るが、間違った判定が増える。

### 種別を合わせて「通る」を出す

判定は、種類の違う値を下の表の順に当てて出す。返す値が決まった段で終わる。照合値だけでは
足りない。[味が出るには 2 つ要る](010-strategy.md#味が出るには-2-つ要る)以上、人らしさが
落ちていれば通らないし、指示できる指標も判定に使う（[指標](100-metrics.md#指標の種類)）。

| | 見るもの | 出る値 | 返す |
| --- | --- | --- | --- |
| 0 | 書き方 | 成立していない | 通らない |
| | | 成立している | 次へ |
| 1 | [人らしさ値](../glossary.md#人らしさ値) | 機械の書きぶりが残っている | 通らない |
| | | 判定できない | 判定できない |
| | | 人 | 次へ |
| 2 | [照合値](../glossary.md#照合値) | 床側 | 通らない |
| | | 帯の中 | 判定できない |
| | | 天井側 | 次へ |
| 3 | 指示できる指標 | [前に出す指標](#前に出す指標)が 1 本も無い | 判定できない |
| | | 幅の外にあるものがある | 判定できない |
| | | 全部が幅の中 | 通る |

各段の意味は次のとおりである。

- 0 段目は、日本語として壊れていないかを見る（[下](#日本語として成立しているかをいちばん先に見る)）。
- 1 段目は、機械の癖が残っていないかを 1 つの数（人らしさ値）で見る。
- 2 段目は、草稿が本人の書いたものに見えるかを 1 つの数（照合値）で見る。
- 3 段目は、言葉で直せる個々の指標が本人の幅に入っているかを見る。

#### 床が 2 本あるとき

この節は、[他人の床](200-extract.md#他人の床は実装していない)を置いたときの読み方である。
他人の床は実装していないので、いまの 2 段目は LLM の床の 1 本の帯だけを読む。他人を
渡しても、較正に足されるだけで床は増えない。

他人の床を置けば、2 段目の帯が 2 本になる。その場合は 2 本を 1 つの値に畳んでから、上の表の
2 段目に入れる。

| | 2 段目に渡す値 |
| --- | --- |
| どちらかの床を超えていない | 床側 |
| どちらかの帯の中にいる | 帯の中 |
| 両方の床を超えた | 天井側 |

畳み方は[評価](200-extract.md#他人の床は実装していない)が決めている。ここで場合分けを
作り直さない。床が 1 本のときは、その 1 本をそのまま読む。表の形は変わらない。

#### 段の順序の理由

0 段目と 1 段目が先にあるのは、どちらも欠陥を見る段だからである。目的は
[その人の味が出ている](000-axis.md#やりたいこと)ことで、それを見るのは 2 段目と 3 段目で
ある。0 段目と 1 段目は、その手前で取り除いておくものを見る。日本語が壊れていれば味を
問う以前の問題であり、機械の書きぶりが残っていれば、その人の書きぶりが入る余地が無い。

1 段目は目標ではない。人らしさ値が高いこと自体に価値は無く、
[代理として使っているだけ](010-strategy.md#味が出るには-2-つ要る)である。そのため、1 段目で
止まったときも目的の側の言葉は出す。具体的には、[型](#使われていない型を渡す)（本人がよく
使う言い回し）は、どの段で止まっても渡す。伏せると、目的について道具が何も言わないまま
止まってしまう。

1 段目と型の向きは衝突しない。1 段目は「同じ言い回しを繰り返せ」と言い、型は「本人は
こう書く」と言う。型を使えば繰り返しも増えるので、同じ方向を指している。

#### 3 段目が「判定できない」を返す理由

3 段目は、幅の外にある指標があっても「通らない」ではなく「判定できない」を返す。3 段目に
来た時点で照合値は天井側にあり、系統で見るかぎり本人の範囲に入っている。それを覆して
「通らない」と言えるだけの根拠は、細く切った 1 つの指標には無い。一方で、黙って通すことも
しない。言えることがある以上、それを指摘として言い、次の周回へ回す。

#### 前に出す指標

3 段目で見るのは、指摘に出せる指標だけである。この集合を「前に出す指標」と呼び、ここで
1 度だけ定める。

> [効くと判定された指標](200-extract.md#どの指標が効くかを決める)から、
> [層 3](100-metrics.md#層-3系統に遡れないもの)と、指示して動かないと分かっているものを
> 除いたもの。

判定も指摘も、この同じ集合から取る（[指摘の選び方](#指摘は-3-本か-4-本に絞る)）。別々に
定めると、判定を止めた理由が指摘に出てこない、という食い違いが起きる。

理由を言えないもので判定を止めることはしない。止めておいて理由を言えなければ、受け取った
側は何もできないからである。

#### 前に出す指標が無ければ、判定できない

前に出す指標が 1 本も無ければ、3 段目は「判定できない」を返す。理由は「この書き手には効く
指標が無い。その人らしさを指標で確かめられない」である。

空の集合は「全部が幅の中」を必ず満たす。そのまま進めば、その人らしさを 1 本も確かめて
いないのに「通る」が返る。この書き手では、数えた量で本人が分かれるという
[軸の仮説](000-axis.md#外れたら分かるようにしてある)が確かめられなかったのである。

空であることと、測れていないことは別である。前に出す指標はあるが、この草稿ではどれも
[除外](100-metrics.md#除外の既定)に掛かって測れなかった、という場合は空ではない。飛ばす
のは個々の指標だけなので（[下](#段が測れないとき)）、残りが全部幅の中なら「通る」を返す。

#### 段が測れないとき

段そのものが測れなければ、「判定できない」を返す。

| 測れていないもの | 返す |
| --- | --- |
| 人らしさ値 | 判定できない。読みづらさの元を確かめずに先へ進めない |
| 照合値 | 判定できない（[系統が欠けたとき](200-extract.md#系統が-1-つでも欠けたら照合値を出さない)） |

飛ばしてよいのは、3 段目の中の個々の指標だけである。[除外](100-metrics.md#除外の既定)に
掛かった指標を、幅の中とも外とも扱わない、という意味である。段そのものを飛ばすことは
しない。

#### 止めた理由を返す

どの段で止まったかを必ず返す。言わなければ、受け取った側は照合値を上げようとして人らしさ
を下げる、という逆向きの直し方をしかねない。

### 日本語として成立しているかを、いちばん先に見る

0 段目は[検査](100-metrics.md#検査は書きぶりではなく壊れ方を見る)である。検査は、和文の間
に空白が入っていないかのように、日本語として壊れていないかを見る指標である
（[用語集](../glossary.md#検査)）。1 本でも線を超えていたら、そこで「通らない」を返す。

1 段目より先に置く理由は 2 つある。日本語として成立していないものを、文体が似ているか
どうかで測っても意味が無い。そして、先に置かなければ壊れた文章が通ってしまう。照合値は
壊れた書き方でも上がるからである。

この段はカセットを見ない。日本語として成立しているかは書き手の性質ではないので、比べる
先は本人の幅ではなく、指標の定義ファイルが持つ固定の線である。

#### 道具が出した指示には、それを満たす壊し方がある

0 段目を置く一番の理由はこれである。ほかの段は「その人と違う」を見ているが、この段は、
道具自身の指摘が生んだ抜け道を塞いでいる。

> 経緯：[文字種](metrics/文字種.md)の空白を増やせという指摘を出したところ、直す側が和欧間
> だけでなく和文間にも空白を入れた。`複数の リポジトリ を扱う` のような文である。
>
> | | 照合値 | 判定 |
> | --- | --- | --- |
> | 和文間に 111 箇所の空白を入れた草稿 | 2.911 | 通る |
> | その空白を取り除いた同じ草稿 | 2.632 | 判定できない |
>
> 通った分は、壊れた空白が稼いでいた。指標は上がり、日本語は壊れ、道具はそれを通した。

この段では指摘を出さない。止めた理由がそのまま直し方になっており、「和文間の空白を取り
除く」以外に選ぶ余地が無いからである。これは[理由を言えないもので止めない](#種別を合わせて通るを出す)
に反しない。止めた理由は言えている。

### 組み合わせで決める

1 つの指標だけで判定しない。単一の点数は騙せることが報告されている（Krishna et al. 2020、
[SPTG の評価](../references/sptg-evaluation-2025.md)経由）。

違う原理の指標を混ぜたときがいちばん当たる（[決定](010-strategy.md#種類の違うものを混ぜるただし-5-系統前後まで)）。
正解率が同じでも判断が 35% 食い違う組み合わせがあり、そういう組み合わせにこそ足す価値が
ある（[SPTG の評価](../references/sptg-evaluation-2025.md)）。

反対に、同じ現象を 3 通りに測ったものは 1 つと数える。どれを何本入れるかは
[評価](200-extract.md#判定に使う系統を選ぶ)が決める。

LLM による判定は混ぜない。SPTG の最良の組み合わせには LLM の判定が入っているが、kakiburi
は使わない（[決定](010-strategy.md#数える側に-llm-を置かない)）。

### 埋め込みを使うなら、較正で確かめる

この節は、埋め込みを使うと決めたときの話である。[埋め込みは当面使わない](100-metrics.md#埋め込みは保留する)。

埋め込みの重みは、手で小さく置くのではなく較正に決めさせる
（[評価](200-extract.md#何を目盛りに載せるのか)）。ここで言えるのは予測である。較正すれば
重みは小さく出るはずであり、大きく出たら、較正か基準の作り方を疑う。

小さく出ると予測する理由は次のとおりである。埋め込みは、同じ依頼から作った 2 つの文章を
比べる場面で崩れる。内容が同じなので区別できず、性能が 38.3% 落ちる
（[SPTG の評価](../references/sptg-evaluation-2025.md)）。kakiburi の床は「同じ依頼で LLM に
素で書かせたもの」なので（[評価](200-extract.md#目盛りを作る)）、まさにその場面にある。

### 当てにならないときは言う

その場面の文章が十分に集まっていないときは、判定を断る。「判定できない」を返し、その場面の
素材が足りないと伝える。集めた文章が少なければ、幅も目盛りも当てにならないからである。

近い場面の素材で代用する道は、いまは取らない。場面をまたいでも一貫すると確かめられている
のは品詞 unigram と読点の打ち方だけで、文字・記号の unigram と文節パターンは場面によって
大きく動く（[柳・金 2022](../references/yanagi-jin-2022.md)）。そのうち品詞 unigram は
kakiburi の指標の集合に無い。[品詞 bigram](metrics/品詞bigram.md) は別物である。

残る読点の打ち方 1 つだけでは[照合値が作れない](200-extract.md#判定に使う系統を選ぶ)。
場面の分類をまたいで取ることも、較正することもできない。

> [!NOTE]
> この道を通したいなら、品詞 unigram を指標の集合に足すところから始めることになる。
>
> この 2 つを「弱い指標」と決めつけることはできない。同じ論文の実験 II では品詞 unigram
> 0.8779・読点の打ち方 0.8236 で下位に来るが、実験 III では読点の打ち方が単独で最良
> （0.8160）である。順位は実験によって入れ替わる。意味があるかは、測ってから決める。

## 指摘を作る

### 外れを出す

指標ごとに、値が幅の外にあるかを見る。上に外れる場合と下に外れる場合の両方を見る。どちら
を見るかは指標の定義に書いてある（[指標](100-metrics.md#定義に落とす)）ので、ここで指標
ごとに場合分けはしない。

両方を見るのは、書きぶりは幅であって上限ではないからである。上だけを見ると、指摘を消そう
とする側は削る方向にばかり直すことになる。

判定のときも指標の定義を順に回す。測った値と幅は指標の名前で突き合わせるので、
[名前が 1 か所にしか無いこと](100-metrics.md#名前は-1-度しか書かない)がここで効く。

### 指摘は 3 本か 4 本に絞る

外れた指標を全部並べることはしない（[決定](010-strategy.md#一度に渡すのは-3-本か-4-本)）。
[前に出す指標](#種別を合わせて通るを出す)のうち、外れの大きい順に上位を取り、最大 4 本まで
渡す。

4 本は上限であって、目標ではない。外れている指標が 4 本に満たなければ、その本数で渡す。
空いた枠を埋めるために、外れていない指標を混ぜることはしない。3 本と 4 本を選び分ける条件
も置かない。[枠の本数は独立な指示の本数ではない](010-strategy.md#一度に渡すのは-3-本か-4-本)
ので、3 と 4 の差を決める根拠が無いからである。

並べ方は次の 1 つに決める。上の鍵から順に比べ、差がついた時点で止める。

| | 鍵 | 向き |
| --- | --- | --- |
| 1 | 外れの大きさ | 降順 |
| 2 | 切り口そのものを調べた研究があるか（[指標](100-metrics.md#直接だけを名乗らせる)） | `直接` が先 |
| 3 | 指標名 | [Unicode の符号位置の昇順](200-extract.md#外れの大きさは幅を-1-とした倍数である) |

2 番目の鍵を入れるのは、裏付けの濃い指標から先に出すためである
（[指標](100-metrics.md#指示できる指標は系統の細い切り口である)）。

`直接` かどうかは、指標の定義ファイルから読む。「## 出どころ」の節の、空行を除いた最初の
行がちょうど `直接。` であれば `直接` である。それ以外はすべて拡張として扱う。出どころの
説明文から読み取ることはしない。読み取らせると、並び順が読み手ごとに変わる。

3 番目まで決めておくのは、2 番目までで決まらないことがあるからである。技術記事では絵文字も
感嘆符も笑いも幅 0 になりうるので、外れの大きさが並び、しかもどれも拡張の指標である。そこで
止めると、上位 3〜4 本が実装ごとに変わり、[決定性](../design/300-test.md#決定性)が落ちる。

[評価](200-extract.md#外れの大きさは幅を-1-とした倍数である)に書いてあるのは、この表の
1 番目と 3 番目である。順序の規則はここに 1 つだけ置き、2 か所に別々の規則を置かない。
3 段目が「判定できない」の理由として名指しする指標も、指摘の先頭も、この同じ並びから
取る。並べ方を 2 つ持つと、判定が「最も外れている」と名指した指標と、指摘の先頭が
食い違いうる。

[外れの大きさ](../glossary.md#外れの大きさ)は、その人の幅を単位にして測る。下端を
[出現割合](200-extract.md#下限は使った割合で見る)で見る指標では、その割合を
[幅の単位に直したもの](200-extract.md#出てこないことの大きさを幅と同じ単位にする)を大きさと
する。割合をそのまま並べることはしない。割合の上限は 1.0 なので、「出てこない」ことがいつ
までも上位に来なくなる。

指示して動かないと分かっている指標は、枠から外す
（[効く指標の条件](200-extract.md#どの指標が効くかを決める)）。動かないものに枠を使えば、
動くものが押し出される。[層 3](100-metrics.md#層-3系統に遡れないもの)も同じ理由で枠に
入れない。

人らしさはこの枠に数えない（[指標](100-metrics.md#指標の種類)）。3〜4 本という上限は
書きぶりの側の話であり、人らしさの指摘は[別に立てる](#人らしさの直し方は書き直しに戻ることがある)。
同じ枠を奪い合わせると、機械臭さを消す指示と、その人へ寄せる指示が席を取り合う。

> 背景：外れの大きい軸を上から選ぶ方法は、書き手を隠す側の研究で検証されている。著者
> ベクトルと平均の差の絶対値で上位 k 軸を選ぶと、同じ本数を無作為に選ぶより 6% 良い
> （[StyleRemix](../references/styleremix-2024.md)）。kakiburi はそれより多くを知っている。
> その書き手が普段どこにいるかだけでなく、この文章がどこにいるかも測れている。だから選ぶ
> 基準は「その人で際立つ軸」ではなく「この文章で外れている軸」になる。

### 直せる形にする

指摘は、次の 3 つを揃えて渡す。外れた指標の名前と数値だけでは直せない。

| | 軸のどこに対応するか |
| --- | --- |
| 観測。この文章ではどうだったか | どこが |
| 直し方。どちらへ、どうすればよいか | どちらへ |
| 普段。その人はどこからどこまでで書いてきたか | どれだけ |

直し方は指標の定義から取る（[指標](100-metrics.md#定義に落とす)）。指摘を出す側で書くと、
指標を足したときに直し方の無い指摘が出てしまう。

普段は、判定に使った見方のまま言う。下端を[出現割合](200-extract.md#下限は使った割合で見る)
で見た指標では、何割の単位で使ってきたかを普段として言う。これを「どこからどこまで」で
言うと、文面がそれ自体で矛盾する。出てこなかったことを外れとしたのに、その指標の幅の下端
は 0 なので、「0 になっている。普段は 0 から N の範囲」と読めてしまう。受け取った側は
「範囲の中ではないか」と考えて直さない。

### 使われていない型を渡す

カセットが持つ[型](../glossary.md#型)のうち、この文章に現れないものを最大 4 本渡す。型とは、
本人がよく使い、基準は使わない言い回しである（[その人の型](200-extract.md#その人の型を取り出す)）。

理由は、その人の型が 1 つも出てこない文章は、分布が本人に寄っていてもその人らしくない
からである。照合値は頻度のベクトルの距離なので、繰り返し使う語の並びはその中に均されて
消え、照合値からは見えない。

渡し方は次のとおりである。

- 何割の記事で使っているかを添える。「本人はこう書く」だけでは、それがその人の癖なのか、
  一度きりの言い回しなのか、受け取った側には分からない。
- 使う位置が偏っていれば、どこで使うかまで言う。書き出しにしか現れない型を「どこかで
  使え」と渡せば、受け取った側は文中に挿しこむ。
- 指摘の枠は奪わない。[3〜4 本](#指摘は-3-本か-4-本に絞る)は書きぶりの指標の話であり、
  型はそこに数えない。奪い合わせると、その人の型を渡す席と、幅から外れた指標を渡す席が
  取り合いになる。

型は、どの段で止まっても渡す（[段の順序の理由](#段の順序の理由)）。<strong>通ったときにも
渡す。</strong> そこで黙れば、道具は「通った」としか言わないまま、その人らしくない文章を
返すことになる。

[機械の型](200-extract.md#機械の型を取り出す)と[機械の語](200-extract.md#機械の語を取り出す)
も、どの段で止まっても渡す。機械の言い回しが残っていることは、人らしさの段で止まった理由
そのものでありうる。この 2 つは、この文章に出ているものを、この文章に出た回数の多い順に
最大 4 本ずつ言う。基準での割合は、回数が並んだときの決め手にしか使わない。基準の割合だけで
並べると、誰でも書く並びが、その機械の癖を押し出す。

> 経緯：実測で、基準の 44% が使う「ことがあり」が、11% しか使わないが草稿では 4 回出ている
> 「地味に」を隠していた。癖は 1 度ではなく何度も出る。

機械の型には、草稿の中で出ている箇所の前後を添えて「言い換える」と言う。機械の語には
箇所を添えず、代わりに本人が同じ品詞でよく使う語を添える。語形が変わるので、語彙素を
そのまま探しても直す場所に当たらないからである。どちらも、本人がその言い回しを使わないのか、
たまに使うのかを言い分ける。選ぶ条件は本人側の割合に上限を置いているだけなので、言い切れば
自分の文章に現に在る言い回しを無いと言うことになる。

### 本人の癖は、判定を止めずに知らせる

[本人の癖](200-extract.md#一貫しているだけの指標は本人の癖として知らせる)（本人の幅は狭いが
基準とは離れていない指標）が幅の外にあれば、知らせとして出す。並べ方と本数の上限は
[指摘](#指摘は-3-本か-4-本に絞る)と同じである。判定には使わない。

2 段目か 3 段目で止まったときだけ出す。その人へ寄せるための知らせなので、人らしさの段で
出すと、受け取った側は 2 つの目的を同時に追うことになる。型は人らしさの段でも出すが、それは
型を使えば繰り返しも増え、人らしさの直しと[同じ向きを指す](#段の順序の理由)からである。
本人の癖にはそれが言えない。

### 一人称は別に見る

一人称は、型とも語とも別の口で見る。どの一人称を選ぶかは、既にある口のどれにも載らない
からである。

| 口 | なぜ落ちるか |
| --- | --- |
| [型](#使われていない型を渡す) | 枠の数だけ採る。実測で `僕は` は出現割合 0.35 で枠から落ちた |
| 語 | 形容詞・形状詞・副詞しか見ないので、代名詞が入らない |
| [機械の語](#使われていない型を渡す) | 基準の側から選ぶ。実測で基準 44 本の `私` は 3 本（7%）で床を割る |

規則は次のとおりである。

> 本人がいちばん多く使う一人称を持つ。草稿がそれと違う一人称を使っていて、その一人称を
> 本人が、本人のいちばん多いものの半分未満でしか使わないなら、そう言う。

一人称は閉じた集合なので、別に見ることができる。名詞と動詞を語から外したのは
[題材が決めるから](200-extract.md#その人の型を取り出す)だが、一人称はどの題材でも同じもの
を選ぶ。そして問われるのは、使うか使わないかではなく、どれを選ぶかである。開いた品詞と
違い、選ばれなかったことがそのまま癖になる。

本人が使わない一人称だけを言うのでは狭すぎる。本人は `私` も使うことがあるが、選んでいる
のは `僕` である。

> 経緯：実測で、本人 49 本のうち `僕` が 28 本（57%）、`私` が 5 本（10%）だった。基準
> 44 本に `僕` は 1 度も出てこない。

一人称が 1 つも出てこない文章には言わない。主語を置かない文章はふつうにあり、実測で本人
自身が 49 本中 21 本でどの一人称も使っていない。

判定には使わない。その題材でだけ別の一人称を選ぶことはありうるからである。これは
[知らせ](../glossary.md#知らせ)として出す（[下](#判定を止める指摘と止めない知らせを分ける)）。

> 照合では一人称を使わない。Delta では[人称代名詞を除くと精度が上がる](../references/burrows-delta.md)。
> 小説の語り手や登場人物を拾ってしまうからである。ここは指摘の口であって、書き手の分類
> ではない。

### 書き出しの構造は、密度でも語の位置でも言えない

文章がどの種類の node（段落、見出しなど）で始まるかを、一人称と同じ形の別の口で見る。
どの種類で始めるかは書き手の癖だからである。実測で、本人 49 本のうち 46 本（93%）が段落で
始まるのに対し、基準 44 本では 31 本（70%）が見出しで始まった。

規則は[一人称](#一人称は別に見る)と同じ形である。

> 本人がいちばん多く使う始め方を持つ。草稿がそれと違う種類で始まっていて、その種類を
> 本人が、本人のいちばん多いものの半分未満でしか使わないなら、そう言う。

閉じた集合のうちどれを選ぶかの問題なので、選ばれなかったことがそのまま癖になる。

既にある口では、これは言えない。

| 口 | なぜ言えないか |
| --- | --- |
| [見出し](metrics/見出し.md) | 1,000 字あたりの本数である。見出しが 1 番目にあっても 3 番目にあっても同じ値になる |
| [型の位置](200-extract.md#どこで使うかも持つ) | 語の位置である。挨拶の前に見出しを 1 本挟んでも 0.000 が 0.02 になるだけで、どちらも「書き出しで」と読まれる |
| [幅](#外れを出す) | 本人の単位の最小〜最大なので、3 本が見出しで始まっていれば幅は 0 と 1 の両方を含み、何も外れない |

なかでも重要なのは最後の行である。「出てこないこと」を言うために
[出現割合の見方](200-extract.md#下限は使った割合で見る)を別に置いたのと同じ理由で、その
裏返し、つまり「本人はほとんどしないのに、この文章はしている」も幅では表せない。

この口の出どころは、挨拶の型である。[Stamatatos §2.5](../references/stamatatos-2009.md) が
挙げる構造的特徴（段落長、字下げ、挨拶や結びの型）のうち、書き出しが挨拶か見出しかは
これに直接当たる。

判定には使わない。その題材でだけ別の始め方をすることはありうるからである。

> 注意：素材の側が正しく取り込まれていなければ、この口は正しく出ない。はてなの取り込みが
> ページタイトルを本文の見出しとして入れていたため、同じ書き手の記事が媒体ごとに違う
> 始まり方をしていた。zenn は 8 本すべてが段落、はてなは 41 本すべてが見出しである。
> そのままでは、書き手ではなく媒体を測ることになる。

### 繰り返せと言うなら、上限も言う

草稿が繰り返している言い回しを全部、本人の上限と照らし、本人より濃く使っているものを
指摘に出す。「その人が現に繰り返している言い回しを繰り返せ」とだけ言って、どこまで繰り
返してよいかを言わなければ、受け取った側は本人の何倍も入れるからである。

> 経緯：本人が 42 本の記事で 25 回しか使わない「ことができます」を、直した 1 本に 11 回
> 入れた例がある。1,000 字あたりにすると、本人の上限 0.3 回に対して 2.1 回で、7 倍である。

これは[検査](100-metrics.md#検査は書きぶりではなく壊れ方を見る)では止まらない。日本語と
しては壊れていないからである。本人の頻度と比べるしかない。

上限は次のように持つ。

- 言い回しごとに上限を持つ。上限は、本人の単位での、日本語 1,000 字あたりの最大である。
- 草稿がその上限に倍率を掛けた値を超えたら、回数と本人の上限を添えて指摘に出す。
- 倍率は 1.0 で、暫定値である。本人が一度も書かなかった濃さなら外である、とする。指示
  できる指標が本人の幅で見るのと揃えてある。

> 経緯：倍率を 2.0 にしていたときは捕まらなかった。本人の上限 1.9 に対し、使いすぎた草稿が
> 2.6 だった。超えてはいるが、2 倍には遠い。

1.0 で誤って言う率は確かめられていない。本人の最大はその人が実際に書いた 1 点でしかなく、
次の 1 本がそれを少し超えることはありうる。しかも上限は本人の全単位から作るので、そのうちの
1 本を当てても原理的に超えない。本人の記事を当てて 1 本も誤らなかったとしても、その結果は
循環していて証拠にならない。確かめるには、上限を作るときに使わなかった本人の記事
（取り置き）で数える必要がある。

道具が勧めた言い回しだけを見てはいけない。受け取った側は、勧められていない言い回しでも
足す。人らしさを通すには語尾を揃えるのがいちばん安い手だからである。勧めた分だけを見て
いると、受け取った側が自分で足した語尾を誰も見ないことになる。

> 経緯：本人が 49 本中 6 本でしか使わない語尾を、直した 1 本に 6 回入れた例がある。渡した
> 言い回しではなかったので、道具は何も言わなかった。
>
> これは機械の言い回しとしても拾えない。機械の側の言い回しとして名指しする口もあるが、
> そちらは基準の一定割合以上が使うものしか名指しできず、この語尾は基準 44 本のうち 1 本
> にしか出てこない。しかも本人も使う。問題は語そのものではなく、濃さである。

上限 0 のもの、つまり本人が使わない言い回しは、この口では言わない。草稿が繰り返している
並びの多くは題材の語なので、本人が使わない並びをすべて挙げれば、指摘が題材の語で埋まる。
この口が言えるのは、本人が使う言い回しを本人より濃く使っていることである。

> 本人が使わない言い回しは、別の口（機械の型と機械の語）が名指しする。この 2 つは基準の
> 側から選ぶので題材の語が混ざらない。見分けが付くのはそこだけである。

上限の表は、カセットを作るときに畳んでおく。検めるまで、どの言い回しを訊かれるかは決まら
ないが、カセットは[本文を持たない](200-extract.md#本文を持たない)ので、検めるときに数え直す
ことができないからである。2 つ以上の単位に現れる言い回しだけを持てば足りる。1 つにしか
出てこないものは上限がほぼ 0 で、表に無いのと同じ扱いになる。

判定には使わない。その人がたまたま多く使う 1 本はありうるからである。

> これは、道具が自分の指摘を検める仕組みである。「繰り返せ」と言ったのは道具の側なので、
> 行きすぎたかどうかも道具が言えなければ、周回（直して測り直す繰り返し）が閉じない。

### 判定を止める指摘と、止めない知らせを分ける

判定に使わない知らせは、判定を止める指摘と見出し 1 本で分けて出す。止めない知らせの手前に、
それが判定に使っていないことと、直すかどうかは書き手が決めることを書く。

分けるのは、同じ画面に並べると矛盾して見えるからである。[本人の癖](#本人の癖は判定を止めずに知らせる)、
[使われていない型](#使われていない型を渡す)、機械の型、機械の語、
[使いすぎ](#繰り返せと言うなら上限も言う)は判定に使わないが、どれも幅の外や本人との違いを、
判定を止める指摘と同じ形で言う。値も向きも同じ形で出ているので、読む側には、どちらが判定
を決めたのかを見分ける手がかりが無い。

> 経緯：「前に出す指標がすべて幅の中にある」と書いた真下に「鉤括弧が幅の外にある」が並ぶ
> 出力が、実際に出た。

但し書きは口ごとに付けず、見出しの 1 か所にまとめる。同じ文を口ごとに並べると、口を足した
ときに 1 か所だけ古くなる。

知らせを消すことでは解決しない。判定を止めないからといって出さなければ、道具は「通った」
としか言わないまま、[その人らしくない文章を返す](#使われていない型を渡す)ことになる。

### 散文で渡す

指摘は表にせず、散文で渡す。ただし数値は落とさない。

散文にする主な理由は、成功している例が散文だからである。人の文章と機械の文章の差を LLM に
記述させ、その記述をそのままプロンプトに置く手順で、読みやすさも課題達成率も人間並みに
なっている（[SICO](../references/sico-2024.md)）。

構造化した形を求めると成績が落ちる、という報告もある
（[SPTG の評価](../references/sptg-evaluation-2025.md)）。ただしこの証拠は弱い。モデル 1 つ、
64 件で、しかも両条件とも偶然を下回る比較である。

数値を落とさないのは、次の周回でも同じ値で照らすからである。丸めたり言い換えたりして情報
を落とせば、指示と判定がずれる。散文にするのは言い方であって、根拠の値ではない。

### 人らしさの直し方は、書き直しに戻ることがある

1 段目（人らしさ値）で止まったときは、人らしさの直し方を渡す。指摘が組まれるのは 3 段目
だけなので、ここで何も出さなければ、機械の書いた草稿は止められるだけで直せない。道具が
いちばん使われる場面で、出力が空になる。

渡し方は次のとおりである。

- 合算した 1 つの値では渡さない。それでは「機械の側にある」としか言えず、どこをどうすれば
  よいかが出てこない。[人らしさの指標](../glossary.md#人らしさの指標)ごとの値で、機械の
  側に落ちているものを名指しする。
- 寄せる向きは[較正が決める](200-extract.md#寄せる向きはこの較正が決める)。指標の定義には
  どちらの動かし方も書いておき、どちらを使うかは較正から読む。
- 文面は「{指標}の人らしさが本人より{低い／高い}（この文章 x / 本人 y）。{直し方}人らしさ値が
  ±e 動く。」とする。x と y はその指標だけで見た人らしさで、y は本人の単位の中央値である。
  e は、その指標だけを本人の値に置き換えて合算し直したときの人らしさ値の変化である。
- 並べる値は指標の量ではなく人らしさなので、「人らしさが」と書く。「句読点の密度が本人より
  足りない」と書けば、続く「読点を減らす」と食い違って読める。
- 文面を直す指摘とは別に、推論設定の直し方を伝える。「この設定で書き直させる」という形で
  ある。kakiburi は書かせる側を持たないので、設定を変えることはできず、直し方として伝える
  ことしかできない。
- 指摘の枠は奪わない。3〜4 本という上限は書きぶりの側の話であり、人らしさはそこに数えない
  （[指標](100-metrics.md#指標の種類)）。混ぜれば、機械臭さを消す指示とその人へ寄せる指示が
  席を取り合う。

向きを定義に固定しないのは、固定すると直し方に従うほど人らしさが下がることがあるからで
ある。先行研究は、人の文章は繰り返しでできており、機械の文章は語彙が散りすぎて繰り返せない
と言う（[Zeng & Nini](../references/zeng-nini-2026.md)）。だが、その向きが成り立つかは基準の
作り方による。同じ型で書かせた生成文は、人より語彙が散らず、短い言い回しを人より多く繰り
返すことがある。

推論設定で直せるのは、繰り返しの量が設定で動くからである。上の実験は温度も頻度ペナルティも
既定値のままだったと、論文自身が認めている。頻度ペナルティを動かせば、繰り返しの量は変わる。

## 回す

### 直したら測り直す

直した文章をもう一度測る。同じ値と同じ目盛りを使っているので、指示どおりに直せば数値は
寄るはずである。

指摘が通じたかは、指摘が名指しした指標で見る。照合値では見ない。

| 何が動いたか | 何が分かるか |
| --- | --- |
| 名指しした指標が動いた | 指摘は通じた |
| 名指しした指標が動かない | [効く指標の条件](200-extract.md#どの指標が効くかを決める)に返す |
| 指標は動いたが照合値が動かない | 効く指標の条件には返さない。理由は下のとおり |

この 2 つを混ぜてはいけない。混ぜると、正しく通じた指摘を「動かない」として落とすことに
なる。

照合値は、1 つの系統の中の 1 つの切り口の変化には鈍い。系統は多くの次元を持ち、1 つの切り口
が動いても、その分は全体の中で薄まる。したがって照合値が動かないことは、指摘の失敗ではない。
3〜4 本の指摘を 1 周入れただけで照合値が帯を越えることは期待しない。そもそも 1 回で通る
ことは期待しない（[ループ](010-strategy.md#使うときはループになる)）。

> 経緯：読点を 40 個から 29 個へ減らし、読点の直前の最頻文字を 22% から 0% にしても、
> [読点の打ち方](metrics/読点の打ち方.md)の距離は 1.7% 動くだけで、照合値は床から天井までの
> 0.9% しか動かなかった。系統が 50 次元あり、読点が 40 個しか無ければ、ほとんどの次元は
> 0 のままで、動いた分が薄まる。

#### 周回を繋ぐものを決める

周回（直して測り直す 1 回分）は、記録として繋ぐ。[効く指標の条件](200-extract.md#どの指標が効くかを決める)
のうち「指示して動くか」は、周回のあいだに起きたことからしか出ないからである。測り直した値
だけでは出ず、何を指摘して、その結果どうなったかの対応が要る。

繋ぐものは次のとおりである。

| 繋ぐもの | なぜ要るか |
| --- | --- |
| 草稿の識別子 | どの文書の周回かを決める。文章が変わっても同じ識別子で続く |
| 周回数 | [散らばりを見る](#直すと差が均されるのを見張る)ときに、同じ周回数どうしを比べる |
| その周で渡した指摘（名指しした指標と向き） | 動いたかを帰属させる先 |
| 直す前と直した後の、その指標の値 | 動いたかの判定そのもの |

識別子は使う側が付ける。本文から推定はしない。直すたびに本文は変わるので、本文から導けば
周回のたびに別の文書になってしまう。

##### 「動いた」の決め方

上の行から順に見て、当たった時点で止める。

| | 条件 | 判定 |
| --- | --- | --- |
| 1 | その周で測れなかった | 判定しない。動いたとも動かないとも記録しない |
| 2 | 指摘した向きへ動いていない（逆向き、または変化なし） | 動いていない。大きさは見ない |
| 3 | その人の幅が 0 | 動いた。割る幅が無いので大きさを見ない |
| 4 | 指摘した向きへ、その人の幅の 1 割以上 | 動いた |
| 5 | それ以外 | 動いていない |

向きを大きさより先に見る。逆にすると、幅 0 の指標が逆向きに動いたときに 2 行目と 3 行目の
両方が当たり、答えが 1 つに決まらない。

1 割は暫定値である（[指標](100-metrics.md#除外の既定)）。骨格が通ったら導き直す。

帰属は指標ごとに閉じる。1 周に 3〜4 本を渡すので、指摘 A のせいで指標 B が動いたかは
分からないが、分ける必要も無い。[効く指標の条件](200-extract.md#どの指標が効くかを決める)
が訊いているのは、「その指標を名指しして指示したとき、その指標が動くか」だけだからである。

##### 動かないと記録するまで

1 周では決めない。動かなかった 1 回は偶然でありうる。

- 名指しして動かなかった周が 2 回続いたら、その指標を動かないものとして記録する。
- 1 度でも動けば、その記録は消える。
- 判定しない周は、続いた回数を切らない。測れなかった周を挟んでも、その前後は続きと数える。

##### 台帳と結論を分けて置く

周ごとの記録（台帳）と、そこから出た結論は、置き場所を分ける。

| | 何か | どこに置くか |
| --- | --- | --- |
| 台帳 | 周ごとの、指摘と前後の値 | カセットの外。周回の草稿と同じ扱いである（[カセット](../design/100-cassette.md#周回のあいだの観測は外でやる)） |
| 結論 | その指標が動くか、動かないか、まだ分からないか | カセットの中。[作り直せないもの](200-extract.md#素材を正本にする) |

台帳を外に置くのは、カセットに履歴を持たせないと決めているからである。持たせれば、作り直せ
ないものが周回のたびに増え、測り直しが重くなる。

結論を中に置くのは、それが効く指標の条件そのものだからである。派生物に置くと、測り直しで
消えたことに気付かないまま、動かない指標が指摘に戻ってくる。

したがって、結論を書き換える操作が要る。台帳から導いた結果を、人がカセットへ入れる。台帳が
失われても結論は残る。結論だけを見ても、なぜそうなったかは追えないが、それでよい。追う必要
が出たら、その指標をもう一度指摘して測り直せばよい。

### 直すと差が均されるのを見張る

別々の文書を同じ周回数だけ回したものどうしの散らばりを見張る。周回とともに散らばりが縮む
なら、文章が平板になっている。

| いつ | 何を比べるか |
| --- | --- |
| 回す前 | 文書 A・B・C の草稿どうし |
| n 周後 | n 周した A・B・C どうし |

| 散らばりの変化 | 意味 |
| --- | --- |
| 変わらない | 正常 |
| 周回とともに縮む | 平板になっている。その人らしくなったのではない |

見張る理由は、人が直した文章は、自由に書いた文章より互いに似通うからである（効果量 1.42、
[Post-Editing](../references/post-editing-2026.md)）。直す経路は、書き手どうしの差を潰す方向
に働く。kakiburi は差を出すための道具なので、これは逆向きの力である。

ただし、書き手どうしの均しは、1 人分しか持たないこの道具からは見えない。そこで見えるものに
置き換えたのが、上の観測である。

同じ文書の周回どうしを比べてはいけない。2 周目は 1 周目を書き直したものなので、題材も構成も
語の大半も共有している。散らばりが小さいのは当たり前で、
[天井](200-extract.md#目盛りに載るのは1-本-対-その人である)（別々の文書どうしの散らばり）と
比べれば、健全なループでも必ず「狭い」と出る。尺度が違う。

> [!NOTE]
> これは Post-Editing が測った量そのものではない。あちらは書き手どうしが似通う話で、
> こちらは同じ書き手の文書どうしが似通う話である。同じ力が働いていると見なして置いた
> 代理の観測であり、確かめられていない。

### 自分を検査する

本人の実際の文章を、この手順に通す。本人がいちばん高く出ることが、目盛りが壊れて
いないことの最低条件である。

これは `build` が目盛りを作るたびに行う。カセットは本文を持たないので、作り終えたあとに
測り直す道が無く、素材を持っているその瞬間にしか測れない。

測るのは、較正に使わなかった単位だけである。

| | 測る単位 | 除く単位 |
| --- | --- | --- |
| 本人 | 相手集合を除いたすべて | [相手集合](200-extract.md#相手集合を-1-つ決める) |
| 基準 | 較正分を除いたすべて | 基準の較正分 |

本人の相手集合を測れば、自分との距離を測ることになる。基準の較正分も除くのは、照合値の
較正が「基準の較正分 × 相手集合」を違う人の対として合わせているからである。それを測り
直せば、分けるように合わせたものの分け具合を測ることになる。

本人の文章より生成文のほうが高く出る指標や組み合わせがあれば、それはその人らしさではなく、
指示に従えたかを測っている（[Sawant](../references/authorship-gap-2026.md)）。数え方が
「指示しやすさ」に寄っているので、[数え方](100-metrics.md#数え方は-kakiburi-が決める)に
戻して直す。

#### 端では見ない

本人と基準を、すべての対ごとに比べる。本人と基準のすべての対で本人が高ければ 1.0 になり、
これが「本人がいちばん高く出る」の言い換えになる。この割合は、素材の数 n によって漂わない。

本人の最小と基準の最大を比べる方法は取らない。端は
[素材を足すほど外へ広がる](200-extract.md#帯は2-つの分布の重なりである)ので、本人の最小は
下がり、基準の最大は上がる。すると、目盛りが良くなっても検査が落ちやすくなる。帯が端を
数で固定しているのと同じ問題である。

1 本の外れで落とさない。割合に下限を置き、下回ったときに疑う。下限は暫定値である。壊れた
目盛りでは割合が 0.5 付近に落ちるので、そこから十分に離して置いてある。どこまで緩めてよい
かは、複数の書き手で測るまで決まらない。

逆に出た対（基準のほうが高く出た対）は名指しする。割合だけでは、目盛り全体が緩んでいる
のか、1 本の単位が外れているのかが分からないからである。

> 経緯：実測では、逆に出た対がすべて基準 1 本に由来していた。その 1 本を除けば、端で
> 見ても通る状態だった。

### 本人が違うと感じたら

数値が通ると言い、本人が違うと言うなら、足りないのは指標である。指示でも目盛りでもない。
[指標](100-metrics.md#集合が変わるとき)に戻る。

逆向きは信号にならない。本人が受け入れたことは、通ったことの証拠にはならない
（[決定](010-strategy.md#本人の読みは判定ではなく候補として使う)）。数値が通らないと言い、
本人がそれに気付かないのは、正常な状態である。
