# 検めて、直す

[戦略](010-strategy.md#言うために何が要るか)が挙げた 4 つ目——<strong>直す側が受け取れる形</strong>
——を作る。<strong>ここで初めて[軸](000-axis.md)が満たされる。</strong>

返すものは 2 つある。

| | 何を言うか |
| --- | --- |
| <strong>判定</strong> | 通ったか。通らないか。判定できないか |
| <strong>指摘</strong> | どこが、こちらへ、これだけ違うか |

<strong>文章がどこから来たかを問わない。</strong> LLM に書かせたものも、自分で書いたものも、同じ
ようにここへ来る（[書かせることはしない](010-strategy.md#書かせることはしない)）。

## 同じ測り方で測る

対象の文章を、[評価](200-extract.md)と <strong>同じ指標、同じ単位、同じ定型の落とし方</strong>で測る。
[正規化](030-normalize.md)も同じ手順を通す。どれかが違えば、比べたものに意味が無い。

### 場面を指定させる

どの場面の幅と目盛りに照らすのかは、文章からは決まらない
（[評価](200-extract.md#場面ごとに分ける)）。

### 草稿の作られ方を疑う

<strong>本人の文章を見せて書かせた草稿は、測定が膨らむ。</strong> 本文の書き出しをそのまま依頼文に
使うと、基準値が <strong>28 ポイント</strong>膨らんだ例がある
（[Sawant](../references/authorship-gap-2026.md)）。

kakiburi は書かせる側を持たないので、これを防げない。<strong>だから訊く。</strong> 本人の文章を参考
として渡したかどうかを申告させ、渡していれば判定に添える。

## 何を見るか

<strong>書きぶりだけを見てはいけない。</strong> 文体・内容・自然さの間には trade-off があり、文体に
強く寄せるほど内容が壊れ、日本語として不自然になる
（[文体転換の評価](../references/tst-evaluation.md)）。

| 次元 | 何を見るか | 何で測るか |
| --- | --- | --- |
| 書きぶり | その人の幅に入っているか | その人らしさの[系統](100-metrics.md#指標には-2-種類ある) |
| <strong>人らしさ</strong> | <strong>機械が書いたと分かる文になっていないか</strong> | 繰り返し、エントロピー、圧縮率、語彙の豊富さ |
| 題材 | 書くべきことが保たれているか | 元の草稿との対照 |
| 日本語 | 読める文になっているか | — |

<strong>人らしさを落とさない。</strong>[通る条件は 2 つ](010-strategy.md#通るには-2-つ要る)であり、
書きぶりが幅に入っても、機械が書いたと分かる文章は通らない。

<strong>題材が保たれていることは前提である</strong>（[性質 3](010-strategy.md#書きぶりとは何か)）。
見ていなければ、前提が成り立っているか分からない。

> [!WARNING]
> <strong>題材と日本語の測り方は、まだ決まっていない。</strong> 素直に作れば LLM に読ませることに
> なるが、それは[数える側に LLM を置かない](010-strategy.md#数える側に-llm-を置かない)に
> 反する。<strong>決まるまで、この 2 つは判定に混ぜない。</strong> 混ぜたことにして先へ進むと、
> 壊れた目盛りの上に全部が建つ。

## 全体の判定は 3 値で返す

### 目盛りに載せる

<strong>点数だけでは読めない。</strong> 0.5 が近いのか遠いのかは、比べる先が無ければ決まらない
（[Sawant](../references/authorship-gap-2026.md)）。[天井と床](200-extract.md#目盛りを作る)
に載せて返す。

| 位置 | 返す値 |
| --- | --- |
| 天井の側 | <strong>通る</strong> |
| 床の側 | <strong>通らない</strong> |
| その間 | <strong>判定できない</strong> |

<strong>無理に判定しない</strong>（[決定](010-strategy.md#届かないときは判定できないと言う)）。帯を
狭めれば判定不能は減るが、間違った判定が増える。

### 組み合わせで決める

<strong>1 つの指標で判定しない。</strong> 単一の点数は騙せる——前身の道具で、語を置換しただけの生成文
が 38 点から 94 点になったことがある（[SPTG の評価](../references/sptg-evaluation-2025.md)）。

<strong>違う原理のものを混ぜたときにいちばん当たる</strong>（[決定](010-strategy.md#種類の違うものを混ぜるただし-5-系統前後まで)）。
同じ系統を足しても意味が無い。正解率が同じでも判断が 35% 食い違う組み合わせがあり、
そこにこそ足す価値がある（[SPTG の評価](../references/sptg-evaluation-2025.md)）。

<strong>LLM の判定は混ぜない。</strong> SPTG の最良の組み合わせには LLM の判定が入っているが、
kakiburi は使わない（[決定](010-strategy.md#数える側に-llm-を置かない)）。

### 埋め込みには重みを置かない

<strong>同じ依頼から作った 2 つを比べる場面で崩れる。</strong> 内容が同じなので区別できず、性能が
<strong>38.3%</strong> 落ちる（[SPTG の評価](../references/sptg-evaluation-2025.md)）。

kakiburi の床は「同じ依頼で LLM に素で書かせたもの」である
（[評価](200-extract.md#目盛りを作る)）。<strong>まさにその場面にいる。</strong> 混ぜてよいが、重みは
小さく置く。

### 当てにならないときは言う

集めた文章が少なければ、幅も目盛りも当てにならない。

<strong>場面の文章が集まっていないときは、近い場面から取るか、断る。</strong> 取るなら <strong>場面をまたい
でも一貫する指標</strong>から取る——品詞と読点の打ち方がそれにあたる
（[柳・金 2022](../references/yanagi-jin-2022.md)）。文字 n-gram と文節パターンは場面で
大きく動くので、当てにならない。

<strong>他の場面から取ったなら、そう伝える。</strong> 黙って混ぜれば、根拠の弱い判定が濃い判定と同じ
顔で出る。

## 指摘を作る

### 外れを出す

指標ごとに、値が幅の外にあるかを見る。<strong>上に外れることと、下に外れることの両方を見る。</strong>
どちらを見るかは指標の定義に書いてある（[指標](100-metrics.md#定義に落とす)）ので、ここ
で指標ごとに場合分けしない。

<strong>上だけを見ると、指摘を消そうとする側は削るほうへ向かう。</strong> 書きぶりは幅であって上限で
はない。

判定も指標の定義を回す。測った値と幅は名前で突き合わせるので、
[名前が 1 か所にしか無いこと](100-metrics.md#名前は-1-度しか書かない)がここで効く。

### 指摘は 3 本か 4 本に絞る

<strong>外れた指標を全部並べてはいけない</strong>（[決定](010-strategy.md#一度に渡すのは-3-本か-4-本)）。

[効くと判定された指標](200-extract.md#どの指標が効くかを決める)のうち、<strong>外れの大きい順</strong>
に上位を取る。外れ具合はその人の幅を単位にして測る。

この選び方は隠す側で検証されている。著者ベクトルと平均の差の絶対値で上位 k 軸を選ぶと、
<strong>同じ本数を無作為に選ぶより 6% 良い</strong>（[StyleRemix](../references/styleremix-2024.md)）。

<strong>kakiburi はそれより多くを知っている。</strong> その書き手が普段どこにいるかだけでなく、この
文章がどこにいるかも測れている。だから選ぶ基準は「その人で際立つ軸」ではなく
<strong>「この文章で外れている軸」</strong>になる。

<strong>指示して動かないと分かっている指標は、枠から外す</strong>
（[条件 3](200-extract.md#どの指標が効くかを決める)）。動かないものに枠を使えば、動くもの
が押し出される。

### 直せる形にする

外れた指標の名前と数値だけでは直せない。<strong>3 つ揃って初めて直せる。</strong>

| | 軸のどこに対応するか |
| --- | --- |
| <strong>観測</strong>。この文章ではどうだったか | ここが |
| <strong>直し方</strong>。どちらへ、どうすればよいか | こちらへ |
| <strong>普段</strong>。その人はどこからどこまでで書いてきたか | これだけ |

<strong>直し方は指標の定義から取る</strong>（[指標](100-metrics.md#定義に落とす)）。指摘を出す側で
書くと、指標を足したときに直し方の無い指摘が出る。

### 散文で渡す

<strong>表にしない。</strong> 構造化した形を求めると成績が落ちる——判定側の実測で、開かれた形より
<strong>24% 悪い</strong>（[SPTG の評価](../references/sptg-evaluation-2025.md)）。直す側でも同じこと
が起きうる。

成功している例も散文である。人の文章と機械の文章の差を LLM に <strong>記述させ</strong>、その記述を
そのままプロンプトに置く手順で、読みやすさも課題達成率も人間並みになっている
（[SICO](../references/sico-2024.md)）。

<strong>ただし数値は落とさない。</strong> 次の周でも同じ値で照らすので、丸めたり言い換えたりして情報
を落とせば、指示と判定がずれる。散文にするのは <strong>言い方</strong>であって、根拠の値ではない。

### 人らしさの直し方は、書き直しに戻ることがある

寄せる向きは分かっている。人の文章は <strong>繰り返しでできており</strong>、機械の文章は語彙が散り
すぎて繰り返せない（[Zeng & Nini](../references/zeng-nini-2026.md)）。

<strong>そして推論設定で動く。</strong> 上の実験は温度も頻度ペナルティも既定値のままだったと論文自身
が認めている。<strong>頻度ペナルティを下げれば繰り返しは増える。</strong>

kakiburi は書かせる側を持たないので、これは <strong>直し方として伝える</strong>——「この設定で書き直
させる」と。文面を直す指摘とは別に立てる。

## 回す

### 直したら測り直す

直した文章をもう一度測る。同じ値と同じ目盛りを使っているので、指示どおりに直せば数値は
寄るはずである。

寄らなければ、指示か指標のどちらかが悪い。<strong>指標が動かないと分かったら、
[条件 3](200-extract.md#どの指標が効くかを決める)に返す。</strong>

<strong>1 回で通ることは期待しない</strong>（[ループ](010-strategy.md#使うときはループになる)）。

### 直すと差が均されるのを見張る

人が直した文章は、自由に書いた文章より <strong>互いに似通う</strong>（効果量 1.42、
[Post-Editing](../references/post-editing-2026.md)）。<strong>直す経路は、書き手どうしの差を潰す
方向に働く。</strong>

kakiburi は差を出すための道具なので、これは逆向きの力である。<strong>周回ごとに、幅が狭まりす
ぎていないかを見る。</strong> 天井（本人の揺れ）より内側に締まったら、それはその人らしくなった
のではなく、平板になっている。

### 自分を検査する

<strong>本人の実際の文章を、ここに通す。</strong> 生成文より低く出る指標や組み合わせがあれば、それは
指示に従えたかを測っている（[Sawant](../references/authorship-gap-2026.md)）。数え方が
「指示しやすさ」に寄っているので、[数え方](100-metrics.md#数え方は-kakiburi-が決める)に
戻して直す。

<strong>本人がいちばん高く出ることが、目盛りが壊れていないことの最低条件である。</strong> 定期的に
回す。

### 本人が違うと感じたら

数値が通ると言い、本人が違うと言うなら、<strong>足りないのは指標である</strong>。指示でも目盛りでも
ない。[指標](100-metrics.md#集合が変わるとき)に戻る。

<strong>逆は信号にならない。</strong> 本人が受け入れたことは、通ったことの証拠にならない
（[決定](010-strategy.md#本人の読みは判定ではなく候補として使う)）。<strong>数値が通らないと言い、
本人が気付かないのは、正常な状態である。</strong>
