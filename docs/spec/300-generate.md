# 戦術: 新しい文章で再現する

[戦略](010-strategy.md)の 3 段目。値を指示に変えて、これから書くものに使う。

## 書くのは借りた側

kakiburi は文章を書かない（[軸](000-axis.md)）。指示を出すところまでをやる。

## 指示の形

指標の名前と値をそのまま並べても、書く側は何をすればよいか分からない。守れる
形に変える。

ただし数値は落とさない。4 段目が同じ値で照らすので、丸めたり言い換えたりして
情報を落とすと、指示と判定がずれる。

## 場面を選ばせる

どの場面の書きぶりを貸すのかを、使う側に指定させる。指定が無ければ既定を使い、
どれを使ったかを伝える。

## コーパスの無い場面

その場面の文章が集まっていないことはある。近い場面から借りるか、断る。

借りたなら、借りたことを伝える。黙って借りると、根拠の弱い指示が根拠のある
指示と同じ顔で出る。

## 判断軸を重ねてよい

判断軸は軸の外にあるが、貸すときに添えることは禁じていない（軸）。人が書いた
ものをそのまま重ねる。kakiburi は導出も検証もしない。

添えたものを 4 段目は読まない。読めば決定的でなくなる。

## 効いたかどうか

書かせたものを 4 段目で測れば、指示が守られたかは分かる。

だが、守られたことと本人のものに読めることは別である。最後は本人が読む。数値が
上がったことは、この判定の代わりにならない。前身では、本人が読んで拒否した文章
が満点を取ったことがある。

読んで違うと感じたなら、足りないのは指標である。指示ではなく
[100](100-metrics.md)に戻る。
