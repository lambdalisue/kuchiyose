# 文書の形

指標は「地の文」「日本語 1,000 字あたり」「段落」といった言葉で書かれる。それらが
何を指すかを、指標ごとではなくここで 1 度だけ決める。

決めないと、指標の定義が読めない。指標ごとに決めると、同じ言葉が指標によって違う
ものを指す。

どこからも使うので、[戦略](010-strategy.md#何をするか)が並べた 3 つには入らない。
<strong>この文書は形だけを決める。そこへ落とす手順は
[入力を正規形にする](030-normalize.md) が決める。</strong>

## 足すのは重い

ここで決めた node にあるものだけが測れる。無いものは、どんな指標を思いついても測れない。

<strong>だから node を足すのは、指標を 1 つ足すのとは重さが違う。</strong>
[正規化](030-normalize.md#意味で認識する)がすべての取り込み元でそれを認識できることと
セットである。認識できない取り込み元では、その node は 0 が並ぶのではなく <strong>測れない</strong>。

## 文書は node でできている

| node | 子を持つか |
| --- | --- |
| 段落 | 持つ |
| 見出し | 持つ |
| 箇条書き | 項目を持つ |
| 番号リスト | 項目を持つ |
| 引用 | 持つ |
| 補足 | 持つ |
| 警告 | 持つ |
| 折りたたみ | 持つ |
| 表 | セルを持つ |
| コードブロック | 持たない |
| 区切り線 | 持たない |
| 画像 | 持たない |
| 強調 | 持つ |
| インラインコード | 持たない |
| リンク | 持つ |

node は <strong>意味で</strong> 定める。書き手が「これは補足である」と示していれば、記法が何で
あっても補足の node になる。記法の違いは入力の側の事情であって、書きぶりではない。

この表が、構造について測れることの全体である。ここに無いものは測れない。

## 地の文

段落、見出し、箇条書きの項目、番号リストの項目、引用、補足、警告、折りたたみ、
表のセルに含まれるテキスト。

含まないもの。コードブロックの中身、インラインコードの中身、画像の代替文字、
リンクの参照先。

コードを外すのは、書き手が日本語で書いた部分ではないためである。外さないと、
コードの多い記事ほど記号の率が上がり、書きぶりではなく題材を測ることになる。

記号を数える指標は、断りがなければ地の文だけを見る。

## 日本語の文字

ひらがな、カタカナ、漢字、および `ー` `々`。

数えないもの。英数字、約物（`。` `、` `「` `（` など）、空白、記号。

率の分母はこれである。「日本語 1,000 字あたり」とは、この文字が 1,000 個あたり
いくつか、という意味になる。

約物を分母から外すのは、読点の多い書き手ほど分母が膨らんで率が下がるのを避ける
ためである。分母が測る対象と連動してはいけない。

## 文

地の文を `。` `！` `？` で切る。閉じ括弧（`」` `』` `）` `"`）が直後に続く場合は、
その括弧までを同じ文に含める。

`…` では切らない。言いさしであって文の終わりではない。

括弧の内側の `。` では切らない。引用の中の文を、外側の文として数えないためである。

## 段落

段落の node ひとつが 1 段落。

箇条書き、番号リスト、引用、コードブロック、表、見出しは段落ではない。これらを
段落に数えると、箇条書きの多い文書ほど「段落が短い」ことになる。

## 見出しの深さ

文書内で最も浅い見出しを深さ 1 とし、そこからの相対で数える。

絶対の深さを使わない理由は、記事のタイトルを見出しにするかどうかが媒体によって
違うためである。同じ構成の文書が、取り込み元によって別の深さになってはいけない。

## 消えるもの——記法の選択

<strong>記法の選択は測れない。</strong> 箇条書きの記号が `-` か `*` か、強調が `**` か `__` か、
見出しが `#` か下線か。

それでよい。入力の形式が混ざっている以上、これらは書き手のものか入力形式のもの
か区別がつかない。区別がつかないものを測ると、書き手ではなく取り込み元を測る。

<strong>[正規化](030-normalize.md#表記を潰さない)が、これを潰す側に置いている。</strong>

## 揃えても残るもの——表記の選択

<strong>記法と表記は違う。</strong> 記法は書式であり、正規化で消える。<strong>表記は地の文の中身
であり、残る。そして残る側は測る価値が高い。</strong>

英語の文体表現を凝集型クラスタリングにかけると、上位のクラスタが
<strong>アポストロフィの字種、末尾に句読点を打つか、発話中の改行</strong> で分かれた
（[Wegmann](../references/wegmann-2022.md)）。<strong>意味を持たない表記の選択が、文体表現の
主成分になっている。</strong>

人が自分で直すときに手を入れるのも、この層である。em dash を削り、短縮形を足す
（[Post-Editing](../references/post-editing-2026.md)）。

日本語で対応するもの。

| | 例 |
| --- | --- |
| 三点リーダの字数 | `…` か `……` か |
| 感嘆符・疑問符の字幅 | `！` か `!` か |
| 括弧の種類 | `「」` `『』` `（）` `〈〉` の使い分け |
| 和欧間の空白 | 入れるか入れないか |
| 波ダッシュ | `〜` か `～` か |
| 中黒と読点 | 並列に `・` を使うか `、` を使うか |
| 数字の字幅 | `１` か `1` か |

<strong>これらは題材と相関しにくく、書き手の選択がそのまま出る。</strong> 優先して採る理由がある。

<strong>ただし取り込み元が正規化していないことが前提である。</strong> 正規化で潰していないか、
指標を足す前に確かめる。潰しているなら、測っているのは取り込み元である。
