# kakiburi の戦略

[軸](000-axis.md)を満たすための方針。何をどう数えるか、どう持つかは戦術で
決める。

## 書いたものを数える

書きぶりは本人が意識していない（性質 1）。だから訊かない。書いたものを数える。

同じ理由で、どこまでが普通かも人が決めない。本人が実際に書いたものから取る。

## 基準を置いて比べる

「人によって違ってしまう部分」という定義は比較を含んでいる。一人分を測って
出るのはその人の数値であって、その人らしさではない。

基準に置くのは、LLM が既定で書いたものである。直したいのがそれだからである。

## 場面は人に指定させる

書きぶりは場面ごとにある。相手も立ち位置も目的も文章の外にあるので、文章から
当てにいけば外す。

## 検めるを足す

軸は取り出して貸すまでである。守られたかどうかを本人が読まずに知る手段として、
検めるを足す。

貸すときと検めるときで同じものを使う。ずれると、指示どおりに書いたものが低く
出る。

## 数える側に LLM を置かない

同じ入力からは同じ結果を出す。軸の要求ではなく、この道具が LLM に「自分らしい
ですか」と訊くより役に立つための条件である。訊けば毎回違う答えが返り、直した
結果が良くなったのかも分からない。

## 作り直せるようにしておく

何を数えるかは変わり続ける。取り出したものは派生物として扱う。

## 確かめ方は 2 つ

分離。本人が書いたものと、基準に置いたものが重ならない。重なるなら、本人と
他人を区別できていない。

通読。取り出したもので 1 本書かせて、本人が読んで自分のものとして受け入れる。
数値の動きは、この判定の代わりにならない。

分離は「区別できていない」を、通読は「区別はできるが再現できていない」を
捕まえる。片方だけでは足りない。
