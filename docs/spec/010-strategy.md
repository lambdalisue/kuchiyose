# kakiburi の戦略

[軸](000-axis.md)を満たすための方針を決める。何をどう数えるか、どんな形式で
持つかは決めない。

## 取り出す

### 訊かずに数える

書きぶりは本人が意識していない（性質 1）。だから取り出す手段は、本人への
質問ではなく、書いたものを数えることになる。

書いたものは残っている。残っていて、本人が意識していない選択が、そこに全部
出ている。

### 一人だけを測っても出ない

書きぶりは「なお人によって違ってしまう部分」である。定義そのものが比較を
含んでいる。一人分を測って得られるのはその人の数値であって、その人らしさ
ではない。違いは、比べる相手がいて初めて出る。

比べる相手は、代筆の目的から決まる。直したいのは、放っておくと出てくる
文章である。したがって基準に置くのは LLM が既定で書いたものになる。他人の
文章や過去の自分の文章を置いてもよく、仕組みは変わらない。

この比較は、思いつけなかったものを見つけるための唯一の手段でもある。あらか
じめ調べる語の一覧を作る方法では、一覧に無いものは永久に見つからない。

### 基準はコーパスから取る

「太字は 1,000 字あたり 4 個まで」のような定数を人が決めてはいけない。決め
られるなら、それは言える人がいるということであり、性質 1 と矛盾する。

代わりに、文書ごとに測った分布そのものを持つ。その人がこれまで実際にどこ
まで振れたかが基準になる。

この形にすると、誤検出はデータの問題になる。一度使っただけで指摘されたなら、
分布の端を取り違えているのであって、条件の書き方が悪いのではない。直すのは
測り方である。

### 上と下の両方を見る

多すぎることだけを咎めると、指摘を消そうとする側は「全部削る」に収束する。
書きぶりは幅であって上限ではない。少なすぎることも同じだけ不自然である。

### 題材ではなく書き方を数える

題材が変わっても書きぶりは変わらない（性質 3）。逆に言えば、題材とともに
動くものを数えると、書きぶりではなく話題を測ってしまう。

数えるのは、何について書いても現れるものに限る。

### 大きい方も数える

書きぶりは語にも文にも全体の組み立てにも現れ、目立つのは大きい方である。
語だけを数えると、いちばん効くところを落とす。

### 場面ごとに分ける

書きぶりは場面ごとにある。したがってコーパスも場面ごとに分ける。混ぜて
測った分布は、どの場面のものでもない中間になる。

場面は人が指定する。文章から場面を当てにいかない。相手も立ち位置も目的も
文章の外にあるので、当てれば必ず外す。

### 測り直せるようにしておく

何を数えるかは変わる。分離しない項目は外し、証拠が出た項目は足す。そのたび
に過去の文章を測り直せなければ、古い数値と新しい数値が混ざる。

取り出したものは派生物として扱い、元になった文章から何度でも作り直せる形に
しておく。

## 貸す、検める

### 貸すと検めるは同じものを見る

貸すときに言う数値と、検めるときに照らす数値を同じにする。ここがずれると、
指示どおりに書いたものが低く出る、あるいはその逆が起きる。

書かせて、検めて、直して、また検める。この使い方は、この一致だけに依存して
いる。

### 検めるのは軸の一部ではない

軸は取り出して貸すまでである。検めるのは、貸したものが守られたかを知る手段
として置く。

貸しただけでは、守られたかどうかを本人が読む以外に知る方法がない。読むのは
高いので、機械が先に見る。

### 指摘には直し方を添える

数値だけでは直せない。どの数値がどちらへどれだけ外れていて、その人の普段は
どうなのかまで出して、初めて直せる。

### 決定的であること

同じ入力からは同じ結果を出す。

軸が要求しているわけではない。これは、この道具が LLM に「自分らしいですか」
と訊くより役に立つための条件である。訊けば毎回違う答えが返り、直した結果が
良くなったのかどうかも分からない。

したがって、数える側に LLM を置かない。

## 日本語であることを使う

語の境界が無いので、文字列の一致で語を数えると別の語の一部を拾う。形態素に
分けてから、原形と品詞で照合する。

日本語に限ったのは、この判断を含めて、取り出し方を 1 つの言語に合わせるため
である。

## できたと確かめる

2 つある。片方だけでは足りない。

分離。本人が書いたものと、基準に置いたものを検めて、結果が重ならない。重なる
なら、その道具は本人と他人を区別できていない。分布を作った文章そのものを
検めても意味がないので、取り出しに使わなかった本人の文章で見る。

通読。取り出したもので 1 本書かせて、本人が読んで自分のものとして受け入れる。
数値がどう動いたかは、この判定の代わりにならない。前身では、本人が読んで
拒否した文章が満点を取ったことがある。

分離は「他人と区別できていない」を、通読は「区別はできるが再現できていない」
を捕まえる。
