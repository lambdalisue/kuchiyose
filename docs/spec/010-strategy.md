# kakiburi の戦略

[軸](000-axis.md)を満たすための方針を決める。何をどう数えるか、どんな形式で
持つかは決めない。

## 取り出す

### 訊かずに数える

書きぶりは本人が意識していない（性質 1）。だから取り出す手段は、本人への
質問ではなく、書いたものを数えることになる。

書いたものは残っている。残っていて、本人が意識していない選択が、そこに全部
出ている。

### 一人だけを測っても出ない

書きぶりは「なお人によって違ってしまう部分」である。定義そのものが比較を
含んでいる。一人分を測って得られるのはその人の数値であって、その人らしさ
ではない。違いは、比べる相手がいて初めて出る。

比べる相手は、代筆の目的から決まる。直したいのは、放っておくと出てくる文章
である。したがって基準に置くのは LLM が既定で書いたものになる。他人の文章や
過去の自分の文章を置いてもよく、仕組みは変わらない。

比較は、思いつけなかったものを見つけるための手段でもある。何を調べるかを
先に決める方法では、決めたものしか見つからない。

### 基準はコーパスから取る

どこまでが普通かを人が決めてはいけない。決められるなら、それは言える人が
いるということであり、性質 1 と矛盾する。

代わりに、その人が実際にどこまで振れたかを基準にする。

この形にすると、誤検出はデータの問題になる。一度使っただけで指摘されたなら、
振れ幅の取り方を間違えているのであって、条件の書き方が悪いのではない。直すの
は測り方である。

### 上と下の両方を見る

多すぎることだけを咎めると、指摘を消そうとする側は「全部削る」に収束する。
書きぶりは幅であって上限ではない。少なすぎることも同じだけ不自然である。

### 題材ではなく書き方を数える

題材が変わっても書きぶりは変わらない（性質 3）。逆に言えば、題材とともに動く
ものを数えると、書きぶりではなく話題を測ってしまう。

数えるのは、何について書いても現れるものに限る。

### 大きい方も数える

書きぶりは語にも文にも全体の組み立てにも現れ、目立つのは大きい方である。
語だけを数えると、いちばん効くところを落とす。

### 場面ごとに分ける

書きぶりは場面ごとにある。したがってコーパスも場面ごとに分ける。混ぜて測った
ものは、どの場面のものでもない中間になる。

場面は人が指定する。文章から当てにいかない。相手も立ち位置も目的も文章の外に
あるので、当てれば外す。

### 測り直せるようにしておく

何を数えるかは変わる。分離しないものは外し、効くと分かったものは足す。その
たびに過去の文章を測り直せなければ、古い数値と新しい数値が混ざる。

取り出したものは派生物として扱い、元になった文章から何度でも作り直せるように
しておく。

## 貸す、検める

### 貸すと検めるは同じものを見る

貸すときに言うことと、検めるときに照らすものを同じにする。ここがずれると、
指示どおりに書いたものが低く出る、あるいはその逆が起きる。

書かせて、検めて、直して、また検める。この使い方は、この一致だけに依存して
いる。

### 検めるのは軸の一部ではない

軸は取り出して貸すまでである。検めるのは、貸したものが守られたかを知る手段
として置く。

貸しただけでは、守られたかどうかを本人が読む以外に知る方法がない。読むのは
高いので、機械が先に見る。

### 検めた結果は直せる形で返す

数値だけでは直せない。どこがどう外れているかと、その人の普段はどうなのかが
揃って、初めて直す手がかりになる。

### 決定的であること

同じ入力からは同じ結果を出す。

軸が要求しているわけではない。これは、この道具が LLM に「自分らしいですか」
と訊くより役に立つための条件である。訊けば毎回違う答えが返り、直した結果が
良くなったのかどうかも分からない。

したがって、数える側に LLM を置かない。

## 日本語であることを使う

日本語には語の境界が無い。だから、書かれた文字をそのまま照合する方法では語を
数えられず、別の語の一部を拾う。語を正しく切る手段を前提に置く。

日本語に限ったのは、この判断を含めて、取り出し方を 1 つの言語に合わせるため
である。

## できたと確かめる

2 つある。片方だけでは足りない。

分離。本人が書いたものと、基準に置いたものを検めて、結果が重ならない。重なる
なら、その道具は本人と他人を区別できていない。ただし基準を作るのに使った文章
を検めても意味がないので、使わなかったもので見る。

通読。取り出したもので 1 本書かせて、本人が読んで自分のものとして受け入れる。
数値がどう動いたかは、この判定の代わりにならない。前身では、本人が読んで拒否
した文章が満点を取ったことがある。

分離は「他人と区別できていない」を、通読は「区別はできるが再現できていない」
を捕まえる。
