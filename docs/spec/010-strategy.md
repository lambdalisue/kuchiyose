# kakiburi の戦略

[軸](000-axis.md)に到達するための道筋を決める。何を指標にするか、どう持つかは
戦術で決める。

曖昧な書きぶりを指標に落とし、本人の文章を評価してその人の値を得て、その値で
新しい文章と既存の文章の両方を書きぶりに寄せる。4 段ある。

| 段 | 戦術 |
| --- | --- |
| 1. 指標の集合として定義する | [100-metrics.md](100-metrics.md) |
| 2. 既存の文章を評価して再現可能にする | [200-extract.md](200-extract.md) |
| 3. 新しい文章で再現する | [300-generate.md](300-generate.md) |
| 4. 既存の文章で再現する | [400-revise.md](400-revise.md) |

## 1. 書きぶりを指標の集合として定義する

書きぶりは曖昧なままでは外に出せない。定量評価できる指標の集合として定義し
直す。

そうしてよい根拠は軸にある。書きぶりは文章に現れ（性質 4）、同じ場面で一貫
して現れる（性質 2）。現れて一貫しているものは数えられる。そして本人が意識
していない（性質 1）以上、訊いて言葉にしてもらう道は初めから無い。

代償を引き受ける。指標の集合で表せない書きぶりは、扱えなくなる。取りこぼしは
指標を足すことでしか減らない。

ここで定義するのは <strong>誰にでも当てられる候補の集まり</strong> である。その人にとってどれが
効くかは決めない。何が特徴になるかは人によって違う（軸）ので、ここで決めれば
必ず誰かの特徴を捨てることになる。

## 2. 既存の文章を評価して再現可能にする

指標だけでは、まだ誰のものでもない。本人が書いたものを指標で評価して、初めて
その人の値になる。

値と一緒に、<strong>どの指標が効くか</strong> もここで決まる。ある人には際立つ指標が、別の人
では何も言っていない。効くかどうかは、その人の文章を測って初めて分かる。

この段で書きぶりは、本人の中にある曖昧なものから、外に出せる値に変わる。軸が
言う「本人の外で使えるようにする」は、ここで達成される。

## 3. 新しい文章で再現する

値を指示に変えて、これから書くものに使う。

## 4. 既存の文章で再現する

値と照らして、すでに書かれたものを寄せる。どこがどれだけ離れているかが分かれ
ば直せる。

3 と 4 は同じ値を使う。違う値を使うと、3 の指示どおりに書いたものが 4 で低く
出る。書かせて、直して、また確かめるという使い方は、この一致に依存している。
