# 非断定の密度

修辞 / 両側 / 日本語 1,000 字あたり。

## 意味

断定を避ける言い方をどれだけ使うか。避けるのは生成文の癖だと思われがちだが、
そうとは限らない。向きを決め打たず両側を見る。

## 数え方

[文](../020-document.md#文)の末尾が次のいずれかである数。

かもしれない / かもしれません / と思われる / のではないか / のではないでしょうか /
だろう / でしょう / ようだ / ようです / 気がする / はずだ / と言えるだろう

一覧はこの定義の一部である。増減させたら、それは別の指標になる。

## 実績

1 人で試し、判定していない。検証セットが揃っていないため（[100](../100-metrics.md#検証セットが揃うまで)）。
