# 非断定の密度

指示 / 文末表現 / 語 / 両側 / 日本語 1,000 字あたり。

## 意味

断定を避ける言い方をどれだけ使うか。避けるのは生成文の癖だと思われがちだが、
そうとは限らない。向きを決め打たず両側を見る。

## 出どころ

[文末表現](文末表現.md)の切り口。辞書と分類は
[有馬ら 2018](../../references/arima-2018.md) による。

[水上ほか](../../references/mizukami-2014.md)は個人性が機能語に宿るとしており、文末表現は
その一部にあたる。<strong>いちばん強く担うとまでは報告されていない。</strong>
## 数え方

[文末](../020-document.md#文末)が次のいずれかで <strong>終わる</strong> 数。

<strong>最長一致で取り、重ならない。</strong> 一覧には短いものが長いものに含まれる組がある
（`だろう` ⊂ `と言えるだろう`）。1 つの文末から取るのは 1 つである。

かもしれない / かもしれません / と思われる / のではないか / のではないでしょうか /
だろう / でしょう / ようだ / ようです / 気がする / はずだ / と言えるだろう

一覧はこの定義の一部である。増減させたら、それは別の指標になる。

## 直し方

<strong>上</strong>: 断定を避ける言い方を減らす。言い切る。

<strong>下</strong>: 断定を避ける言い方を足す。
