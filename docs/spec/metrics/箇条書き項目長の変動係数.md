# 箇条書き項目長の変動係数

<strong>草案。</strong> まだ集合に入っていない（[100](../100-metrics.md#定義を書くことと集合に入れることは別)）。

ばらつき / 下限 / 無次元。

## 意味

箇条書きの項目の長さが揃っているか。定義を並べる書き方では揃い、思いつくままに
並べるとばらつく。

## 数え方

文書内の全ての箇条書き項目を 1 つの分布として、日本語文字数の標準偏差を平均で
割る。入れ子の項目も 1 項目として数える。

## 除外

項目が 5 つ未満の文書では測らない。項目が 1 つだと変動係数は必ず 0 になり、下限側
の判定を潰す。

## 確かめた場面

技術記事。条件 4 だけ確認済み（値が動く）。この書き手では基準と分離しなかったが、
それは[外す理由にならない](../100-metrics.md#目の前の書き手を区別できないことは-外す理由にならない)。
条件 1、2、3、5、6 は未確認。
