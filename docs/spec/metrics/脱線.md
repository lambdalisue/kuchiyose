# 脱線

修辞 / 下限 / 日本語 1,000 字あたり。

## 意味

本筋から外れる書き込み。人が書いたものに現れ、生成されたものからは落ちる。多すぎる
ことではなく、少なすぎることが問題になる、数少ない指標である。

## 数え方

[文](../020-document.md#文)のうち、次のいずれかで始まるものの数。

ちなみに / 余談だが / 余談ですが / 余談だけど / そういえば / 話は逸れるが /
脇道に逸れるが / 蛇足だが / どうでもいいが / なお余談

「なお」は入れない。単独では補足一般に使われ、脱線に限らない。

## 除外

日本語 1,000 字未満の文書では測らない。脱線する余地が無く、0 が並ぶだけになる。

## 実績

1 人で試し、判定していない。検証セットが揃っていないため（[100](../100-metrics.md#検証セットが揃うまで)）。
