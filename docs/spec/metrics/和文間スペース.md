# 和文間スペース

検査 / 上限 / 0.02 / 和文が隣り合う機会に対する割合。

## 意味

日本語の文字どうしの間に空白が入っているか。<strong>ふつうは入らない</strong>——日本語は分かち書き
をしないので、`複数の リポジトリ を扱う` とは書かない。

<strong>[和欧間スペース欠落](和欧間スペース欠落.md)の裏返しではない。</strong> あちらは日本語と英数字
の間に空白を<strong>入れるか</strong>を見る習慣の指標で、入れる人も入れない人もいる。こちらは
<strong>入れてはいけないところに入っているか</strong>を見る。

## 出どころ

<strong>書き手を分けるために置いたのではない。</strong> だから
[検査](../100-metrics.md#4-つ目は書きぶりではなく壊れ方を見る)であって指示できる指標ではない。

実測。[文字種](文字種.md)の空白を上げよという指示に従って和文間に 111 箇所の空白を
入れた草稿が、照合値 2.911 で<strong>通った</strong>。取り除くと 2.632 に落ちて通らなくなった
——<strong>通ったぶんを、壊れた空白が稼いでいた。</strong>

<strong>効くかの 3 条件はこれを拾えない。</strong> 実測で本人も基準もほぼ 0 なので
[基準から離れている](../200-extract.md#離れているかの判定)が成り立たない。<strong>書きぶりの
軸ではないからである</strong>——分かち書きは、その人の選択ではなく壊れ方である。

## 数え方

<strong>「機会」を先に決める。</strong>[地の文](../020-document.md#地の文)を走査し、次の形が現れた
ところを 1 つの機会と数える。

> <strong>和文の文字</strong> → <strong>空白 0 個以上</strong> → <strong>和文の文字</strong>

<strong>そのうち空白が 1 個以上のものを数える。</strong> それ ÷ 機会が値になる。

### 和文の文字

[日本語の文字](../020-document.md#日本語の文字)に<strong>和文約物と全角形を足したもの</strong>である。
`、` `。` `「` `」` `（` `）` `！` `？` と、全角の英数字を含む。全角空白は空白なので除く。

<strong>率の分母を決める[日本語の文字](../020-document.md#日本語の文字)とは目的が違う。</strong>
`。` は日本語の文字として数えないが、<strong>その両側に空白が入らない点は仮名や漢字と変わらない。</strong>

<strong>約物を落とすと 8 割を見落とす。</strong> 実測で、はてなの書き出し 27 本にある和文を割る
折り返しは、仮名漢字どうしが 179 箇所、約物を含めると 935 箇所だった。

### 空白と認めるもの

<strong>半角スペース（U+0020）と全角スペース（U+3000）だけである。</strong> いくつ並んでいてもよい。

<strong>タブと改行は空白と認めず、機会そのものを切る。</strong> どちらも
[node の中の折り返し](../020-document.md#地の文は-1-本の文字列ではない)として現れるもので、
<strong>書き手が字の間に置いたと言えない</strong>。

<strong>分母は日本語の文字数ではない。</strong> 文字数で割ると、英数字を多く使う題材ほど値が
下がる。測れるのは表記の選択ではなく、その記事がどれだけ英語を含むかになってしまう。

## 線

> <strong>0.02 を超えたら、分かち書きである。</strong>

実測で引いた。素材 71 単位——本人の記事 50 本と基準 21 本——の最大が <strong>0.0065</strong>
（本人のはてな記事 1 本）、壊れた草稿が <strong>0.0523</strong> だった。<strong>両側に 3 倍以上の余裕が
ある。</strong>

<strong>カセットを見ない。</strong> 日本語として成立しているかは書き手の性質ではないので、
本人の幅ではなく固定の線で見る——[検査はカセットに依らない](../300-revise.md#日本語として成立しているかをいちばん先に見る)。

## 除外

隣り合う機会が 20 未満の文書では測らない。割合が跳ねる。

## 直し方

<strong>上</strong>: 日本語の文字どうしの間に入った空白を取り除く。

## 覚え書き

<strong>下限を持たない。</strong> 0 が正しい値であって、「少なすぎる」ということが起きない。
[和欧間スペース欠落](和欧間スペース欠落.md)が両側を持つのと違うのはここである。

<strong>取り込みが作る空白は、ここで数える前に落ちている。</strong> 書き出し側が折り返した改行も、
落とした行内コードの跡も、書き手の打鍵ではない——
[正規化が始末する](../030-normalize.md#書き手が打っていない空白を作らない)。
<strong>落とさないままこの指標を置くと、行内コードの多い記事ほど値が上がる</strong>——測れるのは
表記ではなく題材になる。
