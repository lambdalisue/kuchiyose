# 副詞

指示 / 品詞bigram / 品詞 / 両側 / 日本語 1,000 字あたり。

## 意味

副詞をどれだけ使うか。

## 出どころ

[品詞 bigram](品詞bigram.md)の細い切り口である。あの系統は品詞の並びを数百次元で持つが、
<strong>系統としては指示にならない</strong>——「何番目かの次元を増やせ」は言葉にならない
（[指標の種類](../100-metrics.md#指標の種類)）。<strong>副詞は品詞そのものが読めるので、
その 1 つを取り出せば指示になる。</strong>

品詞の分布が書き手を分けることは、日本語で直接確かめられている
（[財津・金](../../references/zaitsu-2018.md)）。

## 数え方

[地の文](../020-document.md#地の文)の形態素のうち、品詞が <strong>副詞</strong> であるものの数を、
日本語の字数 1,000 あたりに直す。

<strong>語形では決めない。</strong> `すでに` は副詞だが `すでの` は名詞である——解析器に決めさせる。

## 除外

<strong>解析器が無ければ測らない。</strong> 0 を返さない。

日本語 1,000 字未満の文書では測らない。

## 直し方

<strong>上</strong>: 「ずっと」「やはり」「かなり」のような副詞を足す。
<strong>下</strong>: 副詞を落とし、動詞と名詞で言い切る。

## 覚え書き

<strong>向きを決め打ってはいけない。</strong> 生成文は副詞を重ねると言われることがあるが、
実測では<strong>逆だった</strong>。

| | 1,000 字あたり |
| --- | --- |
| 本人（zenn） | 9.90 |
| 本人（はてな） | 7.90 |
| 基準（生成） | <strong>3.62</strong> |
| 別に生成した記事 | <strong>3.05</strong> |

<strong>機械のほうが 2〜3 倍少ない。</strong> ただし<strong>実際の AI が書いた記事は 10.69</strong> で、
本人と同じ側に来た——<strong>どの機械が書いたかで変わる。</strong> だから両側を見る。
