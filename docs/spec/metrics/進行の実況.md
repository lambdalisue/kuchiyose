# 進行の実況

指示 / なし / 語 / 上限 / 日本語 1,000 字あたり。

## 意味

文章そのものの進行を説明する文。中身ではなく段取りを語る。

## 出どころ

<strong>系統を名指しできない。</strong> 文章の段取りを述べる定型句という括りに対応する系統が、
先行研究に無い。語彙素は手で選んでおり、どの系統のどの切り口かを言えない。

> [!WARNING]
> <strong>したがってこの指標は[層 3](../100-metrics.md#層-3系統に遡れないもの)である</strong>——
> 測ってよいが、指摘にも判定にも使わない。分離することが確かめられた時点で層が上がる。
> [場面で成立するか](../100-metrics.md#場面で成立しないことがある)を最初に疑う。
## 数え方

[文](../020-document.md#文)のうち、次のいずれかを含むものの数。

本記事では / この記事では / 本稿では / ここからは / ここまでで / 以下では /
順に見て / 前置きが長く / まとめると / 話を戻すと / 本題に入る

文の数を数える。1 つの文に 2 つ含まれても 1 と数える。

## 直し方

<strong>上限だけを持つ</strong>——この種の文を消す。読者は目次を見れば分かる。
