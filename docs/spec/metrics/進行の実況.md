# 進行の実況

指示 / 語 / 上限 / 日本語 1,000 字あたり。

## 意味

文章そのものの進行を説明する文。中身ではなく段取りを語る。

## 出どころ

[機能語](機能語.md)の切り口——文章の段取りを述べる定型句。

> [!WARNING]
> <strong>先行研究の裏付けがいちばん薄い指標である。</strong> 語彙素を手で選んでおり、
> 対応する系統の次元としては特定できていない。[場面で成立するか](../100-metrics.md#場面で成立しないことがある)を
> 最初に疑う。
## 数え方

[文](../020-document.md#文)のうち、次のいずれかを含むものの数。

本記事では / この記事では / 本稿では / ここからは / ここまでで / 以下では /
順に見て / 前置きが長く / まとめると / 話を戻すと / 本題に入る

文の数を数える。1 つの文に 2 つ含まれても 1 と数える。

## 直し方

<strong>上</strong>: この種の文を消す。読者は目次を見れば分かる。

<strong>下</strong>: 段取りを述べる文を足す。
