# 接続詞直後の読点

指示 / 読点の打ち方 / 記号 / 両側 / 割合。

## 意味

接続詞の直後に読点を打つか。<strong>接続詞の語彙素ごとに、打つ・打たないが分かれる。</strong>

## 出どころ

[読点の打ち方](読点の打ち方.md)——直後の文字——の切り口。

規範と個人が分かれる場所として、日本語で直接調べられている。BCCWJ コアデータに
Elastic Net をかけた研究があり、<strong>語彙素「で」「が」「然しながら」「又」「ですから」「猶」「だが」
が強い指標</strong>として挙がっている（岩崎 2018、
[系譜](../../references/japanese-attribution-others.md#岩崎-拓也-2018-読点が接続詞の直後に打たれる要因)）。

## 数え方

[地の文](../020-document.md#地の文)で、品詞が接続詞である形態素のうち、直後が `、`
であるものの割合。

<strong>語彙素ごとに分けて持つ。</strong> 全接続詞をまとめた 1 つの割合にしない——まとめると、
規範で決まる分（文頭の接続詞の後には打つ、という公用文の常識）に薄まる。

<strong>文頭かどうかで分ける。</strong> 文頭の接続詞は打たれやすいことが分かっており、そこは
規範の層である。人が出るのは <strong>文中</strong> の側である。

### 語彙素は固定する

<strong>コーパスから選ばない。</strong> 書き手ごとに違う語彙素を採れば指標の名前が書き手ごとに変わり、
[名前は 1 度しか書かない](../100-metrics.md#名前は-1-度しか書かない)が守れなくなる。

<strong>この一覧はこの定義の一部である。</strong> 岩崎 2018 が強い指標として挙げた <strong>7 つ</strong>に、頻度の高い接続詞を足した 12。

で / が / だが / 然しながら / 又 / 猶 / ですから / しかし / また / そして / ただし / つまり

<strong>名前は「接続詞直後の読点・&lt;語彙素&gt;・&lt;文頭|文中&gt;」</strong>とする。12 × 2 = 24 のスカラーに
なり、どれも 1 つの[指示できる指標](../100-metrics.md#指標の種類)である。


## 除外

その語彙素が <strong>その位置に</strong> 10 回未満しか現れない文書では、その位置の値を測らない。
<strong>位置ごとに掛ける</strong>——文頭に 10 回、文中に 0 回の語彙素は、文中側の分母が 0 になる。

## 直し方

<strong>上</strong>: その接続詞の直後の読点を減らす。とくに文中のものから。

<strong>下</strong>: その接続詞の直後に読点を足す。

## 覚え書き

<strong>場面だけで大きく動く。</strong> 接続詞の直後に読点を打つ割合は、新聞 65.6%、
Yahoo! ブログ 39.5%。<strong>個人を見る前に 26 ポイントの幅がある。</strong>
[場面を固定せずに読まない](../200-extract.md#場面ごとに分ける)。
