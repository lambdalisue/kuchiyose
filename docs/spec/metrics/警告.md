# 警告

指示 / 構造 / 両側 / 日本語 1,000 字あたり。

## 意味

強い注意を、囲みで立てて示すか。[補足](補足.md)と分けるのは、囲みを使うことと
強い注意を出すことが別の癖だからである。

## 出どころ

[Stamatatos §2.5](../../references/stamatatos-2009.md)の応用固有の特徴——段落長、字下げ、
挨拶や結びの型——の、日本語と
[この文書モデル](../020-document.md#文書は-node-でできている)での対応物。

<strong>node の種類ごとの密度は先行研究に直接の対応が無い。</strong> 構造という分類に属することは
確かだが、この粒度で書き手を分けた報告は見当たらない。[場面で成立するか](../100-metrics.md#場面で成立しないことがある)
を最初に疑う側の指標である。

## 数え方

警告の node の数。記法は問わない。

## 直し方

<strong>上</strong>: 警告を減らす。

<strong>下</strong>: 警告を足す。
