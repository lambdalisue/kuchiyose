# 文節パターン

照合 / 品詞。

## 意味

文節を「自立語の品詞 + 付属語の並び」に還元した型の頻度分布。

## 出どころ

[金 2013](../../references/jin-2013.md)、[柳・金 2023](../../references/yanagi-jin-2023.md)、
[金 2014](../../references/jin-2014.md)。

<strong>単独では弱いのに、組み合わせには効く典型である。</strong> 日本語の文学作品 10 人で単独
F1 0.704 と最下位ながら、最良の組み合わせには必ず入っている
（[統合アンサンブル](../../references/japanese-attribution-recent.md)）。
<strong>順位で落とさない</strong>（[指標](../100-metrics.md#単独で弱いことも落とす理由にならない)）。

## 数え方

[地の文](../020-document.md#地の文)を文節に区切り、B 型で表現する——自立語は品詞名に
置き換え、<strong>付属語は表層形のまま</strong>残す
（[柳・金 2023](../../references/yanagi-jin-2023.md)）。

```
赤い / 花が / 咲いた。  →  形容詞 / 名詞＋が / 動詞＋助動詞＋。
```

型ごとに頻度を数え、相対頻度に直す。

## 次元

頻度上位 <strong>800</strong> 程度。

## 除外

日本語 1,000 字未満の文書では測らない。

## 覚え書き

<strong>係り受け解析器が要る。</strong> ほかの系統より依存が重く、解析器と対象のずれの影響も
大きい。<strong>場面によって成立しないことを最初に疑う系統である</strong>
（[指標](../100-metrics.md#場面で成立しないことがある)）。

そして <strong>ジャンルに引きずられやすい側</strong>にある（[柳・金 2022](../../references/yanagi-jin-2022.md)）。
場面を借りるときの手掛かりには使わない。
