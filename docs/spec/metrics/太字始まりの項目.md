# 太字始まりの項目

指示 / 構造 / 上限 / 箇条書き項目に対する割合。

## 意味

`- **語**: 説明` の型で項目を立てる書き方。項目名を太字にして定義を並べる形。

## 出どころ

[Writeprints](../../references/writeprints-liwc.md) の <strong>構造的</strong> 特徴——段落数、文数、
それぞれの平均長、挨拶や結びの有無——の、日本語と
[この文書モデル](../020-document.md#文書は-node-でできている)での対応物。

<strong>node の種類ごとの密度は先行研究に直接の対応が無い。</strong> 構造という分類に属することは
確かだが、この粒度で書き手を分けた報告は見当たらない。[場面で成立するか](../100-metrics.md#場面で成立しないことがある)
を最初に疑う側の指標である。

## 数え方

箇条書きの項目のうち、強調で始まるものの割合。分母は箇条書きの項目数。

## 除外

箇条書きの項目が 3 つ未満の文書では測らない。1 つ該当しただけで割合が跳ねる。

## 直し方

<strong>上</strong>: 項目の先頭の強調を外す。

<strong>下</strong>: 項目の先頭を強調する。
