# 太字始まりの項目

指示 / 構造 / 上限 / 項目に対する割合。

## 意味

`- **語**: 説明` の型で項目を立てる書き方。項目名を太字にして定義を並べる形。

## 出どころ

[Stamatatos §2.5](../../references/stamatatos-2009.md)の応用固有の特徴——段落長、字下げ、
挨拶や結びの型——の、日本語と
[この文書モデル](../020-document.md#文書は-node-でできている)での対応物。

<strong>node の種類ごとの密度は先行研究に直接の対応が無い。</strong> 構造という分類に属することは
確かだが、この粒度で書き手を分けた報告は見当たらない。[場面で成立するか](../100-metrics.md#場面で成立しないことがある)
を最初に疑う側の指標である。

## 数え方

[項目](../020-document.md#項目)のうち、強調で始まるものの割合。分母は項目数。

<strong>番号リストの項目も含める。</strong> `1. <strong>語</strong>: 説明` は箇条書きと同じくらい使われる。

## 除外

項目が 10 未満の文書では測らない。割合の指標なので、既定の 5 では 1 つ該当しただけで値が跳ねる。

## 直し方

<strong>上限だけを持つ</strong>——項目の先頭の強調を外す。
