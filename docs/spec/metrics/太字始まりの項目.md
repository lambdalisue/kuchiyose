# 太字始まりの項目

<strong>草案。</strong> まだ集合に入っていない（[100](../100-metrics.md#定義を書くことと集合に入れることは別)）。

修辞 / 上限 / 箇条書き項目に対する割合。

## 意味

`- **語**: 説明` の型で項目を立てる書き方。項目名を太字にして定義を並べる形。

## 数え方

箇条書きの項目のうち、強調で始まるものの割合。分母は箇条書きの項目数。

## 除外

箇条書きの項目が 3 つ未満の文書では測らない。1 つ該当しただけで割合が跳ねる。

## 直し方

上: この型をやめ、項目を普通の文で書く。

## 確かめた場面

技術記事。条件 4 だけ確認済み（値が動く）。この書き手では基準と分離した。
条件 1、2、3、5、6 は未確認。
