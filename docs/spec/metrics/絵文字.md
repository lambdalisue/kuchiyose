# 絵文字

指示 / 表記 / 表記 / 両側 / 日本語 1,000 字あたり。

## 意味

文字以外で調子を添えるか。

## 出どころ

[文書の形](../020-document.md#表記は残る優先して採る理由がある) が定める <strong>表記の選択</strong> の 1 つ。

英語の文体表現を凝集型クラスタリングにかけると、アポストロフィの字種・末尾の句読点・
改行といった <strong>意味を持たない表記の選択が上位クラスタを作る</strong>
（[Wegmann](../../references/wegmann-2022.md)）。人が自分の文章を直すときに手を入れるのも
この層である（[Post-Editing](../../references/post-editing-2026.md)）。

## 数え方

[地の文](../020-document.md#地の文)に現れる、Unicode の Emoji_Presentation を持つ
文字の数。

<strong>書記素クラスタで 1 つと数える。</strong> 見た目が 1 つだからである——ゼロ幅接合子で繋いだ列、
国旗（地域指標符号の対）、肌の色の指定、異体字セレクタ付きのものは、どれも 1 である。

<strong>Unicode の版を[指紋](../200-extract.md#何で測ったかを指紋にする)に含める。</strong> 版が変われば
絵文字と認める範囲が変わる。

## 直し方

<strong>上</strong>: 絵文字を減らす。

<strong>下</strong>: 絵文字を足す。
