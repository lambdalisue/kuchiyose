# 絵文字

指示 / 表記 / 表記 / 両側 / 日本語 1,000 字あたり。

## 意味

文字以外で調子を添えるか。

## 出どころ

[文書の形](../020-document.md#表記は残る優先して採る理由がある) が定める <strong>表記の選択</strong> の 1 つ。

英語の文体表現を凝集型クラスタリングにかけると、アポストロフィの字種・末尾の句読点・
改行といった <strong>意味を持たない表記の選択が上位クラスタを作る</strong>
（[Wegmann](../../references/wegmann-2022.md)）。人が自分の文章を直すときに手を入れるのも
この層である（[Post-Editing](../../references/post-editing-2026.md)）。

## 数え方

[地の文](../020-document.md#地の文)に現れる絵文字の数。

<strong>数える単位は書記素クラスタである。</strong> 見た目が 1 つだからである——ゼロ幅接合子で繋いだ列、
国旗（地域指標符号の対）、肌の色の指定、異体字セレクタ付きのものは、どれも 1 である。

<strong>何を絵文字と認めるかは、2 段で決める。</strong>

| | 何を拾うか | どの表から |
| --- | --- | --- |
| 1 | <strong>推奨される絵文字の列</strong>（keycap、旗、旗のタグ列、肌の色、ZWJ 列） | `emoji-sequences.txt`、`emoji-zwj-sequences.txt` |
| 2 | <strong>`U+FE0F` を伴う絵文字表示列</strong> | `emoji-variation-sequences.txt` |
| 3 | 1 と 2 に当たらない単独の文字のうち、<strong>`Emoji_Presentation` を持つもの</strong> | `emoji-data.txt` |

<strong>上から順に、最長一致で取る。</strong> あとにすると、`U+0031 U+FE0F U+20E3`（`1️⃣`）の先頭の
`1` が数字として先に消費され、列が壊れる。<strong>旗のタグ列（England・Scotland・Wales）も
1 に含める</strong>——落とすと、タグ符号がばらばらに残る。

<strong>`Emoji_Presentation` だけを入口にしてはいけない。</strong> 既定が文字表示の記号——`U+2764`
（`❤`）など——は `Emoji_Presentation` を持たないが、`U+FE0F` を付ければ絵文字として
表示される。入口を 1 つにすると、<strong>それらが 1 つも数えられないまま、上の「異体字
セレクタ付きも 1」だけが宙に浮く。</strong>

<strong>逆に、表に載らない `U+FE0F` の付け方は数えない。</strong> どの文字でも `U+FE0F` を付ければ
絵文字になるわけではない。<strong>`→` や `✓` をそのまま絵文字に数えると、記号を使う書き手が
絵文字を使う書き手として出る。</strong>

<strong>使った表の版とチェックサムを[指紋](../200-extract.md#何で測ったかを指紋にする)に出す。</strong>
版が上がれば推奨列が増え、同じ本文の数が変わる。

## 保留

<strong>表をまだ持っていない。</strong> 上の 3 段のうち、<strong>1 と 2 は表がなければ引けない</strong>——
推奨列も絵文字表示列も、Unicode が配る一覧で決まるものである。

<strong>数える単位のほうは表なしで決まる。</strong> ZWJ で繋がっているか、地域指標符号が
2 つ並んでいるか、肌の色や異体字セレクタが続いているかは、符号位置だけで判る。
<strong>だからそこは先に通す</strong>——[骨格を先に通す](../010-strategy.md#それでも骨格を先に通す)。

| | いまの状態 |
| --- | --- |
| 数える単位（書記素クラスタ） | <strong>決まっている</strong> |
| どの文字を絵文字と認めるか | <strong>暫定の区画表</strong>。表を入れるまで |

<strong>暫定であることを指紋に出す。</strong> 表を入れたら値が変わるので、それまでの値と
比べてはいけない。

<strong>Unicode の版を[指紋](../200-extract.md#何で測ったかを指紋にする)に含める。</strong> 版が変われば
絵文字と認める範囲が変わる。
