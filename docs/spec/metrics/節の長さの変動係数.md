# 節の長さの変動係数

ばらつき / 下限 / 無次元。

## 意味

節の長さが揃っているか。[段落長の変動係数](段落長の変動係数.md)を 1 つ上の単位で
見たもの。

## 数え方

節ごとの日本語文字数の標準偏差を、その平均で割る。節は深さ 2 の見出しで区切る。

## 除外

節が 5 つ未満の文書では測らない。

## 確かめた場面

技術記事。条件 4 だけ確認済み（値が動く）。この書き手では基準と分離しなかったが、
それは[外す理由にならない](../100-metrics.md#目の前の書き手を区別できないことは-外す理由にならない)。
条件 1、2、3、5、6 は未確認。
