# 文字 bigram

照合 / 記号。

## 意味

隣り合う 2 文字の組の頻度分布。何を書いたかより、どう綴ったかが出る。

## 出どころ

[金 2014](../../references/jin-2014.md)、[尤度比 2026](../../references/fusing-lr-2026.md)、
[柳・金 2022](../../references/yanagi-jin-2022.md)。日本語ブログ 2,287 人で、単独の
計量文体論としては最良（Cllr 0.471）。

## 数え方

[地の文](../020-document.md#地の文)の文字列から、隣接する 2 文字の組を取り、
出現頻度を数える。<strong>相対頻度に直す</strong>——文書の長さが揃わないためである。

<strong>n を 3 以上にしない。</strong> 内容とジャンルの雑音を強く拾う
（[金 2014](../../references/jin-2014.md)）。

## 次元

全体で頻度の高い順に <strong>500</strong>。[尤度比 2026](../../references/fusing-lr-2026.md) が
500 まで増やして収束を確認している。

<strong>頻度で選ぶ。判別力で選抜しない</strong>（[指標](../100-metrics.md#単独で弱いことも落とす理由にならない)）。

## 覚え書き

500 次元に対して標本が足りず、分布が疎になる。
