# 段落あたりの文数

指示 / 長さ / 長さ / 両側 / 無次元。

## 意味

段落をどれくらいの分量で切るか。

## 出どころ

[Stamatatos §2.5](../../references/stamatatos-2009.md)の応用固有の特徴（段落長、字下げ、
挨拶や結びの型）の拡張。平均ではなく <strong>ばらつき</strong> を見る点が先行研究より踏み込んでいる。

> [!NOTE]
> [金 2014](../../references/jin-2014.md) が効かないと名指ししたのは <strong>文の長さ</strong> であって、
> 段落や節の構造ではない。<strong>混同しない。</strong> ただし直接の裏付けも無いので、
> [場面で成立するか](../100-metrics.md#場面で成立しないことがある)は確かめる。

## 数え方

<strong>段落に含まれる</strong>文の数を、段落の数で割る。単位の意味は
[文書の形](../020-document.md#段落)が決める。

<strong>見出しや項目やセルの文を分子に入れない。</strong> 入れれば、見出しの多い文書ほど
「段落あたりの文数」が増える。


## 直し方

<strong>上</strong>: 段落を細かく割る。

<strong>下</strong>: 段落に文をまとめる。
