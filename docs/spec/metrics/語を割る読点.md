# 語を割る読点

検査 / 上限 / 0 / 語を割っている読点の個数。

## 意味

読点が語の内側に入っているか。`あらため、て取得し直す` は `改めて` を割っている。
`体感できるほど、のレイテンシ` も同じ壊れ方である。

<strong>[和文間スペース](和文間スペース.md)と同じ穴である。</strong> あちらは「文字種の空白を増やせ」を
和文間で満たしたもので、こちらは「読点の打ち方を寄せろ」を語の内側で満たしたもの。
<strong>どちらも指標は満たされ、日本語は壊れる。</strong>

## 出どころ

<strong>書き手を分けるために置いたのではない。</strong> だから
[検査](../100-metrics.md#検査は書きぶりではなく壊れ方を見る)であって指示できる指標ではない。

実測。[読点の打ち方](読点の打ち方.md)を寄せろという指示に従った草稿に
`あらため、て取得し直す` と `体感できるほど、のレイテンシ` が入り、<strong>そのまま通った。</strong>

## 数え方

[地の文](../020-document.md#地の文)の形態素列を走査し、次の形を<strong>候補</strong>とする。

> <strong>読点</strong> → <strong>助詞または助動詞</strong>

その読点を抜いて<strong>解析し直し</strong>、<strong>読点があった位置に語の切れ目が残るか</strong>を見る。
残らなければ、読点は語の内側にあった。<strong>残らなかったものの個数</strong>が値である。

<strong>窓は前後 3 形態素に切る。</strong> 文書ぜんぶを解析し直すと、離れた場所の切れ目の変化まで
拾ってしまう。

### なぜ候補を付属語に絞るのか

<strong>助詞と助動詞は単独で文節を始められない。</strong> 読点の直後にそれが来ているなら、前の語に
付いていた可能性がある。

<strong>絞らないと誤る。</strong> 名詞どうしの並びは、読点を外せば別の語に読めてしまう。

| 例 | 読点を外すと | |
| --- | --- | --- |
| `あ、あと` | `ああと` | 別の語に読める |
| `リンタ、フォーマッタ` | `リンタフォーマッタ` | 1 語に読める |

実測で、絞らないと素材 71 本のうち <strong>5 本</strong>で誤り、絞ると <strong>0 本</strong>になった。

### なぜ「その形を本人が書くか」で見ないのか

<strong>それでも捕まる。</strong> 素材に無い「読点＋付属語」の形を外れとすれば、
`あらため、て` も `ほど、の` も両方当たる。<strong>だが本人の記事 2 本を巻き添えにした</strong>
——`ある、という` と `さて、では` である。

| 見方 | 誤検出 | 壊れを捕まえた |
| --- | --- | --- |
| 素材に無い形（本人だけ） | <strong>2 / 50</strong> | 2 / 2 |
| 素材に無い形（本人＋基準） | 1 / 71 | 1 / 2 |
| <strong>語を割る</strong> | <strong>0 / 71</strong> | 1 / 2 |

<strong>0 段目は「通らない」を返す。</strong> 誤って止めることの代償が大きいので、
<strong>捕まえる数より誤検出 0 を採った</strong>（[検査を足す条件](../100-metrics.md#検査を足す条件)）。

<strong>そして基準を素材にしてはいけない。</strong> 「素材に無い形（本人＋基準）」で `、の` を支えて
いたのは、<strong>機械が 5 本に書いた同じ定型</strong>（`記録を残すこと、の三点`）だった。
機械の出力は「人が書く形」の証拠にならない。

<strong>形代を見ないのも、そのためである。</strong> 読点が語を割っているかは書き手の性質ではない。

## 線

> <strong>1 つでもあれば、壊れている。</strong>

実測で引いた。素材 71 本・読点 3,721 個のうち、候補は 15 個、<strong>語を割るものは 0 個</strong>
だった。壊れた草稿だけが 1 個当たる。

## 除外

候補が 1 つも無ければ 0 である。<strong>「測れない」ではない</strong>——読点が語を割っていない
ことは、測れた結果である。

## 直し方

<strong>上</strong>: 語の内側に入った読点を外す。

## 覚え書き

<strong>`ほど、の` は捕まえられていない。</strong> `ほどの` は 2 形態素のままなので、読点を外しても
切れ目が残る。<strong>同じ種類の穴が残っていることを、消さずに書いておく。</strong>
