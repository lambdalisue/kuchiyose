# 機能語

照合 / 語。

## 意味

助詞・助動詞・接続詞・副詞・感動詞の頻度分布。<strong>文体を担う中心である。</strong>

意味を運ばず、題材にほとんど依存せず、書き手が概ね無意識に選ぶ。
[戦略](../010-strategy.md#書きぶりとは何か)の性質 3 と 4 が、そのまま当てはまる語群である。

## 出どころ

[財津・金 2018](../../references/zaitsu-2018.md)（非自立語の使用率、助詞の bigram）、
[Writeprints](../../references/writeprints-liwc.md)（557 次元中 <strong>403 が機能語</strong>）、
[Stamatatos §2.1](../../references/stamatatos-2009.md)。

日本語では実証が強い。話し言葉の個人性変換で、<strong>4,720 万組の言い換えデータベースが、
助詞・助動詞・感動詞・フィラーを集めた 1,338 組の辞書に負けた</strong>
（[水上ほか](../../references/mizukami-2014.md)）。<strong>覆う範囲ではなく、覆う場所が効く。</strong>

## 数え方

[地の文](../020-document.md#地の文)を形態素解析し、品詞が助詞・助動詞・接続詞・副詞・
感動詞である形態素の <strong>表層形</strong> ごとに頻度を数え、相対頻度に直す。

表層形で数える。「は」と「わ」、「けれど」と「けど」は別に扱う。<strong>そこが人によって
違う。</strong>

## 次元

全体で頻度の高い順に <strong>300</strong>。<strong>暫定値であり、確定するまで[指紋](../200-extract.md#何で測ったかを指紋にする)に含める。</strong> 上限は素材の量で決める——次元が標本を超えれば
分布が疎になる。


## 覚え書き

解析器と対象がずれると精度が落ちる（[柳・金 2023](../../references/yanagi-jin-2023.md)）。
新聞で訓練した解析器を技術記事やチャットに当てている自覚を持つ。<strong>どの辞書・どの版で
解析したかを、[基準の記録](../200-extract.md#版と推論設定まで記録する)と同じ扱いで
残す。</strong>
