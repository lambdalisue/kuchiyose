# 笑い

<strong>草案。</strong> まだ集合に入っていない（[100](../100-metrics.md#定義を書くことと集合に入れることは別)）。

記号 / 両側 / 日本語 1,000 字あたり。

## 意味

笑いを表す書き方をどれだけ使うか。

## 数え方

[地の文](../020-document.md#地の文)に現れる、次のいずれかの数。

- `w` `ｗ` の連続。ただし前後が英字でないもの
- `（笑）` `(笑)`
- `草`。ただし単独の語として現れるもの

連続は 1 と数える。`www` は 3 ではなく 1。回数ではなく、笑いを差し込んだ箇所の数を
見たいためである。

## 確かめた場面

なし。前身から一括で引き継いだままで、どの条件も確かめていない。
