# 笑い

指示 / 表記 / 両側 / 日本語 1,000 字あたり。

## 意味

笑いを表す書き方をどれだけ使うか。

## 出どころ

[文書の形](../020-document.md#表記は残る優先して採る理由がある) が定める <strong>表記の選択</strong> の 1 つ。

英語の文体表現を凝集型クラスタリングにかけると、アポストロフィの字種・末尾の句読点・
改行といった <strong>意味を持たない表記の選択が上位クラスタを作る</strong>
（[Wegmann](../../references/wegmann-2022.md)）。人が自分の文章を直すときに手を入れるのも
この層である（[Post-Editing](../../references/post-editing-2026.md)）。

## 数え方

[地の文](../020-document.md#地の文)に現れる、次のいずれかの数。

- `w` `ｗ` の連続。ただし直前と直後が英字でないもの
- `（笑）` `(笑)` `(笑)`
- <strong>前後がどちらも日本語の文字でない</strong> `草`（「雑草」を拾わないため）

連続は 1 と数える。`www` は 3 ではなく 1。<strong>`w` 1 つも 1 と数える。</strong>回数ではなく、笑いを差し込んだ箇所の数を見たいためである。

<strong>1 か所は 1 度だけ数える。</strong> 上の 3 つは重ならないが、重なる書き方が来ても
[対比構文](対比構文.md)と同じ最長一致で 1 つに畳む。

## 直し方

<strong>上</strong>: 笑いの書き方を減らす。

<strong>下</strong>: 笑いの書き方を足す。
