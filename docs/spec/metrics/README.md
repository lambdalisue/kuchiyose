# 指標

[戦略](../010-strategy.md)の 1 段目が定義する、指標の集合。

1 指標 1 ファイル。形と、集合に入る条件は
[100-metrics.md](../100-metrics.md) が決める。

「地の文」「日本語の文字」「文」「段落」といった語の意味は
[020-document.md](../020-document.md) が決める。ここでは繰り返さない。

## ここにあるのは定義だけ

どの条件を確かめたか、どの書き手に効いたかは書かない。前者は測れば出るもの、後者は
書き手ごとに変わるものである
（[100](../100-metrics.md#判定の結果を書き留めない)）。

集合は誰にでも当てる候補である。ある人に効かない指標が別の人には効くので、書き手
ごとの取捨は [200](../200-extract.md#どの指標が効くかを決める) が行う。

## 足すとき、外すとき

足すのはファイルを 1 つ増やすこと、外すのは 1 つ消すことで終わる。それ以上の手続き
を要求しない。手続きが重いと、指標を試すループが止まる。
