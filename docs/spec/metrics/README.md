# 指標

[指標を決める](../100-metrics.md)が定義する、指標の集合。

<strong>指標は既にあるものを使う。</strong> 何が書き手を分けるかは先行研究が確かめている。形も、出どころの
要求も、足し引きの規則も [指標を決める](../100-metrics.md) が決める。ここでは繰り返さない。

「地の文」「日本語の文字」「文」「段落」といった語の意味は
[文書の形](../020-document.md) が決める。

## 2 種類ある

| | 種別 | 何に使うか |
| --- | --- | --- |
| <strong>系統</strong> | `照合` | [検める](../300-revise.md)。数百次元のベクトルを距離で比べる |
| <strong>指示できる指標</strong> | `指示` | [指摘する](../300-revise.md)。3〜4 本を選んで渡す |

<strong>指示できる指標は、系統の細い切り口である</strong>
（[指標](../100-metrics.md#指示できる指標は系統の細い切り口である)）。だから出どころは
必ず系統に遡れる。遡れないものは、先行研究に基づいていない。

## ここにあるのは定義だけ

どの書き手に効いたかは書かない。書き手ごとに変わるものであり、置き場所は
[評価の成果物](../200-extract.md)である
（[指標](../100-metrics.md#測った値は置かない)）。

集合は誰にでも当てる。書き手ごとの選択は
[評価](../200-extract.md#どの指標が効くかを決める) が行い、<strong>そこで落ちても集合からは
外れない</strong>（[指標](../100-metrics.md#集合は広く持つ絞るのはあとである)）。

## 足すとき、外すとき

<strong>手続きは [指標](../100-metrics.md#集合が変わるとき) が決める。</strong> 要点だけ再掲する。

- 足す理由は 2 つだけ。<strong>先行研究が増えたときと、本人の指摘</strong>
- <strong>出どころの無いものは足さない</strong>
- 外してよいのは <strong>重複しているとき</strong> だけ

ファイルの増減そのものは 1 つ足す・1 つ消すで終わる。<strong>軽いのは操作であって、
判断ではない。</strong>
