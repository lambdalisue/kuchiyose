# 指標

[指標を決める](../100-metrics.md)が定義する、指標の集合。

<strong>指標は既にあるものを使う。</strong> 何が書き手を分けるかは先行研究が確かめている。形も、出どころの
要求も、足し引きの規則も [指標を決める](../100-metrics.md) が決める。ここでは繰り返さない。

「地の文」「日本語の文字」「文」「段落」「節」「項目」「見出しの深さ」の意味は
[文書の形](../020-document.md#数える単位) が決める。<strong>定義ファイルで決め直さない。</strong>

## 指標の種類

| | 種別 | 何と比べるか | 何に使うか |
| --- | --- | --- | --- |
| <strong>系統</strong> | `照合` | 本人の分布 | [照合値](../200-extract.md#何を目盛りに載せるのか)にして全体の判定へ |
| <strong>指示できる指標</strong> | `指示` | 本人の幅 | [指摘する](../300-revise.md#指摘は-3-本か-4-本に絞る)。3〜4 本を選んで渡す |
| <strong>人らしさ</strong> | `人らしさ` | [本人と基準の境目](../200-extract.md#人らしさの境目は同じ材料から出る) | [基準との距離](../../glossary.md#基準との距離)にして別立てで判定し、枠の外で渡す |
| <strong>検査</strong> | `検査` | <strong>固定の線</strong>（本人でも基準でもない） | [判定のいちばん先](../300-revise.md#日本語として成立しているかをいちばん先に見る)で使う。指摘は出さない |

<strong>検査だけは、比べる先がその人ではない</strong>（[検査](../100-metrics.md#検査は書きぶりではなく壊れ方を見る)）。
書きぶりの違いではなく、<strong>日本語として成立しているか</strong>を見るためである。

<strong>指示できる指標は、系統の細い切り口である</strong>
（[指標](../100-metrics.md#指示できる指標は系統の細い切り口である)）。<strong>どの系統から切り出した
かは[札](../100-metrics.md#定義に落とす)が名指しする</strong>——出どころの散文から読み取らせない。

<strong>札が `なし` のものは[層 3](../100-metrics.md#層-3系統に遡れないもの)で、指摘にも判定にも
使わない。</strong>

## 系統

ここに定義を持つ系統の一覧である。<strong>層はここに書かない</strong>——
[指標](../100-metrics.md#何を使うか)の 3 つの表が持つ。指示できる指標は、出どころが名指し
した系統から層を継ぐ（[規則](../100-metrics.md#層は系統の属性である指標は系統から引く)）。

| | 分類 |
| --- | --- |
| [文字 bigram](文字bigram.md) | 記号 |
| [機能語](機能語.md) | 語 |
| [品詞 bigram](品詞bigram.md) | 品詞 |
| [読点の打ち方](読点の打ち方.md) | 記号 |
| [文字種](文字種.md) | 表記 |
| [文節パターン](文節パターン.md) | 品詞。<strong>[保留中](文節パターン.md#保留)</strong> |
| [文末表現](文末表現.md) | 語。<strong>[保留中](文末表現.md#保留)</strong> |
| [語の文体値](語の文体値.md) | 語。[使っていない](#語の文体値は定義だけを持つ) |

<strong>定義ファイルを持たない系統もある。</strong> 表記の選択と構造と長さは、切り口だけを指標として
持ち、系統そのものは[文書の形](../020-document.md#表記は残る優先して採る理由がある)と
[指標](../100-metrics.md#層-2別の目的の研究から取るもの)が説明する。埋め込みは
[当面使わない](../100-metrics.md#埋め込みは保留する)。

上のうち <strong>文字 bigram・機能語・品詞 bigram・読点の打ち方・文字種の 5 つ</strong>が、
[尤度比](../../references/fusing-lr-2026.md)が日本語ブログ 2,287 人で扱った計量文体論の
特徴である。<strong>そのまま最良の組み合わせなのではない。</strong> 最良（Cllr 0.32484 / EER 9.3%）は
文字 bigram・読点 bigram・文字種に <strong>埋め込み 2 つ</strong>を混ぜた 5 系統で、<strong>機能語と品詞
bigram はそこから落ちている</strong>（[指標](../100-metrics.md#較正されているのは層-1-の一部である)）。

### 語の文体値は定義だけを持つ

語の文体値は、定義ファイルはあるが、いまは測っていない。語に文体値を付ける表
（[馬場 2022](../../references/baba-2022.md)）を道具に同梱しておらず、表が無ければ値が出ない。
照合値の系統には選ばれず（層 2 なので[判定に使う系統](../200-extract.md#判定に使う系統を選ぶ)
に入らない）、指示できる指標の出どころにもなっていない。指紋にも、外部の表として「使わない」
と記録している。

定義ファイルは消さない。集合は[広く持つ](../100-metrics.md#集合は広く持つ絞るのはあとである)。
表を同梱して測るようにするときは、この定義から始める。

## 人らしさ

| | 向き |
| --- | --- |
| [短い繰り返し](短い繰り返し.md) | 両側 |
| [長い繰り返し](長い繰り返し.md) | 両側 |
| [エントロピー](エントロピー.md) | 両側 |
| [圧縮率](圧縮率.md) | 両側 |
| [語彙の豊富さ](語彙の豊富さ.md) | 両側 |
| [句読点の密度](句読点の密度.md) | 両側 |

[味が出るための 2 つ目の条件](../010-strategy.md#味が出るには-2-つ要る)、つまり基準の書きぶりが
残っていないかを測る。その人らしさの照合に混ぜない。比べる相手は本人の幅ではなく
[本人と基準の境目](../200-extract.md#人らしさの境目は同じ材料から出る)で、その境目に照らした値が
[基準との距離](../../glossary.md#基準との距離)である。種類の名前は、出どころが人と機械の文章を
分ける研究であることから来ている（[指標の種類](../100-metrics.md#指標の種類)）。

どれも両側を持つ。どちらへ寄せるかは
[組み合わせごとの較正が決める](../200-extract.md#人らしさの境目は同じ材料から出る)ので、
定義はどちらの動かし方も書いておく。

<strong>句読点の密度をのぞく 5 つは、同じ現象を別の角度から見ている。</strong> 独立した 5 つの証拠として
数えない（[評価](../200-extract.md#人らしさの境目は同じ材料から出る)）。

<strong>句読点の密度だけが、その 5 つと現象が違う。</strong> 語を数えないので、
<strong>題材の広い文章が誰の手でも機械の側へ出る交絡</strong>を受けない。実測では、これを足して
本人の最小と基準の最大の隔たりが <strong>0.225 から 0.726</strong> へ広がった。

## ここにあるのは定義だけ

どの書き手に効いたかは書かない。書き手ごとに変わるものであり、置き場所は
[評価の成果物](../200-extract.md)である
（[指標](../100-metrics.md#測った値は置かない)）。

集合は誰にでも当てる。書き手ごとの選択は
[評価](../200-extract.md#どの指標が効くかを決める) が行い、<strong>そこで落ちても集合からは
外れない</strong>（[指標](../100-metrics.md#集合は広く持つ絞るのはあとである)）。

## 足すとき、外すとき

<strong>手続きは [指標](../100-metrics.md#集合が変わるとき) が決める。</strong> 要点だけ再掲する。

- 足す理由は 2 つだけ。<strong>先行研究が増えたときと、本人の指摘</strong>
- <strong>出どころの無いものは足さない</strong>
- 外してよいのは <strong>重複しているとき</strong> だけ

ファイルの増減そのものは 1 つ足す・1 つ消すで終わる。<strong>軽いのは操作であって、
判断ではない。</strong>
