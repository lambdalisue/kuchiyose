# 指標

1 指標 1 ファイル。形は [100-metrics.md](../100-metrics.md#指標とは何か)
が決める。

「地の文」「日本語 1,000 字あたり」「文」「段落」といった語の意味は
[020-document.md](../020-document.md) が決める。ここでは繰り返さない。

ここにあるのは <strong>草案</strong> であって、指標の集合ではない。定義は書かれているが、条件を
確かめていない（[100](../100-metrics.md#定義を書くことと集合に入れることは別)）。

条件を確かめる実装がまだ無いので、いまのところ全件が草案である。

集合に入ったあとも、それは誰にでも当てる候補である。ある人に効かない指標が別の人
には効くので、書き手ごとの取捨は [200](../200-extract.md#どの指標が効くかを決める)
が行う。

入る条件も残る条件も [100](../100-metrics.md#集合にいる条件) が決める。満たさなく
なったものが外れる。
