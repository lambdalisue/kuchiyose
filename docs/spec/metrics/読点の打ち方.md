# 読点の打ち方

照合 / 記号。

## 意味

読点を <strong>どこに</strong> 打つか。密度ではなく位置である。

## 出どころ

<strong>日本語の書き手識別を扱った主要な研究すべてに入っている。</strong>
[財津・金 2018](../../references/zaitsu-2018.md)、[金 2014](../../references/jin-2014.md)、
[尤度比 2026](../../references/fusing-lr-2026.md)（読点とその直前の文字の bigram）、
[柳・金 2022](../../references/yanagi-jin-2022.md)。

古典は金・樺島・村上 (1993)「読点と書き手の個性」。有効とされたのは <strong>読点の前の文字、
前の文字の品詞、打つ間隔</strong> の 3 つ
（[系譜](../../references/japanese-attribution-others.md#読点の打ち方定義が確定した)）。

## 数え方

3 つを別の部分ベクトルとして持ち、連結する。

| | 何を数えるか |
| --- | --- |
| 直前の文字 | [地の文](../020-document.md#地の文)の `、` の直前 1 文字の頻度分布（[尤度比](../../references/fusing-lr-2026.md)が使ったのはこちら） |
| 直後の文字 | `、` の直後 1 文字の頻度分布 |
| 間隔 | `、` から次の `、` または文末までの[日本語の文字](../020-document.md#日本語の文字)数の分布 |

いずれも相対頻度に直す。

<strong>直前・直後の次元には「文末」を表す番兵を 1 つ置く。</strong> 文の最後が `、` で終わる書き方が
あり、置かなければその読点が直後の分布からだけ静かに消える。

## 次元

直前・直後はそれぞれ頻度上位 50、間隔は 1〜20 字を 1 字刻み + 21 字以上で 21。
<strong>「50 程度」は暫定値であり、確定するまで[指紋](../200-extract.md#何で測ったかを指紋にする)に含める。</strong>

## 除外

読点が 5 個未満の文書では測らない。分布と呼べる形にならない。

## 覚え書き

<strong>密度（1,000 字あたりの `、` の数）は、この系統に含めない。</strong> 誰もが打つ層——意味・
長さ・構造で決まる分——が大半を占め、規範に薄まる
（[指標](../010-strategy.md#規範の層を分ける)）。人が出るのは位置の側である。

指示に使う切り口は[接続詞直後の読点](接続詞直後の読点.md)が持つ。
