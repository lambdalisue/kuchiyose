# 段落の敬体率

指示 / なし / 構造 / 両側 / 敬体か常体で終わった文に対する割合。

## 意味

段落の文がどれだけ敬体（です・ます）で終わっているか。

<strong>node の種類ごとに数える。</strong> 同じ書き手が場所によって文体を変えるので、
地の文をまとめて数えると使い分けが混ざって消える
（[文体は node の種類ごとに違う](../100-metrics.md#文体は-node-の種類ごとに違う)）。

## 出どころ

[文書の形](../020-document.md#数える単位)が定める <strong>段落</strong>と、その中の文。

<strong>系統を名指しできない。</strong> 文末表現の系統は[保留中](文末表現.md#保留)で、
この指標はそこから切り出したものではない。

## 数え方

[段落](../020-document.md#数える単位)の中の文を数え、<strong>敬体で終わったもの ÷
（敬体で終わったもの ＋ 常体で終わったもの）</strong>を出す。

| | 認める語尾 |
| --- | --- |
| <strong>敬体</strong> | です・ます・ました・ません・でしょう・ましょう・でした・ください |
| <strong>常体</strong> | である・だ・した・する・ない・いる・なる・った・れる・たい |

<strong>どちらでもない文は、分母にも分子にも入れない。</strong> 体言止めと疑問符で終わる文が
それにあたる——入れると、<strong>体言止めの多い書き手ほど敬体率が下がる</strong>。

<strong>句点と感嘆符と疑問符を落としてから見る。</strong>

## 除外

敬体か常体で終わった文が 10 未満の文書では測らない。割合が跳ねる。

## 直し方

<strong>上</strong>: 段落の文末を常体（である・だ）にする。
<strong>下</strong>: 段落の文末を敬体（です・ます）にする。

## 覚え書き

実測で、ある書き手は段落の <strong>93%</strong> を敬体で書き、箇条書きの 85% と見出しの 99% を
常体で書いていた。<strong>まとめて数えれば「敬体 7 割の人」としか言えない。</strong>
