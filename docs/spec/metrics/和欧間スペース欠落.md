# 和欧間スペース欠落

指示 / 表記 / 表記 / 両側 / 和欧が隣接する機会に対する割合。

## 意味

日本語と英数字の間に半角スペースを入れる習慣があるか。入れる人は徹底し、入れない
人は入れないので、書き手を強く分ける。

## 出どころ

[文書の形](../020-document.md#表記は残る優先して採る理由がある) が定める <strong>表記の選択</strong> の 1 つ。

英語の文体表現を凝集型クラスタリングにかけると、アポストロフィの字種・末尾の句読点・
改行といった <strong>意味を持たない表記の選択が上位クラスタを作る</strong>
（[Wegmann](../../references/wegmann-2022.md)）。人が自分の文章を直すときに手を入れるのも
この層である（[Post-Editing](../../references/post-editing-2026.md)）。

## 数え方

<strong>「機会」を先に決める。</strong>[地の文](../020-document.md#地の文)を走査し、次の形が現れた
ところを 1 つの機会と数える。

> [日本語の文字](../020-document.md#日本語の文字) → <strong>空白 0 個以上</strong> → 英数字<br>
> または 英数字 → <strong>空白 0 個以上</strong> → 日本語の文字

<strong>そのうち空白が 0 個のものが「欠落」である。</strong> 欠落 ÷ 機会が値になる。

<strong>「隣接」と書くと空白を挟んだ側が機会から消える。</strong> 消えれば分母が欠落だけになり、
値が必ず 1.0 になる。<strong>機会は、空白を挟んだ側も含む。</strong>

<strong>「英数字」は半角だけである。</strong> U+0030〜U+0039、U+0041〜U+005A、U+0061〜U+007A。
<strong>全角の `Ｒ` や `１` は英数字に数えず、機会にもしない。</strong>

<strong>全角を入れてはいけない。</strong> 全角の英数字は和文と同じ字幅で組まれるものなので、
`日本語Ａ` はベタで組むのが普通である——空白を入れないことが習慣の欠落を意味しない
（[JLREQ](https://www.w3.org/TR/jlreq/)）。<strong>入れれば、全角を選んだというだけで欠落率が
上がる。</strong>

<strong>そして字幅は別の指標が測っている</strong>（[数字の字幅](数字の字幅.md)）。ここに混ぜれば、
[字幅の選択と和欧間の習慣が 1 つの値に潰れる](../100-metrics.md#落としてよいのは重複しているとき)。

<strong>全角しか使わない書き手は、この指標が[測れない](../100-metrics.md#測れない理由を分けて返す)。</strong>
機会が下限に届かないからである。<strong>0 を返さない</strong>——「空白を入れない人」として出すと、
実際には機会が無かっただけの人を指摘することになる。

<strong>空白と認めるのは、半角スペース（U+0020）と全角スペース（U+3000）だけである。</strong>
いくつ並んでいてもよい。

<strong>タブと改行は空白と認めず、機会そのものを切る。</strong> どちらも
[node の中の折り返し](../020-document.md#地の文は-1-本の文字列ではない)として現れるもので、
<strong>書き手が和欧の間に置いたと言えない</strong>——桁揃えや自動折り返しで入る。機会に数えれば、
改行位置の癖がこの指標に化ける。

約物を挟む場合も、機会にも欠落にも数えない。`Rust、` や `（Rust` は、スペースを
入れる習慣のある人でも入れない。

<strong>分母は日本語の文字数ではない。</strong> 文字数で割ると、英数字を多く使う題材ほど値が
上がる。測れるのは習慣ではなく、その記事がどれだけ英語を含むかになってしまう。
分母を機会の数にすれば、英数字の量が変わっても値は動かない。

## 除外

隣接する機会が 20 未満の文書では測らない。割合が跳ねる。

## 直し方

<strong>上</strong>: 和欧間の空白を入れない箇所を減らす。

<strong>下</strong>: 和欧間の空白を入れない箇所を増やす。
