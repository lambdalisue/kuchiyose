# 和欧間スペース欠落

構造 / 両側 / 日本語 1,000 字あたり。

## 意味

日本語と英数字の間に半角スペースを入れる習慣があるか。入れる人は徹底し、入れない
人は入れないので、書き手を強く分ける。

## 数え方

[地の文](../020-document.md#地の文)で、[日本語の文字](../020-document.md#日本語の文字)
と英数字が、空白を挟まずに直接隣り合っている箇所の数。

約物を挟む場合は数えない。`Rust、` や `（Rust` は、スペースを入れる習慣のある人でも
入れない。

## 直し方

上: 和文と英数字の間に半角スペースを入れる。

## 実績

0 人で試し、0 人に効いた。前身の測定は数え方が違うので引き継がない。
