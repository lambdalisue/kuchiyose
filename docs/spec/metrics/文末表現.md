# 文末表現

照合 / 語。

## 意味

文をどう終えるか。敬体・常体の別だけでなく、断定を避ける言い方、会話体、ネット文体まで
含む。

## 出どころ

[有馬ら 2018](../../references/arima-2018.md) の文末表現辞書。抽出規則と、
<strong>敬体 / 常体 / 会話体 / ネット文体</strong> の分類がある。

日本語の個人性変換では、<strong>終助詞がいちばん動かしにくい</strong>と
報告されている（[水上ほか](../../references/mizukami-2014.md)）。

## 数え方

[文末](../020-document.md#文末)の <strong>末尾から</strong>、辞書に載っている文末表現を最長一致で取り、
その表層形ごとに頻度を数え、相対頻度に直す。

<strong>取れなかった文も 1 つの次元として数える。</strong> 落とすと分母が文ごとに変わる。

## 次元

辞書の見出し数に依存する。頻度上位 <strong>150</strong> 程度 + 「該当なし」で 1。
<strong>「150 程度」は暫定値であり、確定するまで[指紋](../200-extract.md#何で測ったかを指紋にする)に含める。</strong>


## 保留

<strong>辞書が手に入るか確かめていない。</strong>[有馬ら](../../references/arima-2018.md)は抽出規則と
4 クラスを報告しているが、辞書そのものが配布されているとは書かれていない。

<strong>[判定に使う系統](../200-extract.md#判定に使う系統を選ぶ)に入っていないので、骨格は
これ無しで通る。</strong> 手に入らなければ、規則から作り直せるかを先に確かめる。

## 覚え書き

この系統の細い切り口として[非断定の密度](非断定の密度.md)がある。指示に使うのは
そちらである。
