# 短い繰り返し

人らしさ / 両側。

## 意味

2〜3 語の短い言い回しがどれだけ反復されるか。

これは[通るための 2 つ目の条件](../010-strategy.md#通るには-2-つ要る)——人が書いたものに
見えるか——を測る系統である。その人らしさではない。

<strong>[長い繰り返し](長い繰り返し.md)と分ける。</strong> 2〜3 語の反復と 4〜5 語の再来は
<strong>別の現象である</strong>——実測では、同じ型で書かせた生成文は短いほうを人より多く反復し、
長いほうを人より少なく再来させる。まとめると <strong>向きが指標の中で割れ、どちらへ動かせば
よいかを言えなくなる</strong>。[粗い括りに丸めない](../100-metrics.md#粗い括りに丸めない)を、
人らしさの側で実行したものである。

## 出どころ

[Zeng & Nini 2026](../../references/zeng-nini-2026.md)。なりすまし文が見破られる原因を
突き止めている。

> Human-authored texts naturally contain <strong>recurring character or word n-grams that
> reflect an individual's habitual phrasing</strong>. Because LLM-generated texts exhibit higher entropy and greater
> lexical diversity, they fail to produce sufficient repetitions

<strong>この主張は n の長さで分けていない。</strong> 分けて測ると、短いほうは逆に出ることがある。

## 数え方

[地の文](../020-document.md#地の文)の形態素列から、2〜3 語の n-gram を取り、
<strong>2 回以上現れたものの割合</strong>を n ごとに出す。分母は <strong>異なり n-gram の数</strong>である。

加えて、最も多く現れた n-gram の出現回数を n ごとに持つ。<strong>回数は窓の語数で割って率にする</strong>
——割らなければ、長い文書ほど大きく出る。

<strong>n-gram は node を跨がない</strong>（[地の文](../020-document.md#地の文)）。跨げば、構造が
作った隣接を繰り返しとして数える。

<strong>1,000 語の窓ごとに出して平均を取る</strong>（[固定長の窓](../100-metrics.md#人らしさは固定長の窓で測る)）。
<strong>窓の中でも node の切れ目は保つ。</strong> 落とせば、跨がないという規則がそこだけ崩れる。

## 次元

n が 2 通り × 2 種 = 4。

## 除外

延べ 1,000 語未満の単位では測らない。n-gram が足りず、割合が跳ねる。

## 直し方

<strong>下</strong>: その人が現に繰り返している短い言い回しを、そのまま繰り返す。言い換えず、
あわせて頻度ペナルティを下げる。

<strong>上</strong>: 同じ短い言い回しの反復を減らす。言い方を変え、頻度ペナルティを上げる。

<strong>向きは較正が決める</strong>（[圧縮率](圧縮率.md)と同じ理由）。

## 覚え書き

<strong>プロンプト以外に手がある</strong>——頻度ペナルティを動かせば反復の量は変わる。
推論設定を指示の一部として扱う。
