# 三点リーダの字数

指示 / 表記 / 両側 / 割合。

## 意味

三点リーダを 1 つで打つか、2 つ重ねるか。`…` と `……`。

<strong>組版の慣習では 2 つ重ねが正式とされるが、守る人と守らない人がいる。</strong> そこが分かれる。

## 出どころ

[文書の形](../020-document.md#表記は残る優先して採る理由がある) が名指しする「三点リーダの字数」。
字種・字数の選択が文体表現の主成分になることは
[Wegmann](../../references/wegmann-2022.md) が示している。

## 数え方

[地の文](../020-document.md#地の文)で連続する `…` を 1 箇所とし、そのうち <strong>2 つ以上
重ねた箇所</strong> の割合。

`...`（半角ピリオド 3 つ）は三点リーダとして数え、別の次元として持つ。

## 除外

三点リーダが 5 箇所未満の文書では測らない。

## 直し方

<strong>上</strong>: `…` 1 つに寄せる。

<strong>下</strong>: `……` に寄せる。

## 覚え書き

頻度は[三点リーダ](三点リーダ.md)が見る。<strong>頻度と字数は別の選択である</strong>——よく使う人の
中に、1 つで打つ人と 2 つ重ねる人がいる。
