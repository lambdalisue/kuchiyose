# 三点リーダ

指示 / 表記 / 表記 / 両側 / 日本語 1,000 字あたり。

## 意味

言いさす、間を置く、省略を示す。

## 出どころ

[文書の形](../020-document.md#表記は残る優先して採る理由がある) が定める <strong>表記の選択</strong> の 1 つ。

英語の文体表現を凝集型クラスタリングにかけると、アポストロフィの字種・末尾の句読点・
改行といった <strong>意味を持たない表記の選択が上位クラスタを作る</strong>
（[Wegmann](../../references/wegmann-2022.md)）。人が自分の文章を直すときに手を入れるのも
この層である（[Post-Editing](../../references/post-editing-2026.md)）。

## 数え方

[地の文](../020-document.md#地の文)に現れる三点リーダの <strong>箇所</strong>の数。

<strong>1 箇所とは、連続する `…` の並び全体、または連続する半角ピリオド 3 つ以上の並び全体を
指す。</strong>`……` は 1 箇所、`...` も 1 箇所、`......` も 1 箇所である。

<strong>文字数で数えない。</strong> 数えれば `……` を使う書き手の密度が倍になり、この指標が
[字数の選択](三点リーダの字数.md)を巻きこんで測ることになる。<strong>頻度と字数は別の選択である。</strong>

## 直し方

<strong>上</strong>: 三点リーダを減らす。言いさしを最後まで書く。

<strong>下</strong>: 三点リーダを足す。
