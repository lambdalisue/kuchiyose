# 数字の字幅

指示 / 表記 / 両側 / 割合。

## 意味

数字に半角 `1` を使うか、全角 `１` を使うか。

## 出どころ

[文書の形](../020-document.md#揃えても残るもの表記の選択) が名指しする「数字の字幅」。
字種の選択が文体表現の主成分になることは
[Wegmann](../../references/wegmann-2022.md) が示している。

## 数え方

[地の文](../020-document.md#地の文)の数字のうち、全角の割合。

## 除外

数字が 10 個未満の文書では測らない。

## 直し方

<strong>上</strong>: 半角数字に寄せる。

<strong>下</strong>: 全角数字に寄せる。

## 覚え書き

<strong>題材と連動しやすい。</strong> 数値を多く扱う記事では半角に寄る。
[条件 5](../100-metrics.md#集合は広く持つ絞るのはあとである)——ほかのものと連動していない
——を、この指標では特に疑う。

[文字種](文字種.md)が全角・半角の数字を別の次元として持っているので、
[重複](../100-metrics.md#落としてよいのは重複しているとき)の候補でもある。
残すなら、こちらは <strong>割合</strong> で、あちらは <strong>分布</strong> という違いで正当化する。
