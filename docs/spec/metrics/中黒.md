# 中黒

指示 / 表記 / 両側 / 日本語 1,000 字あたり。

## 意味

語を並べるときに記号で繋ぐか、読点や箇条書きに開くか。

## 出どころ

[文書の形](../020-document.md#揃えても残るもの表記の選択) が定める <strong>表記の選択</strong> の 1 つ。

英語の文体表現を凝集型クラスタリングにかけると、アポストロフィの字種・末尾の句読点・
改行といった <strong>意味を持たない表記の選択が上位クラスタを作る</strong>
（[Wegmann](../../references/wegmann-2022.md)）。人が自分の文章を直すときに手を入れるのも
この層である（[Post-Editing](../../references/post-editing-2026.md)）。

## 数え方

[地の文](../020-document.md#地の文)に現れる `・` の数。

<strong>カタカナ語の区切りに使われた `・` を除く。</strong> 前後がともにカタカナである `・` は
複合語の区切り（「アプリケーション・サーバ」）であって、並列の選択ではない。除かないと、
<strong>題材がカタカナ語を多く含むかどうかを測ることになる</strong>。

## 覚え書き

[文書の形](../020-document.md#揃えても残るもの表記の選択) が求めているのは
「並列に `・` を使うか `、` を使うか」という <strong>比</strong> である。この指標は密度しか見て
いない。<strong>比を見る指標は、まだ無い。</strong> 並列の検出に係り受け解析が要るためで、
[文節パターン](文節パターン.md)と同じ依存を負う。足すときはそちらと合わせて考える。

## 直し方

<strong>上</strong>: 中黒を減らす。並列を読点に替える。

<strong>下</strong>: 中黒を足す。並列を中黒に替える。
