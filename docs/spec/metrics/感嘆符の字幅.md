# 感嘆符の字幅

指示 / 表記 / 両側 / 割合。

## 意味

感嘆符に全角 `！` を使うか、半角 `!` を使うか。

<strong>頻度とは別の選択である。</strong> よく使う人の中に、全角で通す人と半角で通す人がいる。

## 出どころ

[文書の形](../020-document.md#揃えても残るもの表記の選択) が名指しする「感嘆符・疑問符の
字幅」。

英語では、アポストロフィの字種（`'` と `'`）だけでクラスタが分かれている
（[Wegmann](../../references/wegmann-2022.md)）。<strong>意味を変えない字種の選択が、文体表現の
主成分になる。</strong> 日本語の全角・半角はその対応物である。

## 数え方

[地の文](../020-document.md#地の文)の感嘆符のうち、全角 `！` の割合。

## 除外

感嘆符が 5 個未満の文書では測らない。割合が跳ねる。

## 直し方

<strong>上</strong>: 半角 `!` に寄せる。

<strong>下</strong>: 全角 `！` に寄せる。

## 覚え書き

<strong>取り込み元が正規化していないことが前提である</strong>（[文書の形](../020-document.md#揃えても残るもの表記の選択)）。
潰されているなら、測っているのは取り込み元である。頻度は[感嘆符](感嘆符.md)が見る。
