# 疑問符の字幅

指示 / 表記 / 表記 / 両側 / 割合。

## 意味

疑問符に全角 `？` を使うか、半角 `?` を使うか。

## 出どころ

[文書の形](../020-document.md#表記は残る優先して採る理由がある) が名指しする「感嘆符・疑問符の
字幅」。<strong>英語では</strong>字種の選択が文体表現の主成分になる
（[Wegmann](../../references/wegmann-2022.md)）。日本語での対応は未検証である。

## 数え方

[地の文](../020-document.md#地の文)の疑問符のうち、全角 `？` の割合。

## 除外

疑問符が 5 個未満の文書では測らない。

## 直し方

<strong>上</strong>: 半角 `?` に寄せる。

<strong>下</strong>: 全角 `？` に寄せる。

## 覚え書き

頻度は[疑問符](疑問符.md)が見る。[感嘆符の字幅](感嘆符の字幅.md)と連動しやすいので、
[重複していれば片方を外す](../100-metrics.md#落としてよいのは重複しているとき)——その対象になる。
ただし <strong>片方だけ全角にする書き手はいる</strong>ので、連動を確かめるまでは別に持つ。
