# 体言止め率

指示 / 文末表現 / 語 / 両側 / その種類の文に対する割合。

## 意味

文を名詞で止めるか、言い切るか。

<strong>[敬体率](敬体率.md)では見えない。</strong> あちらは体言止めを分母から落とすので、
<strong>項目をすべて体言止めで書く人の項目は 1 つも数えられない</strong>。実測で、ある書き手の
50 単位のうち箇条書きの敬体率が出たのは <strong>4 単位だけ</strong>で、体言止め率にすると
<strong>30 単位</strong>で測れた——その人がいちばんしていることが、いちばん見えていなかった。

<strong>node の種類ごとに数える</strong>
（[文体は node の種類ごとに違う](../100-metrics.md#文体は-node-の種類ごとに違う)）。

## 出どころ

[文末表現](文末表現.md)の系統の細い切り口である。あの系統は
<strong>「取れなかった文も 1 つの次元として数える」</strong>と決めており、体言止めはその次元にあたる。
これを node の種類ごとに切り出したものがこの指標である。

## 数え方

[地の文に入る種類](../020-document.md#数える単位)ごとに、その種類の node の形態素列を
句点・感嘆符・疑問符で文に割り、<strong>記号を除いた最後の形態素が名詞であるもの ÷ 文の総数</strong>
を出す。

<strong>語尾の文字列では決めない。</strong> `できる` のように、[敬体率](敬体率.md#数え方)の
語尾一覧に載っていない動詞の活用形と見分けが付かないためである。

### 種類ごとに軸を作る

<strong>名前は「体言止め率・&lt;種類&gt;」</strong>とする。作り方は[敬体率](敬体率.md#種類ごとに軸を作る)と
同じで、種類を手で並べない。

## 除外

<strong>解析器が無ければ測らない。</strong> 0 を返さない。

文が 5 未満の種類では測らない。割合が跳ねる。<strong>この下限は暫定値である。</strong>

## 直し方

<strong>上</strong>: その種類の文を名詞で止める。「〜します」「〜できます」を落とす。
<strong>下</strong>: その種類の文を敬体か常体で言い切る。

## 覚え書き

実測で、生成された草稿を本人の言い回しへ寄せる際に項目の文末を敬体へ揃えたところ、
箇条書きの体言止め率が <strong>0.541 から 0.405</strong> へ動いた。本人の中央は <strong>0.714</strong> で、
<strong>直しは本人から離れる方向だった。</strong>
