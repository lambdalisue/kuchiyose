# 圧縮率

人らしさ / 上限。

## 意味

本文を可逆圧縮したときにどれだけ縮むか。<strong>繰り返しの多さを、語の切り方に依存せずに
測る。</strong>

[通るための 2 つ目の条件](../010-strategy.md#通るには-2-つ要る)を測る系統である。

## 出どころ

[Zeng & Nini 2026](../../references/zeng-nini-2026.md)。圧縮後の大きさ、エントロピー、
Type-Token 比の 3 つとも、なりすまし文の方が高かった。

## 数え方

[地の文](../020-document.md#地の文)を UTF-8 のバイト列にし、可逆圧縮したあとの
バイト数を、元のバイト数で割る。

<strong>圧縮器と設定を固定して記録する。</strong> 器が変われば値が変わり、過去の値と比べられなく
なる。[指紋](../200-extract.md#何で測ったかを指紋にする)に含める。

## 次元

1。


## 直し方

<strong>上限だけを持つ</strong>——機械の文章はここが高く出る。同じ言い回し・同じ語を繰り返す。
[繰り返し](繰り返し.md)・[エントロピー](エントロピー.md)と同じ現象を見ているので、
3 つ揃えて動かす。

## 覚え書き

圧縮器のヘッダが結果を支配する。

<strong>形態素解析を必要としない。</strong> 解析器と対象のずれ（[柳・金 2023](../../references/yanagi-jin-2023.md)）
の影響を受けない、数少ない系統である。ほかの系統が場面で崩れたときに、比較の基準として
残る。

[繰り返し](繰り返し.md)、[エントロピー](エントロピー.md)、[語彙の豊富さ](語彙の豊富さ.md)
と同じ現象を見ているので、4 つを別々の証拠として数えない（[評価](../200-extract.md#人らしさの境目は同じ材料から出る)）。
