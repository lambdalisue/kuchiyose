# 文字種

照合 / 表記。

## 意味

ひらがな・カタカナ・漢字・英数字・記号を、どの割合で混ぜるか。

## 出どころ

[尤度比 2026](../../references/fusing-lr-2026.md)。日本語ブログ 2,287 人で <strong>最良の
組み合わせに残った 5 系統の 1 つ</strong>である。

> [!NOTE]
> [金 2014](../../references/jin-2014.md) は「漢字の使用率」を効かない特徴に挙げている。
> <strong>矛盾しない。</strong> 単独の比率としては弱く、<strong>分布として、他の系統と混ぜたときに効く</strong>
> という読み方になる。[単独で弱いことは落とす理由にならない](../100-metrics.md#単独で弱いことも落とす理由にならない)。

## 数え方

[地の文](../020-document.md#地の文)の全文字を次に振り分け、それぞれの割合を出す。

ひらがな / カタカナ / 漢字 / 半角英字 / 全角英字 / 半角数字 / 全角数字 / 約物 / その他記号 / 空白

<strong>全角と半角を分ける。</strong> そこが書き手の選択である
（[文書の形](../020-document.md#揃えても残るもの表記の選択)）。まとめると消える。

## 次元

10。

## 除外

日本語 200 字未満の文書では測らない。
