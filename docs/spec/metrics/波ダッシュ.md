# 波ダッシュ

指示 / 表記 / 両側 / 割合。

## 意味

範囲や伸ばしに波ダッシュ `〜`（U+301C）を使うか、全角チルダ `～`（U+FF5E）を使うか。

<strong>見た目がほぼ同じで、意味も同じで、入力環境で決まりやすい。</strong> だからこそ書き手ごとに
一貫する。

## 出どころ

[文書の形](../020-document.md#揃えても残るもの表記の選択) が名指しする「波ダッシュ」。

英語の `'` と `'` の対応物である。<strong>その字種の違いだけで、文体表現のクラスタが分かれた</strong>
（[Wegmann](../../references/wegmann-2022.md)）。

## 数え方

[地の文](../020-document.md#地の文)の `〜` と `～` の合計のうち、`〜`（U+301C）の割合。

合計の密度は別の次元として持つ。

## 除外

波ダッシュが 3 個未満の文書では測らない。

## 直し方

<strong>上</strong>: 全角チルダ `～` に寄せる。

<strong>下</strong>: 波ダッシュ `〜` に寄せる。

## 覚え書き

<strong>取り込み経路で潰れやすい。</strong> 正規化する処理は珍しくないので、
[正規化で潰していないか](../020-document.md#揃えても残るもの表記の選択)を、この指標を
使う前に確かめる。潰れているなら測っているのは取り込み元である。
