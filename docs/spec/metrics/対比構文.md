# 対比構文

指示 / 語 / 上限 / 日本語 1,000 字あたり。

## 意味

対比の形に載せて主張を立てる書き方。内容ではなく形で強さを出す。

## 出どころ

[機能語](機能語.md)の切り口——接続助詞と複合辞。

助詞・助動詞の並びは日本語の書き手識別の中心である
（[財津・金](../../references/zaitsu-2018.md) の助詞 bigram）。
## 数え方

[地の文](../020-document.md#地の文)に現れる、次のいずれかの数。

ではなく / ではなくて / のではなく / というより / というよりも / だけでなく /
のに対し / に対して / ではあるが / とは違って

<strong>最長一致で取り、重ならない。</strong> 一覧には短いものが長いものに含まれる組がある
（`ではなく` ⊂ `ではなくて`、`に対して` ⊂ `のに対して`）。左から走査し、いちばん長く一致
するものを 1 つ取って、その先から続ける。<strong>決めないと、1 か所が 1 とも 2 とも数えられる。</strong>

一覧はこの定義の一部である。増減させたら、それは別の指標になる。

## 直し方

<strong>上限だけを持つ</strong>——対比で盛り上げず、その内容を直接書き下す。
