# 強調

指示 / 構造 / 構造 / 両側 / 日本語 1,000 字あたり。

## 意味

強調をどれだけ置くか。太字と斜体を区別しない。

## 出どころ

[Stamatatos §2.5](../../references/stamatatos-2009.md)の応用固有の特徴——段落長、字下げ、
挨拶や結びの型——の、日本語と
[この文書モデル](../020-document.md#文書は-node-でできている)での対応物。

<strong>node の種類ごとの密度は先行研究に直接の対応が無い。</strong> 構造という分類に属することは
確かだが、この粒度で書き手を分けた報告は見当たらない。[場面で成立するか](../100-metrics.md#場面で成立しないことがある)
を最初に疑う側の指標である。

## 数え方

[強調の node](../020-document.md#文書は-node-でできている)の数。

<strong>太字と斜体を分けない。</strong> 文書モデルの node が 1 つしか無いためである。分けたいなら、
先に[文書の形](../020-document.md)の node 表を割る。<strong>指標の側で勝手に割ると、020 が
「測れることの全体」と宣言している表と食い違う。</strong>

## 直し方

<strong>上</strong>: 強調を減らす。

<strong>下</strong>: 強調を足す。
