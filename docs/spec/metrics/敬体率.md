# 敬体率

指示 / 文末表現 / 語 / 両側 / 敬体か常体で終わった文に対する割合。

## 意味

文をどれだけ敬体（です・ます）で終えるか。

<strong>node の種類ごとに数える。</strong> 同じ書き手が場所によって文体を変えるので、
地の文をまとめて数えると使い分けが袋の中で消える
（[文体は node の種類ごとに違う](../100-metrics.md#文体は-node-の種類ごとに違う)）。
実測で、ある書き手は段落の 93% を敬体で書き、箇条書きと見出しはほとんど常体で書いていた。
<strong>まとめて数えれば「敬体 7 割の人」としか言えない。</strong>

## 出どころ

[文末表現](文末表現.md)の系統の細い切り口である。あの系統の出どころ
（[有馬ら 2018](../../references/arima-2018.md)）が <strong>敬体 / 常体</strong> の分類を報告しており、
この指標はその 2 クラスの比を node の種類ごとに切り出したものである。

<strong>系統そのものは[保留中](文末表現.md#保留)である</strong>——辞書が手に入るか確かめていない。
だが分類は論文が報告しているので、<strong>この切り口は辞書を待たずに数えられる。</strong>

## 数え方

[地の文に入る種類](../020-document.md#数える単位)ごとに、その種類の node の中の文を数え、
<strong>敬体で終わったもの ÷（敬体で終わったもの ＋ 常体で終わったもの）</strong>を出す。

| | 認める語尾 |
| --- | --- |
| <strong>敬体</strong> | です・ます・ました・ません・でしょう・ましょう・でした・ください |
| <strong>常体</strong> | である・だ・した・する・ない・いる・なる・った・れる・たい |

<strong>どちらでもない文は、分母にも分子にも入れない。</strong> 体言止めと疑問符で終わる文が
それにあたる——入れると、<strong>体言止めの多い書き手ほど敬体率が下がる</strong>。
落とした側は[体言止め率](体言止め率.md)が数える。

<strong>句点と感嘆符と疑問符を落としてから見る。</strong>

### 種類ごとに軸を作る

<strong>種類を手で並べない。</strong>「段落の敬体率」「箇条書きの敬体率」と定義を並べると、
指標を足すたびに種類の数だけ定義が要り、<strong>足し忘れた指標だけが混ぜたまま</strong>になる。

<strong>名前は「敬体率・&lt;種類&gt;」</strong>とする。種類は
[地の文に入るもの](../020-document.md#数える単位)——段落・見出し・項目・引用・補足・警告・
折りたたみ・脚注・セル——で、どれも 1 つの[指示できる指標](../100-metrics.md#指標の種類)である。

<strong>どの種類が効くかは選ばない。</strong> [効くかの判定](../200-extract.md#どの指標が効くかを決める)に
選ばせる——書き手によって使い分ける場所が違うので、ここで決め打つと当たらない書き手が出る。

## 除外

敬体か常体で終わった文が 5 未満の種類では測らない。割合が跳ねる。
<strong>この下限は暫定値である。</strong>

## 直し方

<strong>上</strong>: その種類の文末を敬体（です・ます）にする。
<strong>下</strong>: その種類の文末を常体（である・だ）にする。
