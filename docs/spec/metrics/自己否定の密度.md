# 自己否定の密度

指示 / なし / 語 / 両側 / 日本語 1,000 字あたり。

## 意味

直前に書いたことを自分で引き戻す書き方。単なる逆接ではなく、自分の主張に対する
留保に絞る。

## 出どころ

[機能語](機能語.md)の切り口——文頭の接続詞。

<strong>文頭の接続詞を独立に立てているのは[岩崎 2018](../../references/japanese-attribution-others.md)
だけである。</strong> 金 2014 の品詞 bigram には接続詞のタグは入るが、<strong>どの接続詞かは残らない</strong>
——この指標が見たいのは語彙素の側である。<strong>裏付けは薄い。</strong>
## 数え方

[文](../020-document.md#文)の冒頭が次のいずれかである数。

とはいえ / とはいうものの / もっとも / そうは言っても / そうは言うものの /
とはいっても / ただし

「しかし」「だが」は入れない。あれは話の向きを変える接続であって、自分の主張への
留保とは限らない。入れると出現数が跳ね上がり、この指標が普通の逆接を測ることに
なる。

## 直し方

<strong>上</strong>: 自分の主張への留保を減らす。

<strong>下</strong>: 自分の主張への留保を足す。
