# 自己否定の密度

修辞 / 両側 / 日本語 1,000 字あたり。

## 意味

直前に書いたことを自分で引き戻す書き方。単なる逆接ではなく、自分の主張に対する
留保に絞る。

## 数え方

[文](../020-document.md#文)の冒頭が次のいずれかである数。

とはいえ / とはいうものの / もっとも / そうは言っても / そうは言うものの /
とはいっても / ただし

「しかし」「だが」は入れない。あれは話の向きを変える接続であって、自分の主張への
留保とは限らない。入れると出現数が跳ね上がり、この指標が普通の逆接を測ることに
なる。

## 確かめた場面

技術記事。条件 4 だけ確認済み（値が動く）。この書き手では基準と分離しなかったが、
それは[外す理由にならない](../100-metrics.md#目の前の書き手を区別できないことは-外す理由にならない)。
条件 1、2、3、5、6 は未確認。
