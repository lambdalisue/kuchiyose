# 戦術: 指標を決める

[戦略](010-strategy.md)の 1 段目。曖昧な書きぶりを、定量評価できる指標の集合
として定義する。

ここで決めるのは、何を指標と認めるか、候補をどう出すか、採否をどう決めるか
である。どの指標を採ったかは決めない。それは実験の結果として決まる。

## 指標の要件

[軸](000-axis.md)の定義から 4 つ出る。全部を満たすものだけが指標になる。

1. 人によって差が出る。出ないなら、書きぶりを測っていない。
2. 同じ人なら題材が変わっても動かない（性質 3）。動くなら、話題を測っている。
3. 同じ場面の中で一貫する（性質 2）。1 本ごとにばらつくなら、その記事の事情を
   測っている。
4. 文章から決定的に計算できる（性質 4）。同じ文章からは同じ値が出る。

## 候補の出し方

2 通りある。どちらも要る。

思いつきから。「太字が多い」「文が短い」のように、人が仮説として挙げる。早い
が、思いつける範囲を超えない。

比較から。本人の文章と基準の文章を突き合わせ、目立つ差を拾う。思いつけなかった
ものはここからしか出ない。

## 採否は実験で決める

挙げた候補は仮説である。測って、2 つの検査を通ったものだけを採る。

分離するか。本人のコーパスと基準のコーパスで測って、値が離れる。離れなければ、
その指標は誰が書いても同じものを測っている。

安定するか。同じ人の、題材の違う文書どうしで測って、値が動かない。動くなら、
拾っているのは題材である。

順序は分離が先でよいが、<strong>分離だけで採ってはいけない</strong>。本人と基準とで題材が
違えば、題材の差が分離として出る。2 つ目の検査はそれを弾くために要る。

## 落ちた候補を記録する

落とした候補と理由を残す。残さないと、同じ候補が何度も再発明される。

## 標本は小さい

分離も安定も、手元にある数十本で見るしかない。示せるのは、その標本で反例が
出なかったことだけである。後から覆ることを前提にする。

したがって指標は入れ替わるものとして扱う。1 つ足すのと 1 つ外すのが同じだけ
安くなければ、この手続きは回らない。

## 集合として点検する

書きぶりは語にも文にも組み立てにも現れ、目立つのは大きい方である（軸）。候補は
放っておくと語に寄る。数えやすいからである。

個々の指標が要件を満たすことと、集合として書きぶりを覆っていることは別である。
偏りは集合として見ないと分からない。
