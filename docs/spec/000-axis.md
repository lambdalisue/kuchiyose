# kakiburi の軸

## やりたいこと

LLM に代筆させたときに、<strong>自分が書いたものとして通る</strong>ようにしたい。

出てきたものが自分と違うことは分かる。だが、どこが違うのかは言えない。

<strong>書くものの種類は限らない。</strong> 記事も、チャットも、投稿も、文書も、代筆させたいものは
すべて対象になる。ただし書きぶりは場面ごとに違う（[後述](#場面ごとにある)）ので、
どの場面のものを貸すのかは、そのつど決まっていなければならない。

## 先行研究が答えていること

やりたいことを満たすのに何が要るかは、思いつきで決めない。[先行研究](../references/)
を調べたうえで決める。分かったことは 4 つある。

<strong>1. 「その人らしいか」を測るのは、解決済みである。</strong>

著者識別（authorship attribution）として蓄積がある。日本語でも、1 編 1,100 字の作文
11 人で 99%、<strong>500 字の日記 6 人で 92%</strong> という実証がある
（[金 2013](../references/jin-2013.md)）。日記 500 字で 92% なら、チャットや投稿のような
短い場面でも見込みがある。

<strong>手作りの特徴量で判別性能を競う道は、既に終わっている。</strong> 文体埋め込みが古典的な計量
文体論を上回る（[Kim & Jurgens](../references/kim-jurgens-2026.md)）。ここは借りる。

<strong>2. 「言えない」のは本人の観察力の問題ではない。</strong>

文体を担う機能語は、書き手が概ね無意識に使い、題材に依存しない
（[Stamatatos §2.1](../references/stamatatos-2009.md)）。<strong>無意識だから言えない。</strong>

<strong>3. 素朴な貸し方は、両方とも失敗している。</strong>

| やり方 | 結果 |
| --- | --- |
| 例文を何本か見せる | 頭打ち。平均的な調子に寄り、AI 生成と検出される（[Wang](../references/wang-2025.md)） |
| 文体の特徴を並べて指示する | <strong>例文だけより悪くなる</strong>（[Bhandarkar](../references/bhandarkar-2024.md)） |

<strong>4. 貸す側にも手法はある。ただし数値ではない。</strong>

[Kim & Jurgens (2026)](../references/kim-jurgens-2026.md) は、文体埋め込みから自然言語の
指示を復元するデコーダで、対象の文章を直接プロンプトに入れる方法を上回った。

出てくるのは指示であって数値ではない。したがって <strong>検められない</strong>し、<strong>どこがどれだけ
外れているかも出ない</strong>。

## 軸

以上から、kakiburi がやるべきことが決まる。

<strong>その人の書きぶりを、本人の外で使えるようにする。</strong>

判別で勝つ道具ではない。埋め込みに負ける。生成の質だけを競う道具でもない。残るのは、
<strong>書かせて、検めて、直すループを回せること</strong>である。

それには <strong>決定的で解釈できる数値</strong> が要る。数値であることが、そのまま 3 つを可能に
する。

- 貸すときの指示になる
- 検めるときの物差しになる
- <strong>両者が同じものを見ていることを保証できる</strong>

取り出し方は先行研究から借りる。自前で工夫しない。書くのは借りた側であり、kakiburi は
書かない。

### 賭けているところ

指標を並べて渡すと悪くなることは分かっている。だが
[Bhandarkar](../references/bhandarkar-2024.md) は、その原因を <strong>固定の特徴集合が全ての
著者に等しく効くという前提</strong> に見て、こう書いている。

> instead of static directed prompting, a more effective approach could involve
> <strong>dynamically prompting LLMs by considering each author's individual linguistic
> preferences</strong>

<strong>書き手ごとに、その人に効くものを選んで渡す。</strong> これは提案されただけで試されていない。
kakiburi が賭けているのはここである。

そしてこの賭けは、[何が特徴になるかも人による](#何が特徴になるかも人による)という
書きぶりの性質から、独立に導かれる。<strong>失敗した実験の側と、定義の側から、同じ結論が出て
いる。</strong>

## 書きぶりとは何か

題材と場面を決めたあとに、なお人によって違ってしまう部分である。

場面とは、誰に向けて、どういう立ち位置で、何のために書くかである。同じ題材を同じ場面
で 10 人が書けば 10 通りになる。その差が書きぶりである。

4 つの性質を持つ。1 つでも欠けるものは書きぶりではない。

1. <strong>本人が意識していない。</strong> だから訊いても出てこない。言えるものは書きぶりではなく、
   方針や好みである
2. <strong>同じ場面で書いたものに一貫して現れる。</strong> 1 本にしか現れないものは、その記事の事情
   である
3. <strong>題材が変わっても変わらない。</strong> 変わるものは内容である
4. <strong>文章に現れる。</strong>「丁寧だ」は読んだ人の感想であって、文章にあるのはその感想を生んだ
   何かの方である

性質 1 と 3 は、先行研究が機能語について言っていることと同じである。定義から導いたの
ではなく、<strong>先行研究が示した性質を定義に採った</strong>。

語の選び方にも、文の終え方にも、記事全体の組み立て方にも現れる。目立つのは大きい方で
ある。

### 題材から完全には逃げられない

性質 3 は理想である。実際には、機能語も文字 n-gram も題材情報を拾うことが分かって
いる（[Stamatatos §5](../references/stamatatos-2009.md)）。

<strong>題材の影響を減らす設計は要るが、消しきれる前提では立てない。</strong>

### 場面ごとにある

同じ人でも、技術記事と Slack の投稿では書きぶりが違う。相手も、立ち位置も、その場で
流れて消えるのか後から参照されるのかも違う。どれが動いても書きぶりは動く。

性質 3 が「変わらない」と言っているのは題材についてであって、場面についてではない。
したがって書きぶりはつねに、<strong>ある人の、ある場面での</strong>書きぶりである。取り出すときも
貸すときも、場面を決めずには成立しない。

場面を分けるのは媒体ではない。同じ Slack でも、チームへの報告と社外への連絡は別の場面
になる。

### 何が特徴になるかも人による

ある人にとって際立った特徴が、別の人には何でもないことがある。片方は括弧をまったく
使わず、もう片方は使いも使わなくもする。

したがって書きぶりは「どこがどうか」だけでなく、どこが効くかでもある。どちらも人に
よって違う。

## 軸の外

作ってはいけないという意味ではない。<strong>この道具ではない</strong>、という意味である。

| 外にあるもの | なぜ外か |
| --- | --- |
| 考えかた、判断軸 | 本人が言葉にできる。性質 1 を満たさない |
| 何を書くか（題材、主張、事実） | 書くたびに変わる。性質 2 と 3 を満たさない |
| 誰に向けて書くか（場面） | 扱う前に決まっている前提であって、取り出す対象ではない |
| 文章の良し悪しの評価 | 人によって違わない。読む側にあるものである |
| 文法の正しさ | 人によって違わない。違えばそれは誤りである |
| 場面をまたぐ書き分けの度合い | 性質 2 を満たさない |
| 文章を集めてくること | 材料集めであって、取り出す仕事ではない |
| 日本語以外 | 特徴量が言語ごとに違う。1 つに合わせる |

## 判断軸は訊く

いちばん紛らわしいのが判断軸である。何を良しとし、何を書かないか。その人らしい文章に
要るものなので、取り出したくなる。

取り出さない。諦めではなく、<strong>訊けば答えが返るから</strong> である。

| 訊いたときに | |
| --- | --- |
| 「すべて」と「全て」のどちらを使いますか | 答えられない |
| 何を書かないと決めていますか | 答えられる |

書きぶりが計測でしか取れないのは、無意識の選択の集積だからである。判断軸は意識して
取っている立場なので、本人が言葉にできる。しかも本人の答えが常に正しく、推定する必要
が無い。

<strong>訊けるものは訊く。訊けないものを測る。</strong>

貸すときに判断軸を添えることは禁じない。軸が決めているのは kakiburi が何を <strong>取り出す</strong>
かであって、本人が書いた紙を重ねてはいけないとは言っていない。
