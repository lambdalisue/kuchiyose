# kakiburi の軸

この文書は kakiburi が <strong>何のための道具か</strong> と <strong>何を扱う道具か</strong> だけを
決める。どう作るかは決めない。

## 軸

<strong>その人の書きぶりを、本人の外で使えるようにする。</strong>

書きぶりは本人の中にあり、本人には取り出せない。それを取り出して、本人以外
——実際には LLM——が使える形にする。取り出して、貸す。

kakiburi はこの一行のための道具であり、ここに入らないものは作らない。

## なぜ要るのか

自分の文章を LLM に代筆させると、出てきたものが自分と違うことは分かる。
だが、どこが違うのかは言えない。

言えないのは観察力の問題ではない。書きぶりとは、そもそも言えないものだから
である。本人に訊いても答えは出ないし、挙げてもらった特徴は、たいてい本当の
特徴ではない。

## 書きぶりとは何か

<strong>何を、誰に向けて書くかを決めたあとに、なお人によって違ってしまう部分で
ある。</strong>

同じ題材を、同じ相手に向けて、10 人が書けば 10 通りになる。その差が書きぶり
である。

4 つの性質を持つ。この 4 つを満たすものが書きぶりであり、1 つでも欠けるものは
書きぶりではない。

<strong>1. 本人が意識していない。</strong> 選んでいるが、選んだ覚えがない。だから訊いても
出てこない。言えるものは書きぶりではなく、方針や好みである。

<strong>2. 同じ場面で書いたものに一貫して現れる。</strong> その 1 本の事情ではなく、その人の
性質である。1 本にしか現れないものは書きぶりではない。

<strong>3. 題材が変わっても変わらない。</strong> 題材とともに変わるものは、書きぶりではなく
内容である。

<strong>4. 文章に現れる。</strong> 頭の中にあって文章に痕跡を残さないものは、取り出しよう
がない。「丁寧だ」「論理的だ」は読んだ人の感想であって、文章に現れているのは
その感想を生んだ何かの方である。

### 書きぶりは場面ごとにある

同じ人でも、技術記事と Slack の投稿では書きぶりが違う。<strong>相手が違い、その場での
立ち位置が違うからである。</strong> 敬体か常体か、どこまで前提を説明するか、どこまで
断定するか——すべて動く。

これは定義の綻びではなく、定義そのものである。性質 3 が「変わらない」と言って
いるのは <strong>題材</strong> についてであって、場面についてではない。同じ場面にいる限り
題材が変わっても書きぶりは変わらず、場面が変われば変わる。

したがって「その人の書きぶり」という言い方は、厳密には足りない。書きぶりは
つねに <strong>ある人の、ある場面での</strong> 書きぶりである。取り出すときも貸すときも、
場面を決めずには成立しない。

場面を分けるのは媒体ではなく、相手とそこでの立ち位置である。同じ Slack でも、
チームに向けた報告と社外への連絡は別の場面になる。

### 場面をまたぐ癖は扱わない

場面によってどれだけ書きぶりを変えるかも、人によって違う。記事と Slack が
地続きの人もいれば、別人のように書き分ける人もいる。

これも人の性質ではあるが、場面をまたいで現れるものなので、性質 2 により
書きぶりには入らない。そして <strong>ある場面で 1 本書かせるのに要るものでもない</strong>。
扱わない。

### 大きさを問わない

書きぶりはどの大きさの単位にも現れる。語の選び方にも、文の終え方にも、記事
全体の組み立て方にも。

小さい方だけを書きぶりと呼ばない。語がすべて合っていても、記事の組み立てが
違えば別人のものに読める。<strong>大きい方が目立つ。</strong>

## 軸の外

作ってはいけないという意味ではない。<strong>この道具ではない</strong> という意味である。

| 外にあるもの | なぜ外か |
| --- | --- |
| 考えかた、判断軸 | 本人が言葉にできる。性質 1 を満たさない |
| 何を書くか（題材、主張、事実） | 書くたびに変わる。性質 2 と 3 を満たさない |
| 誰に向けて書くか（場面） | 取り出す対象ではなく、取り出す前に決まっている前提 |
| 文章の良し悪しの評価 | 見るのは「誰が書いたように読めるか」だけ |
| 文法の誤りの指摘、校正 | 正しさの話であって、その人らしさの話ではない |
| 文章を集めてくること | 材料集めであって、取り出す仕事ではない |
| 取り出したものを他人に渡すこと | 「本人の外」のさらに先 |
| 日本語以外 | 書きぶりの多くが日本語に固有 |

### 判断軸が外にあることについて

いちばん紛らわしいのが判断軸である。何を良しとし、何を書かないか。その人
らしい文章に要るものなので、引き込みたくなる。

だが判断軸は意識して取っている立場であり、本人が言葉にできる。性質 1 を
満たさないので、定義により書きぶりではない。

<strong>そしてこれは損失ではない。</strong> 言えるということは、訊けば手に入るということ
である。訊けば手に入るものを、取り出せないものと同じ苦労で推定する理由が
ない。訊けないものを扱うのがこの道具の存在理由である。

## できたと言えるとき

<strong>本人が読んで、自分が書いたものとして受け入れる。</strong>

これだけが条件である。数値がどう動いたかは、この判定の代わりにならない。
前身では、本人が読んで拒否した文章が満点を取ったことがある。
