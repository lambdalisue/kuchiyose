# kakiburi の軸

## 軸

その人の書きぶりを、本人の外で使えるようにする。

書きぶりは本人の中にあり、本人には取り出せない。それを取り出して、本人以外
——実際には LLM——が使える形にする。取り出して、貸す。書くのは借りた側である。

kakiburi はこの一行のための道具であり、ここに入らないものは作らない。

## なぜ要るのか

自分の文章を LLM に代筆させると、出てきたものが自分と違うことは分かる。
だが、どこが違うのかは言えない。

言えないのは観察力の問題ではない。書きぶりとは、そもそも言えないものだから
である。本人に訊いても答えは出ないし、挙げてもらった特徴は、たいてい本当の
特徴ではない。

## 書きぶりとは何か

題材と場面を決めたあとに、なお人によって違ってしまう部分である。

場面とは、誰に向けて、その場でどういう立ち位置で、何のために書くかである。

同じ題材を、同じ場面で、10 人が書けば 10 通りになる。その差が書きぶりである。

4 つの性質を持つ。この 4 つを満たすものが書きぶりであり、1 つでも欠けるものは
書きぶりではない。

1. 本人が意識していない。選んでいるが、選んだ覚えがない。だから訊いても
   出てこない。言えるものは書きぶりではなく、方針や好みである。
2. 同じ場面で書いたものに一貫して現れる。その 1 本の事情ではなく、その人の
   性質である。1 本にしか現れないものは書きぶりではない。
3. 題材が変わっても変わらない。題材とともに変わるものは、書きぶりではなく
   内容である。
4. 文章に現れる。頭の中にあって文章に痕跡を残さないものは、取り出しようが
   ない。「丁寧だ」「論理的だ」は読んだ人の感想であって、文章に現れているのは
   その感想を生んだ何かの方である。

### 場面ごとにある

同じ人でも、技術記事と Slack の投稿では書きぶりが違う。場面の 3 つがどれも
違うからである。

相手が違う。不特定の読者に向けるのか、事情を共有している同僚に向けるのか。
立ち位置が違う。教える側なのか、相談する側なのか。そして何のために書くかが
違う。その場で流れて消えるものなのか、後から参照されるものなのか。

どれが動いても書きぶりは動く。敬体か常体か、どこまで前提を説明し直すか、
どこまで断定するか、見出しを立てるかどうか。最後の 2 つはとくに、後から
参照されるかどうかで決まる。単独で読めなければならない文章と、直前の発言に
続けて読まれる文章では、書き方が変わらない方がおかしい。

これは定義の綻びではなく、定義そのものである。性質 3 が「変わらない」と言って
いるのは題材についてであって、場面についてではない。同じ場面にいる限り題材が
変わっても書きぶりは変わらず、場面が変われば変わる。

したがって「その人の書きぶり」という言い方は、厳密には足りない。書きぶりは
つねに、ある人の、ある場面での書きぶりである。取り出すときも貸すときも、
場面を決めずには成立しない。

場面を分けるのは媒体ではない。同じ Slack でも、チームに向けた報告と社外への
連絡は別の場面になる。媒体はしばしば場面と一致するが、一致することと同じ
ものであることは違う。

### 大きさを問わない

書きぶりはどの大きさの単位にも現れる。語の選び方にも、文の終え方にも、記事
全体の組み立て方にも。

小さい方だけを書きぶりと呼ばない。語がすべて合っていても、記事の組み立てが
違えば別人のものに読める。目立つのはむしろ大きい方である。

## 書きぶりでないもの

定義から落ちるものである。扱わないと決めたのではなく、扱う対象に入らない。

| | なぜ落ちるか |
| --- | --- |
| 考えかた、判断軸 | 性質 1 を欠く。意識して取っている立場なので、本人が言葉にできる |
| 何を書くか（題材、主張、事実） | 性質 2 と 3 を欠く。書くたびに変わる |
| 場面をまたぐ書き分けの度合い | 性質 2 を欠く。1 つの場面の中には現れない |
| 文法の正しさ | 人によって違わない |
| 文章の良し悪し | 人によって違わない |

下の 2 行は性質ではなく定義そのもので落ちている。文法の正しさは誰が書いても
同じものを目指すので、人による差が出るとすればそれは誤りである。良し悪しは
そもそも文章の側にはなく、読む側にある。どちらも「人によって違ってしまう
部分」に当たらない。

なお、場面はここに入らない。場面は扱わないものではなく、扱う前に決まって
いなければならない前提である。

### 判断軸について

いちばん紛らわしい。何を良しとし、何を書かないか。その人らしい文章に要る
ものなので、引き込みたくなる。

だが判断軸は意識して取っている立場であり、本人が言葉にできる。性質 1 を
満たさないので、定義により書きぶりではない。

そしてこれは損失ではない。言えるということは、訊けば手に入るということで
ある。訊けば手に入るものを、取り出せないものと同じ苦労で推定する理由がない。
訊けないものを扱うのがこの道具の存在理由である。

## この道具がやらないこと

書きぶりに関わるが、定義からは落ちないものである。だから、やらないと決める
必要がある。

文章を書くこと。kakiburi は書きぶりを貸すところまでをやる。それを使って
書くのは借りた側である。

文章を集めてくること。どこからどう材料を用意するかは、書きぶりが何かとは
無関係に決まる。この道具の仕事は、与えられた文章から先である。

## 対象は日本語

日本語で書かれた文章だけを扱う。

他の言語にも書きぶりはある。扱わないのは、書きぶりの現れ方が言語ごとに違い、
取り出し方をどれか 1 つの言語に合わせる必要があるからである。どう合わせるかは
この文書の外にある。
