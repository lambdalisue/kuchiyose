# kakiburi の軸

## 軸

その人の書きぶりを、本人の外で使えるようにする。

書きぶりは本人の中にあり、本人には取り出せない。取り出して、本人以外——
実際には LLM——に貸す。書くのは借りた側である。

## なぜ要るのか

代筆させたものが自分と違うことは分かる。だが、どこが違うのかは言えない。
本人に訊いても答えは出ないし、挙げてもらった特徴は、たいてい本当の特徴では
ない。

## 書きぶりとは何か

題材と場面を決めたあとに、なお人によって違ってしまう部分である。

場面とは、誰に向けて、どういう立ち位置で、何のために書くかである。同じ題材を
同じ場面で 10 人が書けば 10 通りになる。その差が書きぶりである。

4 つの性質を持つ。1 つでも欠けるものは書きぶりではない。

1. 本人が意識していない。だから訊いても出てこない。言えるものは書きぶりでは
   なく、方針や好みである。
2. 同じ場面で書いたものに一貫して現れる。1 本にしか現れないものは、その記事の
   事情である。
3. 題材が変わっても変わらない。変わるものは内容である。
4. 文章に現れる。「丁寧だ」は読んだ人の感想であって、文章にあるのはその感想を
   生んだ何かの方である。

語の選び方にも、文の終え方にも、記事全体の組み立て方にも現れる。目立つのは
大きい方である。

### 場面が変われば書きぶりも変わる

技術記事と Slack では、相手も、立ち位置も、その場で流れて消えるのか後から
参照されるのかも違う。どれが動いても書きぶりは動く。

性質 3 が変わらないと言っているのは題材についてであって、場面についてでは
ない。したがって書きぶりはつねに、ある人の、ある場面での書きぶりである。
取り出すときも貸すときも、場面を決めずには成立しない。

場面を分けるのは媒体ではない。同じ Slack でも、チームへの報告と社外への連絡は
別の場面になる。

## 書きぶりでないもの

定義から落ちる。扱わないと決めたのではなく、対象に入らない。

| | なぜ落ちるか |
| --- | --- |
| 考えかた、判断軸 | 性質 1 を欠く。意識して取っている立場なので言葉にできる |
| 題材、主張、事実 | 性質 2 と 3 を欠く。書くたびに変わる |
| 場面をまたぐ書き分けの度合い | 性質 2 を欠く。1 つの場面の中には現れない |
| 文法の正しさ | 人によって違わない。違えばそれは誤りである |
| 文章の良し悪し | 人によって違わない。読む側にあるものである |

場面はここに入らない。扱わないものではなく、扱う前に決まっている前提である。

判断軸が外なのは損失ではない。言えるということは訊けば手に入るということで、
訊けば手に入るものを推定する理由はない。訊けないものを扱うのがこの道具の
存在理由である。

## そのほかの境界

文章を書かない。貸すところまでをやる。

文章を集めてこない。仕事は、与えられた文章から先である。

日本語だけを扱う。他の言語にも書きぶりはあるが、現れ方が言語ごとに違い、
取り出し方をどれかに合わせる必要がある。
