# kakiburi の軸

## 軸

<strong>その人の書きぶりを、本人の外で使えるようにする。</strong>

kakiburi はこの一行のための道具である。ここに入らないものは作らない。

## なぜ要るのか

自分の文章を LLM に代筆させると、出てきたものが自分と違うことは分かる。
だが、どこが違うのかは言えない。

言えないのは、その人の観察力が足りないからではない。書きぶりとは、書いて
いる本人が選んだ意識のないまま積み上がった選択のことだからである。だから
本人に訊いても答えは出ない。挙げてもらった特徴は、たいてい本当の特徴では
ない。

本人の中にあって本人には取り出せない。取り出すのが kakiburi の仕事である。

## 3 つの動き

| 動き | すること |
| --- | --- |
| 取り出す | 書いたものから書きぶりを取り出し、置いておく |
| 貸す | 取り出したものを、他人が使える指示にする |
| 検める | 書かれたものが、その書きぶりに合っているかを見る |

貸すと検めるが <strong>同じものを見ている</strong> ことが、この道具の保証である。貸す
ときに「太字は 1,000 字あたり 0.29 から 3.51」と言い、検めるときも同じ幅で
見る。書かせて、検めて、直して、また検める——この使い方はこの一致だけに
依存している。

kakiburi は文章を書かない。書くのは借りた側である。

## 書きぶりとは何か

<strong>観測できるものに限る。</strong>

「丁寧だ」「論理的だ」は書きぶりではない。読んだ人の感想であって、取り出せ
ない。取り出すのは、本人が選んでいると気付いていない選択である。

- どの語を使い、どの語を使わないか
- 同じ語を漢字で書くか仮名で書くか
- 文をどう終えるか
- 記号をどう使うか
- 段落や箇条書きをどれくらい使うか

数えられるから、貸せるし検められる。数えられないものを軸に入れると、貸す
ときに指示にならず、検めるときに判定にならない。

## ここから出てくること

軸から必然的に落ちてくる原則である。手法を先に選んだのではなく、
「本人に言えないものを取り出す」ことがこの形を要求する。

### 閾値はコーパスから導く。手で決めない

「太字は 1,000 字あたり 4 個まで」を人が決めるなら、それは <strong>言える人がいる</strong>
という前提に立っている。言えないから取り出すのに、取り出し方の中で言える
ことにしてしまっては筋が通らない。

文書ごとに測り、その分布そのものを持つ。判定は分布からの逸脱で行う。

この形にすると、誤検出は <strong>データの問題</strong> になる。「1 回使っただけで減点
された」なら、それは分布の上端を取り違えているという計測の誤りであって、
条件分岐の誤りではない。直すのはコードではなく測り方である。

### 過剰だけでなく不足も見る

減点を過剰の側にしか置かないと、点を上げようとする側は「全部削る」に収束
する。実際に、箇条書きを消した文章が満点を取ったことがある。書き手自身は
どの記事でも箇条書きを使っていたのに。

分布の下端を割ることは、上端を超えることと同じだけ不自然である。

ただし下端を「最小値を下回る」と実装してはいけない。一度でも使わなかった
文書があれば最小値は 0 になり、条件が永久に成り立たない。<strong>その特徴を使った
文書の割合</strong> を持ち、ほぼ毎回使うものが無いときに指摘する。

### 語は形態素で照合する

`仕事が` から `事が` を拾うような誤検出は、部分文字列での照合をやめて
(原形, 品詞) の組で照合すれば構造的に消える。

日本語には語の境界が無い。だから形態素解析が要る。

### 日本語だけを対象にする

限界ではなく決めである。取り出すものの多くが日本語に固有だからである。
漢字と仮名の使い分け、文末表現の分布、和欧間スペースの有無、記号の体系。

言語に依らない形に抽象化すると、抽象化の層が実装より厚くなり、しかも
確かめるための第二の言語が無い。抽象化しない。

## 決定的であること

同じ入力からは同じ結果が出る。

これが無いと、この道具は LLM に「自分らしいですか」と訊くのと変わらなく
なる。訊けば毎回違う答えが返り、直した結果が良くなったのかどうかも分から
ない。<strong>同じ数字が返ることが、この道具が LLM より役に立つ唯一の理由である。</strong>

数えるのは機械がやる。読んで判断するのは借りた側がやる。境界はここにある。

## 軸の外

作ってはいけないという意味ではない。<strong>この道具ではない</strong> という意味である。

| 外にあるもの | なぜ外か |
| --- | --- |
| 考えかた、判断軸、読者想定 | 書きぶりではない |
| 文章の良し悪しの評価 | 測るのは「その人らしいか」だけ |
| 文法の誤りの指摘、校正 | 別の仕事 |
| 文章を集めてくること | 材料集めであって、取り出す仕事ではない |
| 取り出したものを他人に渡すこと | 「本人の外」のさらに先 |
| 日本語以外 | 上記のとおり |

とくに <strong>考えかた</strong> は紛らわしい。その人らしい文章を書くには考えかたが要る
のは確かで、だからこそ引き込みたくなる。だが考えかたは書きぶりではない。
取り出し方も、確かめ方も、貸し方も違う。混ぜると両方が濁る。

## できたと言える条件

単体テストが通ることは、この道具が機能する証明にならない。部品が仕様どおり
に動くことしか言っていない。書きぶりが取り出せているかは、そこには現れない。

決め手は <strong>分離</strong> である。

実際のコーパスから取り出し、答えの分かっている文章を検める。本人が書いた
ものは高く、機械が書いたものは低く、<strong>両者が重ならない</strong>。重なるなら、緑の
テストが何本あろうとその道具は間違っている。

分布を作ったコーパス自身を検めても意味がない。良い点が出るのは当たり前で、
何も証明していない。取り出しに使わなかった本人の文章を 1 本残し、それが
コーパスと同じ範囲に入ることを見る。
