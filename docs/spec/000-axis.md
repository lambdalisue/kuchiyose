# kakiburi の軸

<strong>『どこがその人と違うかを、言えるようにする』</strong>

手法ではない。複数あるものでもない。迷ったときはここに戻る。

この文書はこの一行がどこから出るかだけを書く。そこへどう到達するかは
[戦略](010-strategy.md)が決め、個々の作り方はその先の文書が決める。

## やりたいこと

LLM に代筆させた文章に、<strong>その人の味が出ている</strong>ようにしたい。書くものの種類は
限らない。自分に限る理由はどこにも無いので、以後「その人」と書く。

### 隠すための道具ではない

<strong>AI が書いたことを秘匿するのが目的ではない。</strong> 内容が良ければ、AI が書いたもので
かまわない。

<strong>困るのは、素のままだと読みづらいことである。</strong> 同じものを指すのに毎回違う語を使い、
どの段落も同じ調子で並び、その人が書くはずのない言い回しが混ざる。
<strong>読みづらさの正体は、その人の書きぶりが無いことである。</strong>

> <strong>だから「見破られないこと」は目標ではない。</strong> 検出を避ける側の指標——
> 生成文が人と判定される割合など——は、この軸の根拠に使わない。
> 使うのは<strong>その人の書きぶりが出ているか</strong>と、<strong>読みづらさの元が残っていないか</strong>である。

## なぜこの軸になるのか

代筆させた素の文章がその人と違うことは、読めば分かる。分からないのは、どこが違うのか
である。<strong>しかも手を入れるほど、違うという感触のほうが先に消える。</strong> 軸はこの欠けを
そのまま埋めている。

### なぜ「言う」が要るのか

1 回で通るものが出てこないからである。最先端の手法で個人化しても、出力は<strong>赤の他人
どうしよりまだ本人から遠い</strong>（[Sawant](../references/authorship-gap-2026.md)）。

だから直すことになる。<strong>そして直す側は、指示でしか動かせない。</strong> 人が直すのでも、LLM に
直させるのでも、受け取れるのは言葉である。埋め込みの差分を渡して寄せる道は無い。

だから違いは、<strong>言葉にできる形</strong>でなければならない。「同一人か否か」では直せない。
どの観点が、どちらへ、どれだけ外れているかが要る。

### なぜ道具が要るのか

<strong>誰にも言えないからである。</strong>

| 誰が言うか | 何が起きるか | |
| --- | --- | --- |
| 本人 | 手で直しても差は残るのに、直したものを自分の文章と同じくらい自分らしいと感じる | [Post-Editing](../references/post-editing-2026.md) |
| 他人 | 文体についての判断が一致しない（評価者間 0.641） | [SPTG の評価](../references/sptg-evaluation-2025.md) |
| LLM | 循環する。生成文が本人の文章より高く出る | [Sawant](../references/authorship-gap-2026.md) |

言える主体が要る。<strong>3 つとも落ちた理由は、判断が人か LLM に寄っていることである。</strong>
残るのは、どちらにも寄らず、同じ入力に同じ答えを返すものだけになる。それがこの道具で
あり、ここから、判定できるのは数値だけだという
[決定](010-strategy.md#判定できるのは数値だけである)が出る。

## この軸が置いている仮説

軸は<strong>1 つの仮説の上に立っている。</strong> 全文書がこれを前提にしているので、ここで名指し
しておく。

> <strong>「その人らしさ」には、決定的に数えられる部分がある。</strong>
> そして<strong>その部分だけで、直すのに足りるだけの違いが言える。</strong>

<strong>後半が本体である。</strong> 前半だけなら計量文体論が示している。前半を認めても、
<strong>数えられる部分が薄すぎて何も言えない</strong>という結末はありうる——そこが賭けである。

### 仮説が主張していないこと

<strong>広く取ると必ず外れる。</strong> 何を言っていないかを先に置く。

| | |
| --- | --- |
| <strong>らしさを全部数えられる</strong> | 言っていない。内容・論理・機知は測っていない |
| <strong>数字が揃えば人がそう感じる</strong> | 言っていない。<strong>我々はまだ測っていない</strong>（[残っている穴](#仮説のどこがまだ確かめられていないか)） |
| <strong>本人だと断定できる</strong> | 言っていない。言えるのは<strong>差が見つからなかった</strong>ことだけである |
| <strong>生成が届く</strong> | 言っていない。<strong>識別できることと生成できることは別である</strong>——先行研究は[まだ誰も届いていない](010-strategy.md#味が出るには-2-つ要る)と言っている。仮説は<strong>測る側</strong>についてのものである |
| <strong>誰にでも同じだけ効く</strong> | 言っていない。効く量は書き手ごとに違う（[効くかの判定](200-extract.md#どの指標が効くかを決める)） |

### なぜ数えられると考えるのか

<strong>著者識別が、数えるだけで人を分けているからである。</strong> 日本語のブログ 1,000 字・2,287 人
で、文字 bigram・読点の打ち方・文字種などの<strong>頻度だけ</strong>から EER 9.3% が報告されている
（[尤度比](../references/fusing-lr-2026.md)）。<strong>意味を理解していない量が、書き手を分けている。</strong>

> [!WARNING]
> <strong>その数字をそのまま持ってこない。</strong> 素材は 2008〜09 年の日記であり、埋め込み 2 系統を
> 含む組み合わせである。<strong>論文自身がジャンル間の転移を警告している</strong>
> （[較正されているのは層 1 の一部である](100-metrics.md#較正されているのは層-1-の一部である)）。
> 借りるのは<strong>どの量を見るか</strong>だけで、どれだけ効くかは我々が測って知るしかない。

### 仮説をどう反証できるようにしてあるか

<strong>外れたときに黙って通る作りにしない。</strong> 仮説が成り立っていない書き手・場面では、
<strong>それが判定不能として表に出る。</strong>

| 外れ方 | どこに出るか |
| --- | --- |
| 本人と基準が分かれない | [帯が全体を覆い](200-extract.md#人らしさの境目は同じ材料から出る)、「判定できない」しか返らない |
| 数えた量が書き手を分けない | [効く指標が 0 本](200-extract.md#どの指標が効くかを決める)になり、指摘が出ない |
| 素材が足りない | [目盛りを作らない](200-extract.md#見る前に標本の範囲を確かめる)。0 を返さない |
| 直しても動かない | [動かないと分かった指標を落とす](200-extract.md#どの指標が効くかを決める)（条件 3） |

<strong>どれも「当てはまらないこと」が値ではなく状態として出る。</strong> これが
[届かないときは判定できないと言う](010-strategy.md#届かないときは判定できないと言う)の
本当の役目である——<strong>謙虚さではなく、仮説の自己診断である。</strong>

### いまのところ仮説は持っている

1 人ぶんの素材（本人 50 本 / 基準 21 本）で測った範囲では、成り立っている。

| | |
| --- | --- |
| 照合値の分離 | 本人 2.110〜4.430 / 機械 −2.914〜2.067。<strong>重なりなし</strong> |
| カセットに入れていない本人の記事 | 16 本中 <strong>13 本が通る</strong>、<strong>誤判定 0</strong> |
| 機械の書いた記事 | 21 本 × 3 カセットで<strong>通ったもの 0</strong> |

<strong>1 人ぶんである。</strong> ほかの書き手で成り立つかは、まだ言えない。

### 仮説のどこがまだ確かめられていないか

<strong>数字が揃った文章を、人間の読者が「その人らしい」と感じるかを測っていない。</strong>

道具が測っているのは表層の統計である。<strong>統計が揃うことと、読んでそう感じることのあいだ
に橋を架けていない。</strong> 架けるには読者を集めた評価が要り、そこは
[他人の判断が一致しない](#なぜ道具が要るのか)という、この軸が出発点で避けた場所に戻る。

<strong>だから消さずに書いておく。</strong> ここが埋まっていないことは、道具の限界そのものである。

## だからしないこと

内と外は 1 つの基準で分ける。<strong>言うために内側になければならないか、外から渡されれば
済むか。</strong>

| | 渡されれば済む |
| --- | --- |
| 文章を作る | 草稿は渡されればよい。目的も章立ても、書く人が決める |
| 文章を集めてくる | 材料は渡されればよい |

読み込みも、正規化も、計測も、渡されただけでは済まない。だから内側にある。

作ってはいけないという意味ではない。この道具ではない、という意味である。
