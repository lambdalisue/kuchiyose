# kakiburi の軸

軸とは、この道具が何をやるためのものかを一言で言ったものである。手法ではない。複数
あるものでもない。迷ったときはここに戻る。

決めるのは 2 つ、<strong>何のためにあるか</strong> と <strong>何を扱うか</strong> だけである。どう作るかは
[戦略](010-strategy.md)が、根拠は[先行研究](../references/)が持つ。

## やりたいこと

LLM に代筆させたときに、自分が書いたものとして通るようにしたい。書くものの種類は
限らない。

<strong>出てきたものが自分と違うことは分かる。だが、どこが違うのかは言えない。</strong>

以下の 2 つは、どちらもこの要求から出る。

### 通るには 2 つ要る

その人らしいことと、人が書いたものに見えることである。

2 つ目は 1 つ目から出てこない。文体がどれだけ寄っても、機械が書いたと分かる文章は
通らない。両方について言えるようにする。

## 何のためにあるか

> <strong>どこがその人と違うかを、言えるようにする。</strong>

### なぜ「言う」が要るのか

1 回で通るものが出てこないからである。最先端の手法でも、個人化した出力は赤の他人より
遠い。人が手で直しても、機械寄りの差は残る。

だから直すことになる。<strong>そして直すには、どこが違うかが分かっていなければならない。</strong>
「同一人か否か」では直せない。どの軸が、どちらへ、どれだけ外れているかが要る。

### なぜ道具が要るのか

<strong>誰にも言えないからである。</strong> 本人は自分の文章と直した機械の文章を区別できず、他人の
判断は一致せず、LLM に判定させれば循環する
（[根拠](../references/README.md#分かったこと評価)、
[決定](010-strategy.md#判定できるのは数値だけである)）。

言える主体が要る。それがこの道具である。

### だからしないこと

言うことが目的である以上、次の 2 つは外にある。

| | なぜ |
| --- | --- |
| 文章を作る | 書くことは言うことではない。目的も章立ても、書く人が決める |
| 文章を集めてくる | 材料集めであって、言う仕事ではない |

作ってはいけないという意味ではない。この道具ではない、という意味である。

## 何を扱うか

> <strong>ある人の、ある場面での、書きぶりの違いだけ。</strong>

### 書きぶりとは何か

書きぶりとは、<strong>題材と場面を決めたあとに、なお人によって違ってしまう部分</strong>。
場面とは、誰に向けて、どういう立ち位置で、何のために書くかである。同じ題材を同じ場面
で 10 人が書けば 10 通りになる。その差が書きぶりである。

5 つの性質を持つ。<strong>1 つでも欠けるものは書きぶりではない。</strong>

| | 性質 | どこから来たか |
| --- | --- | --- |
| 1 | 人によって違いうる | <strong>個人差</strong>（[財津・金](../references/zaitsu-2018.md)） |
| 2 | 同じ場面で書いたものに一貫して現れる | <strong>個人内恒常性</strong>（同） |
| 3 | 題材が変わっても変わらない | 機能語は題材に依存しない（[Stamatatos](../references/stamatatos-2009.md)） |
| 4 | 本人が意識していない | 機能語は無意識に使われる（同） |
| 5 | 文章に現れる | この分野が一貫して文章を対象にしてきた |

1 と 2 が土台である。書き手識別が成り立つ条件そのもので、
[財津・金](../references/zaitsu-2018.md)が名指ししている。

> 各個人によって表出される文体的特徴に「個人差」と「個人内恒常性」が存在することから
> 筆者の識別が可能となる

3 から 5 は、この 2 つをどこまで信じてよいかを限定する。3 は恒常性が題材に対しても
求められること。4 は取り出す手段が計測になる理由。5 は対象の線引きである。

### 境界が紛らわしい 2 つ

<strong>性質 1——誰が書いても同じになるものは外れる。</strong>「文頭の接続詞の後に読点を打つ」は
性質 2 から 5 をすべて満たすが、公用文の手引きに書かれている常識である。読点という
1 つの現象の中に、誰もが打つ層と、人によって違う層が混ざっている（石黒 2011、
[岩崎](../references/japanese-attribution-others.md)）。

<strong>性質 2——場面が変われば成り立たない。</strong> 同じ人でも技術記事とチャットでは違い、その
寄与は人の寄与と同じ大きさである（[水上ほか](../references/mizukami-2014.md)）。だから
「同じ場面で」と限定されている。場面を分けるのは媒体ではない。同じチャットでも、
チームへの報告と社外への連絡は別の場面になる。

### 数えない違い

違いはあっても、書きぶりの違いではないもの。どれも上の性質のどれかを満たさない。

| 違い | なぜ数えないか |
| --- | --- |
| 題材が違う | 書くたびに変わる。性質 2 と 3 を満たさない |
| 場面が違う | 扱う前に決まっている前提である。違いとして出せば、人の違いと混ざる |
| 文章の出来が違う | 性質 1 を満たさない。読む側にあるものである |
| 文法が誤っている | 性質 1 を満たさない。違えばそれは誤りである |
| 規範から外れている | 性質 1 を満たさない。誰を測っても同じ値になる |
| 考えかた・判断軸が違う | 性質 4 を満たさない。本人が言葉にできる |
| 場面をまたぐ書き分けの度合いが違う | 性質 2 を満たさない |

<strong>「人が書いたものに見えるか」は、ここには入らない。</strong>
[通る条件の 2 つ目](#通るには-2-つ要る)であり、そこも言えるようにする。

### 日本語だけ

特徴量は言語ごとに違う。1 つに合わせる。
