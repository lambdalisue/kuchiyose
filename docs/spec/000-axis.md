# kakiburi の軸

<strong>この道具が何のためにあるかと、何を扱うかだけを決める。</strong> どう作るかは
[戦略](010-strategy.md)が、根拠は[先行研究](../references/)が持つ。

## やりたいこと

LLM に代筆させたときに、<strong>自分が書いたものとして通る</strong>ようにしたい。

<strong>出てきたものが自分と違うことは分かる。だが、どこが違うのかは言えない。</strong>

書くものの種類は限らない。記事も、チャットも、投稿も、代筆させたいものはすべて対象に
なる。

### 通るには 2 つ要る

<strong>その人らしいこと</strong>と、<strong>人が書いたものに見えること</strong>である。

2 つ目は 1 つ目から出てこない。文体がどれだけ寄っても、機械が書いたと分かる文章は
通らない。<strong>両方について言えるようにする。</strong>

## 軸

<strong>どこがその人と違うかを、言えるようにする。</strong>

やりたいことの一文目——「違うことは分かるが、どこが違うのかは言えない」——に、
そのまま答える。

### なぜ「言う」なのか

<strong>この分野が未解決だと名指ししているのが、そこだからである。</strong>

> An important obstacle is that it is not yet possible to <strong>explain the differences between
> the authors' style</strong>. ... But what we need is a <strong>higher level abstract description</strong> of the
> authorial style.
> ——[Stamatatos 2009](../references/stamatatos-2009.md)

<strong>判別はできる。説明はできない。</strong> 日本語でも 1,000 字あれば書き手を判定できる
（[財津・金](../references/zaitsu-2018.md), [尤度比](../references/fusing-lr-2026.md)）。
だが出てくるのは「同一人か否か」であって、<strong>どこがどう違うかではない。</strong>

直すには、後者が要る。

### 言えるのは数値だけである

<strong>人にも LLM にも言えない。</strong>

| 誰が | 何が起きるか |
| --- | --- |
| 本人 | 自分の文章と、直した LLM の文章を<strong>区別できない</strong> |
| 他人 | 文体についての判断が<strong>一致しない</strong> |
| LLM に判定させる | <strong>循環する。</strong> 生成文が本人の文章より高く出る |
| LLM に特徴を挙げさせる | 同じ人から 2 回抽出して<strong>一致しない</strong> |

（[根拠](../references/README.md#分かったこと評価)、
[決定](010-strategy.md#数える側に-llm-を置かない)）

<strong>残るのは、決定的で解釈できる数値である。</strong> 決定的でなければ物差しにならず、
解釈できなければ「どこが」を言えない。

### 言えれば足りる

<strong>1 回で寄せきる必要はない。</strong> 最先端の手法でも、個人化した出力は赤の他人より遠い。
一方、<strong>直す作業には効果が測られている。</strong>

<strong>言えることが、直せることであり、繰り返せることである。</strong> 回数で寄せる道が、そこで
開く。

<strong>だから、書くのは借りた側である。この道具は書かない。</strong>

## 何を「違い」として数えるか

軸が「どこが違うか」を言う以上、<strong>何を違いに数え、何を数えないかが、この道具の範囲を
決める。</strong>

数えるのは <strong>書きぶりの違い</strong> だけである。

### 書きぶりとは何か

<strong>題材と場面を決めたあとに、なお人によって違ってしまう部分。</strong>

場面とは、誰に向けて、どういう立ち位置で、何のために書くかである。同じ題材を同じ場面
で 10 人が書けば 10 通りになる。その差が書きぶりである。

<strong>性質は[先行研究](../references/)から導く。</strong> 5 つあり、1 つでも欠けるものは書きぶりでは
ない。

#### 土台の 2 つ

書き手識別が成り立つ条件そのものである。[財津・金](../references/zaitsu-2018.md)が
名指ししている。

> 各個人によって表出される文体的特徴に <strong>「個人差」</strong> と <strong>「個人内恒常性」</strong> が存在する
> ことから筆者の識別が可能となる

1. <strong>人によって違いうる</strong>（個人差）
2. <strong>同じ場面で書いたものに一貫して現れる</strong>（個人内恒常性）

<strong>この 2 つが無ければ、識別も再現も原理的に成立しない。</strong> 残る 3 つは、この 2 つを
どこまで信じてよいかを限定する。

#### 恒常性の範囲

3. <strong>題材が変わっても変わらない</strong>

文体の担い手とされる機能語は <strong>題材に依存しない</strong>
（[Stamatatos](../references/stamatatos-2009.md)）。<strong>恒常性は題材に対しても求められる。</strong>

<strong>ただし場面に対しては成り立たない</strong>（[後述](#場面ごとにある)）。だから性質 2 は
「同じ場面で」と限定されている。

#### なぜ訊けないか

4. <strong>本人が意識していない</strong>

同じく機能語について、<strong>書き手が概ね無意識に使う</strong>とされている
（[Stamatatos](../references/stamatatos-2009.md)）。<strong>取り出す手段が計測になるのは、
ここから来る。</strong>

#### 何を対象にするか

5. <strong>文章に現れる</strong>

<strong>この分野が扱ってきたのは一貫して文章そのものである。</strong> 書き手の属性や意図ではない。
「丁寧だ」は読んだ人の感想であって、文章にあるのはその感想を生んだ何かの方である。

### 規範の層がある

<strong>1 つの現象の中に、誰もがやることと、人によって違うことが混ざっている。</strong>
読点についての整理がそのまま当てはまる（石黒 2011、
[岩崎](../references/japanese-attribution-others.md)）。

| 層 | 何が決めるか | 書きぶりか |
| --- | --- | --- |
| 誰もが打つ | 意味・長さ・構造 | <strong>いいえ</strong>（性質 1 を満たさない） |
| 人により異なる | 表記・音調・リズム | <strong>はい</strong> |
| 一部の人が打つ | 強調 | <strong>はい</strong> |

「文頭の接続詞の後に読点を打つ」は性質 2 から 5 をすべて満たす。<strong>それでも書きぶりでは
ない。公用文の手引きに書かれている常識だからである。</strong>

<strong>性質 1 が要るのは、この層を外に出すためである。</strong>

### 場面ごとにある

同じ人でも、技術記事とチャットでは書きぶりが違う。相手も、立ち位置も、その場で流れて
消えるのか後から参照されるのかも違う。<strong>どれが動いても書きぶりは動く。</strong>

<strong>場面の寄与は、人の寄与と同じ大きさである</strong>
（[水上ほか](../references/mizukami-2014.md)）。

したがって書きぶりはつねに <strong>ある人の、ある場面での</strong> 書きぶりである。
<strong>場面を決めずには成立しない。</strong>

場面を分けるのは媒体ではない。同じチャットでも、チームへの報告と社外への連絡は別の
場面になる。

### 何が特徴になるかも人による

<strong>ある人にとって際立った特徴が、別の人には何でもないことがある。</strong> 片方は括弧をまったく
使わず、もう片方は使いも使わなくもする。

同じ手法で 5 人になりすまさせると、成功率が 0.11 から 0.77 まで開き、<strong>どの手法が最良かも
人によって入れ替わる</strong>（[Masks and Mimicry](../references/masks-mimicry-2025.md)）。

したがって書きぶりは「どこがどうか」だけでなく、<strong>どこが効くか</strong> でもある。

## 何を「違い」として数えないか

<strong>違いはあっても、書きぶりの違いではないもの。</strong> どれも性質のどれかを満たさない。

| 違い | なぜ数えないか |
| --- | --- |
| 題材が違う | 書くたびに変わる。性質 2 と 3 を満たさない |
| 場面が違う | <strong>扱う前に決まっている前提</strong>である。違いとして出せば、人の違いと混ざる |
| 文章の出来が違う | 性質 1 を満たさない。読む側にあるものである |
| 文法が誤っている | 性質 1 を満たさない。違えばそれは誤りである |
| 規範から外れている | 性質 1 を満たさない。誰を測っても同じ値になる |
| 考えかた・判断軸が違う | 性質 4 を満たさない。<strong>本人が言葉にできる</strong> |
| 場面をまたぐ書き分けの度合いが違う | 性質 2 を満たさない |

<strong>「人が書いたものに見えるか」は、ここには入らない。</strong>
[通る条件の 2 つ目](#通るには-2-つ要る)であり、そこも言えるようにする。

## この道具がしないこと

数えないものとは別に、<strong>やる仕事そのものが外にあるもの。</strong>

| | なぜ |
| --- | --- |
| <strong>文章を作る</strong> | <strong>書くことは言うことではない。</strong> 目的も章立ても、書く人が決める |
| 文章を集めてくる | 材料集めであって、言う仕事ではない |
| 日本語以外を扱う | 特徴量が言語ごとに違う。1 つに合わせる |

<strong>作ってはいけないという意味ではない。この道具ではない、という意味である。</strong>
