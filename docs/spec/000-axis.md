# kakiburi の軸

この文書は kakiburi が <strong>何のための道具か</strong> だけを決める。どう作るかは
決めない。

## 軸

<strong>その人の書きぶりを、本人の外で使えるようにする。</strong>

書きぶりは本人の中にあり、本人には取り出せない。それを取り出して、本人以外
——実際には LLM——が使える形にする。

kakiburi はこの一行のための道具であり、ここに入らないものは作らない。

## なぜ要るのか

自分の文章を LLM に代筆させると、出てきたものが自分と違うことは分かる。
だが、どこが違うのかは言えない。

言えないのは観察力の問題ではない。書きぶりとは、書いている本人が意識の
ないまま積み上げた選択のことだからである。本人に訊いても答えは出ないし、
挙げてもらった特徴は、たいてい本当の特徴ではない。

## 何を取り出すのか

<strong>観測できるものに限る。</strong>

「丁寧だ」「論理的だ」は書きぶりではない。読んだ人の感想であって、取り出せ
ない。取り出すのは、本人が選んでいると気付いていない選択である。

書きぶりは 2 つの層にある。

<strong>文の書きぶり。</strong> どの語を使い、どの語を使わないか。同じ語を漢字で書くか
仮名で書くか。文をどう終えるか。記号をどう使うか。

<strong>構成。</strong> どう入り、どう締めるか。見出しをどの粒度で立てるか。結論を先に
置くか、経緯から入るか。まとめの節を書くか。コードや図と説明を、どの順で
どれだけ置くか。

### 構成のほうが先に効く

代筆を読んで最初に「これは自分ではない」と感じるのは、たいてい語の選択では
なく構成である。

借りた側を放っておくと、構成は必ず一般的な形に寄る。よい点と悪い点を並べ、
最後にまとめを置き、断定を避けて締める。語がすべて合っていても、この形が
違えば別人の記事に読める。逆に構成が合っていれば、語が多少ずれてもその人の
記事に見える。

構成は書きぶりの飾りではない。<strong>先に効く方</strong> である。

## 3 つの動き

| 動き | すること |
| --- | --- |
| 取り出す | 書いたものから書きぶりを取り出し、置いておく |
| 貸す | 取り出したものを、他人が使える指示にする |
| 検める | 書かれたものが、その書きぶりに合っているかを見る |

貸すと検めるが <strong>同じものを見ている</strong> ことが、この道具の保証である。貸す
ときに言うことと、検めるときに見ることが同じ。書かせて、検めて、直して、
また検めるという使い方は、この一致だけに依存している。

kakiburi は文章を書かない。書くのは借りた側である。

## 決定的であること

同じ入力からは同じ結果が出る。

これが無ければ、この道具は LLM に「自分らしいですか」と訊くのと変わらない。
訊けば毎回違う答えが返り、直した結果が良くなったのかどうかも分からない。
<strong>同じ答えが返ることが、この道具が LLM より役に立つ唯一の理由である。</strong>

## 軸の外

作ってはいけないという意味ではない。<strong>この道具ではない</strong> という意味である。

| 外にあるもの | なぜ外か |
| --- | --- |
| 考えかた、判断軸、読者想定 | 書きぶりではない。訊けば済む（次節） |
| 何を書くか（題材、主張、事実） | 記事ごとに人が与えるもの |
| 文章の良し悪しの評価 | 見るのは「その人らしいか」だけ |
| 文法の誤りの指摘、校正 | 別の仕事 |
| 文章を集めてくること | 材料集めであって、取り出す仕事ではない |
| 取り出したものを他人に渡すこと | 「本人の外」のさらに先 |
| 日本語以外 | 取り出すものの多くが日本語に固有 |

## 判断軸は訊く

いちばん紛らわしいのが判断軸である。何を良しとし、何を書かないか。その人
らしい文章に要るものなので、取り出したくなる。

取り出さない。諦めではなく、<strong>訊けば答えが返るから</strong> である。

| 訊いたときに | |
| --- | --- |
| 「すべて」と「全て」のどちらを使いますか | 答えられない |
| 何を書かないと決めていますか | 答えられる |

書きぶりが計測でしか取れないのは、無意識の選択の集積だからである。判断軸は
意識して取っている立場なので、本人が言葉にできる。しかも本人の答えが常に
正しく、推定する必要が無い。

<strong>訊けるものは訊く。訊けないものを測る。</strong> 軸の「本人が選んでいると気付いて
いない選択」という一文が、そのまま境界になっている。

貸すときに判断軸を添えることは禁じない。軸が決めているのは kakiburi が何を
<strong>取り出す</strong> かであって、本人が書いた紙を重ねてはいけないとは言っていない。

## できたと言える条件

条件は 2 つある。単体テストが通ることは条件に入らない。部品が仕様どおりに
動くことしか言っておらず、書きぶりが取り出せているかはそこに現れない。

<strong>1. 分離。</strong> 本人が書いたものと機械が書いたものを検めて、結果が重ならない。
重なるなら、その道具は本人と他人を区別できていない。

<strong>2. 通読。</strong> 取り出したもので 1 本書かせて、本人が読んで自分のものに読める。
点が上がったという理由だけで良くなったと判断しない。前身では、本人が読んで
拒否した文章が満点を取ったことがある。

2 つは別の失敗を捕まえる。分離は「区別できていない」を、通読は「区別は
できるが再現できていない」を捕まえる。片方だけでは足りない。
