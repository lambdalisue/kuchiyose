# 戦術: 評価して、その人の値にする

[戦略](010-strategy.md)の 2 段目。本人が書いたものを指標で評価し、外に出せる
値に変える。

## 場面ごとに分ける

集めた文章は場面ごとに分けて評価する。混ぜたものは、どの場面のものでもない
中間になる。

場面は人が指定する。相手も立ち位置も目的も文章の外にあるので、文章から当てに
いけば外す。

## 基準を置く

値だけでは、それが特徴なのか普通なのかが分からない。比べる相手を置く。

置くのは LLM が既定で書いたものである。代筆で直したいのがそれだからである。
他人の文章や過去の自分でもよい。

基準は同じ場面で、できるだけ同じ題材のものを使う。題材が揃っていないと、題材の
差が本人らしさとして出る（[100](100-metrics.md)）。

## 単位は 1 文書

指標は文書ごとに測る。全部を連結して 1 度に測ると、分布が消えて 1 点になる。

1 文書では指標が意味を持たないほど短いものは、何本かをまとめて 1 単位にする。

## 値は幅で持つ

1 点にしない。同じ人でも文書ごとに揺れるので、平均だけを持つと、その人が現に
書いている書き方まで外れと判定される。

書きぶりは幅である。実際に振れた範囲を持つ。

### 下限は「使った割合」で見る

下端を「最小値を下回る」で判定してはいけない。一度でも使わなかった文書があれば
最小値は 0 になり、それを下回ることはないので、下限の判定が永久に効かなくなる。

代わりに、その指標が現れた文書の割合を持つ。ほぼ毎回使うものが 1 度も出てこ
なければ、それは外れである。

## 入力を揃える

同じ内容でも、書式が違えば値が変わる。集めた文章は 1 つの形に揃えてから測る。

揃える段で消える特徴は測れない。それでよい。入力の形式が混ざっている以上、
消える特徴は、書き手のものか入力形式のものか区別がつかない。

## 作り直せるようにする

指標は入れ替わる（[100](100-metrics.md)）。入れ替わるたびに過去の文章を測り
直せなければ、古い値と新しい値が混ざる。

揃えたあとの文章を残す。値は派生物として扱い、いつでも捨てて作り直せるように
する。

### 3 つに分けて持つ

| | 作り直せるか |
| --- | --- |
| 揃えたあとの本文 | できない。元のファイルは手元に残っていない |
| 人が決めたこと（場面、基準の置き方、除外） | できない |
| 値 | できる。本文と設定から何度でも |

作り直せないものだけを原本として扱う。値は捨ててよいものとして置く。捨てにくい
場所に置くと、測り直しをためらうようになる。

### 何で測ったかを指紋にする

指標の集合と設定から指紋を作り、値と一緒に保存する。次に測るとき指紋が変わって
いれば、保存してある値を捨てて測り直す。

指紋は指標の定義そのものから導く（[100](100-metrics.md)）。一部だけを混ぜると、
混ぜ忘れた側の指標を足しても指紋が変わらず、古い値が黙って使われる。ここは
[名前を 1 度しか書かない](100-metrics.md#名前は-1-度しか書かない)のと同じ種類の
事故で、やはりエラーにならない。
