# 評価して、その人の値と目盛りにする

[戦略](010-strategy.md#言うために何が要るか)が挙げた 2 つ目と 3 つ目——<strong>その人の側の値</strong>
と <strong>値を読む目盛り</strong>——を作る。

<strong>同じ材料から両方が出る。</strong> 目盛りは別に集めてくるものではない。本人の文章と基準を
[指標](100-metrics.md)で測れば、そこから導かれる。

## 材料を揃える

### 場面ごとに分ける

集めた文章は場面ごとに分けて評価する（[決定](010-strategy.md#場面ごとに閉じる)）。混ぜた
ものは、どの場面のものでもない中間になる。

<strong>場面は人が指定する。</strong> 相手も立ち位置も目的も文章の外にあるので、文章から当てにいけば
外す。

### 基準を置く

<strong>値だけでは、それが特徴なのか普通なのかが分からない。</strong> 比べる相手を置く。

置くのは <strong>LLM が既定で書いたもの</strong>である。代筆で直したいのがそれだからであり、集めて
くるのではなく作れるので、素材が手に入らずに止まらない。

<strong>作るのはこの道具の外である。</strong>[文章を作ることは渡されれば済む](000-axis.md#だからしないこと)
——書かせる側を持たない。<strong>受け取るのは、出来上がった文書と、その作り方の記録である</strong>
（[版と推論設定](#版と推論設定まで記録する)）。

基準は同じ場面、できるだけ同じ題材のものを使う。題材が揃っていなければ、題材の差が
その人らしさとして出る（[決定](010-strategy.md#題材を統制する)）。

#### 依頼文に書き方を漏らさない

本文の書き出しをそのまま依頼文に使うと、書き出しの癖が手掛かりとして漏れ、基準値が
<strong>28 ポイント</strong>膨らんだ例がある（[Sawant](../references/authorship-gap-2026.md)。LLM に
同一著者らしさを判定させた割合が 22% から 50% へ動いた、という値である）。

<strong>依頼文は「何について書くか」の中立な要約にする。</strong>

<strong>中立とは、短いことではない。</strong> 要約には<strong>記事が名指しする物</strong>——製品名、コマンド名、
版番号——を入れる（[決定](010-strategy.md#題材を統制する)）。題名だけを渡すと LLM はそれらを
書かず、<strong>基準の側だけラテン文字と記号が薄くなって、その差だけで帯が分離する。</strong>

<strong>ただし名前の表記は写さない。</strong>「Vim script」か「Vim スクリプト」か、版番号を半角か全角か
——そこは[表記](020-document.md#表記は残る優先して採る理由がある)の層であり、写せば漏れる。
<strong>渡すのは何を指すかであって、どう書くかではない。</strong>

#### 版と推論設定まで記録する

<strong>基準は使う LLM ごとに違う。しかも版ごとに違う。</strong> 日本語では、同一系列の版の違いだけ
で <strong>93.6%</strong> 識別できる（[林・相澤](../references/japanese-llm-style.md)）。

モデル名だけでは足りない。記録が無い基準で作った値は、<strong>次に測ったときに比べられない。</strong>

<strong>推論設定のほうは根拠が弱い。</strong> 同じ論文で推論設定の違いによる識別は <strong>73.0%</strong>（2 クラス）
で、論文自身が「相対的に小さかった」としている。<strong>それでも記録する</strong>——安いので、弱い
ほうに賭けない。

<strong>記録は人が渡す。</strong> 作るのが外である以上、版も設定も文書からは分からない——
<strong>入れるときに一緒に受け取る</strong>（[入れ方](../design/200-command.md#add)）。

<strong>作り方の違う基準を混ぜない。</strong> 版が違えば出力が違うので、混ぜれば測っているのが
版の差になる。<strong>1 つのカセットに 1 つの作り方である</strong>——違うなら別のカセットにする。

### 入力を揃える

同じ内容でも書式が違えば値が変わる。<strong>手順は[正規化](030-normalize.md)が決める。</strong>
ここでは評価に固有の判断だけを決める。

#### 定型を落とす

<strong>場面ごとに、誰が書いても同じになる部分がある。</strong> 落とさなければ書き手どうしの類似が
押し上げられ、差が埋もれる。

日本語の短いレビューで実際に効いている。「発送が早かった」「梱包が丁寧」のような定型が
<strong>著者間の言語的類似を上げ、文体の識別力を下げる</strong>と報告されている
（[日本語レビュー](../references/japanese-attribution-recent.md)）。

| 場面 | 落とす候補 |
| --- | --- |
| 技術記事 | 見出しの定型、生成された目次、他人の文章の引用 |
| チャット | 挨拶、相槌、定型の返信 |
| メール | 署名、宛名、結びの定型 |

<strong>何を落とすかは場面ごとに人が決める。</strong> 場面の一部であって、文章から当てにいくもので
はない。決めたことは[作り直せないもの](#3-つに分けて持つ)として保存する。

<strong>落とす単位は[文](020-document.md#文)である。</strong> 指定した文字列を含む文を、丸ごと落とす。

| なぜ文なのか | |
| --- | --- |
| 文字列だけ抜くと | 残りが繋がって<strong>存在しない文</strong>ができる。文の数も文末も狂う |
| node ごと落とすと | 構造の指標が変わる（[落とすのは中身であって node ではない](#落とすのは中身であってnode-ではない)） |

<strong>判定は部分一致である。</strong> 指定した文字列が文のどこかに現れれば、その文を落とす。文が
指定文字列と丸ごと同じである必要は無い——「お世話になっております」は挨拶の一部として
文の頭に付くので、文全体との一致を求めれば 1 つも落ちない。

<strong>照合そのものは 1 文字ずつの完全一致で、字種も字幅も揃えない。</strong> 揃えれば
[表記を潰さない](030-normalize.md#表記を潰さない)に反する——半角で書いた挨拶と全角で
書いた挨拶は、書き手にとって別の選択である。<strong>正規表現も、あいまい一致も使わない。</strong>

<strong>指定は複数書ける。1 つでも当たれば落とす。</strong> 同じ文が 2 つの指定に当たっても、落ちる
のは 1 度である。

<strong>落とすのは[正規化](030-normalize.md)の後、測る前である。</strong> 順序を決めておかないと、
指定文字列が原文の記法に当たるのか正規形に当たるのかが変わる。

<strong>比べる側と検める側で、同じ指定を使う。</strong> 片方だけに掛ければ、落とした分だけ値がずれた
ものを比べることになる（[検め](300-revise.md#同じ測り方で測る)）。

<strong>空になった node は残す。</strong> 中身が全部落ちた項目も 1 項目として数える。落とせば
構造の指標が動く。

<strong>文字列で書けないものは、落とさない。</strong> 生成された目次や他人の引用は「候補」であって、
文字列として指定できなければ対象にならない。<strong>推定で落としにいかない。</strong>

#### 落とすのは中身であって、node ではない

| | 何をするか |
| --- | --- |
| <strong>中身を落とす</strong> | その文字列を[地の文](020-document.md#地の文)から外す。語や記号の指標に効く |
| <strong>node は残す</strong> | 構造の指標は node を数え続ける |

引用で言えば、<strong>落とすのは引用された他人の文章であって、引用という node ではない。</strong>
どれだけ引用を挟むかは書き手の選択である。

コードブロックの中身は[地の文](020-document.md#地の文)の定義で既に外れている。ここで
重ねて落とさない。落とせば全書き手で 0 が並ぶ。

## その人の値を作る

### 単位は 1 文書

指標は文書ごとに測る。<strong>全部を連結して 1 度に測ると、分布が消えて 1 点になる。</strong>

<strong>単位には名前が要る。</strong> 対を作るときも、値を保存するときも、指摘に添えるときも、単位
を指す言葉が要る。

<strong>名前はカセットの中で一意である。</strong> 同じ名前の単位を 2 つ入れることはできない——
入れようとしたら[断る](030-normalize.md#通らないものは断る)。<strong>黙って上書きしない。</strong>

<strong>[役](#相手集合を-1-つ決める)が違っても同じ名前は使えない。</strong> 名前で役を分けると、
本人の `Rust入門` と基準の `Rust入門` が別物として通ってしまう。ところが
[題材を揃える](#題材の統制は対ではなく素材に効かせる)ほど、本人と基準に <strong>同じ題材の
同じ名前</strong>が付きやすい。<strong>いちばん正しく集めた人がいちばん踏む。</strong>

> 単位を指すのは <strong>名前だけ</strong>である。役は単位の属性であって、名前空間ではない。

#### 短い文書は束ねる

1 文書では指標が意味を持たないほど短いものは、何本かをまとめて 1 単位にする。

<strong>束ねるかどうかと、どれを束ねるかは人が決める。</strong> 文章から当てにいかない——長さで
自動的に束ねると、同じコーパスが取り込みの順で違う単位に割れる。

| | |
| --- | --- |
| <strong>束ねた結果は 1 単位</strong> | 名前を 1 つ持つ。上の一意性がそのまま掛かる |
| <strong>文書の境界は node の境界として残す</strong> | 連結して 1 本の地の文にしない。[node を跨がない](020-document.md#地の文は-1-本の文字列ではない)ものが文書を跨いで繋がる |
| <strong>並べる順は決定的に決める</strong> | 順が変われば node の並びが変わる（[束の中の並び](../design/100-cassette.md#短い文書は束ねる)） |
| <strong>取り込み元が違うものは束ねない</strong> | [升目](030-normalize.md#対応表は取り込み元ごとに持つ)が単位ごとに効かなくなる |

<strong>束ねたことは[作り直せないもの](#3-つに分けて持つ)として保存する。</strong> どの文書をどの順で
束ねたかが残っていなければ、同じ単位を作り直せない。

### 値は幅で持つ

<strong>1 点にしない。</strong> 同じ人でも文書ごとに揺れるので、平均だけを持てば、その人が現に書いて
いる書き方まで外れと判定される。

<strong>書きぶりは幅である。</strong> 実際に振れた範囲——<strong>測れた単位での最小値から最大値まで</strong>——を
持つ。

<strong>百分位で刈らない。</strong> 刈れば、その人が現に 1 度書いた書き方が幅の外に出る。<strong>外れた
1 本で幅が広がるのは、この設計では正しい向きである</strong>——広がれば指摘が減り、狭まれば
本人の書き方を外れと呼ぶ。<strong>間違うなら指摘しない側に間違う。</strong>

（幅が偶然狭く出ることは別の問題として[見張る](#狭いだけで信じない)。）

### 外れの大きさは、幅を 1 とした倍数である

<strong>[指摘の順位付け](300-revise.md#指摘は-3-本か-4-本に絞る)がこの値を使う。</strong>

> 外れの大きさ ＝ 幅の端からはみ出した量 ÷ 幅の大きさ

幅が 10 から 20 の指標で、検める文書が 45 なら、はみ出しは 25、幅は 10 なので <strong>2.5</strong> に
なる。<strong>単位の違う指標が同じ尺度で並ぶ。</strong>

<strong>幅が 0 のときは、この式が使えない。</strong> 全部の単位で同じ値だった指標である。<strong>0 を分母に
しない</strong>——単位が n 本なら、大きさを <strong>n</strong> とする（[出現割合の上限](#出てこないことの大きさを幅と同じ単位にする)
を式に入れた値と同じ。上位に来る側である）。
その人が一度も揺れなかった点が動いている以上、弱い信号ではない。

<strong>同じ値のものが並んだら、指標名の昇順で決める。</strong> 技術記事では絵文字も感嘆符も笑いも
幅 0 になりうるので、<strong>決めておかないと上位 3〜4 本が実装ごとに変わる</strong>——[決定性](../design/300-test.md#決定性)
と[作り直し](../design/300-test.md#作り直せることを試験する)が落ちる。

<strong>昇順は符号位置の順である。</strong> 和名の「昇順」は五十音順とも読めるし、ロケールの
照合順とも読める。<strong>どちらも実装と環境に依る</strong>——決定性のために順序を決めているのに、
そこが揺れては意味が無い。

| | |
| --- | --- |
| 採る | Unicode の符号位置の順（`感嘆符` < `笑い` < `絵文字`） |
| 採らない | 五十音順、ロケールの照合順、読みの順 |

<strong>読みを使わないのは、読みを持っていないからでもある。</strong> 指標名に読みを添えれば、
それが[2 か所目の名前](100-metrics.md#名前は-1-度しか書かない)になる。

### 下限は「使った割合」で見る

<strong>0 を取りうる指標では、下端を「最小値を下回る」で判定してはいけない。</strong> 一度でも使わ
なかった文書があれば最小値は 0 になり、それを下回ることはないので、<strong>下限の判定が永久に
効かなくなる。</strong>

<strong>どちらの規則を使うかは、単位で決まる。</strong> 指標ごとに書かない。

| 単位 | 下端の見方 |
| --- | --- |
| 密度・個数・<strong>その現象の出現に対する割合</strong> | <strong>出現割合</strong>で見る（下記） |
| 無次元（変動係数など）・<strong>常に値を持つ割合</strong> | 幅の下端をそのまま使う |

2 行目は 0 が「使わなかった」を意味しない指標である。変動係数は測れるかぎり必ず値を持ち、
段落の中で 1 文だけのものの割合も 0 が正当な値になる。<strong>こちらは普通に幅で見る。</strong>

<strong>1 行目には、現れた文書の割合を持つ。</strong>

> <strong>本人の単位すべてに現れている</strong>指標が、検める文書で 1 度も出てこなければ外れである。

<strong>「たいてい現れる」では足りない。</strong> 出現割合 0.8 で切れば、<strong>残りの 2 割はその人自身で
ある</strong>——出てこない文書をその人が現に書いているのに、それを「あなたらしくない」と言う
ことになる。

実測で数えた。[前に出す指標](300-revise.md#3-種類を合わせて通るを出す)3 本の出現割合は
0.90 / 0.84 / 0.84 で、<strong>どれか 1 本が誤って止める見込みは 36%</strong> になる。カセットから
抜いた本人の記事 8 本のうち、<strong>3 本が実際にこれで止まっていた</strong>——止めた理由は
「あなたらしくない」だが、実際にはその人の 1〜2 割そのものだった。線を「すべて」に
上げたあと、8 本のうち通るものが <strong>2 本から 6 本になった。</strong>

<strong>拾いたいものは拾える。</strong> この規則が置かれた理由は<strong>毎回使う語が丸ごと消えている</strong>ことを
見逃さないためであって、たまに使わない語を数えることではない。

<strong>分母は「その指標を測れた単位」である。</strong> 全単位ではない。

| 単位の状態 | 分母 | 分子 |
| --- | --- | --- |
| 測れて、1 回以上出た | 入る | <strong>入る</strong> |
| 測れて、0 回だった | 入る | 入らない |
| <strong>コーパスの側の理由で測れなかった</strong>（下限未満・分母 0・書けない記法） | <strong>入らない</strong> | 入らない |

<strong>測れなかった単位を分母に入れてはいけない。</strong> 入れると、短い文書の多い書き手ほど
出現割合が下がり、<strong>毎回使っている語が「たまにしか使わない」ことになる。</strong>

<strong>逆に、値が出た単位だけを分母にしてもいけない。</strong> それでは 0 回の単位が消えて出現割合
が必ず 1.0 になり、<strong>この節が置いた下端の判定が全部の指標で発火する。</strong>

<strong>[環境の側の理由](100-metrics.md#測れない理由を分けて返す)——道具が無い、道具が失敗した
——は、分母から外して済ませない。</strong> 外せば、辞書を入れ忘れたまま <strong>まともな出現割合が
出ているように見える。</strong>

> <strong>環境の側の理由が 1 つでもあれば、目盛りを作らない。</strong> 直すのはコーパスではなく環境で
> あり、直せば全部の値が変わる。

<strong>だから理由を単位ごとに分けて保存する</strong>（[保存の形](../design/100-cassette.md#valuesjsonl)）。
測れて 0 回なら値として `0` を持ち、測れなかったなら値を持たず理由を持つ。<strong>値の有無
だけでは分母を復元できない。</strong>

<strong>測れた単位の数も、値と一緒に保存する。</strong> 出現割合を[幅の単位に直す](#出てこないことの大きさを幅と同じ単位にする)
式が単位数を使うので、<strong>持たせなければ[検めが数え直すことになる](#検めに渡すものをここで全部決める)。</strong>

<strong>0.8 は暫定値である</strong>（[指標](100-metrics.md#除外の既定)）。骨格が通ったら導き直す。

#### 出てこないことの大きさを、幅と同じ単位にする

外れの大きさは[指摘の順位付け](300-revise.md#指摘は-3-本か-4-本に絞る)に使うが、
<strong>幅を単位にした外れと、出現割合とは、そのままでは比べられない。</strong> 前者は 2.5 や 4.0 に
なり、後者は 0.8 から 1.0 にしかならない。<strong>混ぜて並べれば、出てこないことは永久に上位に
来ない</strong>——毎回使う語が丸ごと消えているのに、指摘に出ない。

<strong>出現割合 p を、幅の単位に直してから並べる。</strong>

> p / (1 − p)

毎回使う（p = 1.0 に近い）ほど大きくなり、0.8 では 4.0 になる。<strong>幅 4 つ分の外れと同じ
重さで並ぶ。</strong> 恣意的な対応だが、<strong>1 つの尺度に載せることが目的である。</strong>

<strong>p は 1.0 になりうるので、頭を抑える。</strong> 単位が n 本なら p の上限を n /(n + 1) として
から式に入れる。<strong>抑えなければ無限大に飛び</strong>、比べる相手がいなくなる。

これも暫定値であり、実際にどちらを先に言うべきかが分かったら導き直す。

## 目盛りを作る

指標ごとの幅は、その指標が外れたかを言う。だが <strong>全体として通ったか</strong>は言わない。
<strong>どこからが本人でどこからが他人か</strong>の目盛りが要る（[決定](010-strategy.md#天井と床を測る)）。

### 何を目盛りに載せるのか

<strong>載せるのは 1 つの数である。</strong> 文書 2 本を取って、<strong>同じ人が書いたと言えるか</strong>を表す
1 次元の値を出す。これを <strong>照合値</strong> と呼ぶ。

作り方は[尤度比](../references/fusing-lr-2026.md)に倣う。日本語ブログで較正された唯一の
手順だからである。

| | すること |
| --- | --- |
| 1 | [判定に使う系統](#判定に使う系統を選ぶ)ごとに、2 本の距離を出す |
| 2 | 系統ごとに、<strong>同じ人の対と違う人の対</strong>の距離分布に照らし、尤度比に変える |
| 3 | 尤度比を合算して <strong>1 つの照合値</strong>にする |

<strong>2 が要である。</strong> 距離をそのまま足すと、次元数も尺度も違う系統が勝手な重みで混ざる。
尤度比に変えれば、どの系統も「同じ人らしさが何倍か」という同じ単位になる。

<strong>手元で確かめた。</strong> 等重みで平均すると、寄与の薄い系統を入れるほど隙間が狭まる。
較正すると狭まらない（[スパイク](../spike/200-calibration.md#隙間は狭くなった)）。
<strong>「混ぜると効く」は、較正があって初めて成り立つ。</strong>

<strong>合算の重みは測って決める。</strong> 手で置かない（[決定](010-strategy.md#それでも骨格を先に通す)）。

#### 距離は Cosine Delta で取る

<strong>次元ごとに z 得点にしてから、ベクトルを正規化して、コサイン距離を取る。</strong>

英独仏の 3 コーパスで Delta とその 13 の変種を比べた実験で、<strong>Cosine Delta が明確に上回って
いる</strong>（[Burrows's Delta](../references/burrows-delta.md)）。そして効いている要素も名指し
されている。

> Vector normalization is revealed as the key factor behind the success of Cosine Delta.
> It also improves Burrows's Delta and <strong>makes all measures robust wrt. the choice of n<sub>w</sub></strong>

<strong>後半がこの設計にとって重要である。</strong> 我々の[語彙の大きさ](#語彙は先に決めて固定する)は
どれも暫定値（文字 bigram 500、機能語 300、読点 50。文末表現 150 と文節パターン 800 は
[保留中](metrics/文末表現.md#保留)）であり、<strong>正規化を入れなければ、その暫定値がそのまま
結果を左右する</strong>。入れれば、選び方に対して頑健になる。

<strong>選んでいるのは、z 得点のうえで何の距離を取るかである。</strong> コサインは尺度に依らないので、
ベクトル正規化はコサイン距離そのものに含まれる。<strong>比べている相手は、Burrows が使った
マンハッタン距離である。</strong>

#### z 得点の平均と標準偏差も、先に決めて固定する

<strong>[語彙](#語彙は先に決めて固定する)と同じ扱いにする。</strong> どこから取った平均と標準偏差かで
距離が変わり、<strong>検めが取り直せば、違う軸に載ったベクトルどうしを比べることになる。</strong>

| 決めること | 決め方 |
| --- | --- |
| 何から取るか | <strong>語彙と同じ全体</strong>——その書き手・その場面の文書と、基準の出力 |
| いつ取るか | 評価の最初。語彙を決めた直後に 1 度だけ |
| どこに置くか | 語彙と並べて <strong>派生物</strong>として保存する |
| 誰が使うか | [検め](300-revise.md)も <strong>そのまま使う</strong> |

<strong>[指紋](#何で測ったかを指紋にする)に含める。</strong> 取り直せば過去の値と比べられない。

<strong>相手集合を割る前に取るのも語彙と同じである</strong>——割ってから別々に取れば、側ごとに距離の
意味が変わる。<strong>漏れの向きも同じなので、[骨格の検査](010-strategy.md#それでも骨格を先に通す)
ではそのぶん厳しく読む。</strong>

#### 尤度比はロジスティック回帰で当てはめる

<strong>距離 1 つを尤度比 1 つに変える手続きと、尤度比を合算する手続きの、両方に使う。</strong>

<strong>[尤度比](../references/fusing-lr-2026.md)がそうしている。</strong> 論文の §5.2 が
「Logistic regression calibration and fusion」で、合算の式も較正の分け方も書かれている。
<strong>借りたのは目盛りの単位だけではない——手続きごと借りている。</strong>

<strong>利点。</strong> 距離 1 つを尤度比 1 つに変えるのに、<strong>正規分布を仮定しない</strong>で済む。距離の分布が
正規になる保証は無く、外れた 1 本が裾を動かす。

<strong>仮定はある。</strong> 対数尤度比が距離の 1 次式で書けることを仮定している。<strong>仮定が無いのでは
なく、置く場所が違う。</strong> 骨格を通したとき、当てはめの残差を見て確かめる。

<strong>正則化を入れる。</strong> 下限ちょうどの素材では、相手集合 5 本から作れる同一人の対が 10 本しかない。<strong>正則化が無ければ完全に分離してしまい、尤度比が無限大に飛ぶ。</strong>

<strong>合算の重みは負にならない。</strong> 系統ごとの対数尤度比は、すでに「本人に近いほど大きい」
向きに揃っている。<strong>負の重みは「本人に近いほど本人らしくない」という、成り立ちようの
ないことを言う。</strong>

<strong>これは素材の発見ではない。</strong>[人らしさの向き](#寄せる向きはこの較正が決める)は先行研究の
主張なので素材が覆しうるが、こちらは<strong>距離の定義から決まる</strong>——覆りようが無い。当てはめ
の揺れなので、<strong>負に出たら 0 にする</strong>。実測では 5 系統のうち機能語だけが負に出て、
そのぶん照合値の帯の分離が狭くなっていた。

<strong>反転させず 0 にする。</strong> 反転は素材が言っていないことを言うことになる。

<strong>対の数が釣り合っていないので、事前オッズを外す。</strong>[相手集合の割り](#較正に使う-2-つの対集合)から
作れるのは <strong>同一人 10 対、別人 25 対</strong>で、同じ数にならない。<strong>素のロジスティック回帰が
返すのは事後オッズの対数であり、尤度比ではない</strong>——標本の作り方で決まった事前オッズが、
そのまま切片に乗っている。

<strong>手順を 1 つに決める。</strong>「同じ人の側」を 1、「違う人の側」を 0 と置く。

> 1. <strong>入力を次元ごとに標準化する。</strong> 平均を引き、標準偏差で割る
> 2. 標本に重みを付けず、そのままで L2 付きのロジスティック回帰を当てはめる
> 3. <strong>切片から `log(1 の数 / 0 の数)` を引く。</strong> 傾きは触らない
> 4. 引いたあとの切片と、<strong>1 で使った平均と標準偏差</strong>を保存する

##### 標準化しなければ、尺度が答えを決める

<strong>歩幅も罰則も、次元の尺度に依る。</strong> そのまま渡すと、次元の大きさが当てはめの結果を
決めてしまう。

| 次元の値が | 何が起きるか |
| --- | --- |
| <strong>大きい</strong> | 歩幅が安定条件を超えて<strong>収束しない</strong>。歩幅を変えると答えが変わり、<strong>符号まで逆に出る</strong> |
| <strong>小さい</strong> | 罰則がデータの勾配を上回り、<strong>傾きが 0 付近に潰れる</strong> |

<strong>人らしさでは両方が同時に起きる。</strong>[12 次元](#人らしさの境目は同じ材料から出る)は
0.003 から 7.6 まで <strong>3 桁ちがう</strong>値をそのまま渡すからである。実測では、符号の逆転した
1 次元が合算を支配し、<strong>天井と床が同じ 1 点に潰れた</strong>——素材を何に替えても重なるので、
「常に人らしさの側で止まる」ことになる。

<strong>照合値の側は距離なので範囲が揃っているが、そちらにも同じ手順を掛ける。</strong> 掛ける先で
分けると、どちらの手続きだったかを覚えておくことになる。

<strong>広がりが 0 の次元は、標準偏差を 1 として扱う。</strong> 割れないうえ、定数の列は 2 つの側を
分けない。<strong>落とさない</strong>——落とせば次元の数が素材ごとに変わる。

##### 平均と標準偏差は固定して持つ

<strong>[語彙](#語彙は先に決めて固定する)と同じ扱いである。</strong> 検めが取り直せば、違う軸に載った
値に同じ重みを当てることになる。

| 決めること | 決め方 |
| --- | --- |
| 何から取るか | <strong>その回帰に渡した標本そのもの</strong> |
| いつ取るか | 当てはめの直前。1 度だけ |
| どこに置くか | <strong>重みと並べて</strong>派生物として保存する |
| 誰が使うか | [検め](300-revise.md)も <strong>そのまま使う</strong> |

<strong>重みだけを保存してはいけない。</strong> 標準化して当てはめた重みを標準化なしの値に当てると、
<strong>値だけが静かに変わる</strong>。エラーにはならない。

<strong>読み戻すときは、揃っていることまで確かめる。</strong> 欄があるだけでは足りない——
平均と標準偏差が傾きと同じ数だけ無ければ、<strong>足りない次元だけが標準化されずに通る</strong>。
そこも「値だけが静かに変わる」であって、半端に読むくらいなら読まないほうがよい。

| 確かめること | 通らなければ |
| --- | --- |
| 傾き・平均・標準偏差の数が同じ | <strong>組み立てない</strong> |
| どれも有限である | 同上 |
| <strong>標準偏差が正である</strong> | 同上。0 で割れば無限大か NaN になる |
| <strong>傾きの本数が、受け取る値の数と同じ</strong> | 同上 |

<strong>最後の 1 行を落とすと、いちばん静かに壊れる。</strong> 傾きが 0 本の重みは、どんな入力でも
切片だけを返す——<strong>「いつも同じ値」を出す判定器として正常に動く。</strong> 系統ごとの
較正は距離 1 つを受けるので 1 本、合算は系統の数だけ受ける。人らしさも同じで、
次元ごとは 1 本、合算は指標の数だけである。

<strong>系統が 0 本の較正も断る。</strong> 数が揃っていることだけを見ると、空どうしが揃って
いるとして通る——同じ「定数を返す判定器」が、そこだけ残る。

<strong>広がりが 0 の次元は標準偏差を 1 として持つ</strong>ので、保存されたものに 0 が入って
いること自体が壊れている印である。

<strong>2 の値は、その回帰で実際に使った標本から計算する。</strong>[下限ちょうど](#対が何本あれば信じるか)なら
`log(10 / 25)` だが、<strong>書き写さない</strong>——素材が増えれば数が変わる。<strong>人らしさの較正では
標本が対ではなく単位である</strong>ので、そちらも同じく実際の数から計算する。

<strong>クラス重みで釣り合わせる道は採らない。</strong> 正則化を掛けたまま重みを変えると <strong>傾きまで
動く</strong>ので、切片だけを直す上の手順とは別の答えになりうる。<strong>2 つを「どちらでもよい」と
書けない。</strong>

<strong>これは近似である。</strong> 傾きを L2 で縮めている以上、切片を直しても厳密な対数尤度比には
ならない。<strong>[対数尤度比が距離の 1 次式で書けるという仮定](#尤度比はロジスティック回帰で当てはめる)と
同じ場所に置く</strong>——仮定が無いのではなく、置く場所が違う。骨格を通したとき、残差で
確かめる。

<strong>当てはめ方も決めておく。</strong> ここが実装ごとに違うと、同じ素材から違う目盛りが出る。

| 決めること | |
| --- | --- |
| 目的関数 | <strong>標本ごとの負の対数尤度の平均</strong> + `λ` × 傾きの二乗和。<strong>これを最小化する</strong> |
| 正則化 | <strong>L2。`λ` を[指紋](#何で測ったかを指紋にする)に出す</strong> |
| 切片 | <strong>正則化しない</strong>。事前オッズを外す先がここなので、縮めると外し損なう |
| 最適化 | 解法・収束の判定条件・反復の上限。<strong>すべて指紋に出す</strong> |
| 収束しなかったら | <strong>目盛りを作らない</strong> |

<strong>和ではなく平均にするのは、`λ` の意味を標本数から切り離すためである。</strong> 和にすると、
素材が増えるだけで正則化が相対的に弱くなり、<strong>同じ `λ` が同じ強さを指さなくなる。</strong>

<strong>暫定の値を置く</strong>（[指標](100-metrics.md#除外の既定)）。置かなければ実装ごとに違う
目盛りが出る。

| | 暫定値 |
| --- | --- |
| `λ` | <strong>0.1</strong> |
| 解法 | <strong>勾配降下。学習率 0.5</strong> |
| 反復の上限 | <strong>4,000</strong> |
| 収束の判定 | 反復の上限まで回す。<strong>途中で打ち切らない</strong> |

<strong>骨格が通ったら導き直す</strong>——どれも出どころの無い値である。<strong>暫定のあいだも指紋に出す。</strong>

<strong>当てはまり具合は、見るが止めない。</strong> 残差を報告し、[暫定の印](../design/100-cassette.md#manifestjson)を
立てる。<strong>合否の線をここで手で置かない</strong>——
[骨格が通るまで判定の閾値を手で決めない](010-strategy.md#それでも骨格を先に通す)。
<strong>線を置けば、当てはまらなかったという事実が定数に隠れる。</strong>

<strong>作らないほうへ倒す。</strong> 収束しなかった重みでも値は出る。出た値は目盛りの顔をして、
[判定できない](010-strategy.md#届かないときは判定できないと言う)を返す経路を素通りする。

<strong>強さと収束の条件は暫定値である</strong>（[指標](100-metrics.md#除外の既定)）。骨格が通ったら
導き直す。<strong>暫定のあいだも指紋に出す</strong>——値が変われば過去の目盛りと比べられない。

<strong>人らしさ値も同じ手続きで作る</strong>（[境目](#人らしさの境目は同じ材料から出る)）。あちらは指標ごとにまとめてから 5 つを合算する。

#### 系統が 1 つでも欠けたら、照合値を出さない

系統にも[除外](100-metrics.md#除外の既定)がある。読点が 10 個に満たない文書では読点の
打ち方が測れない。

<strong>欠けた分を抜いて合算しない。</strong> 重みは 5 系統そろっている前提で較正されている。1 つ
抜けば残りの重みの意味が変わり、<strong>同じ目盛りに載らない値</strong>が出る。しかも欠けた系統ほど
その文書で特徴的だった可能性がある。

<strong>照合値を出さず、[検め](300-revise.md#3-種類を合わせて通るを出す)が判定できないを返す。</strong>
どの系統が欠けたかを添える。<strong>人らしさ値も同じ</strong>である。

#### 標準化の物差しは基準から取る

<strong>次元をどこから選ぶかと、平均と標準偏差をどこから取るかは、別の問題である。</strong>
次元は全体から選ぶ（下記）。<strong>だが平均と標準偏差を全体から取ってはいけない。</strong>

> <strong>z 得点の平均と標準偏差は、基準の単位だけから取る。</strong>

<strong>本人の単位が過半を占めるなら、平均は本人のところに来る。</strong> すると本人の記事は
どれも原点の近くに置かれ、<strong>z 得点に残るのは 1 本ごとの雑音だけ</strong>になる。
雑音どうしの向きは揃わないので、<strong>同じ人が書いた 2 本がほぼ直交する。</strong>

実測で確かめた。本人どうしの距離（コサイン）はこうだった。

| 系統 | 全体で標準化 | <strong>基準で標準化</strong> |
| --- | --- | --- |
| 機能語 | <strong>0.997</strong>（コサイン 0.003） | <strong>0.604</strong> |
| 品詞 bigram | 0.931 | <strong>0.303</strong> |
| 読点の打ち方 | 0.852 | <strong>0.495</strong> |
| 文字 bigram | 0.742 | <strong>0.438</strong> |
| 文字種 | 0.605 | <strong>0.176</strong> |

<strong>0.997 は「比べていない」ということである。</strong> 天井に張り付いているので、どう書き
換えても動く余地が無い。<strong>次元を 300 から 20 まで削っても 0.90 までしか下がらなかった</strong>
——次元の数の問題ではなく、物差しの置き場所の問題だった。

<strong>合算の重みも、これで均された。</strong> 機能語の重みは 0.106 から 0.453 になり、
5 系統が 0.448〜0.637 に収まった。

##### 歩幅には下限を敷く

<strong>まれな次元は歩幅が 0 に近い。</strong> そのまま割れば z 得点が爆発し、
<strong>1 つの次元がベクトル全体を支配する。</strong>

> その系統の平均の歩幅の <strong>1 割</strong>を下限とする。<strong>暫定値である。</strong>

実測で、文字種の「半角数字」が 246 まで飛び、<strong>いちばん外れている次元がどの文書でも
それになっていた</strong>。下限を敷くと 63.8 に収まった。

<strong>歩幅 0 の次元は 0 のまま残す。</strong> 全部の文書で同じ値なら、そこに情報は無い。

#### 語彙は先に決めて、固定する

<strong>次元を頻度で選ぶ系統がある</strong>——文字 bigram、機能語、文末表現、読点の打ち方、
文節パターン。<strong>文末表現と文節パターンは[保留中](metrics/文末表現.md#保留)である。</strong><strong>規則はこれらすべてに掛かる</strong>（次元が固定の系統——文字種、品詞 bigram、
語の文体値——には掛からない）。<strong>その N 個が何かを、先に決めて固定しなければ、値が比べられない。</strong>

| 決めること | 決め方 |
| --- | --- |
| 何から選ぶか | <strong>その書き手・その場面の文書と、基準の出力を合わせた全体</strong> |
| <strong>「全体」とは</strong> | <strong>カセットに入っている、測れた単位のすべて</strong>。[相手集合](#相手集合を-1-つ決める)に選ばれた分だけではない |
| いつ決めるか | 評価の最初。1 度だけ |
| どこに置くか | 目盛りと同じく <strong>派生物</strong>として保存する |
| 誰が使うか | [検め](300-revise.md)も <strong>そのまま使う</strong>。新しい文書から選び直さない |

<strong>検めが選び直せば、比べたものに意味が無い。</strong> 違う軸のベクトルどうしの距離になる。

<strong>語彙の選択は、割る前に行う。</strong>[相手集合と測る分](#相手集合を-1-つ決める)に分ける前に、
全体から 1 度だけ選ぶ。

> [!NOTE]
> <strong>これは漏れである。</strong> 較正に使わないはずの単位も、語彙を選ぶときには見ている。
> <strong>それでも先に置く</strong>——側ごとに違う語彙を使えば、側ごとに次元の意味が変わり、
> 照合値が同じ尺度に載らなくなる。<strong>漏れの向きは分離を甘く見せる側なので、
> [骨格の検査](010-strategy.md#それでも骨格を先に通す)ではそのぶん厳しく読む。</strong>

<strong>語彙は[指紋](#何で測ったかを指紋にする)に含める。</strong> 選び直せば過去の値と比べられない。

#### 選び方と並べ方を閉じる

<strong>「頻度上位 N」だけでは、実装ごとに違うものが出る。</strong> 3 つを決める。

| | 決め |
| --- | --- |
| 同順位が N 番目に跨るとき | <strong>識別子の昇順</strong>で先に来たものを採る。何番目までかは動かさない |
| 次元の並び | <strong>頻度の降順、同順位は識別子の昇順。</strong> 決めた順を保存し、以後それを使う |
| 相対頻度の分母 | <strong>選ぶ前の全体。</strong> 上位 N の中で割り直さない |

<strong>3 つ目が値を変える。</strong> 上位 N の中で割り直すと、N をいくつにするかが値そのものを
動かす。<strong>割り直さなければ、N は「どこまで見るか」だけの話になる。</strong>

<strong>1 つ目と 2 つ目は値を変えないが、バイトを変える。</strong> 決めておかないと、
[作り直しても同じものが出る](../design/300-test.md#作り直せることを試験する)が成り立たない。

#### 較正に使う 2 つの対集合

<strong>外から持ってこない。手元の材料でそろう。</strong>

| | 何の対か |
| --- | --- |
| 同じ人の側 | 本人の文書どうし |
| 違う人の側 | 本人の文書と、基準（LLM の既定出力） |

<strong>「違う人」の側が人でないことは、この設計の弱いところである。</strong> 較正しているのは厳密に
は「本人か、LLM か」であって「本人か、他人か」ではない。他人の文章が手に入るなら、そち
らで較正し直す（[床をもう 1 つ](#他人が手に入るなら床をもう-1-つ置く)）。

<strong>較正に使った対から、天井と床を作らない。</strong> 較正は 2 つの対集合を分離するように重みを
決める手続きである。同じ対で目盛りを作れば、<strong>分離するように合わせたものの分離具合を
測る</strong>ことになり、[いちばん危ない検査](010-strategy.md#それでも骨格を先に通す)がそこで
無効になる。

<strong>交差検証ではなく、固定の 2 分割にする。</strong> 交差検証は束ごとに違う重みを作るので、
<strong>新しい文書をどの重みで採点するかが決まらない</strong>。1 組しか作らない形にする。

#### 相手集合を 1 つ決める

<strong>本人の単位を 2 つに割る。</strong>[単位](#単位は-1-文書)の名前の昇順で先頭から取る。<strong>ファイルの
名前ではない</strong>——束ねた単位では両者が食い違い、割り方が変わってしまう。

<strong>取れるのは、判定に使うものをすべて測れた単位だけである。基準の側も同じ条件で選ぶ。</strong>

| 測れていなければならないもの | |
| --- | --- |
| [判定に使う 5 系統](#判定に使う系統を選ぶ) | 照合値がそこから出る |
| <strong>人らしさの 5 指標</strong> | [人らしさ値](#人らしさの境目は同じ材料から出る)がそこから出る |

<strong>後者を忘れると、人らしさ側だけが痩せる。</strong> 人らしさの除外は系統より厳しい——延べ
1,000 語、圧縮率は 2,000 バイト——ので、<strong>5 系統は測れるのに人らしさは測れない単位が
普通に出る。</strong> それを相手集合に入れると、人らしさの較正と帯だけが 5 を割る。

<strong>照合値の側も同じ理由で揃える。</strong>[除外](100-metrics.md#除外の既定)に掛かった単位を入れ
れば、それを含む対から照合値が出ず、<strong>相手の本数が黙って 5 を割る</strong>——天井・床・検めが
同じ散らばりに載らなくなる。

<strong>5 本そろわなければ目盛りを作らない。</strong>[下限](#対が何本あれば信じるか)は、<strong>この条件を
満たした単位</strong>で数える。

| | 何本 | 何に使うか |
| --- | --- | --- |
| <strong>相手集合</strong> | <strong>5</strong> | <strong>あらゆる照合の相手</strong>。天井も床も検めも、必ずこれと対にする |
| 測る分 | <strong>5</strong> | 天井の点になる |

<strong>基準の単位も同じく割る。</strong> 較正分 5、床の点 5。

<strong>どちらも 5 ちょうど取る。</strong> 残った単位は[値と幅](#値は幅で持つ)には使うが、帯には使わ
ない。<strong>本数を揃えないと端が揃わない</strong>——端は最小値と最大値なので、点が多いほうが外へ
広がる。<strong>素材を足すほど帯が広がって判定が鈍る</strong>という、逆向きの挙動になる。

<strong>選ぶのは、どちらも[条件を満たした単位](#相手集合を-1-つ決める)から単位名の昇順である。</strong>

<strong>これがこの設計の要である。</strong> 相手集合が 1 つに定まるので、
[天井・床・検める対象が、まったく同じ形の値になる](#目盛りに載るのは1-本-対-その人である)。

#### 較正と、天井・床

| | 何の対か |
| --- | --- |
| <strong>較正・同じ人の側</strong> | 相手集合の <strong>中の</strong>対 |
| <strong>較正・違う人の側</strong> | 基準の較正分 × 相手集合 |
| <strong>天井</strong> | 測る分の本人の単位 1 本 × 相手集合 の中央値。1 本につき 1 点 |
| <strong>床</strong> | 床の点に取った基準 1 本 × 相手集合 の中央値。1 本につき 1 点 |

<strong>較正に使った対から天井と床を作らない。</strong> 較正は相手集合の中だけで閉じ、天井と床は
<strong>相手集合の外の単位</strong>から出る。同じ対で目盛りを作れば、<strong>分離するように合わせたものの
分離具合を測る</strong>ことになり、
[いちばん危ない検査](010-strategy.md#それでも骨格を先に通す)がそこで無効になる。

<strong>基準も割らないと、床だけが汚れる。</strong> 較正の「違う人の側」は基準 × 相手集合なので、
割らなければ較正に使ったその対で床を測ることになる。<strong>汚れるのが床だけなので、床が
押し下げられて帯が狭まり、分離が実際より良く見える。</strong>

<strong>単位は共有する。対は共有しない。</strong> 相手集合は較正にも天井にも現れるが、<strong>同じ対は
2 度使わない</strong>。[語彙](#語彙は先に決めて固定する)と同じ種類の漏れが残るので、
骨格の検査ではそのぶん厳しく読む。

<strong>重みは 1 組だけできる。</strong> 検めはそれをそのまま使う。

### 目盛りに載るのは「1 本 対 その人」である

<strong>照合値は 2 本の対で決まるが、[検め](300-revise.md)が受け取るのは 1 本である。</strong> 対にする
相手が要り、複数の対を 1 つの数にまとめる必要がある。

> <strong>1 本を、[相手集合](#相手集合を-1-つ決める)のそれぞれと対にして、照合値の中央値を取る。</strong>

<strong>中央値にするのは、外れた 1 本に動かされないためである。</strong> 平均だと、たまたま似ていない
1 本が全体を引き下げる。

<strong>そして天井と床も、同じ形で作る。</strong> ここを外すと目盛りが合わない——<strong>対 1 つ 1 つの分布
より、まとめた値の分布のほうが狭い。</strong> 対の分布で帯を引いて、まとめた値を載せれば、
<strong>ほとんどが帯の外に落ちる。</strong>

<strong>作り方は[較正の節](#較正と天井床)が決める。</strong> ここでは形だけを言う——<strong>どれも 1 本につき
1 点</strong>で、相手は必ず <strong>[相手集合](#相手集合を-1-つ決める)の 5 本</strong>である。

| | 何を 1 点とするか |
| --- | --- |
| <strong>天井</strong> | 測る分の本人の単位 1 本 |
| <strong>床</strong> | 基準の残り 1 本 |
| <strong>検める対象</strong> | 検める文書そのもの |

<strong>3 つとも相手が同じ 5 本なので、同じ散らばりの上に載る。</strong> 相手の本数が違えば中央値の
散らばりが違い、<strong>帯に載せた値が読めなくなる。</strong>

<strong>相手集合を 1 つに保つことが、目盛りが合っていることの中身である。</strong>

<strong>題材で対を絞らない。</strong> 絞れば相手の本数が変わり、上の揃えが崩れる。<strong>相手集合の選び方
にも効かせない</strong>——選ぶ規則は単位の名前の昇順だけである（[統制](#題材の統制は対ではなく素材に効かせる)）。

<strong>天井は「本人の揺れ」である。</strong> 同じ人が書いたものどうしでも完全には一致しない。そこ
まで来れば十分だという上限になる。

<strong>床は「何もしていない状態」である。</strong> ここを超えなければ、LLM に素で書かせたのと変わ
らない。

#### 題材の統制は、対ではなく素材に効かせる

<strong>対ごとに題材を揃えることはしない。</strong> 天井も床も検める対象も、相手は同じ
[相手集合](#相手集合を-1-つ決める) 5 本である。<strong>相手が同じである以上、題材の混ざり方も
同じになる。</strong>

<strong>これは固定の相手集合にしたことで消えた問題である。</strong> 総当たりで天井を作っていたときは、
床だけが題材の揃った対でできていて <strong>床が膨らみ天井が縮んだ</strong>。いまは両方とも、同じ
5 本に対する混ざった題材の値になる。<strong>非対称が無いので、対を選び直して直すものが無い。</strong>

<strong>効かせる先は素材の作り方である。</strong>[基準の題材を、本人が実際に書いた題材から取る](../design/200-command.md#基準は外で作る)
——そうすれば、コーパス全体として本人側と基準側の題材の散り方が揃う。

> [!WARNING]
> <strong>題材から完全には逃げられない</strong>（[決定](010-strategy.md#題材を統制する)）。照合値は
> 題材も拾う（[Wegmann](../references/wegmann-2022.md)）。<strong>ここでやっているのは、
> 片側だけに偏らせないことであって、消すことではない。</strong>

### 対が何本あれば信じるか

<strong>下限を置く。</strong> 天井の点は 5 本、床の点も 5 本しか作らないが、その 1 点 1 点は
[相手集合 5 本との対の中央値](#目盛りに載るのは1-本-対-その人である)である。<strong>対の数で
数えると、実際より多くの証拠があるように見える</strong>——同じ 5 本が何度も現れるからである。

<strong>数えるのは単位の本数である。本人・基準とも 10 単位</strong>を下限とする。

| | 内訳 |
| --- | --- |
| 本人 | [相手集合](#相手集合を-1-つ決める) 5 ＋ 天井の点 5 |
| 基準 | 較正分 5 ＋ 床の点 5 |

<strong>どちらの 5 も直接置いた暫定値である</strong>（[指標](100-metrics.md#除外の既定)）。ほかの下限
から引き算で導かない。

<strong>この分け方で、較正には同一人の対が 10 本、違う人の対が 25 本できる。</strong>
[当てはめ](#尤度比はロジスティック回帰で当てはめる)にはこれで足りる——正則化を入れる
前提で。<strong>帯の端は片側 5 点で決まる</strong>ので、そこが薄いことは承知しておく。下回るなら目盛りを作らず、[検め](300-revise.md#当てにならないときは言う)が
判定できないを返す。

<strong>これも暫定値である</strong>（[指標](100-metrics.md#除外の既定)）。何本から帯が安定するかは
測って決める。

### 帯は、2 つの分布の重なりである

<strong>帯の端も測って決める。</strong> 天井の分布と床の分布が重なる区間が、そのまま
<strong>判定できない帯</strong>になる（[検め](300-revise.md#全体の判定は-3-値で返す)）。

| 照合値の位置 | 判定 |
| --- | --- |
| 天井の下端 <strong>以上</strong>、かつ床の上端 <strong>より上</strong> | <strong>通る</strong> |
| 床の上端 <strong>以下</strong>、かつ天井の下端 <strong>より下</strong> | <strong>通らない</strong> |
| どちらでもない | <strong>判定できない</strong> |

<strong>両方の端を見るのは、分布が分離しても重なっても同じ規則で読めるようにするためである。</strong>

| 分布の関係 | 判定できない帯 |
| --- | --- |
| 分離している（天井の下端 > 床の上端） | 2 つの端に挟まれた <strong>隙間</strong> |
| 重なっている（天井の下端 < 床の上端） | 重なっている <strong>区間</strong> |

片方の端だけで切ると、分離したときに <strong>通ると通らないが同時に成立する</strong>。

<strong>重なりが大きすぎるなら、そこで止める。</strong> 帯を狭めて判定を出すのではない。分離して
いないという事実が出ているので、[骨格が通っていない](010-strategy.md#それでも骨格を先に通す)。

<strong>大きすぎるの線を引く。ただし重なっている側だけである。</strong>

> 重なっている区間の幅が、<strong>天井の広がりと床の広がりのどちらに対しても 5 割を超えたら</strong>、
> 目盛りを作らない。

<strong>端と広がりを決めておく。</strong> 点が片側 5 つしかないので、決め方で帯が大きく動く。

| | |
| --- | --- |
| 天井の <strong>下端</strong> | その分布の最小値 |
| 天井の <strong>上端</strong> | その分布の最大値 |
| 床の <strong>下端</strong> | その分布の最小値 |
| <strong>床の上端</strong> | その分布の <strong>75 パーセンタイル</strong> |
| 分布の <strong>広がり</strong> | 上端 − 下端 |

<strong>床の上端だけを刈る。</strong> 対称に見えるが、<strong>2 つの端は外したときの代償が違う。</strong>

| 端 | 意味 | 外すとどうなる |
| --- | --- | --- |
| 天井の下端 | ここ以上なら通る | 高すぎても <strong>判定できないに落ちるだけ</strong> |
| <strong>床の上端</strong> | ここ以下なら通らない | 高すぎると <strong>書き手に「あなたの文章は機械だ」と言う</strong> |

<strong>床の上端だけが、間違えたときに書き手を否定する。</strong> だから上の裾を刈って保守側に
倒す——刈った分は判定できないになり、それは
[正しい停止](010-strategy.md#届かないときは判定できないと言う)である。

<strong>実測では、これで「人が書いた文章を通らないと言う」誤りが 10 本から 1 本になった。</strong>
通るの数は変わらず、機械の検出だけが 9/9 から 7/9 に落ちる。<strong>この交換を選ぶ。</strong>

<strong>天井は刈らない。</strong> こちらは刈れば「実際に出た値が帯の外に出る」が
[幅](#値は幅で持つ)と同じ理由で効いてくるうえ、外しても判定できないに落ちるだけである。

<strong>75 パーセンタイルは暫定値である。</strong> 向きは代償の非対称から決まるが、どこで刈るかは
1 人分の実測で選んだ——[骨格が通るまで閾値を手で決めない](010-strategy.md#それでも骨格を先に通す)
の但し書きが付いたままである。

<strong>広がりが 0 なら目盛りを作らない。</strong> 5 点が同じ値だと端が決まらず、重なっているのかも
読めない。<strong>これは照合値の帯にも人らしさの帯にも掛かる</strong>——下の 5 割の線とは別である。

<strong>分離しているときは止めない。</strong> 分離は目指している結果であり、隙間が広いほど良い。
<strong>「帯が広いから止める」を隙間にも当てると、いちばん良い結果を拒否することになる。</strong>

<strong>5 割は暫定値である</strong>（[指標](100-metrics.md#除外の既定)）。

> [!NOTE]
> <strong>この線は照合値にだけ引く。</strong> 人らしさの帯が全体を覆うのは
> [設計どおりの結果](100-metrics.md#なぜ人らしさは層-2-を判定から外す原則にかからないのか)
> であり、そのまま書き出して 1 段目が判定できないを返す。

[財津・金](../references/zaitsu-2018.md)が絶対値 4 以下を逃がして判定不能率 14〜19% に
したのと同じ形だが、<strong>端の値は借りない。</strong> あちらは 16 分析の得点合算という別の量である。

### 判定に使う系統を選ぶ

[3〜7 系統でほぼ横ばい](010-strategy.md#種類の違うものを混ぜるただし-5-系統前後まで)になる。
<strong>集合の全部を突き合わせない。</strong> 上限は 5 に置く（我々の判断である）。

<strong>判別力で選ばない</strong>（[決定](010-strategy.md#指標を発明しない)）。基準は
<strong>違うものを見ていること</strong>である。規則はこう置く。

> <strong>[分類](100-metrics.md#定義に落とす)をまたいで取る。同じ分類から 2 つ以上取るときは、
> 独立の系統として立つ根拠を書く。</strong>

<strong>「1 分類から 1 つずつ」ではない。</strong> 較正済みの最良は文字 bigram・読点 bigram・文字種・
単語埋め込み・文字埋め込みで、<strong>記号から 2 つ、埋め込みから 2 つ取っており、語と品詞は
入っていない</strong>（[尤度比](../references/fusing-lr-2026.md)）。

<strong>根拠はこう置く。読点の直後に何が来るかは、文字 bigram とは独立の系統として立つ</strong>
——最良の組み合わせに両方が入っている、という事実からの我々の判断である。<strong>論文が
そう述べているのではない</strong>（[尤度比](../references/fusing-lr-2026.md)は組み合わせの結果を
報告しているだけである）。

<strong>根拠が書けないなら、同じ分類から 2 つ取らない。</strong>

<strong>層 2 と層 3 は判定の系統に選ばない</strong>（[指標](100-metrics.md#層-2別の目的の研究から取るもの)）。
確かめられていないものを目盛りの土台にしない。

<strong>埋め込みは当面入らない</strong>（[指標](100-metrics.md#埋め込みは保留する)）。残る層 1 の
5 つで規則は満たせる——文字 bigram（記号）、読点の打ち方（記号）、機能語（語）、
品詞 bigram（品詞）、文字種（表記）で <strong>4 分類にまたがる 5 系統</strong>になり、重なる記号の
2 つには[独立の根拠がある](#判定に使う系統を選ぶ)。

> [!WARNING]
> <strong>文字種がいちばん怪しい。</strong> 較正した論文で単独 0.84082 の <strong>最下位</strong>であり、最良の
> 組み合わせに入っているとはいえ寄与は Cllr で <strong>0.00061</strong>、<strong>EER はむしろ悪化する</strong>
> （[尤度比](../references/fusing-lr-2026.md)）。
>
> <strong>手元で測っても、重みが決まらない</strong>——相手集合の選び方で <strong>300 倍</strong>振れた
> （[スパイク](../spike/200-calibration.md#文字種について結論が変わった)。文字 bigram は
> 2.3 倍）。<strong>抜いても分離するので、素材が増えるまで決めない。</strong>

### 人らしさの境目は、同じ材料から出る

[人らしさ](100-metrics.md#指標には-4-種類ある)は本人の幅とは比べない。<strong>人が書いたものと
機械が書いたものの境目</strong>と比べる。

<strong>境目も手元の材料で作れる。</strong>

| 側 | 何を使うか |
| --- | --- |
| 人 | 本人の文書 |
| 機械 | 基準（LLM の既定出力） |

<strong>作り方は照合値と同じである。</strong> 5 つの指標は合わせて <strong>12 次元</strong>あり、そのまま「どちら
側か」は決まらない。<strong>1 つの数にしてから比べる。</strong>

| | すること |
| --- | --- |
| 1 | 5 つの指標を測る（12 次元） |
| 2 | <strong>次元ごとに</strong>、人の側の分布と機械の側の分布に照らし、尤度比に変える |
| 3 | <strong>指標ごとに</strong>、その指標の次元の <strong>対数尤度比を平均する</strong> |
| 4 | 5 つを合算して <strong>1 つの人らしさ値</strong>にする |

<strong>次元ごとに変えるのは、照合値との違いである。</strong> 照合値は系統ごとに 1 つの距離を先に作る
が、人らしさは距離を取る相手がいない——比べるのは 2 本の文書ではなく、2 つの集団だから
である。<strong>だから次元がそのまま尤度比の単位になる。</strong>

<strong>3 段目で平均するのは、当てはめる重みを指標の数に抑えるためである。</strong> 較正に使える
単位は少ない。<strong>12 の重みを十数点から当てはめれば、どうとでも決まってしまう</strong>——
繰り返しだけで 8 次元あり、そこが重みを持ち去る。

<strong>対数で平均する。</strong> 尤度比そのままで平均すると、いちばん大きい 1 次元が全体を決めて
しまい、繰り返しの 8 次元を抑えるという目的が消える。合算も[対数の上で当てはめる](#尤度比はロジスティック回帰で当てはめる)
ので、単位が揃う。

<strong>平均は当てはめではないので、標本を要らない。</strong> 次元の重み付けを諦める代わりに、
合算の重みが素材の量に見合う。

<strong>5 つを独立した 5 つの証拠として数えない。</strong> 同じ現象を別の角度から見ているので、合算の
重みは較正が偏らせるはずである。<strong>5 つに均等に開いたら、較正を疑う。</strong>

#### 寄せる向きは、この較正が決める

<strong>定義に固定しない。</strong> 指標の定義は先行研究に基づいて「どちらが機械の側か」を名乗るが、
<strong>それが成り立つかは基準の作り方による</strong>——同じ型で書かせた生成文は、人より語彙が
散らず、短い言い回しを人より多く繰り返すことがある。

<strong>固定すると、直し方に従うほど人らしさが下がる。</strong> 道具が自分の指示で自分の判定を
悪くする。だから[直し方](300-revise.md#人らしさの直し方は書き直しに戻ることがある)の
向きは、次元ごとの傾きの符号から読む。

<strong>判定には素材が言ったことをそのまま使う。</strong> 定義と逆に出た次元を落とすと、判定が
弱くなるだけである——拘束するのは指示の側だけにする。

<strong>次元の向きが割れている指標には、直し方を渡さない。</strong> どちらへ動かせばよいかを
言えないものを指示にしない。<strong>傾きがほぼ 0 の次元は割れに数えない</strong>——どちらへ
動かしても値が変わらない次元に、指標全体の可否を委ねない。

<strong>較正と帯を、単位で分ける。</strong> 対ではなく単位で割るところが照合値と違う——人らしさは
1 本ごとに出る値で、対を作らないからである。

| | どの単位から |
| --- | --- |
| <strong>較正</strong>（4 つの重みを当てはめる） | <strong>帯に使う分を除いた、測れた単位すべて</strong> |
| <strong>帯</strong>（人の側と機械の側の分布） | 測る分の本人の単位と、基準の残り |

<strong>較正には帯と同じ縛りを掛けない。</strong> 帯の点を各側 5 本に固定したのは
[端が最小値と最大値だから](#帯は2-つの分布の重なりである)で、素材を足すほど外へ
広がる。<strong>回帰は漂わない</strong>ので、同じ理由で縛る必要が無い。

<strong>10 単位で 4 つの重みを当てはめると、標本外で当たらない。</strong> 実測では、較正を
帯以外の全単位へ広げただけで、標本外の並べ替え性能（AUC）が <strong>0.815 から 0.907</strong>
へ上がった。

<strong>帯の点は除く。</strong> 較正に使った単位で帯を作れば、分離するように合わせたものの
分離具合を見ることになる（[較正と天井・床](#較正と天井床)と同じ理由）。

<strong>`other/` を足すなら較正の側に足す。</strong> 帯の側に足すと、帯の点の数が本人と基準で釣り
合わなくなる。

<strong>帯の読み方は照合値と同じ</strong>（[規則](#帯は2-つの分布の重なりである)）。<strong>天井にあたるのが
人の側、床にあたるのが機械の側</strong>である。

<strong>ここに「本人」は要らない。</strong> 誰の文章でも人が書いたものは人の側に落ちるので、素材が
足りなければ他の人の文章を混ぜてよい。[場面ごとに閉じる](010-strategy.md#場面ごとに閉じる)
も、人か機械かを分ける用途では緩めてよい——場面は人と機械の別を跨がない。

### 他人が手に入るなら、床をもう 1 つ置く

LLM に対する床は「良くなったか」を言う。<strong>「本人のものとして通るか」は言わない。</strong>

他人の文章に対する床があれば、そちらが言える（[財津・金](../references/zaitsu-2018.md)の
無関係テキスト）。手に入るなら足す。

<strong>ただし無くても成立する設計にする。</strong> 複数の書き手のコーパスが集まるかは確かめていない。
確かめていない前提の上に必須の仕組みを建てない。

#### 較正の「違う人の側」にも足す

<strong>基準だけで較正すると、測っているのは「その人らしさ」ではなく「この基準との違い」に
なる。</strong> 基準と本人が共有している癖は、その系統の距離が動かないので<strong>重みが 0 に落ちる。</strong>

実測。ある書き手の記事を丸ごと常体に変えたところ、<strong>照合値は中央 +0.002 しか動かず、
15 本のうち 9 本が「通る」のままだった。</strong> 機能語の重みは 0.106、ほかの系統は
0.507〜0.705 である。<strong>です・ます を見る唯一の系統が消されていた。</strong>

原因は較正の相手である。基準も敬体で書くので、機能語では本人と離れない——距離のばらつき
が 0.098（ほかの系統は 0.17〜0.48）で、当てはめが重みを落とした。

> [!WARNING]
> <strong>この実験そのものに欠陥があった。</strong>「本人は敬体で書く」を確かめずに前提にしていた。
> 実測すると、<strong>本人の段落の敬体率は 46 本中 6 本が 0.9 を下回り、1 本は 0.00 だった</strong>
> ——常体で書いた記事が 13% ある。<strong>常体の文章は、この書き手にとって外れではない。</strong>
> 通したのは正しい振る舞いだった可能性がある（[文体は node の種類ごとに違う](100-metrics.md#文体は-node-の種類ごとに違う)）。

> <strong>他人 × 相手集合を、[違う人の側](#較正に使う-2-つの対集合)に足す。</strong>

<strong>語彙には入れない。</strong> 固定するのは本人と基準からで、他人はその語彙へ投影する
——検めるときの草稿と同じ扱いである。他人の語で次元を決めれば、<strong>他人が何人来たかで
本人の測り方が変わる。</strong>

#### 他人は、人が書いたものでなければならない

<strong>生成して代わりにしてはいけない。</strong> 生成した他人は基準と同じ機械が書いたものなので、
<strong>機能語では本人と離れない</strong>——「本人 対 機械」という軸の性質が変わらない。

実測で確かめた。文体をわざと散らした（常体・短文・体言止め・口語・長文）他人を 5 本
生成して足したところ、こうなった。

| | 他人なし | 生成した他人あり |
| --- | --- | --- |
| 常体に変えた文章の名指し | 0 / 15 | <strong>0 / 20</strong> |
| 機能語の重み | 0.106 | <strong>0.000</strong> |
| 照合値の帯の天井 | 2.806 | <strong>1.200</strong> |
| 本人を「通らない」と言った本数 | 0 | <strong>1</strong> |

<strong>直らないどころか悪くなる。</strong> 散らした文体は文字種に出て、そちらが重みを総取りし
（0.666 → 0.981）、帯が緩んで本人を 1 本落とした。

<strong>だから、他人が無いあいだ照合値は「この基準との違い」である。</strong> それを名乗ったうえで
使う——[届かないときは判定できないと言う](010-strategy.md#届かないときは判定できないと言う)
のと同じで、<strong>できていないことを黙って通さない。</strong>

#### 足したときに何が変わるか

<strong>足せる形を決めておく。</strong> 決めずに置くと、素材だけ入って判定に効かないという
[いちばん質の悪い状態](../design/100-cassette.md#役は-3-つ)になる——使う側は効いていると
思って集め続ける。

<strong>重みは 1 組のままである</strong>（[理由](#較正と天井床)）。2 つ目の回帰を作らない——作れば、
同じ文章に 2 つの照合値が出て、どちらで判定したのかが言えなくなる。

<strong>他人が手に入ったら、違う人の側を他人に差し替えて[較正し直す](#較正に使う-2-つの対集合)。</strong>
LLM との対で較正した重みを残さない。

<strong>そして LLM の床も、新しい重みで作り直す。</strong> 他人で較正した重みが LLM も分けるとは
限らない——<strong>他人のほうが難しいとは言えない</strong>。他人が本人にどれだけ近いか、基準がどれ
だけ散らばるかで、どちらが難しいかは変わる。LLM に特有の差を使っていた傾きが、他人で
較正し直したときに消えることもある。

<strong>だから 2 本の帯を、それぞれ独立に検める。</strong> 広がりが 0 でないか、重なりが大きすぎない
か（[帯](#帯は2-つの分布の重なりである)）。<strong>どちらか一方でも落ちたら、目盛りを作らない。</strong>

<strong>他人の単位も、較正用と床用に割る。</strong>[相手集合](#相手集合を-1-つ決める)と同じ理由である
——較正に使った対で床を作れば、分離するように合わせたものの分離具合を測ることになる。

| | |
| --- | --- |
| 何本要るか | <strong>基準と同じ下限</strong>。届かなければ、他人の床は作らない |
| 割り方 | <strong>単位の名前の昇順で、前半を較正用、後半を床用</strong> |
| 対の作り方 | <strong>本人 × 他人</strong>。他人どうしの対は作らない——測っているのは本人からの遠さである |
| 帯 | 天井と、<strong>2 つの床それぞれ</strong>で 1 本ずつ作る |

<strong>2 本の帯を上から順に読む。</strong> 決まった時点で止める。

| | 判定 |
| --- | --- |
| 1 | どちらかの床を <strong>超えていない</strong> → <strong>通らない</strong> |
| 2 | どちらかの帯の <strong>中</strong>にいる → <strong>判定できない</strong> |
| 3 | 両方の床を超えた → <strong>通る</strong> |

<strong>床の下を先に見る。</strong> 両方を超えることが「通る」の必要条件である以上、片方で明らかに
床の側にいれば、<strong>もう片方が帯の中でも結論は変わらない</strong>。そこを「判定できない」に
逃がすと、言える場合に言わないことになる——[分からないと言えること](010-strategy.md#届かないときは判定できないと言う)は
<strong>分かるときに言えることを支えるため</strong>にある。

<strong>両方を通ることを求めるのは、2 つが別のことを言っているからである。</strong> LLM の床を超えても
他人の床を超えていない文章は、<strong>素の LLM よりは良いが、まだ誰が書いてもよい文章</strong>で
ある。片方でよいことにすれば、それが「本人のものとして通る」ことになる。

<strong>どちらの床で出した判定かを、値と一緒に返す</strong>（[戦略](010-strategy.md#天井と床を測る)）。
<strong>[検め](300-revise.md#3-種類を合わせて通るを出す)は、この 3 行をそのまま 2 段目——照合値の
段——に使う。</strong>

### コーパスから語を見つける

<strong>形態素解析の辞書は、書き手の名前も、新しい製品名も、その分野の言い回しも知らない。</strong>
知らない語は複数の語に割れる。

<strong>割れたままだと、その語のところで全部が狂う</strong>——機能語の分布も、品詞 bigram も、
[型](#その人の型を取り出す)も、割れた欠片を数えることになる。

<strong>しかも割れ方が揺れる。</strong> 実測で、ある書き手の名前は同じ綴りなのに 3 通りに割られて
いた——名詞＋名詞が 7 回、動詞＋動詞が 1 回、動詞＋固有名詞が 2 回。<strong>同じ語が文脈で
別の品詞になる。</strong>

> <strong>隣り合う 2 形態素が、その出現でおおむね名詞であり、後ろの語がほぼ必ずその前の語の
> 直後にしか現れないなら、1 語である。</strong>

<strong>1 語なら、後ろの欠片は前の欠片の直後にしか現れない。</strong> それが手掛かりである。
<strong>3 回以上・9 割以上・名詞が過半</strong>を線とする。<strong>どれも暫定値である。</strong>

<strong>名詞に絞るのは、絞らないと付属語の連なりが畳まれるからである</strong>——`て+いる`
`と+いう` は正しく割れている。実測で、絞らないと `ている` `という` が語として並んだ。

<strong>多数決にする。</strong> 全部が名詞であることを求めれば、<strong>揺れているからこそ直したい語が
落ちる。</strong>

#### 語は実装が持たない

<strong>道具は書き手も分野も選ばない。</strong> 特定の語を実装や定義ファイルに書けば、その書き手に
しか使えない道具になる。

実測では、ある書き手の素材から <strong>26 語</strong>が見つかった——書き手の名前、
`リファクタリング`、`キーバインド`、`スクリーンショット`。<strong>手で並べた語は 1 つも無い。</strong>

#### 2 度測る

<strong>1 度目で語を見つけ、2 度目でその語を畳んで測る。</strong> 見つけるには解析が要り、
測るには語が要る。

<strong>見つけるのは本人の素材からである。</strong> 基準から見つければ、基準の書きぶりが本人の
測り方を決めることになる。

<strong>カセットが持つ。</strong> 検めるときも同じ辞書で割らなければ、比べたものに意味が無い。

> <strong>語が変われば、延べ語数が変わる。</strong> 窓も下限も動くので、
> [作り直せる形](#作り直せるようにする)で持つ。

### その人の型を取り出す

<strong>分布では言えないものがある。</strong> その人が繰り返し使う語の並び——書き出しの挨拶、
決まった繋ぎ方、結びの型——は、<strong>頻度のベクトルに均されて消える。</strong> 照合値がどれだけ
寄っても、<strong>その人の型が 1 つも出てこない文章</strong>はありうる。

> <strong>本人の単位の 25% 以上に現れ、基準の単位には 5% 以下しか現れない語の並びを、
> その人の型とする。</strong>

<strong>2 つとも要る。</strong> 前者だけなら「ています。」のような誰でも書く並びが並び、後者だけ
なら 1 本にしかない偶然が並ぶ。<strong>25% と 5% は暫定値である。</strong>

<strong>並びの長さは 4〜8 語。</strong> 短すぎれば誰でも書く並びになり、長すぎれば 1 本にしか
出てこない。<strong>長い並びを先に採り、重なっている短い並びは落とす</strong>——`ご無沙汰しており`
と `無沙汰しております` は同じ型の切り出し方が違うだけである。

#### 型は実装が持たない。コーパスから見つける

<strong>道具は書き手を選ばない。</strong> 特定の言い回しを実装や定義ファイルに書けば、その書き手
にしか使えない道具になる。<strong>型は素材から出す。</strong>

<strong>識別子と伏せ字を含む並びは型ではない。</strong> URL・パス・製品名は
[題材であって書きぶりではない](100-metrics.md#題材で判定が覆ってはいけない)。
伏せ字は[識別子を畳んだ跡](100-metrics.md#題材で判定が覆ってはいけない)であって、
書き手が選んだ言い回しではない——渡せば「伏せ字と書け」と言うことになる。

#### 固定部が 2 つあって間が変わる型がある

<strong>連続した並びだけでは拾えないものがある。</strong>

```
どうも、ありすえです。
どうも、いつのまにか Vim プラグイン量産していた、ありすえです。
どうも、最近 Rust と Deno にハマってるありすえです。
どうも、サブタイトル通りご無沙汰しております、有末です。
```

<strong>間に入る一言が毎回違う。</strong> だから 1 つの並びとしては一度も繰り返されていない
——実測で、この書き出しは 11 本の記事にあったのに、連続した並びとしては
<strong>いちばん短い固定部しか残らなかった。</strong>

> <strong>2 つの型が、本人の単位の一定割合以上で同じ node にこの順で現れるなら、
> 繋げて 1 つの穴あきの型とする。</strong>

<strong>繋いだら、部品は落とす。</strong> 3 本に分けて渡せば、受け取った側は 3 か所に挿しこむ
ことになる。

<strong>繋がっている 1 つの言い回しを、穴あきにしない。</strong> 前の終わりと後ろの始まりが重なって
いれば、それは同じ地の文の切り出し方が違うだけである——`ご無沙汰して` と
`しております` のあいだに、入るものは無い。<strong>どちら向きでも見る</strong>。

#### 並べ替えは割合が先である

<strong>長い順に採ってはいけない。</strong> 長い並びから枠を埋めると、<strong>短くて頻度の高い型が
押し出される。</strong>

実測で、11 本の記事に出てくる挨拶の書き出しが、この順番のせいで落ちていた。

#### どこで使うかも持つ

<strong>位置の中央を一緒に残す。</strong> 文書の中の node の番号 ÷ node の総数である。

<strong>そこで使うから型なのであって、どこかに混ぜればよいものではない。</strong> 書き出しにしか
現れない型を「どこかで使え」と渡せば、受け取った側は文中に挿しこむ。

実測では、ある書き手の挨拶の型が位置 0.03 に出た。<strong>[検め](300-revise.md#使われていない型を渡す)は
これを「書き出しで」と言える。</strong>

#### 判定には使わない

<strong>指摘だけである。</strong> 実測で、本人の記事 50 本のうち <strong>5 本が型を 1 つも使っていなかった</strong>
——止める材料にすれば、10% の記事を誤って止める。

### 目盛りも派生物である

天井と床は、指標の集合と基準と素材から導かれる。<strong>保存はするが、原本ではない。</strong> 指標が
入れ替われば作り直す。

## どの指標が効くかを決める

指標の集合は誰にでも当てる。<strong>だが際立つ指標は人によって違う。</strong>

<strong>ここで決まるのは選択であって、採否ではない。</strong> 集合から落ちる指標は無い
（[指標](100-metrics.md#集合は広く持つ絞るのはあとである)）。効かないと判定しても、その
書き手のこの場面で前に出さないというだけである。

効くかどうかは 3 つで見る。

| | 何を見るか | いつ分かるか |
| --- | --- | --- |
| 1 | その人の幅が狭い（一貫している） | ここで |
| 2 | 基準から離れている（その人に固有である） | ここで |
| 3 | <strong>指摘して動く</strong> | <strong>直させてみて初めて</strong> |

<strong>3 つ目は軸からではなく、直す側の事情から来る。</strong> 制御できるスタイルと制御困難なスタイル
があり、その違いはモデルの種類に依存しない（[高橋ら](../references/japanese-llm-style.md)）。
動かない指標を指摘しても、[限られた枠](010-strategy.md#一度に渡すのは-3-本か-4-本)を潰す
だけである。

3 つ目はここでは分からない。<strong>直させて測った結果が返ってくる</strong>
（[検め](300-revise.md#直したら測り直す)）。返るまでは 1 と 2 だけで決め、動くかどうかは
未知として扱う。

<strong>動かないと分かっても、集合からは外さない。</strong> だが <strong>判定でも指摘でも前に出さない</strong>
（[検め](300-revise.md#3-種類を合わせて通るを出す)）。直せない指摘で「通る」を止めれば、
受け取った側は手の打ちようがない。<strong>外れていることは記録に残す</strong>——素材が増えて動くと
分かれば、そこから復活する。

### 狭いかの判定

<strong>比べる先は基準の幅である。</strong> ほかに手元に無い——1 カセットは 1 人ぶんなので、
「みんなの中で狭いか」を言える材料を持たない。

> その人の幅が、<strong>基準の同じ指標の幅の半分以下</strong>なら、狭い。

<strong>基準は「その場面で普通に書いたらどれだけ揺れるか」を表している。</strong> それより明らかに
揺れない点が、その人の一貫している点である。

<strong>半分は暫定値である</strong>（[指標](100-metrics.md#除外の既定)）。

#### 下端を出現割合で見る指標は、出現割合で狭さを見る

<strong>下端の見方と揃える</strong>（[下限は使った割合で見る](#下限は使った割合で見る)）。単位が
密度・個数・その現象の出現に対する割合なら、幅の下端は 0 になりうる——一度でも使わ
なかった単位があれば 0 まで下がる。<strong>そこで素の幅を比べれば、毎回のように使っている
癖ほど幅が広く出て、門前払いになる。</strong> 下端のためにこの規則を置いておきながら効くか
の判定を素の幅で行うのは、規則を半分だけ使っている。

> 出現割合が <strong>0.8 以上</strong>、または <strong>0.2 以下</strong>なら、一貫している。

<strong>どちらの端も一貫である。</strong> 「ほぼ毎回使う」と「ほとんど使わない」は、どちらも揺れて
いない。<strong>0.8 は暫定値である。</strong>

<strong>[下端の判定](#下限は使った割合で見る)より緩い。</strong> 向こうは「すべての単位に現れる」で
切っている。<strong>問いが違うからである</strong>——ここで決めるのは<strong>その指標を前に出すか</strong>であって、
出てこないことを<strong>外れと言うか</strong>ではない。前に出すだけなら、外したときの害は
「言わなくてよいことを言った」で済む。外れと言えば<strong>その文書は通らない。</strong>

<strong>札が読めなければ幅で見る。</strong> 出現割合のほうが通りやすい判定なので、分からないときに
通りやすい側へ倒さない。

<strong>3 つの結び方。</strong> 条件 1 と 2 の両方を満たしたものが「効く」。条件 3 は
[別に持つ](#決まったことは値と一緒に保存する)——満たすことを求めず、<strong>動かないと分かった
ものだけを落とす</strong>。初回は全部が未知なので、1 と 2 だけで決まる。

### 離れているかの判定

素材は少なく、統計的な検定に足りる件数は集まらない。<strong>範囲の交わり方で見る。</strong>

| 形 | 判定 |
| --- | --- |
| 交わらない | 離れている |
| 一方が他方を完全に含む | 離れていない。含む側は「その値も取りうる」としか言っていない |
| 端が重なる | 重なりの幅を、その人の幅と比べる。半分を超えるなら離れていない |
| <strong>その人の幅が 0 で、その 1 点が基準の中にある</strong> | <strong>離れていない</strong>。割る幅が無い |

<strong>幅 0 の 1 点が基準の外なら、交わらないので離れている。</strong> 上の 1 行目がそのまま効く。

#### 出現割合で見る指標は、出現割合の差で離れているかを見る

[狭さ](#下端を出現割合で見る指標は出現割合で狭さを見る)と揃える。範囲の交わり方で見ても、
両方の下端が 0 なら必ず交わってしまう。

> 本人と基準の出現割合の差が <strong>0.4 以上</strong>なら、離れている。

<strong>0.4 は暫定値である。</strong> 一方が 0.8 以上でもう一方が 0.4 以下、という形を最小限で拾える
幅として置いた。

#### 片側でしか測れない指標は、判定しない

<strong>効くかを判定できるのは、両側で測れた指標だけである。</strong> 基準の幅が無ければ
[狭いか](#狭いかの判定)を言えず、基準の範囲が無ければ離れているかも言えない。

<strong>効かないとは判定しない。</strong> 効かないは「比べて、際立たなかった」という判定である。
比べていないものを同じ棚に置くと、<strong>素材が足りないことが「その人には効かない指標だ」
として記録に残る。</strong>

> 判定できなかった指標は、[前に出す指標](300-revise.md#3-種類を合わせて通るを出す)に
> 入れない。<strong>そして、判定できなかったこととして残す。</strong>

### 見る前に標本の範囲を確かめる

<strong>その人側と基準側が、同じ範囲を覆っているかを先に確かめる。</strong> 覆っていなければ、離れて
いても重なっても、どちらの結果も信じられない。

長い文書だけを書いた人と、短い文書ばかりの基準を比べれば、長さと連動する指標はすべて
離れて見える。<strong>それは書きぶりの差ではない。</strong>

<strong>見るのは長さの範囲である</strong>——単位ごとの日本語の文字数。上の例がまさにそれで、
<strong>ほとんどの指標が長さと連動しうる</strong>ので、ここを揃えれば大半の見せかけが消える。

> 本人側の長さの範囲と基準側の長さの範囲が重なる部分が、<strong>どちらの範囲に対しても半分に
> 満たなければ</strong>、その場面の判定を出さない。

<strong>指標ごとではなく、その場面まるごと止める。</strong> 素材の取り方の問題なので、指標を選び直して
直るものではない。

<strong>範囲は最小と最大で測る。だから 1 単位が全体を止めうる。</strong> 実測では、本人の 10 単位のうち
1 本だけが 11,993 字あり、<strong>その 1 本のせいで基準を 6,647 字まで並べることになった</strong>
（[実験](../spike/500-directive-loop.md#基準を-4-本足しても通らない)）。

<strong>それでも粗いままにする。</strong> 分位で測れば外れ値に強くなるが、
<strong>10 単位では分位も信じられない</strong>。同じ理由で「長さと連動しているか」を相関で確かめる道も
採らない——[10 単位の相関は当てにならない](../spike/500-directive-loop.md#長さが原因という仮説は否定された)。

<strong>帯の中の単位だけを残す道も無い。</strong> 残った本数が[下限](#対が何本あれば信じるか)を割れば、
結局止まる。<strong>直し方は素材を足すことだけである。</strong>

<strong>止め方は「目盛りを作らない」である。</strong>[build](../design/200-command.md#build)がそこで終わり、
[検め](300-revise.md#当てにならないときは言う)は判定できないを返す。

<strong>「効く指標を空にする」で代用しない。</strong> 空にすると[3 段判定](300-revise.md#3-種類を合わせて通るを出す)
の 3 段目が素通りし、<strong>判定を出してはいけない場面で「通る」が返る。</strong>

<strong>半分は暫定値である</strong>（[指標](100-metrics.md#除外の既定)）。

数を増やすより先に、範囲を見る。

### 狭いだけで信じない

文書が少なければ、たまたま狭い指標が出る。<strong>30 の指標を 10 本で測れば、いくつかは偶然揃う。</strong>

幅の狭さは、素材が増えても狭いままかで確かめる。確かめられないうちは、効くと断定せずに
素材が足りないことを添える。

### 決まったことは値と一緒に保存する

[検め](300-revise.md)は、効く指標を前に出して指摘にする。効かない指標まで同じ重さで並べ
れば、いちばん言うべきことが埋もれる。

<strong>効かないと判定した指標も、判定ごと残す。</strong> 素材が増えたときに、判定が変わったのか値が
変わったのかを見分けられる。

#### 検めに渡すものを、ここで全部決める

<strong>[検め](300-revise.md)が自分で計算し直してよいものは 1 つも無い。</strong> 検める文書を見てから
幅や集合を作り直せる経路があれば、[目盛りが検める対象で動く](../design/000-architecture.md#分ける基準)。
<strong>だから渡すものを列挙する。ここに無いものを検めが作ってはいけない。</strong>

| 渡すもの | 何に使うか |
| --- | --- |
| 単位ごとの値 | 幅の出どころ。素材が増えたときの作り直し |
| <strong>[測れなかった理由](100-metrics.md#測れない理由を分けて返す)</strong> | 出現割合の分母。判定できないの理由 |
| <strong>指標ごとの幅</strong>（最小・最大） | [外れの大きさ](#外れの大きさは幅を-1-とした倍数である) |
| <strong>出現割合</strong>と、<strong>その分母になった単位の数</strong> | [下端の判定](#下限は使った割合で見る)と、[幅の単位に直す式](#出てこないことの大きさを幅と同じ単位にする) |
| <strong>効くかの判定</strong>（条件 1・2 の結果と、根拠にした値） | 前に出すかどうか |
| <strong>[動いたかの記録](#3-つに分けて持つ)</strong>（条件 3） | 動かないものを落とす |
| <strong>前に出す指標の集合</strong> | <strong>判定と指摘の両方がこれを使う</strong> |
| 固定した語彙 | 距離を同じ軸で取る |
| 固定した z 得点の平均と標準偏差 | 同上 |
| 較正した重みと切片<strong>、標準化の平均と標準偏差</strong> | 照合値・人らしさ値（[標準化](#平均と標準偏差は固定して持つ)） |
| 天井・床・帯 | 3 値の判定 |
| <strong>どの床で作った帯か</strong> | [通ると言えることが違う](#他人が手に入るなら床をもう-1-つ置く) |
| <strong>落とす定型の文字列そのもの</strong> | <strong>検めが同じものを落とせる</strong>（[定型を落とす](#定型を落とす)） |
| 相手集合<strong>の単位名</strong> | 作り直しの再現。<strong>本文もベクトルも渡さない</strong> |
| [指紋](#何で測ったかを指紋にする) | 環境が変わっていないことの確認 |

<strong>前に出す指標の集合を、名前の一覧として保存する。</strong> 条件から毎回導き直させない——
導き直せるなら[検めが導き直す経路が書ける](../design/000-architecture.md#kakiburi-review)。

<strong>欠けているものと、空であることを区別する。</strong> 「効くと判定された指標が 1 つも無い」と
「効くかの判定がまだ行われていない」は別である。<strong>前者は判定を続けてよく、後者は
[判定できない](010-strategy.md#届かないときは判定できないと言う)である。</strong>

<strong>形には版を付ける。</strong> 渡すものが増えれば形が変わる。版が無ければ、古いカセットを新しい
検めが読んだときに <strong>欠けた項目が空として通る</strong>——上の区別がそこで崩れる。

## 作り直せるようにする

集合は増える（[指標](100-metrics.md#集合が変わるとき)）。<strong>増えるたびに過去の文章を測り
直せなければ、古い値と新しい値が混ざる。</strong>

### 3 つに分けて持つ

| | 作り直せるか |
| --- | --- |
| 揃えたあとの本文 | <strong>できない。</strong> 元のファイルは手元に残っていない |
| 人が決めたこと（場面、基準の置き方、落とす定型） | <strong>できない</strong> |
| <strong>直させて分かったこと</strong>（[条件 3](#どの指標が効くかを決める)） | <strong>できない。</strong> 測り直しても再現しない |
| 値と目盛り | できる。本文と設定から何度でも |

<strong>3 行目を派生物に混ぜない。</strong> 指摘して動いたかは <strong>外で起きたこと</strong>であり、コーパスから
導けない。派生物に置けば、[作り直したときに消える](../design/300-test.md#作り直せることを試験する)
——しかも消えたことに気付かないまま、動かない指標が指摘に戻ってくる。

<strong>作り直せないものだけを原本として扱う。</strong> 値は捨ててよいものとして置く。捨てにくい場所
に置けば、測り直しをためらうようになる。

### 何で測ったかを指紋にする

値を作ったときの条件から指紋を作り、値と一緒に保存する。次に測るとき指紋が変わっていれ
ば、保存してある値を捨てて測り直す。

<strong>指紋に入れるもの。</strong>

| | 出どころ |
| --- | --- |
| 指標の定義そのもの | [指標](100-metrics.md#定義に落とす) |
| <strong>数える単位の定義</strong>（地の文に何が入るか、日本語の文字の範囲） | [文書の形](020-document.md#数える単位) |
| <strong>固定した語彙（頻度上位 N の中身）</strong> | [語彙は先に決めて、固定する](#語彙は先に決めて固定する) |
| <strong>形態素解析器の辞書と版</strong> | [機能語](metrics/機能語.md) |
| <strong>圧縮器と設定</strong> | [圧縮率](metrics/圧縮率.md) |
| <strong>固定した z 得点の平均と標準偏差</strong> | [z 得点](#z-得点の平均と標準偏差も先に決めて固定する) |
| <strong>較正の設定</strong>（L2 の強さ、解法、収束の条件、反復の上限、残差の合否の線） | [尤度比](#尤度比はロジスティック回帰で当てはめる) |
| <strong>束の構成と並び</strong>（どの文書をどの単位に、どの順で束ねたか） | [短い文書は束ねる](#短い文書は束ねる) |
| <strong>外部の表の版</strong>（語の文体値の表、Unicode。文末表現の辞書は[保留中](metrics/文末表現.md#保留)） | [指標](100-metrics.md#何を使うか) |
| 埋め込みのモデルと版（[使うと決めたときだけ](100-metrics.md#埋め込みは保留する)） | [指標](100-metrics.md#埋め込みは保留する) |
| 取り込み元の種類、変換の実装と版、適用した対応表 | [正規化](030-normalize.md#変換したことを記録する) |
| 基準の LLM の版と推論設定 | [版と推論設定まで記録する](#版と推論設定まで記録する) |
| 場面、落とす定型、その他 人が決めたこと | [3 つに分けて持つ](#3-つに分けて持つ) |

<strong>一部だけを混ぜない。</strong> 混ぜ忘れた側が変わっても指紋が変わらず、古い値が黙って使われる。
これは[名前を 1 度しか書かない](100-metrics.md#名前は-1-度しか書かない)のと同じ種類の事故
で、やはりエラーにならない。

#### 数えたものを指紋にしない

<strong>「指標が何本あるか」は指紋ではない。</strong> 本数が同じまま数え方・除外・直し方を変えれば、
値の意味が変わったのに指紋は動かない——<strong>古い派生値がそのまま使い回される。</strong>

同じことが版の書き方にも起きる。<strong>`0.8` のような丸めた版を書かない。</strong> `0.8.9` と
`0.8.10` で圧縮の出力が変われば[圧縮率](metrics/圧縮率.md)が変わるのに、指紋は同じである。

| 入れるもの | 入れてはいけないもの |
| --- | --- |
| 定義を正規化した中身の <strong>ハッシュ</strong> | 定義の <strong>本数</strong> |
| 道具の <strong>完全な版</strong>と設定 | 丸めた版、主要版だけ |
| 外部の表の版と <strong>チェックサム</strong> | 表の名前だけ |
| Unicode の版 | 「最新」 |

<strong>ハッシュを取る前に正規化する。</strong> 改行や空白の違いで指紋が動けば、意味の変わっていない
編集で全部の値が捨てられる——<strong>捨てられるのが嫌になって、指紋を見なくなる。</strong>

<strong>ただし変換規則の変更だけは、指紋が変わっても測り直せない</strong>——本文そのものが作り直せ
ないからである（[正規化](030-normalize.md#変換規則を変えると戻れない)）。指紋はそこで
「比べてはいけない」ことを示す印になる。
