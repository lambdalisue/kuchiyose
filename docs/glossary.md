# 用語集

kakiburi の文書に出てくる自前の用語を、使う順に並べる。どれも仕様で決めた意味を
短く言い直したもので、詳しい決め方はリンク先にある。

## 全体の流れ

```
素材のフォルダ ── cassette build ─→ 本人のカセット（統計値）─┐
                                                            ├─ 目盛りを組み立てる
基準のフォルダ ── cassette build ─→ 基準のカセット（統計値）─┘          │
                （既定は同梱）                                         ▼
草稿 ─────────────────────────────────────────────────────── review ─→ 判定 ＋ 指摘
```

フォルダの文書を一度だけ測ってカセットにし、比べるたびに 2 つのカセットから目盛りを
組み立てて、草稿を何度でもそれに当てる。

## 材料

### 素材

本人が実際に書いた文章。1 つのフォルダに入れて渡す。kakiburi は素材の本文を持たず、
作り直すたびにフォルダから読み直す（[評価](spec/200-extract.md#素材を正本にする)）。

### 場面

技術記事、議事録、社内向けの説明文のような、書く状況の区別。同じ人でも場面が
違えば書き方が変わるので、フォルダもカセットも場面ごとに分ける
（[戦略](spec/010-strategy.md#場面ごとに閉じる)）。カセットは場面の名前を名札として持ち、
判定には本人と基準の両方の場面の名前が並ぶ。

### 単位

測るときのひとまとまり。ふつうは 1 文書である。基準の文書は、本人の長い記事に長さを
届かせるために、目盛りを組み立てるときに何本か束ねて 1 単位にすることがある。本人の
文書は束ねない（[評価](spec/200-extract.md#短い文書は束ねる)）。

### 基準

本人と比べる相手の文書。カセットとして渡す。渡さなければ、道具に同梱した基準の
カセットを使う。同梱の基準は、題材を広く取って LLM に素で書かせた文章から作ってある。
道具は基準が機械の文章か人の文章かを区別しない。別の人のカセットを渡せば、その人と
比べることになる（[評価](spec/200-extract.md#基準を置く)）。

### カセット

`cassette build` が 1 つのフォルダから作るファイル（`.kb`）。フォルダの文書を 1 本ずつ
測った統計値、そのフォルダから見つけた[語のまとめ方](#語のまとめ方)、[調整](#調整)、
指紋、場面の名前を持つ。本文も目盛りも入っていない。本人のカセットも基準のカセットも
同じ形である（[設計](design/100-cassette.md)）。

### 語のまとめ方

形態素解析の辞書に無い語（名前、製品名、分野の言い回し）が細かく割れるのを、1 語に
まとめる規則。カセットごとに自分の文書から自動で見つける。草稿は本人のカセットの
まとめ方で測る。人は触らない（[評価](spec/200-extract.md#コーパスから語を見つける)）。

### 調整

カセットに書いておく、人が決めたこと。指摘に出る対象を無効にすることと、一人称や文体を
申告することがある。測った値には触らないので、作り直しは要らない。カセットを渡せば
調整も一緒に渡る。基準として渡したカセットの調整は使わない
（[評価](spec/200-extract.md#素材を正本にする)）。

### 目盛り

草稿を読むための物差し。本人のカセットと基準のカセットから、`review` と `cassette diff` の
たびに組み立てる。保存しない。下の天井・床・帯・幅がその中身である。

### 取り込み元

文書の書式。Markdown と HTML があり、拡張子で決まる。`.md` と `.markdown` は Markdown、
`.html` と `.htm` は HTML で、ほかの拡張子は読まない
（[正規化](spec/030-normalize.md#対応表は取り込み元ごとに持つ)）。

## 測るもの

### 指標

文章から数える量。何を数えるかは先行研究で確かめられたものから選び、1 指標
1 ファイルで[定義](spec/metrics/README.md)してある。形と使い道で次の種類に分かれる
（[指標](spec/100-metrics.md#指標の種類)）。

### 系統

文字 bigram や品詞 bigram のような、たくさんの次元をまとめて見る指標。1 つの数で
なく分布なので、そのままでは「ここを直せ」と言えない。照合値の材料になる。

### 指示できる指標

三点リーダの多さや文末の形のような、1 つの数で表せて、直し方を言葉で言える指標。

### 人らしさの指標

同じ言い回しの繰り返し、語彙の狭さ、句読点の密度のように、誰の文章にも使える次元を
測る指標。その人らしさではなく「基準の書きぶりが残っていないか」を見る。基準との距離の
材料になる。名前は出どころ（人と機械の文章を分ける研究）から来ている。

### 検査

和文の間に空白が入っていないかのような、日本語として壊れていないかを見る指標。
本人とは比べず、固定の線で見る。

### 幅

本人の素材で、その指標が実際に取った最小値から最大値まで。草稿の値がこの中にあれば
「本人もそう書くことがある」とみなす（[評価](spec/200-extract.md#値は幅で持つ)）。

## 判定

### 照合値

草稿が本人の書いたものに見えるかを表す 1 つの数。系統ごとの距離を、同じ人の対と
違う人の対に照らして尤度比に直し、合算する。正なら本人寄り、負なら基準寄り
（[評価](spec/200-extract.md#何を目盛りに載せるのか)）。

### 基準との距離

基準の書きぶりが残っていないかを表す 1 つの数。人らしさの指標から出す。正なら基準から
離れて本人の側、負なら基準に近い側。既定の基準では、機械の癖が残っていないかを見る
ことになるが、機械かどうかを判定しているのではない
（[評価](spec/200-extract.md#人らしさの境目は同じ材料から出る)）。

### 相手集合

照合値を出すときに、草稿と突き合わせる本人の単位の組。草稿も、天井も、床も、同じ
相手集合と比べるので、同じ物差しの上に並ぶ（[評価](spec/200-extract.md#相手集合を-1-つ決める)）。

### 天井

本人の文章どうしの照合値が取る範囲。「ここまで来れば本人の揺れの中」という目安
（[戦略](spec/010-strategy.md#天井と床を測る)）。

### 床

基準の文章の照合値が取る範囲。既定の基準なら「ここを越えなければ何もしていないのと同じ」
という目安。

### 帯

天井と床のあいだで、どちらとも言えない区間。草稿の値がここに入ると「判定できない」
になる。天井と床が重なっていれば、重なっている区間が帯である。離れていれば、隙間の
真ん中のまわりの狭い区間だけが帯で、真ん中より上は通る、下は通らない
（[評価](spec/200-extract.md#帯は2-つの分布の重なりである)）。

### 判定

通る・通らない・判定できない、の 3 つ。点数ではない。検査 → 基準との距離 → 照合値 →
指示できる指標の順に見て、最初に決まったところで止まる
（[検め](spec/300-revise.md#種別を合わせて通るを出す)）。

### 判定できない

素材が足りない、草稿が短すぎる、草稿が帯の中にあって決められない、本人を基準と
見分けられない、といった状態。失敗ではない。言えないことを言わないための答えである
（[戦略](spec/010-strategy.md#届かないときは判定できないと言う)）。

## 指摘

### 指摘

どの指標が、どちらへ、どれだけ本人から外れているかを言葉にしたもの。多すぎると
直す側が混乱するので、判定に効くものを 3〜4 本に絞って出す
（[検め](spec/300-revise.md#指摘は-3-本か-4-本に絞る)）。

### 効く指標

本人の幅が狭く、しかも基準から離れている指標。本人を見分けるのに役立つものだけを
指摘に使う。基準との比べ方で決まるので、目盛りを組み立てるたびに決める
（[評価](spec/200-extract.md#どの指標が効くかを決める)）。

### 外れの大きさ

草稿の値が幅からどれだけはみ出したかを、幅を 1 とした倍数で表したもの。単位の違う
指標を同じ尺度で並べて、指摘の順位を決める（[評価](spec/200-extract.md#外れの大きさは幅を-1-とした倍数である)）。

### 型

本人がよく使い、基準は使わない言い回し。「本人はこう書く」の手本として渡す。判定には
使わない（[評価](spec/200-extract.md#その人の型を取り出す)）。

### 基準の型

型の裏返しで、基準がよく使い、本人はほとんど使わない言い回し。草稿に出ていれば
「言い換える」と知らせる。判定には使わない（[評価](spec/200-extract.md#基準の型を取り出す)）。

### 基準の語

基準がよく使い、本人はほとんど使わない語（形容詞・形状詞・副詞の語彙素）。語形が変わると
型では拾えない癖を拾う。本人が同じ品詞でよく使う語を、置き換える先として添える
（[評価](spec/200-extract.md#基準の語を取り出す)）。

### 本人の癖

本人の幅は狭いが、基準とは離れていない指標。効く指標からは外れるが、草稿がそこから外れれば
知らせる。判定には使わない（[評価](spec/200-extract.md#一貫しているだけの指標は本人の癖として知らせる)）。

### 知らせ

判定には使わないが、書き手が知っておくとよいこと。一人称の違いや書き出しの構造など。
指摘とは見出しで分けて出す（[検め](spec/300-revise.md#判定を止める指摘と止めない知らせを分ける)）。
